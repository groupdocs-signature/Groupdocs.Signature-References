## PdfTextStickerVerifyExtensions class

Предоставляет расширения для проверки объектов стикеров PDF.

Тип PdfTextStickerVerifyExtensions раскрывает следующие члены:

### Конструкторы
| Конструктор | Описание |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.options/pdftextstickerverifyextensions/__init__/) | Инициализирует расширения проверки подписи PDF‑текстового стикера с пустыми значениями. |

### Свойства
| Свойство | Описание |
| :- | :- |
| [contents](/signature/python-net/groupdocs.signature.options/pdftextstickerverifyextensions/contents/) | Содержимое стикера, подлежащее проверке. |
| [icon](/signature/python-net/groupdocs.signature.options/pdftextstickerverifyextensions/icon/) | Иконка стикера для проверки. Значение не будет проверяться, если равно None. |
| [subject](/signature/python-net/groupdocs.signature.options/pdftextstickerverifyextensions/subject/) | Тема стикера для проверки. |
| [title](/signature/python-net/groupdocs.signature.options/pdftextstickerverifyextensions/title/) | Заголовок стикера для проверки. Значение игнорируется при проверке, если это пустая строка или None. |
