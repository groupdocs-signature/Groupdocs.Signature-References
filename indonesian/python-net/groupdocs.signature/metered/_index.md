## Metered class

Mengelola lisensi bermeter (bayar per penggunaan).

Lisensi Metered menagih berdasarkan konsumsi aktual (biasanya halaman atau
dokumen yang diproses). Atur pasangan kunci publik/privat sekali pada
pembukaan aplikasi; pembungkus melaporkan penggunaan kembali ke GroupDocs
server lisensi di latar belakang.

Tipe Metered mengekspos anggota berikut:

### Metode
| Metode | Deskripsi |
| :- | :- |
| [get_consumption_credit](/signature/python-net/groupdocs.signature/metered/get_consumption_credit/) | Kembalikan jumlah kredit yang telah dikonsumsi sejauh ini. |
| [get_consumption_quantity](/signature/python-net/groupdocs.signature/metered/get_consumption_quantity/) | Kembalikan jumlah data yang telah diproses sejauh ini. |
| [set_metered_key](/signature/python-net/groupdocs.signature/metered/set_metered_key/#public_key-private_key) | Aktifkan penagihan metered dengan pasangan kunci publik/privat yang diberikan. |
