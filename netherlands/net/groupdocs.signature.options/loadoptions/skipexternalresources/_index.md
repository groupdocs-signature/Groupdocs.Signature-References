## LoadOptions.SkipExternalResources property

Haalt op of stelt een vlag in die voorkomt dat het document externe bronnen laadt. De standaardwaarde is true: externe bronnen worden niet geladen, behalve diegenen die overeenkomen met [`WhitelistedResources`](../whitelistedresources).

```csharp
public bool SkipExternalResources { get; set; }
```

### Opmerkingen

Een document kan verwijzen naar bronnen die buiten het document zijn opgeslagen: gekoppelde afbeeldingen, afbeeldingen ingevoegd via een INCLUDEPICTURE‑veld, gekoppelde afbeeldingen in presentaties en spreadsheets, en afbeeldingen en stijlbladen waarnaar een SVG‑afbeelding verwijst. Het laden van zo'n bron zorgt ervoor dat de bibliotheek het adres opvraagt. Op een server die onbetrouwbare documenten verwerkt, kan een document dit gebruiken om de server verzoeken naar interne adressen te laten sturen (server‑side request forgery), en een UNC‑ of file://‑pad kan Windows doen om de NTLM‑referenties van het account naar een andere host te sturen. Bij een offline of lucht‑gescheiden installatie falen de verzoeken of wachten ze op een time‑out.

Resources die worden overgeslagen, worden niet weergegeven in paginavoorbeelden of in documenten die als afbeeldingen zijn opgeslagen, en afbeelding-, barcode- en QR-code-zoekopdrachten zien ze niet. Stel deze eigenschap alleen in op false voor vertrouwde documenten, en geef de voorkeur aan het toestaan van specifieke adressen met [`WhitelistedResources`](../whitelistedresources).

De instelling is van toepassing op tekstverwerkingsdocumenten, presentaties, spreadsheets en SVG-afbeeldingen, inclusief documenten in archieven. Voor SVG-afbeeldingen worden de niet-toegestane referenties verwijderd uit de afbeelding voordat deze wordt gelezen, en een SVG-afbeelding die geen goed gevormde XML is, wordt afgewezen. De instelling regelt geen controle op certificaatintrekking, tijdstempelservers of licenties.

Deze eigenschap vervangt LoadExternalResources, die de tegenovergestelde betekenis heeft.
