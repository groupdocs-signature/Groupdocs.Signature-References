## return_content property

서명의 이미지 콘텐츠가 반환되는지 여부를 결정하는 플래그.

True 로 설정하면, 이미지 서명 내용이 [`ImageSearchOptions.return_content_type`](/signature/python-net/groupdocs.signature.options/imagesearchoptions/return_content_type/) 에서 지정된 형식의 원시 이미지 데이터로 유지됩니다. 기본적으로 이 옵션은 비활성화되어 있습니다 (False).
