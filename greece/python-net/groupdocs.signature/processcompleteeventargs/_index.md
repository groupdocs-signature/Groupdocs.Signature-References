## ProcessCompleteEventArgs class

Παρέχει δεδομένα για το πλήρες γεγονός των διαδικασιών υπογραφής, επαλήθευσης και αναζήτησης.

Ο τύπος ProcessCompleteEventArgs εκθέτει τα ακόλουθα μέλη:

### Ιδιότητες
| Ιδιότητα | Περιγραφή |
| :- | :- |
| [canceled](/signature/python-net/groupdocs.signature/processcompleteeventargs/canceled/) | Η διαδικασία ακυρώθηκε. |
| [completed](/signature/python-net/groupdocs.signature/processcompleteeventargs/completed/) | Το χρονικό σημείο ολοκλήρωσης της διαδικασίας. |
| [ticks](/signature/python-net/groupdocs.signature/processcompleteeventargs/ticks/) | Ο χρόνος σε χιλιοστά του δευτερολέπτου που δαπανήθηκε από το γεγονός Έναρξη της διαδικασίας. |
| [total_signatures](/signature/python-net/groupdocs.signature/processcompleteeventargs/total_signatures/) | Η συνολική ποσότητα των επεξεργασμένων υπογραφών. |
| [status](/signature/python-net/groupdocs.signature/processeventargs/status/) | Η τρέχουσα κατάσταση της διαδικασίας. (κληρονομείται από [`ProcessEventArgs`](/signature/python-net/groupdocs.signature/processeventargs/)) |
