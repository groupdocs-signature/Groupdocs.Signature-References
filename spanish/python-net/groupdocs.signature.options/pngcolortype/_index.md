## PngColorType class

El tipo PngColorType expone los siguientes miembros:

### Campos
| Campo | Descripción |
| :- | :- |
| [GRAYSCALE](/signature/python-net/groupdocs.signature.options/pngcolortype/grayscale/) | Representa el tipo de color donde cada píxel es una muestra en escala de grises. |
| [TRUECOLOR](/signature/python-net/groupdocs.signature.options/pngcolortype/truecolor/) | Representa el tipo de color donde cada píxel es una triple R,G,B. |
| [INDEXED_COLOR](/signature/python-net/groupdocs.signature.options/pngcolortype/indexed_color/) | Representa el tipo de color donde cada píxel es un índice de paleta; debe aparecer un bloque PLTE. |
| [GRAYSCALE_WITH_ALPHA](/signature/python-net/groupdocs.signature.options/pngcolortype/grayscale_with_alpha/) | Representa el tipo de color donde cada píxel es una muestra en escala de grises seguida de una muestra alfa. |
| [TRUECOLOR_WITH_ALPHA](/signature/python-net/groupdocs.signature.options/pngcolortype/truecolor_with_alpha/) | Representa el tipo de color donde cada píxel es una triple R,G,B seguida de una muestra alfa. |
