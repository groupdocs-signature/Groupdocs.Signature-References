## include_standard_metadata_signatures property

Flag yang menunjukkan apakah tanda tangan metadata dokumen standar seperti Penulis, Pemilik, tanggal pembuatan, dan tanggal modifikasi termasuk dalam daftar metadata.

Jika disetel ke False (default), GetDocumentInfo tidak akan menyertakan tanda tangan metadata ini. Ketika disetel ke True, informasi dokumen akan menyertakan tanda tangan metadata standar.
