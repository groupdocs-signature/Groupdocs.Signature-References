## SignatureSettings.IncludeStandardMetadataSignatures property

Получает или задает флаг для включения в список метаданных встроенных стандартных подписей метаданных документа, таких как Автор, Владелец, дата создания документа, дата изменения и т.д. Если этот флаг установлен в false (по умолчанию), GetDocumentInfo не будет включать эти подписи метаданных. Когда флаг установлен в true, информация о документе будет включать эти стандартные подписи метаданных.

```csharp
public bool IncludeStandardMetadataSignatures { get; set; }
```
