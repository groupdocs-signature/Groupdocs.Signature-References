## BarcodeSignOptions.ReturnContent property

ドキュメントページに配置された署名のバーコード画像コンテンツを取得するフラグを取得または設定します。このフラグが true に設定されている場合、バーコード署名画像コンテンツは必要な形式である [`ReturnContentType`](../returncontenttype) に従って生の画像データを保持します。デフォルトではこのオプションは無効です。

public bool ReturnContent { get; set; }
