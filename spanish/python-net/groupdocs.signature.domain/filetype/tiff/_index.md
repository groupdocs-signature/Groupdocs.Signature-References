## TIFF field

Tagged Image File Format (.tiff) representa imágenes raster que están destinadas a usarse en una variedad de dispositivos que cumplen con este estándar de formato de archivo. Es capaz de describir datos de imagen binaria, en escala de grises, con paleta de colores y de color completo en varios espacios de color. Obtenga más información sobre este formato de archivo aquí.
