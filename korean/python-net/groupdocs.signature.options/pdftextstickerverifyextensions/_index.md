## PdfTextStickerVerifyExtensions class

PDF 스티커 개체를 검증하기 위한 확장을 제공합니다.

### 생성자
| 생성자 | 설명 |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.options/pdftextstickerverifyextensions/__init__/) | 빈 값으로 PDF 텍스트 스티커 서명 검증 확장을 초기화합니다. |

| 속성 | 설명 |
