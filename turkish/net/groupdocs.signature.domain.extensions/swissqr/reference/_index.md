## SwissQR.Reference property

Alacaklı ödeme referansını alır veya ayarlar. Referans, SwissQR IBAN'ları için zorunludur, yani CHxx30000xxxxxx ile CHxx31999xxxxx arasındaki IBAN'lar. Belirtilirse, referans ya geçerli bir SwissQR referansı (ISR referans formuna karşılık gelen) ya da ISO 11649'a göre geçerli bir alacaklı referansı ("RFxxxx") olmalıdır. Her ikisi de biçimlendirme amacıyla boşluk içerebilir.

```csharp
public string Reference { get; set; }
```

### Property Value

Alacaklı ödeme referansı.
