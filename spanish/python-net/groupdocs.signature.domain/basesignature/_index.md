## BaseSignature class

Representa la clase base para firmas.

El tipo BaseSignature expone los siguientes miembros:

### Métodos
| Método | Descripción |
| :- | :- |
| [clone](/signature/python-net/groupdocs.signature.domain/basesignature/clone/) | Clonar instancia de firma. |
| [equals](/signature/python-net/groupdocs.signature.domain/basesignature/equals/#obj) | Compara el objeto de firma dado con esta instancia para igualdad. |
| [equals_object](/signature/python-net/groupdocs.signature.domain/basesignature/equals_object/) |  |

| :- | :- |

| [height](/signature/python-net/groupdocs.signature.domain/basesignature/height/) | La altura de la firma. |
| [is_signature](/signature/python-net/groupdocs.signature.domain/basesignature/is_signature/) | La bandera que indica si este componente representa una firma (`True`) o contenido del documento (`False`). |

| [modified_on](/signature/python-net/groupdocs.signature.domain/basesignature/modified_on/) | La fecha de modificación de la firma. |

| [signature_id](/signature/python-net/groupdocs.signature.domain/basesignature/signature_id/) | El identificador único de la firma, usado para modificar la firma en el documento mediante operaciones de actualización o eliminación. |

| [top](/signature/python-net/groupdocs.signature.domain/basesignature/top/) | La posición superior de la firma. |
| [width](/signature/python-net/groupdocs.signature.domain/basesignature/width/) | El ancho de la firma. |
