## return_content property

Le drapeau qui détermine si le contenu image d'une signature est renvoyé.

Si défini sur True, le contenu de la signature d'image est conservé en tant que données d'image brutes dans le format spécifié par [`ImageSearchOptions.return_content_type`](/signature/python-net/groupdocs.signature.options/imagesearchoptions/return_content_type/). Par défaut, cette option est désactivée (False).
