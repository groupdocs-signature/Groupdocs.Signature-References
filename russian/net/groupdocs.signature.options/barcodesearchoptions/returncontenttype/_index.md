## BarcodeSearchOptions.ReturnContentType property

Указывает тип файла возвращаемого содержимого изображения подписи штрихкода, когда включено свойство ReturnContent. По умолчанию установлено Null. Это означает возвращать изображение штрихкода в оригинальном формате. Этот формат изображения указан в [`Format`](../../../groupdocs.signature.domain/barcodesignature/format). Возможные поддерживаемые значения: FileType.JPEG, FileType.PNG, FileType.BMP. Если указанный формат не поддерживается, будет возвращено содержимое изображения штрихкода в формате .png.

public FileType ReturnContentType { get; set; }
