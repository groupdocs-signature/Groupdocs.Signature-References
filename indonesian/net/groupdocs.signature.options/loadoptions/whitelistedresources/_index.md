## LoadOptions.WhitelistedResources property

Mendapatkan atau mengatur fragmen alamat sumber daya eksternal yang dimuat bahkan ketika [`SkipExternalResources`](../skipexternalresources) bernilai true. Nilai default adalah daftar kosong.

```csharp
public List<string> WhitelistedResources { get; set; }
```

### Catatan

Sebuah sumber daya dimuat ketika alamat lengkapnya mengandung salah satu fragmen. Perbandingan mengabaikan huruf besar/kecil, dan fragmen kosong diabaikan. Lebih pilih fragmen panjang seperti "https://cdn.example.com/images/": fragmen pendek juga akan cocok dengan alamat lain yang kebetulan mengandungnya.

Mengatur properti ini ke null akan mengosongkan daftar. Daftar tidak berpengaruh ketika [`SkipExternalResources`](../skipexternalresources) bernilai false, karena pada saat itu semua sumber daya eksternal akan dimuat.
