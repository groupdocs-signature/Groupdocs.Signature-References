## ProcessCompleteEventArgs class

서명, 검증 및 검색 프로세스의 완료 이벤트에 대한 데이터를 제공합니다.

ProcessCompleteEventArgs 유형은 다음 멤버를 노출합니다:

### 속성
| 속성 | 설명 |
| :- | :- |
| [canceled](/signature/python-net/groupdocs.signature/processcompleteeventargs/canceled/) | 프로세스가 취소되었습니다. |
| [completed](/signature/python-net/groupdocs.signature/processcompleteeventargs/completed/) | 프로세스 완료 시점입니다. |
| [ticks](/signature/python-net/groupdocs.signature/processcompleteeventargs/ticks/) | 프로세스 시작 이벤트 이후 경과된 시간(밀리초)입니다. |
| [total_signatures](/signature/python-net/groupdocs.signature/processcompleteeventargs/total_signatures/) | 처리된 서명의 총 수량입니다. |
| [status](/signature/python-net/groupdocs.signature/processeventargs/status/) | 현재 프로세스 상태. ([`ProcessEventArgs`](/signature/python-net/groupdocs.signature/processeventargs/)에서 상속됨) |
