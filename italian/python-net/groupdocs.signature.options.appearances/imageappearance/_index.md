## ImageAppearance class

Rappresenta le funzionalità di aspetto esteso per una firma immagine.

Il tipo ImageAppearance espone i seguenti membri:

### Costruttori
| Costruttore | Descrizione |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.options.appearances/imageappearance/__init__/) | Inizializza una nuova istanza di ImageAppearance con valori predefiniti. |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [brightness](/signature/python-net/groupdocs.signature.options.appearances/imageappearance/brightness/) | La luminosità dell'immagine, con un valore predefinito di 1 corrispondente alla luminosità originale dell'immagine. |
| [contrast](/signature/python-net/groupdocs.signature.options.appearances/imageappearance/contrast/) | Il contrasto dell'immagine. Il valore predefinito è 1, che corrisponde al contrasto originale dell'immagine. |
| [gamma_correction](/signature/python-net/groupdocs.signature.options.appearances/imageappearance/gamma_correction/) | La gamma dell'immagine. |
| [grayscale](/signature/python-net/groupdocs.signature.options.appearances/imageappearance/grayscale/) | Il flag in scala di grigi; impostare su True per applicare un filtro in scala di grigi. |
