## PdfSaveFileFormat class

Тип PdfSaveFileFormat раскрывает следующие члены:

### Поля
| Поле | Описание |
| :- | :- |
| [DEFAULT](/signature/python-net/groupdocs.signature.domain/pdfsavefileformat/default/) | Формат файла не будет изменён. |
| [PDF](/signature/python-net/groupdocs.signature.domain/pdfsavefileformat/pdf/) | Сохраняет документ в формате Pdf (Adobe Portable Document). |
| [DOC](/signature/python-net/groupdocs.signature.domain/pdfsavefileformat/doc/) | Сохраняет документ в формате Microsoft Word 97-2007. |
| [XPS](/signature/python-net/groupdocs.signature.domain/pdfsavefileformat/xps/) | Сохраняет документ в формате XPS (XML Paper Specification). |
| [DOC_X](/signature/python-net/groupdocs.signature.domain/pdfsavefileformat/doc_x/) | Сохраняет документ в формате Microsoft Word Open XML. |
| [SVG](/signature/python-net/groupdocs.signature.domain/pdfsavefileformat/svg/) | Сохраняет документ в формате SVG (Scalable Vector Graphics). |
| [EPUB](/signature/python-net/groupdocs.signature.domain/pdfsavefileformat/epub/) | Сохраняет документ в формате IDPF EPUB. |
| [PPTX](/signature/python-net/groupdocs.signature.domain/pdfsavefileformat/pptx/) | Сохраняет документ в формате файла презентации PowerPoint Open XML |
