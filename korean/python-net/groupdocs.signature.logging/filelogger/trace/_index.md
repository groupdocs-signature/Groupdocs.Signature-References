## trace {#message}

콘솔에 추적 메시지를 기록합니다.

Trace 로그 메시지는 애플리케이션 흐름에 대한 일반적으로 유용한 정보를 제공합니다.

```python
def trace(self, message):
    ...
```

| 매개변수 | 형식 | 설명 |
| :- | :- | :- |
| message | `str` | trace 메시지. |

| 발생 | 설명 |
| :- | :- |
| `ValueError` | `message`가 None인 경우 발생합니다. |
