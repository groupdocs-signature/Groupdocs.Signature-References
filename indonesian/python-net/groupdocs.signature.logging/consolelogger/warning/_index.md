## warning {#message}

Menulis pesan peringatan ke konsol. Pesan log peringatan memberikan informasi tentang kejadian yang tidak terduga dan dapat dipulihkan dalam alur aplikasi.

```python
def warning(self, message):
    ...
```

| Parameter | Tipe | Deskripsi |
| :- | :- | :- |
| message | `str` | Pesan peringatan. |

| Melepaskan | Deskripsi |
| :- | :- |
| `ValueError` | Jika `message` bernilai None. |
