Mewakili kelas dasar untuk tanda tangan.

Tipe BaseSignature menampilkan anggota-anggota berikut:

| Metode | Deskripsi |
| :- | :- |
| [clone](/signature/python-net/groupdocs.signature.domain/basesignature/clone/) | Duplikat instance tanda tangan. |
| [equals](/signature/python-net/groupdocs.signature.domain/basesignature/equals/#obj) | Membandingkan objek tanda tangan yang diberikan dengan instance ini untuk kesetaraan. |
