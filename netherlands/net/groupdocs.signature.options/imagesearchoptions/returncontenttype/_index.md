## ImageSearchOptions.ReturnContentType property

Specificeert het bestandstype van de geretourneerde inhoud van de afbeeldinghandtekening wanneer de eigenschap ReturnContent is ingeschakeld. Standaard is deze ingesteld op Null. Dat betekent dat de afbeeldinginhoud in het oorspronkelijke formaat wordt geretourneerd. Dit afbeeldingformaat wordt gespecificeerd op [`Format`](../../../groupdocs.signature.domain/imagesignature/format). Mogelijke ondersteunde waarden zijn: FileType.JPEG, FileType.PNG, FileType.BMP. Als het opgegeven formaat niet wordt ondersteund, wordt de afbeeldinginhoud in het oorspronkelijke formaat geretourneerd.

public FileType ReturnContentType { get; set; }
