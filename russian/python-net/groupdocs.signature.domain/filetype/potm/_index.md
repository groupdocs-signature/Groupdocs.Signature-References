## POTM field

PowerPoint Open XML Macro-Enabled Presentation Template (.potm) — это шаблоны Microsoft PowerPoint с поддержкой макросов. Файлы POTM создаются в PowerPoint 2007 или более новых версиях и содержат настройки по умолчанию, которые можно использовать для создания дальнейших файлов презентаций.
