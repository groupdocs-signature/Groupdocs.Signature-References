## GIF field

Graphical Interchange Format File (.gif) är en typ av starkt komprimerad bild. För varje bild tillåter GIF vanligtvis upp till 8 bitar per pixel och upp till 256 färger är tillåtna i bilden. Läs mer om detta filformat här.
