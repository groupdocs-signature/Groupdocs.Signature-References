## ooxml_compliance property

Необязательный уровень соответствия OOXML для подписанного документа.

При установке переопределяет соответствие оригинального документа. Если None (по умолчанию), сохраняется соответствие загруженного документа. Применяется только к форматам OOXML (Docx, Docm, Dotx, Dotm, FlatOpc и варианты FlatOpc).
