## IRectangle class

Ορίζει ιδιότητες διεπαφής για την περιοχή υπογραφής σε μια σελίδα εγγράφου.

Ο τύπος IRectangle εκθέτει τα ακόλουθα μέλη:

### Ιδιότητες
| Ιδιότητα | Περιγραφή |
| :- | :- |
| [height](/signature/python-net/groupdocs.signature.domain/irectangle/height/) | Το ύψος της περιοχής υπογραφής σε μια σελίδα εγγράφου σε μονάδες μέτρησης (pixel, ποσοστά ή χιλιοστά· δείτε `MeasureType` SizeMeasureType). |
| [left](/signature/python-net/groupdocs.signature.domain/irectangle/left/) | Η αριστερή θέση X της περιοχής υπογραφής σε μια σελίδα εγγράφου σε μονάδες μέτρησης (pixel, ποσοστά ή χιλιοστά). Δείτε το `MeasureType` για την απαρίθμηση `LocationMeasureType`. |
| [location_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/location_measure_type/) | Ο τύπος μέτρησης (pixel, ποσοστά ή χιλιοστά) για τις ιδιότητες Left και Top. |
| [size_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/size_measure_type/) | Ο τύπος μέτρησης (pixel, ποσοστά ή χιλιοστά) για τις ιδιότητες Width και Height. |
| [stretch](/signature/python-net/groupdocs.signature.domain/irectangle/stretch/) | Η λειτουργία τέντωσης σε μια σελίδα εγγράφου. |
| [top](/signature/python-net/groupdocs.signature.domain/irectangle/top/) | Η κορυφαία θέση Y της περιοχής υπογραφής στη σελίδα του εγγράφου σε μονάδες μέτρησης (pixel, ποσοστά ή χιλιοστά). Δείτε το `MeasureType` για τον τύπο μέτρησης θέσης. |
| [width](/signature/python-net/groupdocs.signature.domain/irectangle/width/) | Το πλάτος της περιοχής υπογραφής σε μια σελίδα εγγράφου σε τιμές μέτρησης (pixel, ποσοστά ή χιλιοστά). Δείτε το `MeasureType` SizeMeasureType. |
