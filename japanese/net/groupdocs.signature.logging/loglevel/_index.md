## LogLevel enumeration

[`SignatureSettings`](../../groupdocs.signature/signaturesettings) に設定されたロガーに渡されるメッセージの種類を指定します。値はフラグで、たとえば `LogLevel.Error | LogLevel.Warning` のように組み合わせられます。

```csharp
[Flags]
public enum LogLevel
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| None | `0` | 何も記録されません。 |
| Error | `1` | エラー: 操作が失敗しました。 |
| Warning | `2` | 警告: 操作は成功しましたが、結果が期待通りでない可能性があります。 |
| Trace | `4` | トレース: 操作の手順、たとえば開始と終了です。 |
| All | `7` | エラー、警告、トレースです。これがデフォルトです。 |
