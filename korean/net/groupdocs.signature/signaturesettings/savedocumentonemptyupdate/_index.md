## SignatureSettings.SaveDocumentOnEmptyUpdate property

Update 메서드에 업데이트할 서명이 없을 때 원본 문서를 다시 저장할지 여부를 가져오거나 설정합니다. 이 플래그가 true(기본값)로 설정되면 Update 메서드에 서명이 없더라도 문서는 해당 히스토리 프로세스 로그(날짜 및 작업 유형)와 함께 저장됩니다. 플래그가 false로 설정되면 원본 문서는 전혀 수정되지 않습니다.

public bool SaveDocumentOnEmptyUpdate { get; set; }
