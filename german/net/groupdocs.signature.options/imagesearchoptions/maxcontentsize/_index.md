## ImageSearchOptions.MaxContentSize property

Für einen von Null abweichenden Wert gibt dieses Flag die maximale Bildgröße für das Suchkriterium an. Standardmäßig ist dieses Flag auf Null gesetzt und beeinflusst das Suchergebnis nicht.
