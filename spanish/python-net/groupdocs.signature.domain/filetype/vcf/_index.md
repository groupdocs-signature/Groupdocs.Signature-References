## VCF field

El archivo vCard (.vcf) es un formato de archivo digital para almacenar información de contactos. El formato se usa ampliamente para el intercambio de datos entre aplicaciones populares de intercambio de información. Obtenga más información sobre este formato de archivo aquí.
