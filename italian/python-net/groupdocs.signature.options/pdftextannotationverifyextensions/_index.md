## PdfTextAnnotationVerifyExtensions class

Descrive le estensioni per la verifica degli oggetti di annotazione testo PDF.

Il tipo PdfTextAnnotationVerifyExtensions espone i seguenti membri:

### Costruttori
| Costruttore | Descrizione |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.options/pdftextannotationverifyextensions/__init__/) | Inizializza le estensioni di verifica della firma di annotazione di testo PDF con valori vuoti. |

| Proprietà | Descrizione |
| :- | :- |
| [contents](/signature/python-net/groupdocs.signature.options/pdftextannotationverifyextensions/contents/) | Il contenuto dell'annotazione di testo da verificare; la verifica viene saltata se il valore è una stringa vuota o None. |
