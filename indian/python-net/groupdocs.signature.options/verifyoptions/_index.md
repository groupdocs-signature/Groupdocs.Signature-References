## VerifyOptions class

एक दस्तावेज़ को सत्यापित करने के विकल्प रखता है।

VerifyOptions प्रकार निम्नलिखित सदस्यों को उजागर करता है:

### गुण
| गुण | विवरण |
| :- | :- |
| [all_pages](/signature/python-net/groupdocs.signature.options/verifyoptions/all_pages/) | फ़्लैग जो संकेत करता है कि प्रत्येक दस्तावेज़ पृष्ठ सत्यापित किया जाना चाहिए या नहीं। डिफ़ॉल्ट रूप से मान True है। |
| [extensions](/signature/python-net/groupdocs.signature.options/verifyoptions/extensions/) | वैकल्पिक हस्ताक्षर विकल्प सत्यापन के लिए अतिरिक्त एक्सटेंशन। |
| [is_valid](/signature/python-net/groupdocs.signature.options/verifyoptions/is_valid/) | वैध प्रॉपर्टी फ़्लैग। |
| [page_number](/signature/python-net/groupdocs.signature.options/verifyoptions/page_number/) | सत्यापित करने के लिए दस्तावेज़ पृष्ठ संख्या; यदि सेट नहीं किया गया है, तो दस्तावेज़ के सभी पृष्ठ पहली घटना के लिए सत्यापित किए जाते हैं (न्यूनतम मान 1 है)। |
| [pages_setup](/signature/python-net/groupdocs.signature.options/verifyoptions/pages_setup/) | सत्यापित किए जाने वाले पृष्ठों को निर्दिष्ट करने के लिए पृष्ठ विकल्प। |
| [shape_position](/signature/python-net/groupdocs.signature.options/verifyoptions/shape_position/) | हेडर/फ़ूटर में हस्ताक्षर सत्यापित करने के लिए दस्तावेज़ लेआउट में उपयोग की जाने वाली आकृति की स्थिति। |
