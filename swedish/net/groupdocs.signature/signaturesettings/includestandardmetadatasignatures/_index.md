## SignatureSettings.IncludeStandardMetadataSignatures property

Hämtar eller anger flagga för att inkludera i Metadata‑listan de inbäddade standarddokumentmetadata‑signaturerna såsom Författare, Ägare, dokumentets skapelsedatum, ändringsdatum osv. Om denna flagga är falsk (standard) kommer GetDocumentInfo inte att inkludera dessa metadata‑signaturer. När flaggan är sann kommer dokumentinformationen att inkludera dessa standard‑metadata‑signaturer.

public bool IncludeStandardMetadataSignatures { get; set; }
