## Permissions class

Тип Permissions раскрывает следующие члены:

### Поля
| Поле | Описание |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.options/permissions/none/) | Разрешить все действия, включая печать, изменение и извлечение данных. |
| [DENY_PRINTING](/signature/python-net/groupdocs.signature.options/permissions/deny_printing/) | Запретить печать документа. |
| [DENY_MODIFICATION](/signature/python-net/groupdocs.signature.options/permissions/deny_modification/) | Запретить изменение содержимого, включая заполнение форм и добавление или изменение аннотаций. |
| [DENY_DATA_EXTRACTION](/signature/python-net/groupdocs.signature.options/permissions/deny_data_extraction/) | Запретить извлечение текста и графики из документа. |
| [DENY_ALL](/signature/python-net/groupdocs.signature.options/permissions/deny_all/) | Запретить все действия, включая печать, изменение и извлечение данных. |
