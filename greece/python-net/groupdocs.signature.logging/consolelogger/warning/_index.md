## warning {#message}

Γράφει ένα προειδοποιητικό μήνυμα στην κονσόλα. Τα προειδοποιητικά μηνύματα καταγραφής παρέχουν πληροφορίες για απρόσμενα και ανακτήσιμα γεγονότα στη ροή της εφαρμογής.

```python
def warning(self, message):
    ...
```

| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| message | `str` | Το μήνυμα προειδοποίησης. |

| Εγείρει | Περιγραφή |
| :- | :- |
| `ValueError` | Εάν το `message` είναι None. |
