## ImageSearchOptions.MinContentSize property

Für einen von Null abweichenden Wert gibt dieses Flag die minimale Bildgröße für das Suchkriterium an. Standardmäßig ist dieses Flag auf Null gesetzt und beeinflusst das Suchergebnis nicht.
