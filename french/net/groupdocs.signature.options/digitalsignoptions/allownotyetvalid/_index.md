## DigitalSignOptions.AllowNotYetValid property

Obtient ou définit un drapeau qui permet de signer avec un certificat dont la période de validité n'a pas encore commencé. La valeur par défaut est false : signer avec un tel certificat lève [`GroupDocsSignatureException`](../../../groupdocs.signature/groupdocssignatureexception), et le document n'est pas signé.

```csharp
public bool AllowNotYetValid { get; set; }
```

### Remarques

Les validateurs signalent une signature créée avant que le certificat ne devienne valide comme non valide. Un tel certificat était généralement émis pour une date ultérieure, ou l'horloge de l'ordinateur est incorrecte. Lorsque cette propriété est vraie, le document est signé, et un avertissement est écrit dans le journal configuré dans [`SignatureSettings`](../../../groupdocs.signature/signaturesettings).

Le certificat est comparé à l'heure actuelle en UTC. Le drapeau s'applique aux mêmes certificats que [`AllowExpired`](../allowexpired), qui contrôle les certificats dont la période de validité est terminée.
