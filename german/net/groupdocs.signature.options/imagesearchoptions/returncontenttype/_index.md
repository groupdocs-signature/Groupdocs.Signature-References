## ImageSearchOptions.ReturnContentType property

Gibt den Dateityp des zurückgegebenen Inhalts der Bildsignatur an, wenn die ReturnContent‑Eigenschaft aktiviert ist. Standardmäßig ist er auf Null gesetzt. Das bedeutet, dass der Bildinhalt im Originalformat zurückgegeben wird. Dieses Bildformat wird bei [`Format`](../../../groupdocs.signature.domain/imagesignature/format) angegeben. Mögliche unterstützte Werte sind: FileType.JPEG, FileType.PNG, FileType.BMP. Wenn das angegebene Format nicht unterstützt wird, wird der Bildinhalt im Originalformat zurückgegeben.

public FileType ReturnContentType { get; set; }
