## ImageSearchOptions.ReturnContentType property

ReturnContent プロパティが有効な場合に画像署名の返却コンテンツのファイルタイプを指定します。デフォルトは Null に設定されています。これは画像コンテンツを元の形式で返すことを意味します。この画像形式は [`Format`](../../../groupdocs.signature.domain/imagesignature/format) で指定されます。サポートされる可能な値は: FileType.JPEG、FileType.PNG、FileType.BMP です。指定された形式がサポートされていない場合、画像コンテンツは元の形式で返されます。

public FileType ReturnContentType { get; set; }
