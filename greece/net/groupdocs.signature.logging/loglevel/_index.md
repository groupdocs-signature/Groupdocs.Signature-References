## LogLevel enumeration

Καθορίζει ποιοι τύποι μηνυμάτων περνούν στον καταγραφέα που ορίζεται στο [`SignatureSettings`](../../groupdocs.signature/signaturesettings). Οι τιμές είναι σημαίες και μπορούν να συνδυαστούν, για παράδειγμα `LogLevel.Error | LogLevel.Warning`.

```csharp
[Flags]
public enum LogLevel
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| None | `0` | Τίποτα δεν καταγράφεται. |
| Error | `1` | Σφάλματα: μια λειτουργία απέτυχε. |
| Warning | `2` | Προειδοποιήσεις: μια λειτουργία ολοκληρώθηκε, αλλά το αποτέλεσμα της μπορεί να μην είναι αυτό που περιμένετε. |
| Trace | `4` | Ανιχνεύσεις: τα βήματα μιας λειτουργίας, όπως η έναρξη και το τέλος της. |
| All | `7` | Σφάλματα, προειδοποιήσεις και ανιχνεύσεις. Αυτό είναι το προεπιλεγμένο. |
