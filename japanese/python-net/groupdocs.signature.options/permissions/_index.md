## Permissions class

Permissions 型は次のメンバーを公開します:

### フィールド
| フィールド | 説明 |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.options/permissions/none/) | 印刷、変更、データ抽出を含むすべての操作を許可します。 |
| [DENY_PRINTING](/signature/python-net/groupdocs.signature.options/permissions/deny_printing/) | ドキュメントの印刷を拒否します。 |
| [DENY_MODIFICATION](/signature/python-net/groupdocs.signature.options/permissions/deny_modification/) | フォームへの入力や注釈の追加・変更を含むコンテンツの変更を拒否します。 |
| [DENY_DATA_EXTRACTION](/signature/python-net/groupdocs.signature.options/permissions/deny_data_extraction/) | ドキュメントからのテキストおよびグラフィックの抽出を拒否します。 |
| [DENY_ALL](/signature/python-net/groupdocs.signature.options/permissions/deny_all/) | 印刷、変更、データ抽出を含むすべての操作を拒否します。 |
