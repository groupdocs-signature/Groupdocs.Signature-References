Définit différents formats de sauvegarde de fichiers.
## Champs

| Champ | Description |
| --- | --- |
| [Default](#Default) | Le format de fichier ne sera pas modifié. |
| [Pps](#Pps) | Enregistre le document au format diaporama Microsoft Power Point 97-2003. |
| [Ppt](#Ppt) | Enregistre le document au format présentation Microsoft Power Point 97-2003. |
| [Pdf](#Pdf) | Enregistre le document au format PDF. |
| [Xps](#Xps) | Enregistre le document au format XPS (XML Paper Specification). |
| [Pptx](#Pptx) | Enregistre le document au format présentation Microsoft Power Point Open XML. |
| [Ppsx](#Ppsx) | Enregistre le document au format diaporama Microsoft Power Point Open XML. |
| [Tiff](#Tiff) | Rendu d’une ou plusieurs pages du document et enregistrement dans un fichier TIFF à page unique ou multipage. |
| [Odp](#Odp) | Enregistre le document au format présentation Open Office. |
| [Pptm](#Pptm) | Enregistre le document au format présentation Microsoft Power Point Open XML macro-enabled. |
| [Ppsm](#Ppsm) | Enregistre le document au format diaporama Microsoft Power Point Open XML macro-enabled. |
| [Potx](#Potx) | Enregistre le document au format modèle Microsoft Power Point. |
| [Potm](#Potm) | Enregistre le document au format modèle Microsoft Power Point macro-enabled. |
| [Html](#Html) | Enregistre le document au format HTML. |
| [Otp](#Otp) | Enregistre le document en tant que modèle de présentation Open Office. |
