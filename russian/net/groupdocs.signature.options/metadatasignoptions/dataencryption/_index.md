## MetadataSignOptions.DataEncryption property

Получает или задает реализацию интерфейса [`IDataEncryption`](../../../groupdocs.signature.domain.extensions/idataencryption) для шифрования всех подписей Metadata в этой коллекции параметров. Если это значение установлено, все добавленные подписи будут использовать это шифрование по умолчанию или собственное DataEncryption, если оно было назначено.

public IDataEncryption DataEncryption { get; set; }
