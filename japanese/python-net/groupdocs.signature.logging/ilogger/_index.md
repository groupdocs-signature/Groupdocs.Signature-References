## ILogger class

ロギングを実行するために使用されるメソッドを定義します。

ILogger 型は次のメンバーを公開します：

### メソッド
| メソッド | 説明 |
| :- | :- |
| [error](/signature/python-net/groupdocs.signature.logging/ilogger/error/#message-ex) | エラーログメッセージを書き込みます。エラーログメッセージは、アプリケーションのフローで回復不可能なイベントに関する情報を提供します。 |
| [error_file](/signature/python-net/groupdocs.signature.logging/ilogger/error_file/) |  |
| [error_string](/signature/python-net/groupdocs.signature.logging/ilogger/error_string/) |  |
| [trace](/signature/python-net/groupdocs.signature.logging/ilogger/trace/#message) | アプリケーションフローに関する一般的に有用な情報を提供するトレースメッセージを書き込みます。 |
| [trace_file](/signature/python-net/groupdocs.signature.logging/ilogger/trace_file/) |  |
| [trace_string](/signature/python-net/groupdocs.signature.logging/ilogger/trace_string/) |  |
| [warning](/signature/python-net/groupdocs.signature.logging/ilogger/warning/#message) | 警告ログメッセージを書き込みます。警告メッセージは、アプリケーションのフローで予期しない、かつ回復可能なイベントに関する情報を提供します。 |
| [warning_file](/signature/python-net/groupdocs.signature.logging/ilogger/warning_file/) |  |
| [warning_string](/signature/python-net/groupdocs.signature.logging/ilogger/warning_string/) |  |
