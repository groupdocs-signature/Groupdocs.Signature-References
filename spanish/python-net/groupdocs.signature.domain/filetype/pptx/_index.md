## PPTX field

PowerPoint Open XML Presentation (.pptx) son archivos de presentación creados con la popular aplicación Microsoft PowerPoint. A diferencia de la versión anterior del formato de archivo de presentación PPT, que era binario, el formato PPTX se basa en el formato de presentación Open XML de Microsoft PowerPoint. Obtén más información sobre este formato de archivo aquí.
