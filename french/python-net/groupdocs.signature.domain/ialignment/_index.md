## IAlignment class

Décrit l'alignement de la zone de signature sur une page de document.

Le type IAlignment expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [horizontal_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/horizontal_alignment/) | L'alignement horizontal de l'image sur une page de document. |
| [margin](/signature/python-net/groupdocs.signature.domain/ialignment/margin/) | L'espace spécifié par défaut entre l'image et les bords du document (s'applique lorsque l'alignement horizontal ou vertical est défini). |
| [margin_measure_type](/signature/python-net/groupdocs.signature.domain/ialignment/margin_measure_type/) | Le type de mesure de la marge (pixels, pourcentages ou millimètres). |
| [vertical_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/vertical_alignment/) | L'alignement vertical de l'image sur une page de document. |
