## PngFilterType class

Тип PngFilterType раскрывает следующие члены:

### Поля
| Поле | Описание |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.options/pngfiltertype/none/) | null-фильтр означает отсутствие фильтрации строк данных изображения. |
| [SUB](/signature/python-net/groupdocs.signature.options/pngfiltertype/sub/) | sub-фильтр означает, что к данным изображения будет применена вычитающая фильтрация. |
| [UP](/signature/python-net/groupdocs.signature.options/pngfiltertype/up/) | up-фильтр означает, что будет применён построчный фильтр вычитания. |
| [AVG](/signature/python-net/groupdocs.signature.options/pngfiltertype/avg/) | avg-фильтр означает, что к данным изображения будет применён средний фильтр. |
| [PAETH](/signature/python-net/groupdocs.signature.options/pngfiltertype/paeth/) | Фильтр предсказателя пути. |
| [ADAPTIVE](/signature/python-net/groupdocs.signature.options/pngfiltertype/adaptive/) | Адаптивная фильтрация означает, что процесс сохранения выберет наиболее подходящий фильтр для каждой строки данных. Наилучшее сжатие, самая медленная скорость выполнения. |
