## UpdateResult class

Rappresenta il risultato della modifica delle firme nel documento.

Il tipo UpdateResult espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/updateresult/destin_document_size/) | La dimensione del documento di destinazione. |
| [failed](/signature/python-net/groupdocs.signature.domain/updateresult/failed/) | L'elenco delle firme che non sono state aggiornate [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [processing_time](/signature/python-net/groupdocs.signature.domain/updateresult/processing_time/) | Il tempo di esecuzione del processo in millisecondi. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/updateresult/source_document_size/) | La dimensione del documento di origine. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/updateresult/succeeded/) | L'elenco delle firme modificate con successo [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/updateresult/total_signatures/) | Il totale delle firme elaborate. |
