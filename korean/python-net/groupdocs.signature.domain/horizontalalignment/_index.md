## HorizontalAlignment class

HorizontalAlignment 형식은 다음 멤버를 노출합니다:

### 필드
| 필드 | 설명 |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/horizontalalignment/none/) | 객체는 명시적으로 위치가 지정되며, 일반적으로 Left 속성을 사용합니다. |
| [LEFT](/signature/python-net/groupdocs.signature.domain/horizontalalignment/left/) | 객체가 수평 정렬 기준에 왼쪽 정렬되도록 지정합니다. |
| [CENTER](/signature/python-net/groupdocs.signature.domain/horizontalalignment/center/) | 객체가 수평 정렬 기준에 대해 가운데 정렬되도록 지정합니다. |
| [RIGHT](/signature/python-net/groupdocs.signature.domain/horizontalalignment/right/) | 객체가 수평 정렬 기준에 오른쪽 정렬되도록 지정합니다. |
