Représente la classe de base pour les signatures.

Le type BaseSignature expose les membres suivants :

| Méthode | Description |
| :- | :- |
| [clone](/signature/python-net/groupdocs.signature.domain/basesignature/clone/) | Cloner l'instance de signature. |
| [equals](/signature/python-net/groupdocs.signature.domain/basesignature/equals/#obj) | Compare l'objet de signature donné avec cette instance pour l'égalité. |
| [equals_object](/signature/python-net/groupdocs.signature.domain/basesignature/equals_object/) |  |
| [get_hash_code](/signature/python-net/groupdocs.signature.domain/basesignature/get_hash_code/) | Fournit une implémentation remplacée de GetHashCode. |
