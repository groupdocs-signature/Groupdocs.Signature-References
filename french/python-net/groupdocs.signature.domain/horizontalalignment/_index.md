## HorizontalAlignment class

Le type HorizontalAlignment expose les membres suivants :

### Champs
| Champ | Description |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/horizontalalignment/none/) | L'objet est positionné explicitement, généralement en utilisant sa propriété Left. |
| [LEFT](/signature/python-net/groupdocs.signature.domain/horizontalalignment/left/) | Spécifie que l'objet doit être aligné à gauche par rapport à la base d'alignement horizontal. |
| [CENTER](/signature/python-net/groupdocs.signature.domain/horizontalalignment/center/) | Spécifie que l'objet doit être centré par rapport à la base d'alignement horizontal. |
| [RIGHT](/signature/python-net/groupdocs.signature.domain/horizontalalignment/right/) | Spécifie que l'objet doit être aligné à droite par rapport à la base d'alignement horizontal. |
