## IDocumentInfo class

Le proprietà della descrizione del documento.

Il tipo IDocumentInfo espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [barcode_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/barcode_signatures/) | La raccolta delle firme barcode del documento aggiunte o aggiornate dai metodi [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [digital_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/digital_signatures/) | La raccolta delle firme digitali del documento aggiunte o aggiornate dai metodi [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [documents](/signature/python-net/groupdocs.signature.domain/idocumentinfo/documents/) | La raccolta di tutti i documenti esistenti nei file di archivio. Questa proprietà è supportata solo per i tipi di documento archivio. |
| [file_type](/signature/python-net/groupdocs.signature.domain/idocumentinfo/file_type/) | Il tipo di formato file. |
| [form_field_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/form_field_signatures/) | La raccolta delle firme dei campi modulo del documento aggiunte o aggiornate dai metodi [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [form_fields](/signature/python-net/groupdocs.signature.domain/idocumentinfo/form_fields/) | La raccolta di tutti i campi modulo supportati esistenti nel documento. Questa proprietà è supportata solo per i tipi di documento PDF e Word Processing. |
| [image_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/image_signatures/) | La raccolta delle firme immagine del documento aggiunte o aggiornate dai metodi [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [max_page_height](/signature/python-net/groupdocs.signature.domain/idocumentinfo/max_page_height/) | L'altezza massima della pagina. |
| [metadata_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/metadata_signatures/) | La raccolta delle firme di metadati del documento. |
| [page_count](/signature/python-net/groupdocs.signature.domain/idocumentinfo/page_count/) | Il conteggio delle pagine del documento. |
| [pages](/signature/python-net/groupdocs.signature.domain/idocumentinfo/pages/) | La raccolta delle descrizioni delle pagine del documento. |
| [process_logs](/signature/python-net/groupdocs.signature.domain/idocumentinfo/process_logs/) | La raccolta dei registri di processo della cronologia del documento. |
| [qr_code_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/qr_code_signatures/) | La raccolta delle firme QR-code del documento aggiunte o aggiornate dai metodi [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/signatures/) | La raccolta di tutti i tipi di firma presenti nel documento come oggetti [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [size](/signature/python-net/groupdocs.signature.domain/idocumentinfo/size/) | La dimensione del documento in byte. |
| [text_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/text_signatures/) | La raccolta delle firme di testo del documento aggiunte o aggiornate dai metodi [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [width_for_max_height](/signature/python-net/groupdocs.signature.domain/idocumentinfo/width_for_max_height/) | La larghezza per l'altezza massima della pagina. |
