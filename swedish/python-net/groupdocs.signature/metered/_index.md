## Metered class

Hantera mätbaserad (betala per användning) licensiering.

Metered-licenser faktureras baserat på faktisk förbrukning (vanligtvis sidor eller
dokument som bearbetas). Ställ in det offentliga/privata nyckelparet en gång vid
programstart; omslaget rapporterar användning tillbaka till GroupDocs
licensservern i bakgrunden.

Metered-typen visar följande medlemmar:

### Metoder
| Metod | Beskrivning |
| :- | :- |
| [get_consumption_credit](/signature/python-net/groupdocs.signature/metered/get_consumption_credit/) | Returnerar antalet krediter som har förbrukats hittills. |
| [get_consumption_quantity](/signature/python-net/groupdocs.signature/metered/get_consumption_quantity/) | Returnerar mängden data som har bearbetats hittills. |
| [set_metered_key](/signature/python-net/groupdocs.signature/metered/set_metered_key/#public_key-private_key) | Aktivera mätad fakturering med det angivna offentliga/privata nyckelparet. |
