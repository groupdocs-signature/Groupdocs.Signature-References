## show_properties property

Il flag che forza le proprietà della firma a essere mostrate o nascoste; quando è vero, il campo firma utilizza un formato di aspetto predefinito (ad es., `Digitally signed by {PdfDigitalSignature.contact_info} Date: {Date} Reason: {PdfDigitalSignature.reason} Location: {PdfDigitalSignature.location}`) e il valore predefinito è True.
