## error {#message-ex}

Записывает сообщение об ошибке в журнал; сообщения об ошибках предоставляют информацию о необратимых событиях в потоке приложения.

```python
def error(self, message, ex):
    ...
```

| Параметр | Тип | Описание |
| :- | :- | :- |
| message | `str` | Сообщение error. |
| ex | `Exception` | Исключение. |
