| [MaxContentSize](../../groupdocs.signature.options/imagesearchoptions/maxcontentsize) { get; set; } | 0 以外の値の場合、このフラグは検索条件の画像の最大サイズを指定します。デフォルトではこのフラグは 0 に設定されており、検索結果に影響しません。 |

| [PageNumber](../../groupdocs.signature.options/searchoptions/pagenumber) { get; set; } | 検索対象の Document ページ番号を取得または設定します。値はオプションです。 |
| [PagesSetup](../../groupdocs.signature.options/searchoptions/pagessetup) { get; set; } | 署名検索の対象ページを指定するオプション。 |

| [ReturnContentType](../../groupdocs.signature.options/imagesearchoptions/returncontenttype) { get; set; } | ReturnContent プロパティが有効な場合、画像署名の返却コンテンツのファイルタイプを指定します。デフォルトでは Null に設定されています。これは画像コンテンツを元の形式で返すことを意味します。この画像形式は [`Format`](../../groupdocs.signature.domain/imagesignature/format) で指定されます。サポートされている可能な値は: FileType.JPEG、FileType.PNG、FileType.BMP です。指定された形式がサポートされていない場合、画像コンテンツは元の形式で返されます。 |
