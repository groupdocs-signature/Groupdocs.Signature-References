さまざまな保存ファイル形式を定義します。

## フィールド

| フィールド | 説明 |
| --- | --- |
|  | [Default](#Default) | ファイル形式は変更されません。 |
|
|  | [Pps](#Pps) | ドキュメントを Microsoft Power Point 97-2003 スライドショーとして保存します。 |
|
|  | [Ppt](#Ppt) | ドキュメントを Microsoft Power Point 97-2003 プレゼンテーションとして保存します。 |
|
|  | [Pdf](#Pdf) | ドキュメントを PDF 形式で保存します。 |
|
|  | [Xps](#Xps) | ドキュメントを XPS (XML Paper Specification) 形式で保存します。 |
|
|  | [Pptx](#Pptx) | ドキュメントを Microsoft Power Point Open XML プレゼンテーション形式で保存します。 |
|
|  | [Ppsx](#Ppsx) | ドキュメントを Microsoft Power Point Open XML スライドショー形式で保存します。 |
|
|  | [Tiff](#Tiff) | ドキュメントのページまたは複数ページをレンダリングし、単一または複数ページの TIFF ファイルに保存します。 |
|
|  | [Odp](#Odp) | ドキュメントを Open Office プレゼンテーションとして保存します。 |
|
|  | [Pptm](#Pptm) | ドキュメントを Microsoft Power Point Open XML マクロ有効プレゼンテーションとして保存します。 |
|
|  | [Ppsm](#Ppsm) | ドキュメントを Microsoft Power Point Open XML マクロ有効スライドショーとして保存します。 |
|
|  | [Potx](#Potx) | ドキュメントを Microsoft Power Point テンプレートとして保存します。 |
|
|  | [Potm](#Potm) | ドキュメントを Microsoft Power Point マクロ有効テンプレートとして保存します。 |
|
|  | [Html](#Html) | ドキュメントを HTML 形式で保存します。 |
|
|  | [Otp](#Otp) | ドキュメントを Open Office プレゼンテーションテンプレートとして保存します。 |
|
