## DigitalSignatureAppearance class

Περιγράφει την εμφάνιση της Γραμμής Υπογραφής για Ψηφιακή Υπογραφή. Μια Γραμμή Υπογραφής μπορεί να εφαρμοστεί μόνο για μία Ψηφιακή Υπογραφή. Η Γραμμή Υπογραφής βρίσκεται πάντα στην πρώτη σελίδα. Αυτή η δυνατότητα μπορεί να είναι χρήσιμη για μορφές αρχείων .docx, .doc, .odt και .xlsx.
