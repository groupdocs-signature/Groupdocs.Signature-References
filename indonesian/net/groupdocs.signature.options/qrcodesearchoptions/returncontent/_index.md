## QrCodeSearchOptions.ReturnContent property

Mendapatkan atau mengatur flag untuk mengambil konten gambar QR-Code dari tanda tangan pada halaman dokumen. Jika flag ini diatur ke true, konten gambar tanda tangan QR-Code akan mempertahankan data gambar mentah dengan format yang diperlukan [`ReturnContentType`](../returncontenttype). Secara default opsi ini dinonaktifkan.

public bool ReturnContent { get; set; }
