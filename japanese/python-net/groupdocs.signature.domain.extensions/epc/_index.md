## EPC class

欧州支払委員会のクイックレスポンスコードを表します。

EPC 型は次のメンバーを公開します:

### コンストラクタ
| コンストラクタ | 説明 |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.domain.extensions/epc/__init__/) | 新しい EPC オブジェクトを初期化します。 |

### メソッド
| メソッド | 説明 |
| :- | :- |
| [equals](/signature/python-net/groupdocs.signature.domain.extensions/epc/equals/#obj) | EPC のプロパティを比較するために Equals メソッドをオーバーライドします。 |
| [equals_object](/signature/python-net/groupdocs.signature.domain.extensions/epc/equals_object/) |  |
| [get_hash_code](/signature/python-net/groupdocs.signature.domain.extensions/epc/get_hash_code/) | EPC のハッシュコードを計算します。 |

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [amount](/signature/python-net/groupdocs.signature.domain.extensions/epc/amount/) | 金額です。 |
| [bic](/signature/python-net/groupdocs.signature.domain.extensions/epc/bic/) | 受取人の BIC（最大 11 文字）です。 |
| [charset](/signature/python-net/groupdocs.signature.domain.extensions/epc/charset/) | EPC / SEPA QR コードの文字セット実装です。デフォルトではこの値は 1 に設定されています。 |
| [code](/signature/python-net/groupdocs.signature.domain.extensions/epc/code/) | 事業コード（最大 4 文字）です。 |
| [iban](/signature/python-net/groupdocs.signature.domain.extensions/epc/iban/) | 受取人の口座（IBAN）です。 |
| [identification](/signature/python-net/groupdocs.signature.domain.extensions/epc/identification/) | EPC / SEPA QR コードの識別子です。デフォルトではこの値は SCT に設定されています。 |
| [information](/signature/python-net/groupdocs.signature.domain.extensions/epc/information/) | ヒント情報（最大 70 文字）です。 |
| [name](/signature/python-net/groupdocs.signature.domain.extensions/epc/name/) | 受取人の名前（最大 70 文字）です。 |
| [reference](/signature/python-net/groupdocs.signature.domain.extensions/epc/reference/) | 支払参照（最大 35 文字）です。 |
| [remittance](/signature/python-net/groupdocs.signature.domain.extensions/epc/remittance/) | 送金情報（最大 140 文字）です。 |
| [version](/signature/python-net/groupdocs.signature.domain.extensions/epc/version/) | EPC / SEPA QR コードのバージョン実装です。デフォルトは "002" です。 |
