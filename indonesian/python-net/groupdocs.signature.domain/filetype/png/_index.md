## PNG field

Portable Network Graphic (.png) adalah jenis format file gambar raster yang menggunakan kompresi lossless. Format file ini dibuat sebagai pengganti Graphics Interchange Format (GIF) dan tidak memiliki batasan hak cipta. Pelajari lebih lanjut tentang format file ini di sini.
