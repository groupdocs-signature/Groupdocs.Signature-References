## PdfDigitalSignatureAppearance class

Descrive l'aspetto delle firme digitali sui documenti PDF.

Maggiori informazioni

- See more simple examples on creating digital electronic signatures with GroupDocs.Signature: https://docs.groupdocs.com/signature/net/sign-document-with-digital-signature-advanced/
- See more advanced examples of settings of various electronic signature with GroupDocs.Signature: https://docs.groupdocs.com/signature/net/sign-documents-with-extra-digital-signature-properties/

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [background](/signature/python-net/groupdocs.signature.options.appearances/pdfdigitalsignatureappearance/background/) | Il colore di sfondo dell'aspetto della firma. |
| [contact_info_label](/signature/python-net/groupdocs.signature.options.appearances/pdfdigitalsignatureappearance/contact_info_label/) | L'etichetta delle informazioni di contatto, impostata di default su "Contact"; se vuota, nessuna etichetta di contatto verrà visualizzata nell'area della firma digitale. |
| [date_signed_at_label](/signature/python-net/groupdocs.signature.options.appearances/pdfdigitalsignatureappearance/date_signed_at_label/) | L'etichetta della data di firma. Valore predefinito: "Date". |
| [digital_signed_label](/signature/python-net/groupdocs.signature.options.appearances/pdfdigitalsignatureappearance/digital_signed_label/) | L'etichetta firmata digitalmente. Valore predefinito: "Digitally signed by". |
| [font_family_name](/signature/python-net/groupdocs.signature.options.appearances/pdfdigitalsignatureappearance/font_family_name/) | Il nome della famiglia di caratteri per visualizzare le etichette, il valore predefinito è "Arial". |
| [font_size](/signature/python-net/groupdocs.signature.options.appearances/pdfdigitalsignatureappearance/font_size/) | La dimensione del carattere per visualizzare le etichette. |
| [foreground](/signature/python-net/groupdocs.signature.options.appearances/pdfdigitalsignatureappearance/foreground/) | Il colore del testo in primo piano dell'aspetto della firma. |
| [is_foreground_image](/signature/python-net/groupdocs.signature.options.appearances/pdfdigitalsignatureappearance/is_foreground_image/) | Il flag che indica se l'immagine nell'aspetto della firma è disegnata come immagine in primo piano. |
| [location_label](/signature/python-net/groupdocs.signature.options.appearances/pdfdigitalsignatureappearance/location_label/) | L'etichetta della posizione visualizzata nell'area della firma digitale, impostata di default su "Location"; se impostata a una stringa vuota, non appare alcuna etichetta di posizione. |
| [reason_label](/signature/python-net/groupdocs.signature.options.appearances/pdfdigitalsignatureappearance/reason_label/) | L'etichetta del motivo visualizzata nell'area della firma digitale. |
