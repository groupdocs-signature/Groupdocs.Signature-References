## DigitalVBA class

Representerar digital signatur för kalkylblads‑VBA‑projekt. Den ger möjlighet att signera VBA‑projekt i specifika kalkylbladsdokumentformat som Xlsm eller Xltm. Om flera DigitalVBA‑tillägg läggs till i DigitalSignOptions.Extensions används endast det första vid dokumentsignering.

public class DigitalVBA : SignatureExtension
