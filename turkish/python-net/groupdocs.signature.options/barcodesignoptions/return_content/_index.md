## return_content property

Belge sayfasına yerleştirilen bir imzanın barcode görüntü içeriğini alıp almayacağını gösteren bayrak.

True olarak ayarlandığında, barkod imza görüntü içeriği `return_content_type` tarafından belirtilen formatta ham görüntü verisi olarak korunur. Varsayılan olarak, bu seçenek devre dışı bırakılmıştır (False).
