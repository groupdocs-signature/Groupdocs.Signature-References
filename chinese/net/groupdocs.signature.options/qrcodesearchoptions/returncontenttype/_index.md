## QrCodeSearchOptions.ReturnContentType property

指定在启用 ReturnContent 属性时返回的 QR-Code 签名图像内容的文件类型。默认设置为 Null，这意味着返回原始格式的 QR-Code 图像内容。此图像格式在 [`Format`](../../../groupdocs.signature.domain/qrcodesignature/format) 中指定。可能支持的值有：FileType.JPEG、FileType.PNG、FileType.BMP。如果提供的格式不受支持，则返回原始 .png 格式的 QR-Code 图像内容。

public FileType ReturnContentType { get; set; }
