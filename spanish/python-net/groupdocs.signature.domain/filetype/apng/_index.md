## APNG field

Animated Portable Network Graphics (.png) es un formato de archivo de imagen raster que utiliza compresión sin pérdida. Fue desarrollado como una extensión de PNG para soportar animación, sirviendo como una alternativa al formato GIF sin limitaciones de derechos de autor. Obtenga más información sobre este formato de archivo aquí.
