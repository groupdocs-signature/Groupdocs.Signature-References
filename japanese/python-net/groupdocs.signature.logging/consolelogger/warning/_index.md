## warning {#message}

コンソールに警告メッセージを書き込みます。警告ログメッセージは、アプリケーションのフローで予期しない、かつ回復可能なイベントに関する情報を提供します。

```python
def warning(self, message):
    ...
```

| パラメーター | 型 | 説明 |
| :- | :- | :- |
| message | `str` | 警告メッセージです。 |

| 例外 | 説明 |
| :- | :- |
| `ValueError` | もし `message` が None の場合。 |
