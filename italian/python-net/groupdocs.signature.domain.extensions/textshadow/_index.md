## TextShadow class

Rappresenta le proprietà dell'ombra del testo per le firme di testo.

Il risultato può variare a seconda del tipo di firma e del formato del documento.

TextShadow è consigliato per l'uso con la firma `TextAsImage` per tutti i tipi di documento supportati, anche con semplici [`TextSignature`](/signature/python-net/groupdocs.signature.domain/textsignature/) e [`TextSignature`](/signature/python-net/groupdocs.signature.domain/textsignature/) come filigrana per fogli di calcolo (`.xslx`) e presentazioni (`.pptx`).

Una semplice [`TextSignature`](/signature/python-net/groupdocs.signature.domain/textsignature/) per documenti Word (`.docx`) è consigliata anche, ma ha funzionalità limitate.

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [angle](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/angle/) | L'angolo per posizionare l'ombra rispetto al testo. Il valore predefinito è 0. |
| [blur](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/blur/) | La sfocatura dell'ombra. Il valore predefinito è 4. |
| [color](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/color/) | Il colore dell'ombra. Il valore predefinito è Black. |
| [distance](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/distance/) | La distanza dal testo all'ombra. |
| [transparency](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/transparency/) | La trasparenza dell'ombra. |
