## __init__ {#signature_id}

```python
def __init__(self, signature_id):
    ...
```

| 매개변수 | 형식 | 설명 |
| :- | :- | :- |
| signature_id | `str` | `Signature`의 `Sign` 또는 `Search` 메서드로 얻은 고유 서명 식별자. |
