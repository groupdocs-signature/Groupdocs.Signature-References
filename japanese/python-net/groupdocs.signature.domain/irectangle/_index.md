## IRectangle class

ドキュメントページ上の署名領域のインターフェースプロパティを定義します。

IRectangle 型は次のメンバーを公開します:

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [height](/signature/python-net/groupdocs.signature.domain/irectangle/height/) | ドキュメントページ上の署名領域の高さ（測定単位はピクセル、パーセント、またはミリメートル；`MeasureType` の SizeMeasureType を参照）。 |
| [left](/signature/python-net/groupdocs.signature.domain/irectangle/left/) | ドキュメントページ上の署名領域の左側 X 位置（測定単位はピクセル、パーセント、またはミリメートル）。`LocationMeasureType` 列挙体については `MeasureType` を参照してください。 |
| [location_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/location_measure_type/) | Left および Top プロパティの測定単位（ピクセル、パーセント、またはミリメートル）です。 |
| [size_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/size_measure_type/) | Width および Height プロパティの測定単位（ピクセル、パーセント、またはミリメートル）です。 |
| [stretch](/signature/python-net/groupdocs.signature.domain/irectangle/stretch/) | ドキュメントページ上のストレッチモードです。 |
| [top](/signature/python-net/groupdocs.signature.domain/irectangle/top/) | ドキュメントページ上の署名領域の上部 Y 位置を測定単位（ピクセル、パーセント、またはミリメートル）で示します。場所の測定タイプについては `MeasureType` を参照してください。 |
| [width](/signature/python-net/groupdocs.signature.domain/irectangle/width/) | ドキュメントページ上の署名領域の幅を測定値（ピクセル、パーセント、またはミリメートル）で示します。`MeasureType` の SizeMeasureType を参照してください。 |
