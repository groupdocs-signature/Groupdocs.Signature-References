主要的 GroupDocs.Signature 命名空间，包含顶层 API 类。

### 类
| 类 | 描述 |
| :- | :- |
| [`License`](/signature/python-net/groupdocs.signature/license/) | 管理 GroupDocs.Signature 许可。 |
| [`Metered`](/signature/python-net/groupdocs.signature/metered/) | 管理计量（按使用付费）许可。 |
| [`ProcessCompleteEventArgs`](/signature/python-net/groupdocs.signature/processcompleteeventargs/) | 提供签名、验证和搜索过程完成事件的数据。 |
| [`ProcessCompleteEventHandler`](/signature/python-net/groupdocs.signature/processcompleteeventhandler/) | 表示处理签名、验证和搜索过程完成事件的方法委托。 |
| [`ProcessEventArgs`](/signature/python-net/groupdocs.signature/processeventargs/) | 提供签名、验证和搜索过程不同事件的数据。 |
| [`ProcessProgressEventArgs`](/signature/python-net/groupdocs.signature/processprogresseventargs/) | 提供签名、验证和搜索过程的 OnProgress 事件数据。 |
| [`ProcessProgressEventHandler`](/signature/python-net/groupdocs.signature/processprogresseventhandler/) | 表示处理签名、验证和搜索进度事件的方法委托。 |
| [`ProcessStartEventArgs`](/signature/python-net/groupdocs.signature/processstarteventargs/) | 提供签名、验证和搜索过程的开始事件数据。 |
| [`ProcessStartEventHandler`](/signature/python-net/groupdocs.signature/processstarteventhandler/) | 表示处理签名、验证和搜索过程开始事件的方法委托。 |
| [`Signature`](/signature/python-net/groupdocs.signature/signature/) | 表示控制文档签名过程的主类。 |
| [`SignatureSettings`](/signature/python-net/groupdocs.signature/signaturesettings/) | 表示用于自定义[`Signature`](/signature/python-net/groupdocs.signature/signature/)行为的设置。 |

### 异常
| 异常 | 描述 |
| :- | :- |
| [`GroupDocsSignatureException`](/signature/python-net/groupdocs.signature/groupdocssignatureexception/) | 表示文档处理期间发生的通用错误。 |
| [`IncorrectPasswordException`](/signature/python-net/groupdocs.signature/incorrectpasswordexception/) | 当指定的密码不正确时抛出的异常。 |
| [`PasswordRequiredException`](/signature/python-net/groupdocs.signature/passwordrequiredexception/) | 当加载文档需要密码时抛出的异常。 |
