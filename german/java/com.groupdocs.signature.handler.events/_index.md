Der **GroupDocs.Signature.Handler.Events**-Namespace stellt Klassen für Eingabe‑ und Ausgabe‑Datenhandler bereit.



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ProcessCompleteEventArgs](../com.groupdocs.signature.handler.events/processcompleteeventargs) | Stellt Daten zum Abschlussereignis von Signatur-, Verifizierungs- und Suchvorgängen bereit. |
| [ProcessCompleteEventHandler](../com.groupdocs.signature.handler.events/processcompleteeventhandler) | Stellt einen Methodendelegaten dar, der Prozesse bei Abschlussereignissen für Signatur, Verifizierung und Suche behandelt. |
| [ProcessEventArgs](../com.groupdocs.signature.handler.events/processeventargs) | Stellt Daten für verschiedene Ereignisse von Signatur-, Verifizierungs- und Suchvorgängen bereit. |
| [ProcessProgressEventArgs](../com.groupdocs.signature.handler.events/processprogresseventargs) | Stellt Daten für das OnProgress-Ereignis von Signatur-, Verifizierungs- und Suchvorgängen bereit. |
| [ProcessProgressEventHandler](../com.groupdocs.signature.handler.events/processprogresseventhandler) | Stellt einen Methodendelegaten dar, der Prozesse bei Fortschrittsereignissen für Signatur, Verifizierung und Suche behandelt. |
| [ProcessStartEventArgs](../com.groupdocs.signature.handler.events/processstarteventargs) | Stellt Daten für das Start-Ereignis von Signatur-, Verifizierungs- und Suchvorgängen bereit. |
| [ProcessStartEventHandler](../com.groupdocs.signature.handler.events/processstarteventhandler) | Stellt einen Methodendelegaten dar, der Prozesse bei Startereignissen für Signatur, Verifizierung und Suche behandelt. |
