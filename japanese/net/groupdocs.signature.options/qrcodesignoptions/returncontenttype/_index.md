## QrCodeSignOptions.ReturnContentType property

ReturnContent プロパティが有効な場合の QR-Code 署名の返却画像コンテンツのファイルタイプを指定します。デフォルトは Null に設定されています。これは、元の形式で QR-Code 画像コンテンツを返すことを意味します。この画像形式は [`Format`](../../../groupdocs.signature.domain/qrcodesignature/format) で指定されます。サポートされる可能な値は: FileType.JPEG、FileType.PNG、FileType.BMP です。指定された形式がサポートされていない場合、QR-Code 画像コンテンツは .png 形式で返されます。

public FileType ReturnContentType { get; set; }
