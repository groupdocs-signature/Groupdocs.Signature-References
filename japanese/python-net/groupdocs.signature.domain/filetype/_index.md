## FileType class

ファイルタイプを表します。

詳細を見る

- More about file types supported by GroupDocs.Signature: Document formats supported by GroupDocs.Signature (https://docs.groupdocs.com/display/signaturenet/Supported+Document+Formats)
- More about how to get supported formats list in C#: How to get supported file formats in C# code (https://docs.groupdocs.com/display/signaturenet/Get+supported+file+formats)

FileType タイプは以下のメンバーを公開します：

### メソッド
| メソッド | 説明 |
| :- | :- |
| [equals](/signature/python-net/groupdocs.signature.domain/filetype/equals/#other) | 現在の FileType が指定された FileType オブジェクトと同じかどうかを判断します。 |
| [equals](/signature/python-net/groupdocs.signature.domain/filetype/equals/#obj) | 現在の [`FileType`](/signature/python-net/groupdocs.signature.domain/filetype/) が指定されたオブジェクトと同じかどうかを判断します。 |
| [equals_file_type](/signature/python-net/groupdocs.signature.domain/filetype/equals_file_type/) |  |
| [equals_object](/signature/python-net/groupdocs.signature.domain/filetype/equals_object/) |  |
| [from_extension](/signature/python-net/groupdocs.signature.domain/filetype/from_extension/#extension) | ファイル拡張子をファイルタイプにマップします。 |
| [get_hash_code](/signature/python-net/groupdocs.signature.domain/filetype/get_hash_code/) | 現在の [`FileType`](/signature/python-net/groupdocs.signature.domain/filetype/) オブジェクトのハッシュコードを返します。 |
| [get_supported_file_types](/signature/python-net/groupdocs.signature.domain/filetype/get_supported_file_types/) | サポートされているファイルタイプを取得します。 |
| [to_string](/signature/python-net/groupdocs.signature.domain/filetype/to_string/) | 現在のオブジェクトを表す文字列を返します。 |

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [extension](/signature/python-net/groupdocs.signature.domain/filetype/extension/) | ファイル名の拡張子（ピリオド「.」を含む）例：".doc"。 |
| [file_format](/signature/python-net/groupdocs.signature.domain/filetype/file_format/) | ファイルタイプ名、例："Microsoft Word Document"。 |

### 例

```python
from groupdocs.signature.domain import FileType
import os

# サポートされているすべてのファイルタイプを一覧表示
for ft in FileType.get_supported_file_types():
    print(f"{ft.extension}: {ft.file_format}")

# 特定のファイル拡張子がサポートされているか確認する
extension = os.path.splitext("contract.pdf")[1]
if FileType.from_extension(extension) == FileType.UNKNOWN:
    print(f"{extension} files are not supported")
else:
    print(f"{extension} files are supported")
```
