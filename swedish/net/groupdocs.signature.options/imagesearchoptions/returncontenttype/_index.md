## ImageSearchOptions.ReturnContentType property

Anger filtypen för det returnerade innehållet av bildsignaturen när egenskapen ReturnContent är aktiverad. Som standard är den satt till Null. Det innebär att bildinnehållet returneras i originalformat. Detta bildformat anges i [`Format`](../../../groupdocs.signature.domain/imagesignature/format). Möjliga stödjade värden är: FileType.JPEG, FileType.PNG, FileType.BMP. Om det angivna formatet inte stöds returneras bildinnehållet i originalformat.

public FileType ReturnContentType { get; set; }
