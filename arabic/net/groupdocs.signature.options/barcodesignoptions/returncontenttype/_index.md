## BarcodeSignOptions.ReturnContentType property

يحدد نوع الملف لمحتوى الصورة المُرجع لتوقيع الباركود عندما تكون خاصية ReturnContent مفعّلة. بشكل افتراضي يتم تعيينه إلى Null. وهذا يعني إرجاع محتوى صورة الباركود بالتنسيق الأصلي. يتم تحديد تنسيق الصورة هذا في [`Format`](../../../groupdocs.signature.domain/barcodesignature/format). القيم المدعومة الممكنة هي: FileType.JPEG, FileType.PNG, FileType.BMP. إذا كان التنسيق المُقدم غير مدعوم فسيتم إرجاع محتوى صورة الباركود بتنسيق .png.

public FileType ReturnContentType { get; set; }
