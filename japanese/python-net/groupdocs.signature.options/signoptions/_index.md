## SignOptions class

署名オプションを表します。

詳細を見る

- See more simple examples on creating various electronic signatures with GroupDocs.Signature: https://docs.groupdocs.com/signature/net/electronic-signature-types/
- See more advanced examples of settings of various electronic signature with GroupDocs.Signature: https://docs.groupdocs.com/signature/net/signing/

SignOptions 型は次のメンバーを公開します:

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [all_pages](/signature/python-net/groupdocs.signature.options/signoptions/all_pages/) | 署名はすべての文書ページに配置されます。 |
| [appearance](/signature/python-net/groupdocs.signature.options/signoptions/appearance/) | 追加の署名外観。 |
| [document_type](/signature/python-net/groupdocs.signature.options/signoptions/document_type/) | 署名オプションの文書タイプ (`DocumentType`)。 |
| [extensions](/signature/python-net/groupdocs.signature.options/signoptions/extensions/) | 署名の拡張機能。 |
| [hash_algorithm](/signature/python-net/groupdocs.signature.options/signoptions/hash_algorithm/) | 暗号操作に使用されるハッシュアルゴリズム。PDF ファイルのデジタル署名でのみサポートされます。 |
| [page_number](/signature/python-net/groupdocs.signature.options/signoptions/page_number/) | 署名対象の文書ページ番号。 |
| [pages_setup](/signature/python-net/groupdocs.signature.options/signoptions/pages_setup/) | 署名対象ページを指定するオプション。 |
| [signature_type](/signature/python-net/groupdocs.signature.options/signoptions/signature_type/) | 署名タイプ (`SignatureType`)。 |
| [zorder](/signature/python-net/groupdocs.signature.options/signoptions/zorder/) | テキスト署名の Z オーダー位置。重なり合う署名の表示順序を決定します。 |
