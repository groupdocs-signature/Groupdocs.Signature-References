## SaveOptions class

Καθορίζει πρόσθετες επιλογές (όπως κωδικός πρόσβασης) κατά την αποθήκευση ενός εγγράφου για υπογραφή.

Ο τύπος SaveOptions εκθέτει τα ακόλουθα μέλη:
