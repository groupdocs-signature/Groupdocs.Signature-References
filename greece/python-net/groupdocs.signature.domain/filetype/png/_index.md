## PNG field

Portable Network Graphic (.png) είναι ένας τύπος μορφής αρχείου ραστερικής εικόνας που χρησιμοποιεί ασυμπίεστη συμπίεση. Αυτή η μορφή αρχείου δημιουργήθηκε ως αντικατάσταση του Graphics Interchange Format (GIF) και δεν έχει περιορισμούς πνευματικών δικαιωμάτων. Μάθετε περισσότερα για αυτή τη μορφή αρχείου εδώ.
