## SignatureSettings.IncludeStandardMetadataSignatures property

メタデータリストに、Author、Owner、作成日、更新日などの埋め込み標準ドキュメントメタデータ署名を含めるかどうかのフラグを取得または設定します。このフラグが false（既定）に設定されている場合、GetDocumentInfo はこれらのメタデータ署名を含めません。このフラグが true に設定されている場合、ドキュメント情報に標準メタデータ署名が含まれます。

```csharp
public bool IncludeStandardMetadataSignatures { get; set; }
```
