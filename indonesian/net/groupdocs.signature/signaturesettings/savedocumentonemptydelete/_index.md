## SignatureSettings.SaveDocumentOnEmptyDelete property

Mendapatkan atau mengatur flag untuk menyimpan kembali dokumen sumber ketika metode Delete tidak memiliki tanda tangan yang terpengaruh untuk dihapus. Jika flag ini diatur ke true (secara default) dokumen akan disimpan dengan log proses riwayat yang sesuai (tanggal dan jenis operasi) meskipun metode Delete tidak memiliki tanda tangan untuk dihapus. Ketika flag ini diatur ke false, dokumen sumber tidak akan diubah sama sekali.

public bool SaveDocumentOnEmptyDelete { get; set; }
