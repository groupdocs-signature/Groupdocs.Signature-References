### PageArea {#PageArea}

public static final int PageArea

Τεντώστε την περιοχή υπογραφής κατά μήκος του ύψους και του πλάτους της σελίδας. Η ιδιότητα Margin θα χρησιμοποιηθεί για την εφαρμογή των απαιτούμενων τιμών μετατόπισης.
