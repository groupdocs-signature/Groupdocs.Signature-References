## SaveOptions.OverwriteExistingFiles property

Ottiene o imposta se sovrascrivere il file esistente con il nuovo file di output. Altrimenti verrà creato un nuovo file con un numero come suffisso. Per impostazione predefinita questo valore è true, il che significa che il file verrà sovrascritto.

public bool OverwriteExistingFiles { get; set; }
