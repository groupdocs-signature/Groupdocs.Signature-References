## IAlignment class

ドキュメントページ上の署名領域の配置を説明します。

IAlignment 型は次のメンバーを公開します:

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [horizontal_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/horizontal_alignment/) | ドキュメントページ上の画像の水平配置です。 |
| [margin](/signature/python-net/groupdocs.signature.domain/ialignment/margin/) | 水平または垂直配置が設定されている場合に適用される、画像とドキュメントの端の間にデフォルトで指定されるスペースです。 |
| [margin_measure_type](/signature/python-net/groupdocs.signature.domain/ialignment/margin_measure_type/) | 余白の測定単位（ピクセル、パーセント、またはミリメートル）です。 |
| [vertical_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/vertical_alignment/) | ドキュメントページ上の画像の垂直配置です。 |
