## DOCX field

Microsoft Word Open XML Document (.docx) — известный формат документов Microsoft Word. С 2007 года, начиная с выпуска Microsoft Office 2007, структура этого нового формата документа была изменена с обычного двоичного на комбинацию XML и двоичных файлов. Узнайте больше об этом формате файла здесь.
