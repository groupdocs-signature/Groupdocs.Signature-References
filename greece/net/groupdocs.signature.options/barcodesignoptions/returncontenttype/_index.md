## BarcodeSignOptions.ReturnContentType property

Καθορίζει τον τύπο αρχείου του επιστρεφόμενου περιεχομένου εικόνας της υπογραφής Barcode όταν η ιδιότητα ReturnContent είναι ενεργοποιημένη. Από προεπιλογή ορίζεται σε Null. Αυτό σημαίνει ότι η εικόνα Barcode θα επιστραφεί στην αρχική μορφή. Αυτή η μορφή εικόνας καθορίζεται στο [`Format`](../../../groupdocs.signature.domain/barcodesignature/format). Οι πιθανές υποστηριζόμενες τιμές είναι: FileType.JPEG, FileType.PNG, FileType.BMP. Εάν η παρεχόμενη μορφή δεν υποστηρίζεται, τότε το περιεχόμενο εικόνας Barcode θα επιστραφεί σε μορφή .png.

public FileType ReturnContentType { get; set; }
