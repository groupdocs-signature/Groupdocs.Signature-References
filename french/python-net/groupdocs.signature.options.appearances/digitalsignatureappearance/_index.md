## DigitalSignatureAppearance class

Représente l'apparence d'une ligne de signature pour une signature numérique. Une seule ligne de signature peut être appliquée à une signature numérique unique, et elle est toujours placée sur la première page. Cette fonctionnalité est utile pour les formats de fichiers .docx, .doc, .odt et .xlsx.
