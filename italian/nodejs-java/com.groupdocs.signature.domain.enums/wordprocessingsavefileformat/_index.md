Definisce diversi formati di salvataggio dei file per i documenti WordProcessing.
## Campi

| Campo | Descrizione |
| --- | --- |
| [Default](#Default) | Il formato del file non verrà modificato. |
| [Doc](#Doc) | Salva il documento come documento Microsoft Word 97-2003. |
| [Dot](#Dot) | Salva il documento come modello Microsoft Word 97-2003. |
| [Docx](#Docx) | Salva il documento come documento Microsoft Word OpenXML. |
| [Docm](#Docm) | Salva il documento come documento Microsoft Word OpenXML abilitato per macro. |
| [Dotx](#Dotx) | Salva il documento come modello Microsoft Word OpenXML. |
| [Dotm](#Dotm) | Salva il documento come modello Microsoft Word OpenXML abilitato per macro. |
| [FlatOpc](#FlatOpc) | Salva il documento come Office Open XML WordprocessingML memorizzato in un file XML piatto anziché in un pacchetto ZIP. |
| [FlatOpcMacroEnabled](#FlatOpcMacroEnabled) | Salva il documento come documento Office Open XML WordprocessingML abilitato per macro memorizzato in un file XML piatto anziché in un pacchetto ZIP. |
| [FlatOpcTemplate](#FlatOpcTemplate) | Salva il documento come modello Office Open XML WordprocessingML (senza macro) memorizzato in un file XML piatto anziché in un pacchetto ZIP. |
| [FlatOpcTemplateMacroEnabled](#FlatOpcTemplateMacroEnabled) | Salva il documento come modello Office Open XML WordprocessingML abilitato per macro memorizzato in un file XML piatto anziché in un pacchetto ZIP. |
| [Rtf](#Rtf) | Salva il documento nel formato RTF. |
| [WordML](#WordML) | Salva il documento nel formato Microsoft Word 2003 WordprocessingML. |
| [Pdf](#Pdf) | Salva il documento nel formato PDF (Adobe Portable Document). |
| [Xps](#Xps) | Salva il documento nel formato XPS (XML Paper Specification). |
| [Ps](#Ps) | Salva il documento nel formato PS (PostScript). |
| [Mhtml](#Mhtml) | Salva il documento nel formato MHTML (archivio web). |
| [Epub](#Epub) | Salva il documento nel formato IDPF EPUB. |
| [Odt](#Odt) | Salva il documento come documento Open Office. |
| [Ott](#Ott) | Salva il documento come modello Open Office. |
| [Text](#Text) | Salva il documento nel formato di testo semplice. |
| [Tiff](#Tiff) | Renderizza una o più pagine del documento e le salva in un file TIFF a pagina singola o multipagina. |
| [Png](#Png) | Renderizza una pagina del documento e la salva come file PNG. |
| [Bmp](#Bmp) | Renderizza una pagina del documento e la salva come file BMP. |
| [Emf](#Emf) | Renderizza una pagina del documento e la salva come file vettoriale EMF (Enhanced Meta File). |
| [Jpeg](#Jpeg) | Renderizza una pagina del documento e la salva come file JPEG. |
| [Azw3](#Azw3) | Renderizza una pagina del documento e la salva come file Azw3. |
