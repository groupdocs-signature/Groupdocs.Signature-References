## return_content property

Флаг, указывающий, следует ли получать изображение штрихкода подписи на странице документа.

Если установить `True`, содержимое изображения подписи штрих‑кода сохраняется как необработанные данные в формате, указанном в `return_content_type`. Отключено по умолчанию.
