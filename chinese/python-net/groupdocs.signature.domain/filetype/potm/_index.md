## POTM field

PowerPoint Open XML 启用宏的演示文稿模板 (.potm) 是支持宏的 Microsoft PowerPoint 模板文件。POTM 文件由 PowerPoint 2007 或以上版本创建，包含可用于创建后续演示文件的默认设置。了解更多关于此文件格式的信息。
