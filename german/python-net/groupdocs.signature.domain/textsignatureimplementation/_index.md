## TextSignatureImplementation class

Der TextSignatureImplementation Typ stellt die folgenden Mitglieder bereit:

### Felder
| Feld | Beschreibung |
| :- | :- |
| [NATIVE](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/native/) | Textsignatur als natives Textobjekt auf der Dokumentseite. |
| [IMAGE](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/image/) | Textsignatur als Bildobjekt auf der Dokumentseite. |
| [ANNOTATION](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/annotation/) | Textsignatur als Textanmerkungsobjekt auf der PDF-Seite. Anmerkungen sind nur in der lizenzierten Version sichtbar. |
| [STICKER](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/sticker/) | Textsignatur als Aufkleberobjekt auf der PDF-Seite. |
| [FORM_FIELD](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/form_field/) | Textsignatur als Text in einem angegebenen Formularfeld. Mit diesem Implementierungstyp können nur die Optionen TextSignOptions.Text, TextSignOptions.FormTextFieldType und TextSignOptions.FormTextFieldTitle verwendet werden. |
| [WATERMARK](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/watermark/) | Textsignatur als Wasserzeichen auf der Dokumentseite. |
