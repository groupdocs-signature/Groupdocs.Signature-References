## StampTypes class

스탬프 유형에 대한 컨테이너를 나타냅니다.

StampTypes 유형은 다음 멤버를 제공합니다:

### 메서드
| 메서드 | 설명 |
| :- | :- |
| [parse](/signature/python-net/groupdocs.signature.domain/stamptypes/parse/#parsing_type) | 지정된 파싱 유형 이름과 일치하는 스탬프 유형을 반환합니다. |
| [try_parse](/signature/python-net/groupdocs.signature.domain/stamptypes/try_parse/#parsing_type) | 주어진 파싱 유형 이름에 대한 스탬프 유형을 반환합니다. 스탬프 이름을 알 수 없는 경우 예외가 발생하지 않으며 메서드는 None을 반환합니다. |
