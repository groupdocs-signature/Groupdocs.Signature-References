## form_text_field_type property

El tipo de campo de formulario en el que colocar la firma de texto. Esta propiedad es aplicable solo cuando `signature_implementation` está configurado a `TextSignatureImplementation.FORM_FIELD` (es decir, TextToFormField). El valor predeterminado es `FormTextFieldType.ALL_TEXT_TYPES`.
