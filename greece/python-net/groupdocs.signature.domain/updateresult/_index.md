## UpdateResult class

Αντιπροσωπεύει το αποτέλεσμα της τροποποίησης των υπογραφών στο έγγραφο.

Ο τύπος UpdateResult εκθέτει τα ακόλουθα μέλη:

### Ιδιότητες
| Ιδιότητα | Περιγραφή |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/updateresult/destin_document_size/) | Το μέγεθος του προορισμού εγγράφου. |
| [failed](/signature/python-net/groupdocs.signature.domain/updateresult/failed/) | Η λίστα των υπογραφών που δεν ενημερώθηκαν [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [processing_time](/signature/python-net/groupdocs.signature.domain/updateresult/processing_time/) | Ο χρόνος εκτέλεσης της διαδικασίας σε χιλιοστά του δευτερολέπτου. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/updateresult/source_document_size/) | Το μέγεθος του πηγαίου εγγράφου. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/updateresult/succeeded/) | Η λίστα των υπογραφών που τροποποιήθηκαν επιτυχώς [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/updateresult/total_signatures/) | Συνολικές επεξεργασμένες υπογραφές. |
