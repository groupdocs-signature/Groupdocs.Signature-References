## PPT field

PowerPoint-Präsentation (.ppt) stellt eine PowerPoint-Datei dar, die aus einer Sammlung von Folien für die Anzeige als Diashow besteht. Sie definiert das Binärdateiformat, das von Microsoft PowerPoint 97‑2003 verwendet wird. Erfahren Sie hier mehr über dieses Dateiformat.
