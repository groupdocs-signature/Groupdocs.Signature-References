## ProcessCompleteEventArgs class

Fornisce dati sull'evento di completamento dei processi di firma, verifica e ricerca.

Il tipo ProcessCompleteEventArgs espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [canceled](/signature/python-net/groupdocs.signature/processcompleteeventargs/canceled/) | Il processo è stato annullato. |
| [completed](/signature/python-net/groupdocs.signature/processcompleteeventargs/completed/) | Il timestamp di completamento del processo. |
| [ticks](/signature/python-net/groupdocs.signature/processcompleteeventargs/ticks/) | Il tempo in millisecondi trascorso dall'evento di avvio del processo. |
| [total_signatures](/signature/python-net/groupdocs.signature/processcompleteeventargs/total_signatures/) | Il numero totale di firme elaborate. |
| [status](/signature/python-net/groupdocs.signature/processeventargs/status/) | Lo stato attuale del processo. (eredita da [`ProcessEventArgs`](/signature/python-net/groupdocs.signature/processeventargs/)) |
