## SwissQR.Reference property

获取或设置债权人付款参考。对于 SwissQR IBAN（即 CHxx30000xxxxxx 至 CHxx31999xxxxx 范围内的 IBAN），此参考是必填的。如果提供，参考必须是有效的 SwissQR 参考（对应 ISR 参考表单）或符合 ISO 11649 的有效债权人参考（"RFxxxx"）。两者均可包含空格用于格式化。

```csharp
public string Reference { get; set; }
```

### Property Value

债权人付款参考。
