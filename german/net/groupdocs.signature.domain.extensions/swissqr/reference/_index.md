## SwissQR.Reference property

Liest oder setzt die Zahlungsreferenz des Gläubigers. Die Referenz ist für SwissQR‑IBANs verpflichtend, d. h. für IBANs im Bereich CHxx30000xxxxxx bis CHxx31999xxxxx. Ist sie angegeben, muss die Referenz entweder eine gültige SwissQR‑Referenz (entsprechend dem ISR‑Referenzformat) oder eine gültige Gläubigerreferenz gemäß ISO 11649 ("RFxxxx") sein. Beide können zur Formatierung Leerzeichen enthalten.

```csharp
public string Reference { get; set; }
```

### Property Value

Die Gläubigerzahlungsreferenz.
