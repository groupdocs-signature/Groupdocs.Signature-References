## min_content_size property

De minimale grootte van afbeeldingsgegevens, in bytes, die tijdens een zoekopdracht in aanmerking wordt genomen. Een niet‑nulwaarde geeft de minimale grootte aan; de standaard is nul, wat geen effect heeft op het zoekresultaat.
