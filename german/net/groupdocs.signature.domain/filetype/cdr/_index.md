## FileType.CDR field

CorelDraw Vector Graphic Drawing (.cdr) ist eine Vektorgrafik-Datei, die nativ mit CorelDRAW erstellt wird, um digitale, codierte und komprimierte Bilder zu speichern. Eine solche Zeichnungsdatei enthält Text, Linien, Formen, Bilder, Farben und Effekte für die vektorbasierte Darstellung von Bildinhalten. Weitere Informationen zu diesem Dateiformat finden Sie [hier](https://wiki.fileformat.com/image/cdr).
