## DOCX field

Le document Open XML Microsoft Word (.docx) est un format bien connu pour les documents Microsoft Word. Introduit à partir de 2007 avec la sortie de Microsoft Office 2007, la structure de ce nouveau format de document est passée du binaire simple à une combinaison de fichiers XML et binaires. En savoir plus sur ce format de fichier ici.
