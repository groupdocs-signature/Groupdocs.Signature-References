## QrCodeSearchOptions.ReturnContentType property

Указывает тип файла возвращаемого содержимого изображения подписи QR‑Code, когда свойство ReturnContent включено. По умолчанию установлено Null. Это означает возвращать содержимое изображения QR‑Code в оригинальном формате. Этот формат изображения указан в [`Format`](../../../groupdocs.signature.domain/qrcodesignature/format). Возможные поддерживаемые значения: FileType.JPEG, FileType.PNG, FileType.BMP. Если указанный формат не поддерживается, будет возвращено содержимое изображения QR‑Code в оригинальном .png.

public FileType ReturnContentType { get; set; }
