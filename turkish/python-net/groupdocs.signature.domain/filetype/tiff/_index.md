## TIFF field

Tagged Image File Format (.tiff), bu dosya formatı standardına uyan çeşitli cihazlarda kullanılmak üzere tasarlanmış raster görüntüleri temsil eder. Birçok renk uzayında iki seviyeli, gri tonlamalı, palet renkli ve tam renkli görüntü verilerini tanımlayabilir. Bu dosya formatı hakkında daha fazla bilgi edinin burada.
