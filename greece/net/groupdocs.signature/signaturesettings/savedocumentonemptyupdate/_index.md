## SignatureSettings.SaveDocumentOnEmptyUpdate property

Λαμβάνει ή ορίζει τη σημαία για επαναποθήκευση του πηγαίου εγγράφου όταν η μέθοδος Update δεν έχει υπογραφές για ενημέρωση. Εάν αυτή η σημαία οριστεί σε true (προεπιλογή), το έγγραφο θα αποθηκεύεται με το αντίστοιχο ιστορικό καταγραφής διαδικασίας (ημερομηνία και τύπος λειτουργίας) ακόμη και αν η μέθοδος Update δεν έχει υπογραφές για ενημέρωση. Όταν αυτή η σημαία οριστεί σε false, το πηγαίο έγγραφο δεν θα τροποποιηθεί καθόλου.

```csharp
public bool SaveDocumentOnEmptyUpdate { get; set; }
```
