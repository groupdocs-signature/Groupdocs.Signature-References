## MetadataSignOptions.DataEncryption property

Obtient ou définit l'implémentation de l'interface [`IDataEncryption`](../../../groupdocs.signature.domain.extensions/idataencryption) pour chiffrer toutes les signatures Metadata au sein de cette collection d'options. Si cette valeur est définie, toutes les signatures ajoutées utiliseront ce chiffrement par défaut ou leur propre DataEncryption si elle a été assignée.
