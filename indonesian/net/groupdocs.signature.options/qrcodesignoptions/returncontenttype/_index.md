## QrCodeSignOptions.ReturnContentType property

Menentukan jenis file dari konten gambar yang dikembalikan untuk tanda tangan QR-Code ketika properti ReturnContent diaktifkan. Secara default disetel ke Null. Itu berarti mengembalikan konten gambar QR-Code dalam format asli. Format gambar ini ditentukan di [`Format`](../../../groupdocs.signature.domain/qrcodesignature/format). Nilai yang didukung antara lain: FileType.JPEG, FileType.PNG, FileType.BMP. Jika format yang diberikan tidak didukung, maka konten gambar QR-Code akan dikembalikan dalam format .png.
