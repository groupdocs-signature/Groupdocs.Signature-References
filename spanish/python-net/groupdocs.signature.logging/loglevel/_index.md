## LogLevel class

El tipo LogLevel expone los siguientes miembros:

### Campos
| Campo | Descripción |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.logging/loglevel/none/) | No se registra nada. |
| [ERROR](/signature/python-net/groupdocs.signature.logging/loglevel/error/) | Errores: una operación falló. |
| [WARNING](/signature/python-net/groupdocs.signature.logging/loglevel/warning/) | Advertencias: una operación tuvo éxito, pero su resultado puede no ser lo que esperas. |
| [TRACE](/signature/python-net/groupdocs.signature.logging/loglevel/trace/) | Trazas: los pasos de una operación, como su inicio y su fin. |
| [ALL](/signature/python-net/groupdocs.signature.logging/loglevel/all/) | Errores, advertencias y trazas. Este es el predeterminado. |
