## SearchOptions class

Bir belgeden imzaları çıkarmak için seçenekleri temsil eder.

Daha fazla bilgi edinin

- See more simple examples on searching for various electronic signatures with GroupDocs.Signature: https://docs.groupdocs.com/signature/net/search-for-electronic-signatures-in-document/
- See more advanced examples of searching for various electronic signature with GroupDocs.Signature: https://docs.groupdocs.com/signature/net/searching/

SearchOptions türü aşağıdaki üyeleri gösterir:

### Özellikler
| Özellik | Açıklama |
| :- | :- |
| [all_pages](/signature/python-net/groupdocs.signature.options/searchoptions/all_pages/) | Her belge sayfasında arama yapılıp yapılmayacağını gösteren bayrak. Varsayılan olarak bu değer True'dur. |
| [page_number](/signature/python-net/groupdocs.signature.options/searchoptions/page_number/) | Arama için belge sayfa numarası (isteğe bağlı). |
| [pages_setup](/signature/python-net/groupdocs.signature.options/searchoptions/pages_setup/) | İmza araması için sayfaları belirtme seçenekleri. |
| [shape_position](/signature/python-net/groupdocs.signature.options/searchoptions/shape_position/) | Belge düzeninde şekil konumunun döndürülüp döndürülmeyeceğini gösteren bayrak. Yalnızca Word belgeleri için kullanılabilir. |
| [skip_external](/signature/python-net/groupdocs.signature.options/searchoptions/skip_external/) | Yalnızca `IsSignature` olarak işaretlenmiş imzaları döndürmek için bayrak. Varsayılan değer `False`'dur; bu, belirtilen kriterlere uyan tüm imzaların döndürüleceği anlamına gelir. |
