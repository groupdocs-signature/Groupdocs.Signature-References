## MetadataSearchOptions.DataEncryption property

Obtiene o establece la implementación de la interfaz [`IDataEncryption`](../../../groupdocs.signature.domain.extensions/idataencryption) para descifrar todas las firmas de Metadatos dentro de esta colección de opciones. Si este valor se establece, todas las firmas encontradas usarán este cifrado por defecto o su propio DataEncryption si fue asignado.
