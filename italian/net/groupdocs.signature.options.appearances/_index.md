Il namespace fornisce classi per aspetti aggiuntivi delle firme.

## Classi

| Classe | Descrizione |
| --- | --- |
| [DigitalSignatureAppearance](./digitalsignatureappearance) | Descrive l'aspetto della linea di firma per la firma digitale. Una linea di firma può essere applicata solo a una firma digitale. La linea di firma è sempre sulla prima pagina. Questa funzionalità può essere utile per i formati di file .docx, .doc, .odt e .xlsx. |
| [ImageAppearance](./imageappearance) | Descrive le funzionalità di aspetto esteso per la firma immagine. |
| [PdfDigitalSignatureAppearance](./pdfdigitalsignatureappearance) | Descrive l'aspetto della firma digitale nei documenti PDF. |
| [PdfTextAnnotationAppearance](./pdftextannotationappearance) | Descrive l'aspetto dell'oggetto di annotazione testuale PDF (Titolo, Soggetto, Contenuto). |
| [PdfTextStickerAppearance](./pdftextstickerappearance) | Descrive l'aspetto dell'oggetto adesivo di annotazione testuale PDF e della finestra pop-up dell'adesivo. |
| [SignatureAppearance](./signatureappearance) | Rappresenta l'aspetto della firma - opzioni aggiuntive per implementazioni alternative della firma sulla pagina del documento. |
