## ImageAppearance class

Representa características de apariencia extendidas para una firma de imagen.

El tipo ImageAppearance expone los siguientes miembros:

| :- | :- |

| Propiedad | Descripción |
| :- | :- |
| [brightness](/signature/python-net/groupdocs.signature.options.appearances/imageappearance/brightness/) | El brillo de la imagen, con un valor predeterminado de 1 que corresponde al brillo original de la imagen. |
| [contrast](/signature/python-net/groupdocs.signature.options.appearances/imageappearance/contrast/) | El contraste de la imagen. El valor predeterminado es 1, que corresponde al contraste original de la imagen. |
