## PPTX field

PowerPoint Open XML Präsentation (.pptx) sind Präsentationsdateien, die mit der beliebten Microsoft PowerPoint‑Anwendung erstellt werden. Im Gegensatz zur vorherigen Version des Präsentationsdateiformats PPT, das binär war, basiert das PPTX‑Format auf dem Microsoft PowerPoint Open XML‑Präsentationsdateiformat. Erfahren Sie hier mehr über dieses Dateiformat.
