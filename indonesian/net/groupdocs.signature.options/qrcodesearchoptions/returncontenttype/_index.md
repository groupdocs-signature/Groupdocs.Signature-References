## QrCodeSearchOptions.ReturnContentType property

Menentukan tipe file dari konten gambar yang dikembalikan untuk tanda tangan QR-Code ketika properti ReturnContent diaktifkan. Secara default nilainya diatur ke Null. Artinya akan mengembalikan konten gambar QR-Code dalam format asli. Format gambar ini ditentukan di [`Format`](../../../groupdocs.signature.domain/qrcodesignature/format). Nilai yang didukung antara lain: FileType.JPEG, FileType.PNG, FileType.BMP. Jika format yang diberikan tidak didukung, maka konten gambar QR-Code dalam format .png asli akan dikembalikan.

public FileType ReturnContentType { get; set; }
