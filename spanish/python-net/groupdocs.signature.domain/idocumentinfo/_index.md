## IDocumentInfo class

Las propiedades de descripción del documento.

El tipo IDocumentInfo expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [barcode_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/barcode_signatures/) | La colección de firmas de código de barras del documento añadidas o actualizadas por los métodos [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [digital_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/digital_signatures/) | La colección de firmas digitales del documento añadidas o actualizadas por los métodos [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [documents](/signature/python-net/groupdocs.signature.domain/idocumentinfo/documents/) | La colección de todos los documentos existentes dentro de los archivos de archivo. Esta propiedad solo es compatible con tipos de documentos de archivo. |
| [file_type](/signature/python-net/groupdocs.signature.domain/idocumentinfo/file_type/) | El tipo de formato de archivo. |
| [form_field_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/form_field_signatures/) | La colección de firmas de campos de formulario del documento añadidas o actualizadas por los métodos [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [form_fields](/signature/python-net/groupdocs.signature.domain/idocumentinfo/form_fields/) | La colección de todos los campos de formulario compatibles existentes en el documento. Esta propiedad solo es compatible con tipos de documentos PDF y de procesamiento de texto. |
| [image_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/image_signatures/) | La colección de firmas de imagen del documento añadidas o actualizadas por los métodos [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [max_page_height](/signature/python-net/groupdocs.signature.domain/idocumentinfo/max_page_height/) | La altura máxima de página. |
| [metadata_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/metadata_signatures/) | La colección de firmas de metadatos del documento. |
| [page_count](/signature/python-net/groupdocs.signature.domain/idocumentinfo/page_count/) | El recuento de páginas del documento. |
| [pages](/signature/python-net/groupdocs.signature.domain/idocumentinfo/pages/) | La colección de descripciones de páginas del documento. |
| [process_logs](/signature/python-net/groupdocs.signature.domain/idocumentinfo/process_logs/) | La colección de registros de proceso del historial del documento. |
| [qr_code_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/qr_code_signatures/) | La colección de firmas de códigos QR del documento añadidas o actualizadas por los métodos [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/signatures/) | La colección de todos los tipos de firmas presentes en el documento como objetos [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [size](/signature/python-net/groupdocs.signature.domain/idocumentinfo/size/) | El tamaño del documento en bytes. |
| [text_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/text_signatures/) | La colección de firmas de texto del documento añadidas o actualizadas por los métodos [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [width_for_max_height](/signature/python-net/groupdocs.signature.domain/idocumentinfo/width_for_max_height/) | El ancho para la altura máxima de la página. |
