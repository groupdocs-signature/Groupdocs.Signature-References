## PdfTextStickerVerifyExtensions class

Παρέχει επεκτάσεις για την επαλήθευση αντικειμένων αυτοκόλλητου PDF.

Ο τύπος PdfTextStickerVerifyExtensions εκθέτει τα ακόλουθα μέλη:

| Κατασκευαστής | Περιγραφή |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.options/pdftextstickerverifyextensions/__init__/) | Αρχικοποιεί τις επεκτάσεις επαλήθευσης υπογραφής αυτοκόλλητου κειμένου PDF με κενές τιμές. |
