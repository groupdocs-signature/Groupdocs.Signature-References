## name property

Le modèle d'expression régulière utilisé pour faire correspondre le nom d'une signature de champ de formulaire lors de la recherche.

Il peut s'agir d'un littéral simple tel que \"text\" ou d'une expression régulière comme \"abc\\d+\". La valeur par défaut est une chaîne vide.
