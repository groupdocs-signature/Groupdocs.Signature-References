## APNG field

Animated Portable Network Graphics (.png) är ett rasterbildfilformat som använder förlustfri komprimering. Det utvecklades som en utökning av PNG för att stödja animation, och fungerar som ett alternativ till GIF-formatet utan upphovsrättsliga begränsningar. Läs mer om detta filformat här.
