## BarcodeSearchOptions.ReturnContentType property

ReturnContent プロパティが有効な場合のバーコード署名の返却画像コンテンツのファイルタイプを指定します。デフォルトは Null に設定されており、これはバーコード画像コンテンツを元の形式で返すことを意味します。この画像形式は [`Format`](../../../groupdocs.signature.domain/barcodesignature/format) で指定されます。サポートされる可能な値は: FileType.JPEG、FileType.PNG、FileType.BMP です。指定された形式がサポートされていない場合、バーコード画像コンテンツは .png 形式で返されます。

public FileType ReturnContentType { get; set; }
