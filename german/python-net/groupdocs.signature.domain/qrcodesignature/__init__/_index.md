## __init__ {#signature_id}

Initialisiert ein QrCodeSignature‑Objekt mit einer Signatur‑Kennung, die nach einem Suchvorgang erhalten wurde.

Der eindeutige Bezeichner wird verwendet, um zusätzliche Eigenschaften für diese Signatur aus der Signatur-Informationsschicht des Dokuments abzurufen.

```python
def __init__(self, signature_id):
    ...
```

| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| signature_id | `str` | Einzigartige Signatur-Kennung, die durch die Signatur- oder Suchmethode erhalten wird. |
