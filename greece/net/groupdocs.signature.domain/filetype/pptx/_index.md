## FileType.PPTX field

Οι παρουσιάσεις PowerPoint Open XML (.pptx) είναι αρχεία παρουσίασης που δημιουργούνται με τη δημοφιλή εφαρμογή Microsoft PowerPoint. Σε αντίθεση με την προηγούμενη έκδοση του μορφότυπου αρχείου παρουσίασης PPT που ήταν δυαδική, η μορφή PPTX βασίζεται στο ανοιχτό XML μορφότυπο αρχείου παρουσίασης του Microsoft PowerPoint. Μάθετε περισσότερα για αυτό το μορφότυπο αρχείου [εδώ](https://wiki.fileformat.com/presentation/pptx).
