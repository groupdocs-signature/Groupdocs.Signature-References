## SignResult class

Représente le résultat du processus de signature d'un document avec des signatures nouvellement créées.

Le type SignResult expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/signresult/destin_document_size/) | La taille du document de destination. |
| [failed](/signature/python-net/groupdocs.signature.domain/signresult/failed/) | La liste des signatures qui n'ont pas pu être créées. |
| [processing_time](/signature/python-net/groupdocs.signature.domain/signresult/processing_time/) | Le temps d'exécution du processus en millisecondes. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/signresult/source_document_size/) | La taille du document source. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/signresult/succeeded/) | La liste des signatures nouvellement créées [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/signresult/total_signatures/) | Le total des signatures traitées. |
