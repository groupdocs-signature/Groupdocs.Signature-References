## SignatureSettings.SaveDocumentOnEmptyDelete property

削除メソッドで削除対象の署名がない場合に、ソースドキュメントを再保存するかどうかのフラグを取得または設定します。このフラグが true（既定）に設定されている場合、削除対象がなくても履歴プロセスログ（日時と操作種別）とともにドキュメントが保存されます。このフラグが false に設定されている場合、ソースドキュメントは一切変更されません。

public bool SaveDocumentOnEmptyDelete { get; set; }
