## Permissions class

Le type Permissions expose les membres suivants :

### Champs
| Champ | Description |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.options/permissions/none/) | Autoriser toutes les actions, y compris l'impression, la modification et l'extraction de données. |
| [DENY_PRINTING](/signature/python-net/groupdocs.signature.options/permissions/deny_printing/) | Refuser l'impression du document. |

| [DENY_ALL](/signature/python-net/groupdocs.signature.options/permissions/deny_all/) | Refuser toutes les actions, y compris l'impression, la modification et l'extraction de données. |
