## SignResult class

Stellt das Ergebnis des Signaturvorgangs für ein Dokument mit neu erstellten Unterschriften dar.

Der Typ SignResult stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/signresult/destin_document_size/) | Die Größe des Zieldokuments. |
| [failed](/signature/python-net/groupdocs.signature.domain/signresult/failed/) | Die Liste der Signaturen, die nicht erstellt werden konnten. |
| [processing_time](/signature/python-net/groupdocs.signature.domain/signresult/processing_time/) | Die Ausführungszeit des Prozesses in Millisekunden. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/signresult/source_document_size/) | Die Größe des Quelldokuments. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/signresult/succeeded/) | Die Liste der neu erstellten Signaturen [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/signresult/total_signatures/) | Die insgesamt verarbeiteten Signaturen. |
