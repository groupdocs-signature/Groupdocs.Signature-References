## SaveOptions class

يحدد خيارات إضافية (مثل كلمة المرور) عند حفظ مستند للتوقيع.

نوع SaveOptions يعرض الأعضاء التالية:

### المُنشئات
| المُنشئ | الوصف |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.options/saveoptions/__init__/) | ينشئ مثيلًا جديدًا من فئة SaveOptions بالقيم الافتراضية. |
| [__init__](/signature/python-net/groupdocs.signature.options/saveoptions/__init__/#overwrite_existing_file) | ينشئ مثيلًا جديدًا من فئة SaveOptions بنوع الإخراج المحدد وعلمية الاستبدال. |

### الخصائص
| خاصية | الوصف |
| :- | :- |
| [add_missing_extenstion](/signature/python-net/groupdocs.signature.options/saveoptions/add_missing_extenstion/) | العلم الذي يحدد ما إذا كان يجب إضافة امتداد تلقائيًا عندما يكون مفقودًا في مسار ملف الإخراج. القيمة الافتراضية هي False. |
| [overwrite_existing_files](/signature/python-net/groupdocs.signature.options/saveoptions/overwrite_existing_files/) | العلم الذي يشير إلى ما إذا كان يجب استبدال ملف موجود بالملف الناتج الجديد. |
| [password](/signature/python-net/groupdocs.signature.options/saveoptions/password/) | كلمة المرور المستخدمة لحماية المستند الموقع المحفوظ. غير مدعومة للمستندات من نوع صورة. |
| [use_original_password](/signature/python-net/groupdocs.signature.options/saveoptions/use_original_password/) | العلم الذي يحدد ما إذا كان يجب استخدام كلمة المرور من [`LoadOptions`](/signature/python-net/groupdocs.signature.options/loadoptions/) عند حفظ المستند الموقع كحماية. القيمة الافتراضية هي True. غير مدعومة للمستندات من نوع صورة. |
