## StretchMode enumeration

Représente le mode d'étirement de la zone de signature sur une page de document.

```csharp
public enum StretchMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Valeur par défaut. Aucun mode d'étirement ne sera appliqué. |
| PageWidth | `1` | Étendre la zone de signature le long de la largeur de la page. La propriété Margin sera utilisée pour appliquer les valeurs de décalage requises |
| PageHeight | `2` | Étendre la zone de signature le long de la hauteur de la page. La propriété Margin sera utilisée pour appliquer les valeurs de décalage requises. |
| PageArea | `3` | Étirez la zone de signature le long de la hauteur et de la largeur de la page. La propriété Margin sera utilisée pour appliquer les valeurs de décalage requises. |
