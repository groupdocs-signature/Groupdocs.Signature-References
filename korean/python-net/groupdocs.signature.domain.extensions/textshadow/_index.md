## TextShadow class

텍스트 서명에 대한 텍스트 그림자 속성을 나타냅니다.

결과는 서명 유형 및 문서 형식에 따라 달라질 수 있습니다.

TextShadow는 모든 지원되는 문서 유형에 대해 `TextAsImage` 서명과 함께 사용할 것을 권장하며, 간단한 [`TextSignature`](/signature/python-net/groupdocs.signature.domain/textsignature/) 및 [`TextSignature`](/signature/python-net/groupdocs.signature.domain/textsignature/)를 워터마크로 사용하여 스프레드시트(`.xslx`)와 프레젠테이션(`.pptx`)에 적용할 수 있습니다.

간단한 [`TextSignature`](/signature/python-net/groupdocs.signature.domain/textsignature/)는 Word 문서 (`.docx`)에 대해 권장되지만 기능이 제한적입니다.

TextShadow 유형은 다음 멤버를 노출합니다:

### 생성자
| 생성자 | 설명 |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/__init__/) | TextShadow를 기본 옵션으로 초기화합니다. |

### 메서드
| 메서드 | 설명 |

### 속성
| 속성 | 설명 |
| :- | :- |
| [angle](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/angle/) | 텍스트에 대한 그림자 배치 각도입니다. 기본값은 0입니다. |
| [blur](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/blur/) | 그림자의 흐림 정도입니다. 기본값은 4입니다. |
| [color](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/color/) | 그림자의 색상입니다. 기본값은 검정색입니다. |
| [distance](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/distance/) | 텍스트와 그림자 사이의 거리입니다. |
| [transparency](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/transparency/) | 그림자의 투명도입니다. |
