## TIFF field

Il Tagged Image File Format (.tiff) rappresenta immagini raster destinate all'uso su una varietà di dispositivi che rispettano questo standard di formato file. È in grado di descrivere dati immagine a due livelli, in scala di grigi, a colori con palette e a colori completi in diversi spazi colore. Scopri di più su questo formato file qui.
