## SignatureSettings.SaveDocumentOnEmptyDelete property

Obtient ou définit le drapeau permettant de resauvegarder le document source lorsque la méthode Delete n'a aucune signature affectée à supprimer. Si ce drapeau est défini sur true (par défaut), le document sera enregistré avec le journal du processus d'historique correspondant (date et type d'opération) même si la méthode Delete n'a aucune signature à supprimer. Lorsque ce flat est défini sur false, le document source ne sera pas modifié du tout.
