Der **GroupDocs.Signature**-Namespace stellt Klassen zum Signieren von Dokumenten verschiedener Formate mit Stempeln, Barcodes, QR-Codes, Text, Bild, Metadaten, Formularfeldern und digitalen Signaturen bereit.


## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [Signature](../com.groupdocs.signature/signature) | Stellt die Hauptklasse dar, die den Dokumentensignaturprozess steuert. |
| [SignatureSettings](../com.groupdocs.signature/signaturesettings) | Definiert Einstellungen zur Anpassung des Verhaltens von [Signature](../com.groupdocs.signature/signature). |
