## return_content property

Das Flag, das angibt, ob der Barcode-Bildinhalt einer Signatur auf einer Dokumentseite abgerufen werden soll.

Wenn auf `True` gesetzt, wird der Bildinhalt der Barcode‑Signatur als Rohbilddaten im von `return_content_type` angegebenen Format beibehalten. Standardmäßig deaktiviert.
