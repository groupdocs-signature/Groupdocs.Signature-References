Haupt-GroupDocs.Signature-Namespace mit API-Klassen auf oberster Ebene.

### Klassen
| Klasse | Beschreibung |
| :- | :- |
| [`License`](/signature/python-net/groupdocs.signature/license/) | Verwaltet die Lizenzierung von GroupDocs.Signature. |
| [`Metered`](/signature/python-net/groupdocs.signature/metered/) | Verwaltet die nutzungsbasierte (Pay-per-Use) Lizenzierung. |
| [`ProcessCompleteEventArgs`](/signature/python-net/groupdocs.signature/processcompleteeventargs/) | Stellt Daten zum Abschlussereignis von Signatur-, Verifizierungs- und Suchvorgängen bereit. |
| [`ProcessCompleteEventHandler`](/signature/python-net/groupdocs.signature/processcompleteeventhandler/) | Stellt einen Methodendelegaten dar, der Abschlussereignisse für Signatur, Verifizierung und Suche verarbeitet. |
| [`ProcessEventArgs`](/signature/python-net/groupdocs.signature/processeventargs/) | Stellt Daten für verschiedene Ereignisse von Signatur-, Verifizierungs- und Suchvorgängen bereit. |
| [`ProcessProgressEventArgs`](/signature/python-net/groupdocs.signature/processprogresseventargs/) | Stellt Daten für das OnProgress-Ereignis von Signatur-, Verifizierungs- und Suchvorgängen bereit. |
| [`ProcessProgressEventHandler`](/signature/python-net/groupdocs.signature/processprogresseventhandler/) | Stellt einen Methodendelegaten dar, der Fortschrittsereignisse für das Signieren, die Verifizierung und die Suche verarbeitet. |
| [`ProcessStartEventArgs`](/signature/python-net/groupdocs.signature/processstarteventargs/) | Stellt Daten für das Startereignis der Signier-, Verifizierungs- und Suchvorgänge bereit. |
| [`ProcessStartEventHandler`](/signature/python-net/groupdocs.signature/processstarteventhandler/) | Stellt einen Methodendelegaten dar, der Startereignisse des Prozesses für das Signieren, die Verifizierung und die Suche verarbeitet. |
| [`Signature`](/signature/python-net/groupdocs.signature/signature/) | Stellt die Hauptklasse dar, die den Dokumenten‑Signaturprozess steuert. |
| [`SignatureSettings`](/signature/python-net/groupdocs.signature/signaturesettings/) | Stellt Einstellungen zur Anpassung des Verhaltens von [`Signature`](/signature/python-net/groupdocs.signature/signature/) dar. |

| [`IncorrectPasswordException`](/signature/python-net/groupdocs.signature/incorrectpasswordexception/) | Die Ausnahme, die ausgelöst wird, wenn das angegebene Passwort inkorrekt ist. |
