## StampTypes class

スタンプタイプのコンテナを表します。

StampTypes タイプは次のメンバーを公開します:

### メソッド
| メソッド | 説明 |
| :- | :- |
| [parse](/signature/python-net/groupdocs.signature.domain/stamptypes/parse/#parsing_type) | 指定されたパース タイプ名に一致するスタンプ タイプを返します。 |
| [try_parse](/signature/python-net/groupdocs.signature.domain/stamptypes/try_parse/#parsing_type) | 指定されたパース タイプ名に対するスタンプ タイプを返します。スタンプ名が不明な場合、例外はスローされず、メソッドは None を返します。 |

### フィールド
| フィールド | 説明 |
| :- | :- |
| [ALL_TYPES](/signature/python-net/groupdocs.signature.domain/stamptypes/all_types/) | すべてのスタンプ タイプ。 |
| [ROUND](/signature/python-net/groupdocs.signature.domain/stamptypes/round/) | 丸形スタンプ タイプ オブジェクト。 |
| [SQUARE](/signature/python-net/groupdocs.signature.domain/stamptypes/square/) | 四角形スタンプ タイプ オブジェクト。 |
