## LoadOptions.WhitelistedResources property

Gets or sets fragments of addresses of external resources that are loaded even when [`SkipExternalResources`](../skipexternalresources) is true. The default value is an empty list.

```csharp
public List<string> WhitelistedResources { get; set; }
```

### Remarks

A resource is loaded when its full address contains one of the fragments. The comparison ignores case, and empty fragments are ignored. Prefer long fragments such as "https://cdn.example.com/images/": a short fragment also matches other addresses that happen to contain it.

Setting this property to null clears the list. The list has no effect when [`SkipExternalResources`](../skipexternalresources) is false, because then every external resource is loaded.
