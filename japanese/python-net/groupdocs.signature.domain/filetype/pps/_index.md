## PPS field

PowerPoint Slide Show (.pps) は、スライドショー目的で Microsoft PowerPoint を使用して作成されます。PPS ファイルの読み取りおよび作成は Microsoft PowerPoint 97-2003 に対応しています。このファイル形式の詳細については、こちらをご覧ください。
