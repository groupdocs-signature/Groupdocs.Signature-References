## FormFieldSearchOptions.Name property

Spécifie le modèle d'expression régulière du nom de la signature de champ de formulaire s'il doit être recherché. Vous pouvez l'utiliser simplement comme \"text\" ou une expression régulière comme \"abc\\\\d+\". La valeur par défaut est une chaîne vide.
