## PNG field

Portable Network Graphic（.png）は、ロスレス圧縮を使用するラスタ画像ファイル形式です。このファイル形式は、Graphics Interchange Format（GIF）の代替として作成され、著作権制限がありません。こちらでこのファイル形式の詳細をご覧ください。
