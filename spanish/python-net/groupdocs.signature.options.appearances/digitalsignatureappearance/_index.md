## DigitalSignatureAppearance class

Representa la apariencia de una línea de firma para una firma digital. Sólo se puede aplicar una línea de firma a una firma digital única, y siempre se coloca en la primera página. Esta característica es útil para los formatos de archivo .docx, .doc, .odt y .xlsx.
