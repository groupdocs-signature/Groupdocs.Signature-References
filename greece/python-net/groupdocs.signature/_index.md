Κύριος ονοματικός χώρος GroupDocs.Signature με κλάσεις API υψηλού επιπέδου.

### Κλάσεις
| Κλάση | Περιγραφή |
| :- | :- |
| [`License`](/signature/python-net/groupdocs.signature/license/) | Διαχειρίζεται την άδεια χρήσης του GroupDocs.Signature. |
| [`Metered`](/signature/python-net/groupdocs.signature/metered/) | Διαχειρίζεται τη μετρημένη (πληρωμή ανά χρήση) άδεια. |
| [`ProcessCompleteEventArgs`](/signature/python-net/groupdocs.signature/processcompleteeventargs/) | Παρέχει δεδομένα για το πλήρες γεγονός των διαδικασιών υπογραφής, επαλήθευσης και αναζήτησης. |
| [`ProcessCompleteEventHandler`](/signature/python-net/groupdocs.signature/processcompleteeventhandler/) | Αντιπροσωπεύει έναν delegate μεθόδου που διαχειρίζεται τα γεγονότα ολοκλήρωσης διαδικασιών για υπογραφή, επαλήθευση και αναζήτηση. |
| [`ProcessEventArgs`](/signature/python-net/groupdocs.signature/processeventargs/) | Παρέχει δεδομένα για διαφορετικά γεγονότα των διαδικασιών υπογραφής, επαλήθευσης και αναζήτησης. |
| [`ProcessProgressEventArgs`](/signature/python-net/groupdocs.signature/processprogresseventargs/) | Παρέχει δεδομένα για το γεγονός OnProgress των διαδικασιών υπογραφής, επαλήθευσης και αναζήτησης. |
| [`ProcessProgressEventHandler`](/signature/python-net/groupdocs.signature/processprogresseventhandler/) | Αντιπροσωπεύει έναν delegate μεθόδου που διαχειρίζεται τα γεγονότα προόδου για υπογραφή, επαλήθευση και αναζήτηση. |
| [`ProcessStartEventArgs`](/signature/python-net/groupdocs.signature/processstarteventargs/) | Παρέχει δεδομένα για το γεγονός έναρξης των διαδικασιών υπογραφής, επαλήθευσης και αναζήτησης. |
| [`ProcessStartEventHandler`](/signature/python-net/groupdocs.signature/processstarteventhandler/) | Αντιπροσωπεύει έναν delegate μεθόδου που διαχειρίζεται τα γεγονότα έναρξης διαδικασίας για υπογραφή, επαλήθευση και αναζήτηση. |
| [`Signature`](/signature/python-net/groupdocs.signature/signature/) | Αντιπροσωπεύει την κύρια κλάση που ελέγχει τη διαδικασία υπογραφής εγγράφων. |
| [`SignatureSettings`](/signature/python-net/groupdocs.signature/signaturesettings/) | Αντιπροσωπεύει τις ρυθμίσεις για την προσαρμογή της συμπεριφοράς του [`Signature`](/signature/python-net/groupdocs.signature/signature/). |

### Εξαιρέσεις
| Εξαίρεση | Περιγραφή |
| :- | :- |
| [`GroupDocsSignatureException`](/signature/python-net/groupdocs.signature/groupdocssignatureexception/) | Αντιπροσωπεύει τα γενικά σφάλματα που συμβαίνουν κατά την επεξεργασία εγγράφων. |
| [`IncorrectPasswordException`](/signature/python-net/groupdocs.signature/incorrectpasswordexception/) | Η εξαίρεση που εκτοξεύεται όταν ο καθορισμένος κωδικός πρόσβασης είναι λανθασμένος. |
| [`PasswordRequiredException`](/signature/python-net/groupdocs.signature/passwordrequiredexception/) | Η εξαίρεση που εκτοξεύεται όταν απαιτείται κωδικός πρόσβασης για τη φόρτωση του εγγράφου. |
