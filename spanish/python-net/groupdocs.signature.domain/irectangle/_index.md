## IRectangle class

Define propiedades de interfaz para el área de firma en una página del documento.

El tipo IRectangle expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [height](/signature/python-net/groupdocs.signature.domain/irectangle/height/) | La altura del área de firma en una página de documento en unidades de medida (píxeles, porcentajes o milímetros; vea `MeasureType` SizeMeasureType). |
| [left](/signature/python-net/groupdocs.signature.domain/irectangle/left/) | La posición X izquierda del área de firma en una página de documento en unidades de medida (píxeles, porcentajes o milímetros). Vea `MeasureType` para la enumeración `LocationMeasureType`. |
| [location_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/location_measure_type/) | El tipo de medida (píxeles, porcentajes o milímetros) para las propiedades Left y Top. |
| [size_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/size_measure_type/) | El tipo de medida (píxeles, porcentajes o milímetros) para las propiedades Width y Height. |
| [stretch](/signature/python-net/groupdocs.signature.domain/irectangle/stretch/) | El modo de estiramiento en una página de documento. |
| [top](/signature/python-net/groupdocs.signature.domain/irectangle/top/) | La posición Y superior del área de firma en la página del documento en unidades de medida (píxeles, porcentajes o milímetros). Consulte `MeasureType` para el tipo de medida de ubicación. |
| [width](/signature/python-net/groupdocs.signature.domain/irectangle/width/) | El ancho del área de firma en una página de documento en valores de medida (píxeles, porcentajes o milímetros). Consulte `MeasureType` SizeMeasureType. |
