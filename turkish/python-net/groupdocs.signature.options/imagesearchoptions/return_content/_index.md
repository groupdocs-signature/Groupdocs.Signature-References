## return_content property

İmzanın görüntü içeriğinin döndürülüp döndürülmeyeceğini belirleyen bayrak.

True olarak ayarlanırsa, görüntü imza içeriği, [`ImageSearchOptions.return_content_type`](/signature/python-net/groupdocs.signature.options/imagesearchoptions/return_content_type/) tarafından belirtilen formatta ham görüntü verisi olarak tutulur. Varsayılan olarak bu seçenek devre dışı bırakılmıştır (False).
