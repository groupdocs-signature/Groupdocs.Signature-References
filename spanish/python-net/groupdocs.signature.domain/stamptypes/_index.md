## StampTypes class

Representa un contenedor para tipos de sello.

El tipo StampTypes expone los siguientes miembros:

### Métodos
| Método | Descripción |
| :- | :- |
| [parse](/signature/python-net/groupdocs.signature.domain/stamptypes/parse/#parsing_type) | Devuelve el tipo de sello que coincide con el nombre del tipo de análisis especificado. |
| [try_parse](/signature/python-net/groupdocs.signature.domain/stamptypes/try_parse/#parsing_type) | Devuelve un tipo de sello para el nombre del tipo de análisis proporcionado. Si el nombre del sello es desconocido, no se lanza ninguna excepción y el método devuelve None. |

### Campos
| Campo | Descripción |
| :- | :- |
| [ALL_TYPES](/signature/python-net/groupdocs.signature.domain/stamptypes/all_types/) | Todos los tipos de sello. |
| [ROUND](/signature/python-net/groupdocs.signature.domain/stamptypes/round/) | Objeto de tipo de sello redondo. |
| [SQUARE](/signature/python-net/groupdocs.signature.domain/stamptypes/square/) | Objeto de tipo de sello cuadrado. |
