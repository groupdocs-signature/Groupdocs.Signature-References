## SignatureSettings.SaveDocumentOnEmptyDelete property

Получает или задает флаг для повторного сохранения исходного документа, когда метод Delete не имеет подпечатей для удаления. Если этот флаг установлен в true (по умолчанию), документ будет сохраняться с соответствующим журналом истории процесса (дата и тип операции), даже если метод Delete не имеет подписей для удаления. Когда этот флаг установлен в false, исходный документ не будет изменён вообще.

```csharp
public bool SaveDocumentOnEmptyDelete { get; set; }
```
