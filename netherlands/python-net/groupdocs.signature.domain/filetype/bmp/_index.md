## BMP field

Bitmap Image File (.bmp) wordt gebruikt om bitmap digitale afbeeldingen op te slaan. Deze afbeeldingen zijn onafhankelijk van de grafische adapter en worden ook wel device independent bitmap (DIB) bestandsformaat genoemd. Meer informatie over dit bestandsformaat hier.
