## information_type_id property

De identificatie van de Royal Mail Mailmark barcode payload voor elk producttype.

Geldige waarden:
- "0" – Domestic Sorted and Unsorted
- "A" – On-line Postage
- "B" – Franking
- "C" – Consolidation
