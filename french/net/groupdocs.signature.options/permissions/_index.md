## Permissions enumeration

Spécifie des autorisations configurables pour les documents PDF, telles que l'impression, la modification du contenu et l'extraction de données. Ces paramètres ne s'appliquent qu'au format PDF et contrôlent l'accès des utilisateurs et les capacités d'interaction.

```csharp
[Flags]
public enum Permissions
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Autoriser toutes les actions, y compris l'impression, la modification et l'extraction de données. |
| DenyPrinting | `1` | Refuser l'impression du document. |
| DenyModification | `2` | Refuser la modification du contenu, y compris le remplissage des formulaires et l'ajout ou la modification d'annotations. |
| DenyDataExtraction | `4` | Refuser l'extraction de texte et de graphiques du document. |
| DenyAll | `7` | Refuser toutes les actions, y compris l'impression, la modification et l'extraction de données. |
