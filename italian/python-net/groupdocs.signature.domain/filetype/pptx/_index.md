## PPTX field

PowerPoint Open XML Presentation (.pptx) sono file di presentazione creati con la popolare applicazione Microsoft PowerPoint. A differenza della versione precedente del formato di file di presentazione PPT, che era binario, il formato PPTX si basa sul formato di file di presentazione Open XML di Microsoft PowerPoint. Scopri di più su questo formato di file qui.
