## FileType.BMP field

Bitmap Image File (.bmp) wird verwendet, um digitale Bitmap-Bilder zu speichern. Diese Bilder sind unabhängig vom Grafikadapter und werden auch als Device Independent Bitmap (DIB)-Dateiformat bezeichnet. Weitere Informationen zu diesem Dateiformat finden Sie [hier](https://wiki.fileformat.com/image/bmp).
