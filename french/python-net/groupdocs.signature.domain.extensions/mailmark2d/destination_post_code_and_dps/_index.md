## destination_post_code_and_dps property

La propriété contient le code postal de l'adresse de livraison avec DPS, qui pour les adresses intérieures se compose d'une zone (1‑2 caractères), d'un district (1‑2 caractères), d'un secteur (1 caractère), d'une unité (2 caractères) et du DPS (2 caractères), doit respecter un format PAF® valide et a une longueur maximale de 9 caractères.
