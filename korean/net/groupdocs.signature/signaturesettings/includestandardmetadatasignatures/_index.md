## SignatureSettings.IncludeStandardMetadataSignatures property

Metadata 목록에 저자, 소유자, 문서 생성 날짜, 수정 날짜 등과 같은 포함된 표준 문서 메타데이터 서명을 포함하도록 플래그를 가져오거나 설정합니다. 이 플래그가 false(기본값)로 설정되면 GetDocumentInfo는 이러한 메타데이터 서명을 포함하지 않습니다. 플래그가 true로 설정되면 문서 정보에 이러한 표준 메타데이터 서명이 포함됩니다.

```csharp
public bool IncludeStandardMetadataSignatures { get; set; }
```
