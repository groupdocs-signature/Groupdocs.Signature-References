Rappresenta la Modalità di Stretch dell'area della Firma nella Pagina del Documento.

## Campi

| Campo | Descrizione |
| --- | --- |
|  | [None](#None) | Valore predefinito. |
|
|  | [PageWidth](#PageWidth) | Allunga l'area della firma lungo la larghezza della pagina. |
|
|  | [PageHeight](#PageHeight) | Allunga l'area della firma lungo l'altezza della pagina. |
|
|  | [PageArea](#PageArea) | Allunga l'area della firma lungo l'altezza e la larghezza della pagina. |
|
### None {#None}
```
public static final int None
```


Valore predefinito. Non verrà applicata alcuna modalità di allungamento.


### PageWidth {#PageWidth}
```
public static final int PageWidth
```


Allunga l'area della firma lungo la larghezza della pagina. La proprietà Margin verrà utilizzata per applicare i valori di offset richiesti.


### PageHeight {#PageHeight}
```
public static final int PageHeight
```


Allunga l'area della firma lungo l'altezza della pagina. La proprietà Margin verrà utilizzata per applicare i valori di offset richiesti.


### PageArea {#PageArea}
```
public static final int PageArea
```


Allunga l'area della firma lungo l'altezza e la larghezza della pagina. La proprietà Margin verrà utilizzata per applicare i valori di offset richiesti.
