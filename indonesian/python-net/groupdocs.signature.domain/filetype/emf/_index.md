## EMF field

Enhanced Windows Metafile (.emf) mewakili gambar grafis secara device-independen. Meta-file EMF terdiri dari rekaman berukuran variabel dalam urutan kronologis yang dapat merender gambar yang disimpan setelah diparsing pada perangkat output apa pun. Pelajari lebih lanjut tentang format file ini di sini.
