## LogLevel class

Тип LogLevel раскрывает следующие члены:

### Поля
| Поле | Описание |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.logging/loglevel/none/) | Ничего не записывается. |
| [ERROR](/signature/python-net/groupdocs.signature.logging/loglevel/error/) | Ошибки: операция завершилась неудачей. |
| [WARNING](/signature/python-net/groupdocs.signature.logging/loglevel/warning/) | Предупреждения: операция завершилась успешно, но её результат может отличаться от ожидаемого. |
| [TRACE](/signature/python-net/groupdocs.signature.logging/loglevel/trace/) | Трассировки: шаги операции, такие как её начало и конец. |
| [ALL](/signature/python-net/groupdocs.signature.logging/loglevel/all/) | Ошибки, предупреждения и трассировки. Это значение по умолчанию. |
