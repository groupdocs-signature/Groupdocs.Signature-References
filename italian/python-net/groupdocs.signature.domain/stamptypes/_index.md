## StampTypes class

Rappresenta un contenitore per i tipi di timbro.

Il tipo StampTypes espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [parse](/signature/python-net/groupdocs.signature.domain/stamptypes/parse/#parsing_type) | Restituisce il tipo di timbro corrispondente al nome del tipo di parsing specificato. |
| [try_parse](/signature/python-net/groupdocs.signature.domain/stamptypes/try_parse/#parsing_type) | Restituisce un tipo di timbro per il nome del tipo di parsing fornito. Se il nome del timbro è sconosciuto, non viene sollevata alcuna eccezione e il metodo restituisce None. |

### Campi
| Campo | Descrizione |
| :- | :- |
| [ALL_TYPES](/signature/python-net/groupdocs.signature.domain/stamptypes/all_types/) | Tutti i tipi di timbro. |
| [ROUND](/signature/python-net/groupdocs.signature.domain/stamptypes/round/) | Oggetto tipo timbro rotondo. |
| [SQUARE](/signature/python-net/groupdocs.signature.domain/stamptypes/square/) | Oggetto tipo timbro quadrato. |
