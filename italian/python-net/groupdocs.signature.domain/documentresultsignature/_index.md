## DocumentResultSignature class

Rappresenta il risultato dell'elaborazione di un processo di firma di un documento archivio per un documento con firme appena create.

Maggiori informazioni

- More about signing documents withing archives using GroupDocs.Signature: https://docs.groupdocs.com/signature/net/signing-archive-documents/

Il tipo DocumentResultSignature espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [clone](/signature/python-net/groupdocs.signature.domain/basesignature/clone/) | Clona l'istanza della firma. (inherited from [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/)) |
| [equals](/signature/python-net/groupdocs.signature.domain/basesignature/equals/) | Confronta l'oggetto firma fornito con questa istanza per uguaglianza. (inherited from [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/)) |
| [equals_object](/signature/python-net/groupdocs.signature.domain/basesignature/equals_object/) | (ereditato da [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/)) |
| [get_hash_code](/signature/python-net/groupdocs.signature.domain/basesignature/get_hash_code/) | Fornisce un'implementazione sovrascritta di GetHashCode. (ereditato da [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/)) |
