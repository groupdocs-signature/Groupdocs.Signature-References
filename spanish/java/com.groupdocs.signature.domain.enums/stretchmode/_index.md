Representa el modo de estiramiento del área de firma en la página del documento.

## Campos

| Campo | Descripción |
| --- | --- |
|  | [None](#None) | Valor predeterminado. |
|
|  | [PageWidth](#PageWidth) | Estirar el área de la firma a lo largo del ancho de la página. |
|
|  | [PageHeight](#PageHeight) | Estirar el área de la firma a lo largo de la altura de la página. |
|
|  | [PageArea](#PageArea) | Estirar el área de la firma a lo largo de la altura y el ancho de la página. |
|
### None {#None}
```
public static final int None
```


Valor predeterminado. No se aplicará modo de estiramiento.


### PageWidth {#PageWidth}
```
public static final int PageWidth
```


Estirar el área de la firma a lo largo del ancho de la página. La propiedad Margin se usará para aplicar los valores de desplazamiento requeridos


### PageHeight {#PageHeight}
```
public static final int PageHeight
```


Estirar el área de la firma a lo largo de la altura de la página. La propiedad Margin se usará para aplicar los valores de desplazamiento requeridos.


### PageArea {#PageArea}
```
public static final int PageArea
```


Estirar el área de la firma a lo largo de la altura y el ancho de la página. La propiedad Margin se usará para aplicar los valores de desplazamiento requeridos.
