## form_text_field_type property

Het type formulierveld waarin de tekstopdracht moet worden geplaatst. Deze eigenschap is alleen van toepassing wanneer `signature_implementation` is ingesteld op `TextSignatureImplementation.FORM_FIELD` (d.w.z. TextToFormField). De standaardwaarde is `FormTextFieldType.ALL_TEXT_TYPES`.
