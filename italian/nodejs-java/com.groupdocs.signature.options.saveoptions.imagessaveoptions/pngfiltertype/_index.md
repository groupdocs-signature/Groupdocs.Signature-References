Rappresenta il tipo di filtro dell'immagine PNG.
## Campi

| Campo | Descrizione |
| --- | --- |
| [None](#None) | Il filtro nullo, significa nessuna filtrazione per le righe dei dati dell'immagine. |
| [Sub](#Sub) | Il filtro sub, significa che verrà applicata una filtrazione sottrattiva ai dati dell'immagine. |
| [Up](#Up) | Il filtro up, significa che verrà applicato un filtro di sottrazione riga per riga. |
| [Avg](#Avg) | Il filtro avg, significa che verrà applicato un filtro medio ai dati dell'immagine. |
| [Paeth](#Paeth) | Il filtro predittore di percorso. |
| [Adaptive](#Adaptive) | Filtraggio adattivo, significa che il processo di salvataggio sceglierà il filtro più adatto per ogni riga di dati. |
