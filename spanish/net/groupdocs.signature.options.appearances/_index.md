El espacio de nombres proporciona clases para apariencias de firma adicionales.

## Clases

| Clase | Descripción |
| --- | --- |
| [DigitalSignatureAppearance](./digitalsignatureappearance) | Describe la apariencia de la Línea de Firma para Firma Digital. Una Línea de Firma solo puede aplicarse a una Firma Digital. La Línea de Firma siempre está en la primera página. Esta característica puede ser útil para los formatos de archivo .docx, .doc, .odt y .xlsx. |
| [ImageAppearance](./imageappearance) | Describe las características de apariencia ampliadas para la Firma de Imagen. |
| [PdfDigitalSignatureAppearance](./pdfdigitalsignatureappearance) | Describe la apariencia de la Firma Digital en documentos PDF. |
| [PdfTextAnnotationAppearance](./pdftextannotationappearance) | Describe la apariencia del objeto de anotación de texto PDF (Título, Asunto, Contenido). |
| [PdfTextStickerAppearance](./pdftextstickerappearance) | Describe la apariencia del objeto de etiqueta de anotación de texto PDF y la ventana emergente de la etiqueta. |
| [SignatureAppearance](./signatureappearance) | Representa la apariencia de la firma: opciones adicionales para implementaciones alternativas de firma en la página del documento. |
