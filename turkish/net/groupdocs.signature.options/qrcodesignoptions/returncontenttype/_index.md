## QrCodeSignOptions.ReturnContentType property

ReturnContent özelliği etkin olduğunda QR-Code imzasının döndürülen görüntü içeriğinin dosya türünü belirtir. Varsayılan olarak Null olarak ayarlanır. Bu, QR-Code görüntü içeriğinin orijinal formatta döndürüleceği anlamına gelir. Bu görüntü formatı [`Format`](../../../groupdocs.signature.domain/qrcodesignature/format) adresinde belirtilir. Desteklenen olası değerler: FileType.JPEG, FileType.PNG, FileType.BMP. Sağlanan format desteklenmiyorsa QR-Code görüntü içeriği .png formatında döndürülür.

public FileType ReturnContentType { get; set; }
