## LoadOptions.WhitelistedResources property

Haalt op of stelt fragmenten van adressen van externe bronnen in die worden geladen zelfs wanneer [`SkipExternalResources`](../skipexternalresources) true is. De standaardwaarde is een lege lijst.

```csharp
public List<string> WhitelistedResources { get; set; }
```

### Opmerkingen

Een bron wordt geladen wanneer het volledige adres een van de fragmenten bevat. De vergelijking negeert hoofdlettergebruik, en lege fragmenten worden genegeerd. Geef de voorkeur aan lange fragmenten zoals \"https://cdn.example.com/images/\": een kort fragment komt ook overeen met andere adressen die het toevallig bevatten.

Het instellen van deze eigenschap op null maakt de lijst leeg. De lijst heeft geen effect wanneer [`SkipExternalResources`](../skipexternalresources) false is, omdat dan elke externe bron wordt geladen.
