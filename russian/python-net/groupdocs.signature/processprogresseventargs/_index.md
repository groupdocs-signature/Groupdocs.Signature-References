## ProcessProgressEventArgs class

Предоставляет данные для события OnProgress процессов подписи, проверки и поиска.

Тип ProcessProgressEventArgs предоставляет следующие члены:

| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature/processprogresseventargs/__init__/) |  |

### Свойства
| Свойство | Описание |
| :- | :- |
| [cancel](/signature/python-net/groupdocs.signature/processprogresseventargs/cancel/) | Флаг, указывающий, следует ли отменить процесс. |
| [processed_signatures](/signature/python-net/groupdocs.signature/processprogresseventargs/processed_signatures/) | Количество обработанных подписей. |
| [progress](/signature/python-net/groupdocs.signature/processprogresseventargs/progress/) | Прогресс в процентах, от 0 до 100. |
| [ticks](/signature/python-net/groupdocs.signature/processprogresseventargs/ticks/) | Время в миллисекундах, прошедшее с момента начала процесса. |
| [status](/signature/python-net/groupdocs.signature/processeventargs/status/) | Текущее состояние процесса. (унаследовано от [`ProcessEventArgs`](/signature/python-net/groupdocs.signature/processeventargs/)) |
