java.lang.Object
```
public final class SpreadsheetSaveFileFormat
```

Определяет различные форматы сохранения для документов Spreadsheet.

## Поля

| Поле | Описание |
| --- | --- |
|  | [Default](#Default) | Формат файла не будет изменён. |
|
|  | [CSV](#CSV) | Сохраняет документ в виде файла со значениями, разделёнными запятыми. |
|
|  | [Excel97To2003](#Excel97To2003) | Сохраняет документ как книгу Microsoft Excel 97-2003 (.xls). |
|
|  | [Xlsx](#Xlsx) | Сохраняет документ как книгу Microsoft Excel OpenXML. |
|
|  | [Xlsm](#Xlsm) | Сохраняет документ как книгу Microsoft Excel с поддержкой макросов. |
|
|  | [Xltx](#Xltx) | Сохраняет документ как шаблон Microsoft Excel. |
|
|  | [Xltm](#Xltm) | Сохраняет документ как шаблон Microsoft Excel с поддержкой макросов. |
|
|  | [Xlam](#Xlam) | Сохраняет документ как надстройку Microsoft Excel с поддержкой макросов. |
|
|  | [Pdf](#Pdf) | Сохраняет документ как PDF‑файл. |
|
|  | [ODS](#ODS) | Сохраняет документ как книгу Open Office. |
|
|  | [Xlsb](#Xlsb) | Сохраняет документ как двоичную книгу Microsoft Excel. |
|
|  | [XPS](#XPS) | Сохраняет документ как файл XML Paper Specification. |
|
|  | [TIFF](#TIFF) | Сохраняет документ в формате Tagged Image File Format. |
|
|  | [SVG](#SVG) | Сохраняет документ как файл Scalable Vector Graphics. |
|
|  | [Dif](#Dif) | Сохраняет документ в формате Data Interchange Format. |
|
|  | [Emf](#Emf) | Сохраняет документ в формате Windows Enhanced Metafile. |
|
|  | [Jpg](#Jpg) | Сохраняет документ в формате JPEG. |
|
|  | [Png](#Png) | Сохраняет документ в формате Portable Network Graphics. |
|
