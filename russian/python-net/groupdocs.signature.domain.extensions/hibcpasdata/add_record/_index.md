```python
def add_record(self, data_type, data):
    ...
```

| Параметр | Тип | Описание |
| :- | :- | :- |
| data_type | `HIBCPASDataType` | Тип данных записи. |
| data | `str` | Данные записи. |

## add_record {#record}

Добавляет новую запись.

```python
def add_record(self, record):
    ...
```

| Параметр | Тип | Описание |
| :- | :- | :- |
