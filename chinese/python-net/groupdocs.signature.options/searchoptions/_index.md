## SearchOptions class

表示从文档中提取签名的选项。

了解更多

- See more simple examples on searching for various electronic signatures with GroupDocs.Signature: https://docs.groupdocs.com/signature/net/search-for-electronic-signatures-in-document/
- See more advanced examples of searching for various electronic signature with GroupDocs.Signature: https://docs.groupdocs.com/signature/net/searching/

SearchOptions 类型公开以下成员：

### 属性
| 属性 | 描述 |
| :- | :- |
| [all_pages](/signature/python-net/groupdocs.signature.options/searchoptions/all_pages/) | 指示是否在每个文档页上进行搜索的标志。默认情况下此值为 True。 |
| [page_number](/signature/python-net/groupdocs.signature.options/searchoptions/page_number/) | 用于搜索的文档页码（可选）。 |
| [pages_setup](/signature/python-net/groupdocs.signature.options/searchoptions/pages_setup/) | 指定签名搜索页码的选项。 |
| [shape_position](/signature/python-net/groupdocs.signature.options/searchoptions/shape_position/) | 指示是否返回文档布局中形状位置的标志。仅适用于 Word 文档。 |
| [skip_external](/signature/python-net/groupdocs.signature.options/searchoptions/skip_external/) | 仅返回标记为 `IsSignature` 的签名的标志。默认值为 `False`，这表示返回所有符合指定条件的签名。 |
