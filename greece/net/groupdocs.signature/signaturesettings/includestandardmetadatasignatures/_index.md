## SignatureSettings.IncludeStandardMetadataSignatures property

Ανακτά ή ορίζει τη σημαία για την ένταξη στη Λίστα Μεταδεδομένων των ενσωματωμένων τυπικών υπογραφών μεταδεδομένων εγγράφου όπως Συγγραφέας, Ιδιοκτήτης, ημερομηνία δημιουργίας εγγράφου, ημερομηνία τροποποίησης κ.λπ. Εάν αυτή η σημαία οριστεί σε false (προεπιλογή) το GetDocumentInfo δεν θα περιλαμβάνει αυτές τις υπογραφές μεταδεδομένων. Όταν αυτή η σημαία οριστεί σε true, οι πληροφορίες εγγράφου θα περιλαμβάνουν αυτές τις τυπικές υπογραφές μεταδεδομένων.

```csharp
public bool IncludeStandardMetadataSignatures { get; set; }
```
