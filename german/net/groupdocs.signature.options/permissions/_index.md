## Permissions enumeration

Gibt konfigurierbare Berechtigungen für PDF-Dokumente an, wie Drucken, Inhaltsänderung und Datenauszug. Diese Einstellungen gelten ausschließlich für das PDF-Format und steuern den Benutzerzugriff sowie die Interaktionsmöglichkeiten.

```csharp
[Flags]
public enum Permissions
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| None | `0` | Alle Aktionen zulassen, einschließlich Drucken, Ändern und Datenextraktion. |
| DenyPrinting | `1` | Drucken des Dokuments verweigern. |
| DenyModification | `2` | Inhaltsänderungen verweigern, einschließlich Ausfüllen von Formularen und Hinzufügen oder Ändern von Anmerkungen. |
| DenyDataExtraction | `4` | Extraktion von Text und Grafiken aus dem Dokument verweigern. |
| DenyAll | `7` | Alle Aktionen verweigern, einschließlich Drucken, Ändern und Datenextraktion. |
