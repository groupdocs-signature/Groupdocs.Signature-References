## SignatureSettings.IncludeStandardMetadataSignatures property

Obtient ou définit le drapeau permettant d'inclure dans la liste des métadonnées les signatures de métadonnées de document standard intégrées telles que Auteur, Propriétaire, date de création du document, date de modification, etc. Si ce drapeau est défini sur false (par défaut), la méthode GetDocumentInfo n'inclura pas ces signatures de métadonnées. Lorsque ce drapeau est défini sur true, les informations du document incluront ces signatures de métadonnées standard.

```csharp
public bool IncludeStandardMetadataSignatures { get; set; }
```
