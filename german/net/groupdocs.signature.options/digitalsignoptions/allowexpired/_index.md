## DigitalSignOptions.AllowExpired property

Liest oder schreibt ein Flag, das das Signieren mit einem Zertifikat erlaubt, dessen Gültigkeitszeitraum beendet ist. Der Standardwert ist false: Das Signieren mit einem abgelaufenen Zertifikat löst [`GroupDocsSignatureException`](../../../groupdocs.signature/groupdocssignatureexception) aus, und das Dokument wird nicht signiert.

```csharp
public bool AllowExpired { get; set; }
```

### Hinweise

Validatoren melden eine mit einem abgelaufenen Zertifikat erstellte Signatur als ungültig. Setzen Sie diese Eigenschaft nur dann auf true, wenn Sie eine solche Signatur dennoch benötigen, zum Beispiel zum Testen mit einem alten Zertifikat. Das Dokument wird dann signiert und eine Warnung in den Logger geschrieben, der in [`SignatureSettings`](../../../groupdocs.signature/signaturesettings) festgelegt ist.

Das Zertifikat wird mit der aktuellen Zeit in UTC verglichen, nicht mit [`SignTime`](../../../groupdocs.signature.domain/digitalsignature/signtime). Das Flag gilt für das Zertifikat, das über [`CertificateFilePath`](../certificatefilepath), [`CertificateStream`](../certificatestream) oder [`Signature`](../signature) bereitgestellt wird, und beim Signieren einer Tabellenkalkulation für das Zertifikat der ersten [`DigitalVBA`](../../../groupdocs.signature.domain.extensions/digitalvba)-Erweiterung. Digitale Signaturen von Bildern verwenden kein Zertifikat und werden nicht geprüft. Ein Zertifikat, dessen Gültigkeitszeitraum noch nicht begonnen hat, wird durch [`AllowNotYetValid`](../allownotyetvalid) gesteuert.
