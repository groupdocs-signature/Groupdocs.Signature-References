## return_content property

Flaggan som anger om streckkodsbildens innehåll för en signatur på en dokumentsida ska hämtas.

Om den är satt till `True` behålls bildinnehållet för streckkodssignaturen som rå bilddata i det format som anges av `return_content_type`. Inaktiverad som standard.
