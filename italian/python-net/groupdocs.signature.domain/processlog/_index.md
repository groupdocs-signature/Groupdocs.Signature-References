## ProcessLog class

Rappresenta i dettagli del processo del documento.

Il tipo ProcessLog espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [date](/signature/python-net/groupdocs.signature.domain/processlog/date/) | La data e l'ora del processo. |
| [failed](/signature/python-net/groupdocs.signature.domain/processlog/failed/) | La quantità di firme che non sono riuscite durante l'elaborazione. |
| [message](/signature/python-net/groupdocs.signature.domain/processlog/message/) | La descrizione del processo. |
| [signatures](/signature/python-net/groupdocs.signature.domain/processlog/signatures/) | L'elenco delle firme elaborate con successo. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/processlog/succeeded/) | La quantità di firme elaborate con successo. |
| [type](/signature/python-net/groupdocs.signature.domain/processlog/type/) | Il tipo di processo. |
