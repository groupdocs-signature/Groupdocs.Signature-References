## TextShadow class

表示文本签名的文字阴影属性。结果可能因签名类型和文档格式而异。建议在所有受支持的文档类型中将 TextShadow 与 TextAsImage 签名一起使用，也可用于简单的 TextSignature 以及在电子表格 (.xlsx) 和演示文稿 (.pptx) 中将 TextSignature 作为水印。也推荐在 Word (.docx) 中使用简单的 TextSignature，但功能有限。

public class TextShadow : SignatureExtension
