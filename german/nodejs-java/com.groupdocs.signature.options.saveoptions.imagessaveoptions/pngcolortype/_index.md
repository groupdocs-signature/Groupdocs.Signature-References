## Felder

| Feld | Beschreibung |
| --- | --- |
| [Grayscale](#Grayscale) | Stellt den Farbtyp dar, bei dem jedes Pixel eine Graustufenprobe ist. |
| [Truecolor](#Truecolor) | Stellt den Farbtyp dar, bei dem jedes Pixel ein R,G,B‑Tripel ist. |
| [IndexedColor](#IndexedColor) | Stellt den Farbtyp dar, bei dem jedes Pixel ein Palettenindex ist; ein PLTE‑Chunk muss erscheinen. |
| [GrayscaleWithAlpha](#GrayscaleWithAlpha) | Stellt den Farbtyp dar, bei dem jedes Pixel ein Graustufen‑Sample gefolgt von einem Alpha‑Sample ist. |
| [TruecolorWithAlpha](#TruecolorWithAlpha) | Stellt den Farbtyp dar, bei dem jedes Pixel ein R,G,B‑Tripel gefolgt von einem Alpha‑Sample ist. |
