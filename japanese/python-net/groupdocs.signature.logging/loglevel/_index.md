## LogLevel class

LogLevel 型は次のメンバーを公開します：

### フィールド
| フィールド | 説明 |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.logging/loglevel/none/) | 何も記録されません。 |
| [ERROR](/signature/python-net/groupdocs.signature.logging/loglevel/error/) | エラー: 操作が失敗しました。 |
| [WARNING](/signature/python-net/groupdocs.signature.logging/loglevel/warning/) | 警告: 操作は成功しましたが、結果が期待通りでない可能性があります。 |
| [TRACE](/signature/python-net/groupdocs.signature.logging/loglevel/trace/) | トレース: 操作の手順、開始や終了など。 |
| [ALL](/signature/python-net/groupdocs.signature.logging/loglevel/all/) | エラー、警告、トレース。これがデフォルトです。 |
