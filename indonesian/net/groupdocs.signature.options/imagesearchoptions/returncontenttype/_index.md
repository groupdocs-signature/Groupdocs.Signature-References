## ImageSearchOptions.ReturnContentType property

Menentukan jenis file dari konten yang dikembalikan dari tanda tangan gambar ketika properti ReturnContent diaktifkan. Secara default diatur ke Null. Itu berarti mengembalikan konten gambar dalam format asli. Format gambar ini ditentukan di [`Format`](../../../groupdocs.signature.domain/imagesignature/format). Nilai yang didukung antara lain: FileType.JPEG, FileType.PNG, FileType.BMP. Jika format yang diberikan tidak didukung, maka konten gambar dalam format asli akan dikembalikan.
