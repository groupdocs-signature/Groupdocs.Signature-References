## QrCodeSignOptions.ReturnContentType property

Καθορίζει τον τύπο αρχείου του επιστρεφόμενου περιεχομένου εικόνας της υπογραφής QR-Code όταν η ιδιότητα ReturnContent είναι ενεργοποιημένη. Από προεπιλογή ορίζεται σε Null. Αυτό σημαίνει ότι θα επιστραφεί το περιεχόμενο εικόνας QR-Code στην αρχική μορφή. Αυτή η μορφή εικόνας καθορίζεται στο [`Format`](../../../groupdocs.signature.domain/qrcodesignature/format). Οι πιθανές υποστηριζόμενες τιμές είναι: FileType.JPEG, FileType.PNG, FileType.BMP. Εάν η παρεχόμενη μορφή δεν υποστηρίζεται, τότε το περιεχόμενο εικόνας QR-Code θα επιστραφεί σε μορφή .png.

public FileType ReturnContentType { get; set; }
