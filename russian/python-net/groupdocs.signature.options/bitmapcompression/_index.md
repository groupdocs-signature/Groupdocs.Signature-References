## BitmapCompression class

Тип BitmapCompression раскрывает следующие члены:

### Поля
| Поле | Описание |
| :- | :- |
| [RGB](/signature/python-net/groupdocs.signature.options/bitmapcompression/rgb/) | Без сжатия. |
| [RLE8](/signature/python-net/groupdocs.signature.options/bitmapcompression/rle8/) | Сжатие RLE 8‑бит/пиксель. Может использоваться только с 8‑битными/пиксельными битмапами. |
| [RLE4](/signature/python-net/groupdocs.signature.options/bitmapcompression/rle4/) | Сжатие RLE 4‑бит/пиксель. Может использоваться только с 4‑битными/пиксельными битмапами. |
| [BITFIELDS](/signature/python-net/groupdocs.signature.options/bitmapcompression/bitfields/) | Битовые поля. Может использоваться только с 16‑ и 32‑битными/пиксельными битмапами. |
| [JPEG](/signature/python-net/groupdocs.signature.options/bitmapcompression/jpeg/) | Сжатие JPEG. Битмап содержит изображение JPEG. |
| [PNG](/signature/python-net/groupdocs.signature.options/bitmapcompression/png/) | Сжатие PNG. Битмап содержит изображение PNG. |
