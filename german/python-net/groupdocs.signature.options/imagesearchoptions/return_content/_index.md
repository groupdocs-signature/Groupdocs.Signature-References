## return_content property

Das Flag, das bestimmt, ob der Bildinhalt einer Signatur zurückgegeben wird.

Wenn auf True gesetzt, wird der Bildsignaturinhalt als Rohbilddaten im von [`ImageSearchOptions.return_content_type`](/signature/python-net/groupdocs.signature.options/imagesearchoptions/return_content_type/) angegebenen Format beibehalten. Standardmäßig ist diese Option deaktiviert (False).
