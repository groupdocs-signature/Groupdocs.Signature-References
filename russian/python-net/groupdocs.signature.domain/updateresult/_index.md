## UpdateResult class

Представляет результат изменения подписей в документе.

Тип UpdateResult раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/updateresult/destin_document_size/) | Размер целевого документа. |
| [failed](/signature/python-net/groupdocs.signature.domain/updateresult/failed/) | Список подписей, которые не были обновлены [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [processing_time](/signature/python-net/groupdocs.signature.domain/updateresult/processing_time/) | Время выполнения процесса в миллисекундах. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/updateresult/source_document_size/) | Размер исходного документа. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/updateresult/succeeded/) | Список успешно изменённых подписей [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/updateresult/total_signatures/) | Общее количество обработанных подписей. |
