## SaveOptions.OverwriteExistingFiles property

Получает или задает, следует ли перезаписывать существующий файл новым выходным файлом. В противном случае будет создан новый файл с номером в качестве суффикса. По умолчанию это значение установлено в true, что означает, что файл будет перезаписан.

```csharp
public bool OverwriteExistingFiles { get; set; }
```
