## VerticalAlignment class

Il tipo VerticalAlignment espone i seguenti membri:

### Campi
| Campo | Descrizione |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/verticalalignment/none/) | L'oggetto è posizionato esplicitamente, solitamente usando la sua proprietà Top. |
| [TOP](/signature/python-net/groupdocs.signature.domain/verticalalignment/top/) | Specifica che l'oggetto deve trovarsi nella parte superiore della base di allineamento verticale. |
| [CENTER](/signature/python-net/groupdocs.signature.domain/verticalalignment/center/) | Specifica che l'oggetto deve essere centrato rispetto alla base di allineamento verticale. |
| [BOTTOM](/signature/python-net/groupdocs.signature.domain/verticalalignment/bottom/) | Specifica che l'oggetto deve trovarsi nella parte inferiore della base di allineamento verticale. |
