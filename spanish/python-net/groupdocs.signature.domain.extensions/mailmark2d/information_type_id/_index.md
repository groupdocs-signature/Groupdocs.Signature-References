## information_type_id property

El identificador de la carga útil del código de barras Royal Mail Mailmark para cada tipo de producto.

Valores válidos:
- "0" – Domestic Sorted and Unsorted
- "A" – On-line Postage
- "B" – Franking
- "C" – Consolidation
