## IRectangle class

Definiert Schnittstelleneigenschaften für den Signaturbereich auf einer Dokumentseite.

Der Typ IRectangle stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [height](/signature/python-net/groupdocs.signature.domain/irectangle/height/) | Die Höhe des Signaturbereichs auf einer Dokumentseite in Maßeinheiten (Pixel, Prozente oder Millimeter; siehe `MeasureType` SizeMeasureType). |
| [left](/signature/python-net/groupdocs.signature.domain/irectangle/left/) | Die linke X-Position des Signaturbereichs auf einer Dokumentseite in Maßeinheiten (Pixel, Prozente oder Millimeter). Siehe `MeasureType` für die Aufzählung `LocationMeasureType`. |
| [location_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/location_measure_type/) | Der Messungstyp (Pixel, Prozente oder Millimeter) für die Eigenschaften Left und Top. |
| [size_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/size_measure_type/) | Der Messungstyp (Pixel, Prozente oder Millimeter) für die Eigenschaften Width und Height. |
| [stretch](/signature/python-net/groupdocs.signature.domain/irectangle/stretch/) | Der Dehnungsmodus auf einer Dokumentseite. |
| [top](/signature/python-net/groupdocs.signature.domain/irectangle/top/) | Die obere Y‑Position des Signaturbereichs auf der Dokumentseite in Maßeinheiten (Pixel, Prozente oder Millimeter). Siehe `MeasureType` für den Standort‑Maßtyp. |
| [width](/signature/python-net/groupdocs.signature.domain/irectangle/width/) | Die Breite des Signaturbereichs auf einer Dokumentseite in Messwerten (Pixel, Prozente oder Millimeter). Siehe `MeasureType` SizeMeasureType. |
