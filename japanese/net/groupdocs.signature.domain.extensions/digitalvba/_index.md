## DigitalVBA class

Spreadsheets VBAプロジェクトのデジタル署名を表します。XlsmやXltmなどの特定のSpreadsheetsドキュメント形式でVBAプロジェクトに署名する機能を提供します。DigitalSignOptions.Extensionsに複数のDigitalVBA拡張機能が追加された場合、最初のものだけがドキュメント署名に使用されます。

```csharp
public class DigitalVBA : SignatureExtension
```
