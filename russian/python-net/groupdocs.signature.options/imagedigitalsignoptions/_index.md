## ImageDigitalSignOptions class

Представляет параметры для встраивания цифровой (стеганографической) подписи Aspose.Imaging в растровые изображения.

Тип ImageDigitalSignOptions раскрывает следующие члены:

### Конструкторы
| Конструктор | Описание |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.options/imagedigitalsignoptions/__init__/) | Инициализирует новый экземпляр класса ImageDigitalSignOptions со значениями по умолчанию. |
