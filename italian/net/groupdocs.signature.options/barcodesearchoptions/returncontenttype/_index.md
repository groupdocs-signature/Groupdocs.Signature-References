## BarcodeSearchOptions.ReturnContentType property

Specifica il tipo di file del contenuto immagine restituito della firma Barcode quando la proprietà ReturnContent è abilitata. Per impostazione predefinita è impostato su Null. Ciò significa restituire il contenuto immagine del Barcode nel formato originale. Questo formato immagine è specificato in [`Format`](../../../groupdocs.signature.domain/barcodesignature/format). I possibili valori supportati sono: FileType.JPEG, FileType.PNG, FileType.BMP. Se il formato fornito non è supportato, verrà restituito il contenuto immagine del Barcode in formato .png.

public FileType ReturnContentType { get; set; }
