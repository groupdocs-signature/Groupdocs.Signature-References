## APNG field

Animated Portable Network Graphics（.png）は、ロスレス圧縮を使用するラスタ画像ファイル形式です。PNG の拡張として開発され、アニメーションをサポートし、著作権制限のない GIF 形式の代替となります。こちらでこのファイル形式の詳細をご覧ください。
