## DigitalSignOptions.AllowNotYetValid property

Gets or sets a flag that allows signing with a certificate whose validity period has not started yet. The default value is false: signing with such a certificate throws [`GroupDocsSignatureException`](../../../groupdocs.signature/groupdocssignatureexception), and the document is not signed.

```csharp
public bool AllowNotYetValid { get; set; }
```

### Remarks

Validators report a signature made before the certificate becomes valid as not valid. Such a certificate was usually issued for a later date, or the computer's clock is wrong. When this property is true, the document is signed, and a warning is written to the logger set in [`SignatureSettings`](../../../groupdocs.signature/signaturesettings).

The certificate is compared with the current time in UTC. The flag applies to the same certificates as [`AllowExpired`](../allowexpired), which controls certificates whose validity period has ended.
