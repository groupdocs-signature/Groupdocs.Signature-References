Το χώρο ονομάτων **GroupDocs.Signature.Domain** παρέχει κλάσεις για εργασία με την αναπαράσταση εγγράφων.


## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [Background](../com.groupdocs.signature.domain/background) | Αντιπροσωπεύει την εμφάνιση του φόντου |
| [Border](../com.groupdocs.signature.domain/border) | Παράδειγμα για τη διατήρηση των ιδιοτήτων γραμμής περιγράμματος. |
| [DeleteResult](../com.groupdocs.signature.domain/deleteresult) | Αποτέλεσμα της διαγραφής υπογραφής(ών) από το έγγραφο. |
| [Padding](../com.groupdocs.signature.domain/padding) | Αντιπροσωπεύει τις πληροφορίες γεμίσματος ή περιθωρίου που σχετίζονται με το στοιχείο. |
| [PageInfo](../com.groupdocs.signature.domain/pageinfo) | Κλάση περιγραφής σελίδας εγγράφου |
| [ProcessLog](../com.groupdocs.signature.domain/processlog) | Αντιπροσωπεύει τις λεπτομέρειες της διαδικασίας εγγράφου. |
| [SearchResult](../com.groupdocs.signature.domain/searchresult) | Αποτέλεσμα της αναζήτησης υπογραφών στο καθορισμένο έγγραφο. |
| [SignResult](../com.groupdocs.signature.domain/signresult) | Αποτέλεσμα της διαδικασίας υπογραφής του εγγράφου με νεοδημιουργημένες υπογραφές. |
| [SignatureFont](../com.groupdocs.signature.domain/signaturefont) | Δημιουργήστε μια παρουσία της κλάσης SignatureFont για να καθορίσετε τις ιδιότητες της γραμματοσειράς. |
| [UpdateResult](../com.groupdocs.signature.domain/updateresult) | Αποτέλεσμα της τροποποίησης των υπογραφών στο έγγραφο. |
| [VerificationResult](../com.groupdocs.signature.domain/verificationresult) | Παράδειγμα για τη διατήρηση των αποτελεσμάτων της διαδικασίας επαλήθευσης. |
