Der **GroupDocs.Signature.Options.Appearances** Namespace stellt Klassen für zusätzliche Signaturdarstellungen bereit.


## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [DigitalSignatureAppearance](../com.groupdocs.signature.options.appearances/digitalsignatureappearance) | Beschreibt das Aussehen der Signaturzeile für digitale Signaturen. |
| [ImageAppearance](../com.groupdocs.signature.options.appearances/imageappearance) | Beschreibt erweiterte Darstellungs‑Features für Bildsignaturen. |
| [PdfDigitalSignatureAppearance](../com.groupdocs.signature.options.appearances/pdfdigitalsignatureappearance) | Beschreibt das Aussehen digitaler Signaturen in PDF-Dokumenten. |
| [PdfTextAnnotationAppearance](../com.groupdocs.signature.options.appearances/pdftextannotationappearance) | Beschreibt das Aussehen des PDF‑Textanmerkungsobjekts (Titel, Betreff, Inhalt). |
| [PdfTextStickerAppearance](../com.groupdocs.signature.options.appearances/pdftextstickerappearance) | Beschreibt das Aussehen des PDF‑Textanmerkungs‑Sticker‑Objekts und das Pop‑up‑Fenster des Stickers. |
| [SignatureAppearance](../com.groupdocs.signature.options.appearances/signatureappearance) | Stellt das Signatur‑Aussehen dar – zusätzliche Optionen für alternative Implementierungen des Signierens auf der Dokumentenseite. |
