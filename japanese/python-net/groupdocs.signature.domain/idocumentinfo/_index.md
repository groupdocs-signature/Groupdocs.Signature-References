## IDocumentInfo class

ドキュメント記述プロパティです。

IDocumentInfo 型は次のメンバーを公開します:

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [barcode_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/barcode_signatures/) | [`Signature`](/signature/python-net/groupdocs.signature/signature/) メソッドによって追加または更新されたドキュメントのバーコード署名のコレクション。 |
| [digital_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/digital_signatures/) | [`Signature`](/signature/python-net/groupdocs.signature/signature/) メソッドによって追加または更新されたドキュメントのデジタル署名のコレクション。 |
| [documents](/signature/python-net/groupdocs.signature.domain/idocumentinfo/documents/) | アーカイブファイル内のすべての既存ドキュメントのコレクション。このプロパティはアーカイブ文書タイプでのみサポートされます。 |
| [file_type](/signature/python-net/groupdocs.signature.domain/idocumentinfo/file_type/) | ファイル形式の種類。 |
| [form_field_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/form_field_signatures/) | [`Signature`](/signature/python-net/groupdocs.signature/signature/) メソッドによって追加または更新されたドキュメントのフォームフィールド署名のコレクション。 |
| [form_fields](/signature/python-net/groupdocs.signature.domain/idocumentinfo/form_fields/) | ドキュメント内のすべての既存のサポートされているフォームフィールドのコレクション。このプロパティは PDF および Word Processing 文書タイプでのみサポートされます。 |
| [image_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/image_signatures/) | [`Signature`](/signature/python-net/groupdocs.signature/signature/) メソッドによって追加または更新されたドキュメントの画像署名のコレクション。 |
| [max_page_height](/signature/python-net/groupdocs.signature.domain/idocumentinfo/max_page_height/) | ページの最大高さ。 |
| [metadata_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/metadata_signatures/) | ドキュメントメタデータ署名のコレクション。 |
| [page_count](/signature/python-net/groupdocs.signature.domain/idocumentinfo/page_count/) | ドキュメントのページ数。 |
| [pages](/signature/python-net/groupdocs.signature.domain/idocumentinfo/pages/) | ドキュメントページの説明のコレクション。 |
| [process_logs](/signature/python-net/groupdocs.signature.domain/idocumentinfo/process_logs/) | ドキュメント履歴プロセスログのコレクション。 |
| [qr_code_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/qr_code_signatures/) | [`Signature`](/signature/python-net/groupdocs.signature/signature/) メソッドによって追加または更新されたドキュメントの QR コード署名のコレクション。 |
| [signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/signatures/) | ドキュメント内に存在するすべての署名タイプを [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/) オブジェクトとして表したコレクション。 |
| [size](/signature/python-net/groupdocs.signature.domain/idocumentinfo/size/) | ドキュメントのサイズ（バイト単位）。 |
| [text_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/text_signatures/) | [`Signature`](/signature/python-net/groupdocs.signature/signature/) メソッドによって追加または更新されたドキュメントのテキスト署名のコレクション。 |
| [width_for_max_height](/signature/python-net/groupdocs.signature.domain/idocumentinfo/width_for_max_height/) | 最大ページ高さの幅。 |
