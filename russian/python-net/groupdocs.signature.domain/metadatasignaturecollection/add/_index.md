## add {#signature}

Добавляет объект метаданных подписи в коллекцию.

Вызывает исключение, если значение имени не уникально в существующей коллекции.

```python
def add(self, signature):
    ...
```

| Параметр | Тип | Описание |
| :- | :- | :- |
| signature | `MetadataSignature` | Метаданные подписи, которые будут добавлены в коллекцию. |
