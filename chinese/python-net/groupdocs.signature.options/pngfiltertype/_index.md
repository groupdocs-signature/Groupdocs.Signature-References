## PngFilterType class

PngFilterType 类型公开以下成员：

### 字段
| 字段 | 描述 |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.options/pngfiltertype/none/) | null-filter，表示对图像数据行不进行过滤。 |
| [SUB](/signature/python-net/groupdocs.signature.options/pngfiltertype/sub/) | sub filter，表示将对图像数据应用减法过滤。 |
| [UP](/signature/python-net/groupdocs.signature.options/pngfiltertype/up/) | up filter，表示将应用逐行减法过滤。 |
| [AVG](/signature/python-net/groupdocs.signature.options/pngfiltertype/avg/) | avg filter，表示将对图像数据应用平均过滤。 |
| [PAETH](/signature/python-net/groupdocs.signature.options/pngfiltertype/paeth/) | path predictor 过滤器。 |
| [ADAPTIVE](/signature/python-net/groupdocs.signature.options/pngfiltertype/adaptive/) | 自适应过滤，表示保存过程将为每个数据行选择最合适的过滤器。压缩率最高，执行时间最慢。 |
