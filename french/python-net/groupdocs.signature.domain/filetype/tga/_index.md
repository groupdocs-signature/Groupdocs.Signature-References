## TGA field

Truevision TGA (.tga), également connu sous le nom de TARGA, est un format de fichier d'image raster développé par Truevision Inc. Il prend en charge diverses profondeurs de couleur et une compression RLE optionnelle. Les fichiers TGA sont couramment utilisés dans les jeux vidéo, les pipelines d'animation et les applications graphiques pour le rendu d'images de haute qualité avec prise en charge optionnelle du canal alpha. En savoir plus sur ce format de fichier ici.
