## information_type_id property

L'identifiant de la charge utile du code-barres Royal Mail Mailmark pour chaque type de produit.

Valeurs valides :
- "0" – Domestic Sorted and Unsorted
- "A" – On-line Postage
- "B" – Franking
- "C" – Consolidation
