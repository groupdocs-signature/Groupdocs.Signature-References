L’espace de noms fournit des classes pour des apparences de signature supplémentaires.

## Classes

| Classe | Description |
| --- | --- |
| [DigitalSignatureAppearance](./digitalsignatureappearance) | Décrit l'apparence de la ligne de signature pour la signature numérique. Une ligne de signature ne peut être appliquée qu'à une seule signature numérique. La ligne de signature se trouve toujours sur la première page. Cette fonctionnalité peut être utile pour les formats de fichiers .docx, .doc, .odt et .xlsx. |
| [ImageAppearance](./imageappearance) | Décrit les fonctionnalités d'apparence étendues pour la signature d'image. |
| [PdfDigitalSignatureAppearance](./pdfdigitalsignatureappearance) | Décrit l'apparence de la signature numérique sur les documents PDF. |
| [PdfTextAnnotationAppearance](./pdftextannotationappearance) | Décrit l'apparence de l'objet d'annotation de texte PDF (Titre, Sujet, Contenu). |
| [PdfTextStickerAppearance](./pdftextstickerappearance) | Décrit l'apparence de l'objet autocollant d'annotation de texte PDF et la fenêtre contextuelle de l'autocollant. |
| [SignatureAppearance](./signatureappearance) | Représente l'apparence de la signature - options supplémentaires pour les implémentations alternatives de la signature sur la page du document. |
