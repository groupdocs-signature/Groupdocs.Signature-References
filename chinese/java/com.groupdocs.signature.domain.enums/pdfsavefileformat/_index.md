定义不同的保存文件格式。

## 字段

| 字段 | 描述 |
| --- | --- |
|  | [Default](#Default) | 文件格式将不会被更改。 |
|
|  | [Pdf](#Pdf) | 将文档另存为 PDF（Adobe Portable Document）格式。 |
|
|  | [Doc](#Doc) | 将文档保存为 Microsoft Word 97-2007 文档格式。 |
|
|  | [Xps](#Xps) | 将文档保存为 XPS（XML Paper Specification）格式。 |
|
|  | [DocX](#DocX) | 将文档保存为 Microsoft Word Open XML 文件格式。 |
|
|  | [Svg](#Svg) | 将文档保存为 SVG（Scalable Vector Graphics）格式。 |
|
|  | [Epub](#Epub) | 将文档保存为 IDPF EPUB 格式。 |
|
|  | [Pptx](#Pptx) | 将文档保存为 PowerPoint Open XML 演示文件格式 |
|
