## TEXT_TO_FORM_FIELD field

Signature texte sous forme de texte dans le champ de formulaire spécifié. Avec ce type d'implémentation, seules les options TextSignOptions.Text, TextSignOptions.FormTextFieldTitle et TextSignOptions.FormTextFieldType peuvent être utilisées.

### Valeur
`2`
