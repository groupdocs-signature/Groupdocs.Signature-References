## TextShadow class

テキスト署名のテキストシャドウプロパティを表します。結果は署名タイプや文書フォーマットにより異なる場合があります。TextShadowは、すべてのサポート対象文書タイプで TextAsImage 署名と併用することが推奨され、また、スプレッドシート（.xlsx）やプレゼンテーション（.pptx）でシンプルな TextSignature や透かしとしての TextSignature とも使用できます。Word（.docx）用のシンプルな TextSignature も推奨されますが、機能は限定的です。

```csharp
public class TextShadow : SignatureExtension
```
