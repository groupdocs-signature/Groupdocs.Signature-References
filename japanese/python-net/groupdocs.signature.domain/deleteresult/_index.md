## DeleteResult class

ドキュメントから署名の削除結果です。

DeleteResult 型は次のメンバーを公開します:

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/deleteresult/destin_document_size/) | 更新されたドキュメントサイズです。 |
| [failed](/signature/python-net/groupdocs.signature.domain/deleteresult/failed/) | 削除されなかった署名の一覧 [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/)。 |
| [processing_time](/signature/python-net/groupdocs.signature.domain/deleteresult/processing_time/) | プロセスの実行時間（ミリ秒）。 |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/deleteresult/source_document_size/) | ソースドキュメントのサイズ。 |
| [succeeded](/signature/python-net/groupdocs.signature.domain/deleteresult/succeeded/) | 正常に削除された署名の一覧 [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/)。 |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/deleteresult/total_signatures/) | 処理された署名の総数。 |
