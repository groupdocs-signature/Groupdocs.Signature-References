## IAlignment class

Описывает выравнивание области подписи на странице документа.

Тип IAlignment раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [horizontal_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/horizontal_alignment/) | Горизонтальное выравнивание изображения на странице документа. |
| [margin](/signature/python-net/groupdocs.signature.domain/ialignment/margin/) | Пространство, которое по умолчанию указывается между изображением и краями документа (применяется, когда установлено горизонтальное или вертикальное выравнивание). |
| [margin_measure_type](/signature/python-net/groupdocs.signature.domain/ialignment/margin_measure_type/) | Тип измерения отступа (пиксели, проценты или миллиметры). |
| [vertical_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/vertical_alignment/) | Вертикальное выравнивание изображения на странице документа. |
