## QrCodeSignOptions.ReturnContentType property

ReturnContent 속성이 활성화된 경우 QR-Code 서명의 반환 이미지 콘텐츠 파일 형식을 지정합니다. 기본값은 Null이며, 이는 원본 형식으로 QR-Code 이미지 콘텐츠를 반환한다는 의미입니다. 이 이미지 형식은 [`Format`](../../../groupdocs.signature.domain/qrcodesignature/format)에서 지정됩니다. 지원 가능한 값은 FileType.JPEG, FileType.PNG, FileType.BMP입니다. 제공된 형식이 지원되지 않으면 .png 형식의 QR-Code 이미지 콘텐츠가 반환됩니다.

public FileType ReturnContentType { get; set; }
