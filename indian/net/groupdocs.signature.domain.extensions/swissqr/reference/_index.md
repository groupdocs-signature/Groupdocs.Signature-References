## SwissQR.Reference property

क्रेडिटर भुगतान संदर्भ प्राप्त करता है या सेट करता है। यह संदर्भ SwissQR IBANs के लिए अनिवार्य है, अर्थात CHxx30000xxxxxx से CHxx31999xxxxx तक की रेंज में IBANs। यदि निर्दिष्ट किया गया है, तो संदर्भ या तो वैध SwissQR संदर्भ (ISR संदर्भ फ़ॉर्म के अनुरूप) या ISO 11649 के अनुसार वैध क्रेडिटर संदर्भ (\"RFxxxx\") होना चाहिए। दोनों में फ़ॉर्मेटिंग के लिए स्पेस हो सकते हैं।

public string Reference { get; set; }
