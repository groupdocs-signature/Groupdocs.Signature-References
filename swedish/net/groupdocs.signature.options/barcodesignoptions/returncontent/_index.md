## BarcodeSignOptions.ReturnContent property

Hämtar eller anger flaggan för att få streckkodens bildinnehåll för en signatur som placerats på dokumentsidan. Om denna flagga är satt till true kommer streckkodsignaturens bildinnehåll att behålla rå bilddata i det erforderliga formatet [`ReturnContentType`](../returncontenttype). Som standard är detta alternativ inaktiverat.

public bool ReturnContent { get; set; }
