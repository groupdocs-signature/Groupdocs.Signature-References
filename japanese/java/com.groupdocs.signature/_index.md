## クラス

| クラス | 説明 |
| --- | --- |
| [Signature](../com.groupdocs.signature/signature) | ドキュメント署名プロセスを制御するメインクラスを表します。 |
| [SignatureSettings](../com.groupdocs.signature/signaturesettings) | カスタマイズされた [Signature](../com.groupdocs.signature/signature) の動作のための設定を定義します。 |
