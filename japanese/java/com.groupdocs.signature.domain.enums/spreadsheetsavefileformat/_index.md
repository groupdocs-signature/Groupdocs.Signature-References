```
public final class SpreadsheetSaveFileFormat
```

スプレッドシートドキュメントのさまざまな保存形式を定義します。

## フィールド

| フィールド | 説明 |
| --- | --- |
|  | [Default](#Default) | ファイル形式は変更されません。 |
|
|  | [CSV](#CSV) | ドキュメントをカンマ区切り値ファイルとして保存します。 |
|
|  | [Excel97To2003](#Excel97To2003) | ドキュメントを Microsoft Excel 97-2003 ワークブック（.xls）として保存します。 |
|
|  | [Xlsx](#Xlsx) | ドキュメントを Microsoft Excel OpenXML ワークブックとして保存します。 |
|
|  | [Xlsm](#Xlsm) | ドキュメントを Microsoft Excel マクロ有効ブックとして保存します。 |
|
|  | [Xltx](#Xltx) | ドキュメントを Microsoft Excel テンプレートとして保存します。 |
|
|  | [Xltm](#Xltm) | ドキュメントを Microsoft Excel マクロ有効テンプレートとして保存します。 |
|
|  | [Xlam](#Xlam) | ドキュメントを Microsoft Excel マクロ有効アドインとして保存します。 |
|
|  | [Pdf](#Pdf) | ドキュメントを PDF ファイルとして保存します。 |
|
|  | [ODS](#ODS) | ドキュメントを Open Office ワークブックとして保存します。 |
|
|  | [Xlsb](#Xlsb) | ドキュメントを Microsoft Excel バイナリ ワークブックとして保存します。 |
|
|  | [XPS](#XPS) | ドキュメントを XML Paper Specification ファイルとして保存します。 |
|
|  | [TIFF](#TIFF) | ドキュメントを Tagged Image File Format で保存します。 |
|
|  | [SVG](#SVG) | ドキュメントを Scalable Vector Graphics ファイルとして保存します。 |
|
|  | [Dif](#Dif) | ドキュメントを Data Interchange Format で保存します。 |
|
|  | [Emf](#Emf) | ドキュメントを Windows Enhanced Metafile 形式で保存します。 |
|
|  | [Jpg](#Jpg) | ドキュメントを JPEG 形式で保存します。 |
|
|  | [Png](#Png) | ドキュメントを Portable Network Graphics 形式で保存します。 |
