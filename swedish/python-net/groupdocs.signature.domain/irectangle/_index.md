## IRectangle class

Definierar gränssnittsegenskaper för signaturområde på en dokumentsida.

IRectangle-typen exponerar följande medlemmar:

### Egenskaper
| Egenskap | Beskrivning |
| :- | :- |
| [height](/signature/python-net/groupdocs.signature.domain/irectangle/height/) | Höjden på signaturområdet på en dokumentsida i mätenheter (pixlar, procent eller millimeter; se `MeasureType` SizeMeasureType). |
| [left](/signature/python-net/groupdocs.signature.domain/irectangle/left/) | Den vänstra X-positionen för signaturområdet på en dokumentsida i mätenheter (pixlar, procent eller millimeter). Se `MeasureType` för `LocationMeasureType`-enumerationen. |
| [location_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/location_measure_type/) | Måtttypen (pixlar, procent eller millimeter) för egenskaperna Left och Top. |
| [size_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/size_measure_type/) | Måtttypen (pixlar, procent eller millimeter) för egenskaperna Width och Height. |
| [stretch](/signature/python-net/groupdocs.signature.domain/irectangle/stretch/) | Sträckningsläget på en dokumentsida. |
| [top](/signature/python-net/groupdocs.signature.domain/irectangle/top/) | Den övre Y-positionen för signaturområdet på dokumentsidan i mätenheter (pixlar, procent eller millimeter). Se `MeasureType` för platsmåtttypen. |
| [width](/signature/python-net/groupdocs.signature.domain/irectangle/width/) | Bredden på signaturområdet på en dokumentsida i målvärden (pixlar, procent eller millimeter). Se `MeasureType` SizeMeasureType. |
