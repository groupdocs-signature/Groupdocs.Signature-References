## StretchMode enumeration

Representa el modo de estiramiento del área de firma en una página de documento.

```csharp
public enum StretchMode
```

### Values

| Nombre | Value | Descripción |
| --- | --- | --- |
| None | `0` | Valor predeterminado. No se aplicará modo de estiramiento. |
| PageWidth | `1` | Estirar el área de la firma a lo largo del ancho de la página. La propiedad Margin se usará para aplicar los valores de desplazamiento requeridos. |
| PageHeight | `2` | Estirar el área de la firma a lo largo de la altura de la página. La propiedad Margin se usará para aplicar los valores de desplazamiento requeridos. |
| PageArea | `3` | Estire el área de la firma a lo largo de la altura y el ancho de la página. La propiedad Margin se usará para aplicar los valores de desplazamiento requeridos. |
