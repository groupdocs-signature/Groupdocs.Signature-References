## QrCodeSearchOptions.ReturnContentType property

ReturnContent özelliği etkinleştirildiğinde QR-Code imzasının döndürülen görüntü içeriğinin dosya türünü belirtir. Varsayılan olarak Null olarak ayarlanır. Bu, QR-Code görüntü içeriğinin orijinal formatta döndürüleceği anlamına gelir. Bu görüntü formatı [`Format`](../../../groupdocs.signature.domain/qrcodesignature/format) adresinde belirtilir. Olası desteklenen değerler: FileType.JPEG, FileType.PNG, FileType.BMP. Sağlanan format desteklenmiyorsa QR-Code görüntü içeriği orijinal .png formatında döndürülecektir.

public FileType ReturnContentType { get; set; }
