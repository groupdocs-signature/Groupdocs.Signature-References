## TGA field

Truevision TGA (.tga), también conocido como TARGA, es un formato de archivo de imagen raster desarrollado por Truevision Inc. Soporta diversas profundidades de color y compresión RLE opcional. Los archivos TGA se utilizan comúnmente en videojuegos, pipelines de animación y aplicaciones gráficas para renderizado de imágenes de alta calidad con soporte opcional de canal alfa. Obtenga más información sobre este formato de archivo aquí.
