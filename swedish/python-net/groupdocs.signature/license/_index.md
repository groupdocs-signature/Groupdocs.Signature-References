## License class

Hantera GroupDocs.Signature-licensiering.

Licensierade byggen låser upp hela funktionsuppsättningen för omslaget vid
runtime. Olicensierade byggen körs i evalueringsläge med samma API
yta men med begränsningar för utskriftsstorlek och vattenmärkta innehåll.

Licenstypen exponerar följande medlemmar:
