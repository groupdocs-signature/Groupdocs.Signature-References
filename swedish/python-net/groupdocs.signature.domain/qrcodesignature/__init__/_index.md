## __init__ {#signature_id}

Initierar ett QrCodeSignature-objekt med en signaturidentifierare som erhållits efter en sökprocess.

Den unika identifieraren används för att hämta ytterligare egenskaper för denna signatur från dokumentets signaturinformationslager.

```python
def __init__(self, signature_id):
    ...
```

| Parameter | Typ | Beskrivning |
| :- | :- | :- |
| signature_id | `str` | Unik signaturidentifierare erhållen via signerings‑ eller sökmetod. |
