## DataMatrixEncodeMode enumeration

Λειτουργία κωδικοποίησης του κωδικοποιητή DataMatrix, προεπιλογή σε Auto.

```csharp
public enum DataMatrixEncodeMode
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| Auto | `0` | Αυτόματη επιλογή της καλύτερης λειτουργίας κωδικοποίησης για την κωδικοποίηση DataMatrix |
| ASCII | `1` | Κωδικοποιεί έναν αλφαριθμητικό ή δύο αριθμητικούς χαρακτήρες ανά byte |
| Full | `6` | Κωδικοποίηση τιμών 8 bit |
| Custom | `7` | Κωδικοποίηση με την κωδικοποίηση που καθορίζεται στο BarcodeGenerator.Parameters.Barcode.DataMatrix.CodeTextEncoding |
| C40 | `8` | Χρησιμοποιεί κωδικοποίηση C40. Κωδικοποιεί αλφαριθμητικούς κεφαλαίους, πεζούς και ειδικούς χαρακτήρες |
| Text | `9` | Χρησιμοποιεί κωδικοποίηση Text. Κωδικοποιεί αλφαριθμητικούς πεζούς, κεφαλαίους και ειδικούς χαρακτήρες. |
| EDIFACT | `10` | Χρησιμοποιεί κωδικοποίηση EDIFACT. Χρησιμοποιεί έξι bits ανά χαρακτήρα, κωδικοποιεί ψηφία, κεφαλαία γράμματα και πολλά σημεία στίξης, αλλά δεν υποστηρίζει πεζά γράμματα. |
| ANSIX12 | `11` | Χρησιμοποιεί κωδικοποίηση ANSI X12. |
| ExtendedCodetext | `12` | Η λειτουργία ExtendedCodetext επιτρέπει τη χειροκίνητη εναλλαγή σχήματος κωδικοποίησης στο κείμενο κώδικα. Μορφή: "\\Encodation_scheme_name:text\\Encodation_scheme_name:text". Τα επιτρεπόμενα σχήματα κωδικοποίησης είναι: EDIFACT, ANSIX12, ASCII, C40, Text, Auto. Παράδειγμα εκτεταμένου κειμένου κώδικα: @"\\ansix12:ANSIX12TEXT\\ascii:backslash must be \\\\ doubled\\edifact:EdifactEncodedText" Όλες οι ανάστροφες καθέτους (\\) πρέπει να διπλασιαστούν στο κείμενο. |
