## GifSaveOptions class

Представляет параметры сохранения в формате GIF для графических документов.

Тип GifSaveOptions раскрывает следующие члены:

### Конструкторы
| Конструктор | Описание |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.options/gifsaveoptions/__init__/) | Инициализирует GifSaveOptions со значениями по умолчанию. |
