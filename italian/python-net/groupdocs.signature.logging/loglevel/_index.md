## LogLevel class

Il tipo LogLevel espone i seguenti membri:

### Campi
| Campo | Descrizione |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.logging/loglevel/none/) | Niente viene registrato. |
| [ERROR](/signature/python-net/groupdocs.signature.logging/loglevel/error/) | Errori: un'operazione è fallita. |
| [WARNING](/signature/python-net/groupdocs.signature.logging/loglevel/warning/) | Avvisi: un'operazione è riuscita, ma il suo risultato potrebbe non essere quello che ti aspetti. |
| [TRACE](/signature/python-net/groupdocs.signature.logging/loglevel/trace/) | Tracce: i passaggi di un'operazione, come l'inizio e la fine. |
| [ALL](/signature/python-net/groupdocs.signature.logging/loglevel/all/) | Errori, avvisi e tracce. Questo è il valore predefinito. |
