## LogLevel enumeration

Указывает, какие типы сообщений передаются в регистратор, установленный в [`SignatureSettings`](../../groupdocs.signature/signaturesettings). Значения являются флагами и могут быть объединены, например `LogLevel.Error | LogLevel.Warning`.

```csharp
[Flags]
public enum LogLevel
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Ничего не записывается. |
| Error | `1` | Ошибки: операция завершилась неудачей. |
| Warning | `2` | Предупреждения: операция завершилась успешно, но её результат может отличаться от ожидаемого. |
| Trace | `4` | Трассировки: шаги операции, такие как её начало и конец. |
| All | `7` | Ошибки, предупреждения и трассировки. Это значение по умолчанию. |
