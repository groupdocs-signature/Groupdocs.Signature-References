## IRectangle class

Definisce le proprietà dell'interfaccia per l'area della firma su una pagina del documento.

Il tipo IRectangle espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [height](/signature/python-net/groupdocs.signature.domain/irectangle/height/) | L'altezza dell'area della firma su una pagina del documento in unità di misura (pixel, percentuali o millimetri; vedere `MeasureType` SizeMeasureType). |
| [left](/signature/python-net/groupdocs.signature.domain/irectangle/left/) | La posizione X sinistra dell'area della firma su una pagina del documento in unità di misura (pixel, percentuali o millimetri). Vedere `MeasureType` per l'enumerazione `LocationMeasureType`. |
| [location_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/location_measure_type/) | Il tipo di misura (pixel, percentuali o millimetri) per le proprietà Left e Top. |
| [size_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/size_measure_type/) | Il tipo di misura (pixel, percentuali o millimetri) per le proprietà Width e Height. |
| [stretch](/signature/python-net/groupdocs.signature.domain/irectangle/stretch/) | La modalità di stretching su una pagina del documento. |
| [top](/signature/python-net/groupdocs.signature.domain/irectangle/top/) | La posizione Y superiore dell'area della firma sulla pagina del documento in unità di misura (pixel, percentuali o millimetri). Vedi `MeasureType` per il tipo di misura della posizione. |
| [width](/signature/python-net/groupdocs.signature.domain/irectangle/width/) | La larghezza dell'area della firma su una pagina del documento in valori di misura (pixel, percentuali o millimetri). Vedi `MeasureType` SizeMeasureType. |
