## return_content property

De vlag die bepaalt of de afbeeldingsinhoud van een handtekening wordt geretourneerd.

Indien ingesteld op True, wordt de inhoud van de afbeeldinghandtekening bewaard als ruwe afbeeldingsgegevens in het formaat dat is opgegeven door [`ImageSearchOptions.return_content_type`](/signature/python-net/groupdocs.signature.options/imagesearchoptions/return_content_type/). Standaard is deze optie uitgeschakeld (False).
