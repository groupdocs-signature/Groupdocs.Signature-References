## IAlignment class

描述文档页面上签名区域的对齐方式。

IAlignment 类型公开以下成员：

### 属性
| 属性 | 描述 |
| :- | :- |
| [horizontal_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/horizontal_alignment/) | 图像在文档页上的水平对齐方式。 |
| [margin](/signature/python-net/groupdocs.signature.domain/ialignment/margin/) | 默认情况下图像与文档边缘之间的间距（在设置水平或垂直对齐时适用）。 |
| [margin_measure_type](/signature/python-net/groupdocs.signature.domain/ialignment/margin_measure_type/) | 边距测量类型（像素、百分比或毫米）。 |
| [vertical_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/vertical_alignment/) | 图像在文档页上的垂直对齐方式。 |
