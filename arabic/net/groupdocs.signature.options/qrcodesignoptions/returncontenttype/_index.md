## QrCodeSignOptions.ReturnContentType property

يحدد نوع الملف لمحتوى الصورة المعاد إرجاعه لتوقيع QR-Code عندما تكون خاصية ReturnContent مفعّلة. بشكل افتراضي يتم تعيينه إلى Null. وهذا يعني إرجاع محتوى صورة QR-Code بالتنسيق الأصلي. يتم تحديد تنسيق الصورة هذا في [`Format`](../../../groupdocs.signature.domain/qrcodesignature/format). القيم المدعومة الممكنة هي: FileType.JPEG, FileType.PNG, FileType.BMP. إذا كان التنسيق المقدم غير مدعوم فسيتم إرجاع محتوى صورة QR-Code بتنسيق .png.

public FileType ReturnContentType { get; set; }
