## SaveOptions.OverwriteExistingFiles property

Obtiene o establece si se sobrescribe el archivo existente con el nuevo archivo de salida. De lo contrario, se creará un nuevo archivo con un número como sufijo. Por defecto, este valor se establece en true, lo que significa que el archivo será sobrescrito.

public bool OverwriteExistingFiles { get; set; }
