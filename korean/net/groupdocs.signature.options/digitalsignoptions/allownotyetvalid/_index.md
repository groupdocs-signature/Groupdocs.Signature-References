## DigitalSignOptions.AllowNotYetValid property

인증서의 유효 기간이 아직 시작되지 않은 경우에도 서명할 수 있도록 하는 플래그를 가져오거나 설정합니다. 기본값은 false이며, 이러한 인증서로 서명하면 [`GroupDocsSignatureException`](../../../groupdocs.signature/groupdocssignatureexception)이 발생하고 문서가 서명되지 않습니다.

```csharp
public bool AllowNotYetValid { get; set; }
```

### 비고

검증자는 인증서가 유효해지기 전에 만든 서명을 유효하지 않다고 보고합니다. 이러한 인증서는 보통 나중 날짜에 발급되었거나 컴퓨터 시계가 잘못된 경우입니다. 이 속성이 true이면 문서가 서명되고, [`SignatureSettings`](../../../groupdocs.signature/signaturesettings)에서 설정된 로거에 경고가 기록됩니다.

인증서는 UTC 기준 현재 시간과 비교됩니다. 이 플래그는 유효 기간이 끝난 인증서를 제어하는 [`AllowExpired`](../allowexpired)과 동일한 인증서에 적용됩니다.
