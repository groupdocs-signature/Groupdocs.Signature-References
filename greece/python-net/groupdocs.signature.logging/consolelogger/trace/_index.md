## trace {#message}

Γράφει ένα μήνυμα εντοπισμού στην κονσόλα.

Τα μηνύματα καταγραφής Trace παρέχουν γενικά χρήσιμες πληροφορίες σχετικά με τη ροή της εφαρμογής.

```python
def trace(self, message):
    ...
```

| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| message | `str` | Το μήνυμα trace. |

| Εγείρει | Περιγραφή |
| :- | :- |
| `ValueError` | Εγείρεται όταν το `message` είναι None. |
