## TextShadow class

Menunjukkan properti bayangan teks untuk tanda tangan teks.

Hasil dapat bervariasi tergantung pada jenis tanda tangan dan format dokumen.

TextShadow direkomendasikan untuk digunakan dengan tanda tangan `TextAsImage` untuk semua tipe dokumen yang didukung, juga dengan [`TextSignature`](/signature/python-net/groupdocs.signature.domain/textsignature/) sederhana dan [`TextSignature`](/signature/python-net/groupdocs.signature.domain/textsignature/) sebagai watermark untuk spreadsheet (`.xslx`) dan presentasi (`.pptx`).

[`TextSignature`](/signature/python-net/groupdocs.signature.domain/textsignature/) sederhana untuk dokumen Word (`.docx`) juga direkomendasikan, tetapi memiliki fungsionalitas terbatas.

Tipe TextShadow mengekspos anggota-anggota berikut:

### Properti
| Properti | Deskripsi |
| :- | :- |

| [blur](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/blur/) | Keburaman bayangan. Nilai default adalah 4. |
| [color](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/color/) | Warna bayangan. Nilai default adalah Hitam. |
| [distance](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/distance/) | Jarak dari teks ke bayangan. |
| [transparency](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/transparency/) | Transparansi bayangan. |
