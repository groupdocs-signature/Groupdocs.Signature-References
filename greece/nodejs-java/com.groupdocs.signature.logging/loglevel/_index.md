Καθορίζει τους διαθέσιμους τύπους επιπέδων καταγραφής. Αυτή η απαρίθμηση μπορεί να χρησιμοποιηθεί ως σημαίες για να οριστούν πολλές πιθανές τιμές ως ενεργά bits. Παράδειγμα: LogLevel.Error | LogLevel.Warning ή LogLevel.Error | LogLevel.Trace
## Πεδία

| Πεδίο | Περιγραφή |
| --- | --- |
| [None](#None) | Καμία περιορισμένη καταγραφή· όλες οι πληροφορίες θα καταγράφονται από το trace, την προειδοποίηση έως τα σφάλματα |
| [Error](#Error) | Καμία περιορισμένη καταγραφή· όλες οι πληροφορίες θα καταγράφονται από το trace, την προειδοποίηση έως τα σφάλματα |
| [Warning](#Warning) | Ίδιο με το επίπεδο Όλα, όλα τα μηνύματα συμπεριλαμβανομένου του επιπέδου Trace θα καταγραφούν |
| [Trace](#Trace) | Το επίπεδο καταγραφής για να περιλαμβάνει μηνύματα από το επίπεδο Προειδοποίηση έως Σφάλμα |
| [All](#All) | Όλα τα γεγονότα επιπέδου Καταγραφής (Σφάλμα, Προειδοποίηση, Trace) θα συμπεριληφθούν στην καταγραφή |
