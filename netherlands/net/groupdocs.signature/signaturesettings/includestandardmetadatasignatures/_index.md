## SignatureSettings.IncludeStandardMetadataSignatures property

Haalt op of stelt een vlag in om de ingebedde standaarddocumentmetadata‑handtekeningen, zoals Auteur, Eigenaar, aanmaakdatum van het document, wijzigingsdatum, enz., op te nemen in de Metadata‑lijst. Als deze vlag op false staat (standaard) zal GetDocumentInfo deze metadata‑handtekeningen niet opnemen. Wanneer deze vlag op true staat, zal de documentinformatie deze standaardmetadata‑handtekeningen bevatten.

public bool IncludeStandardMetadataSignatures { get; set; }
