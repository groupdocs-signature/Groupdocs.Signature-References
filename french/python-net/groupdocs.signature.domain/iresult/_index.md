## IResult class

Représente une interface commune pour le résultat du processus de signature.

Le type IResult expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/iresult/destin_document_size/) | La taille du document de destination. |
| [failed](/signature/python-net/groupdocs.signature.domain/iresult/failed/) | La liste des signatures qui n'ont pas été traitées. |
| [processing_time](/signature/python-net/groupdocs.signature.domain/iresult/processing_time/) | Le temps d'exécution du processus en millisecondes. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/iresult/source_document_size/) | La taille du document source. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/iresult/succeeded/) | La liste des signatures traitées avec succès [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/iresult/total_signatures/) | Le total des signatures traitées. |
