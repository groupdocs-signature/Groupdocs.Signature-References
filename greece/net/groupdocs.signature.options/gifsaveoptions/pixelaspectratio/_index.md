## GifSaveOptions.PixelAspectRatio property

Λαμβάνει ή ορίζει την αναλογία διαστάσεων pixel του GIF.

### Παρατηρήσεις

Pixel Aspect Ratio - Στοιχείο που χρησιμοποιείται για τον υπολογισμό μιας προσέγγισης της αναλογίας διαστάσεων του pixel στην αρχική εικόνα. Εάν η τιμή του πεδίου δεν είναι 0, αυτή η προσέγγιση της αναλογίας υπολογίζεται βάσει του τύπου: Aspect Ratio = (Pixel Aspect Ratio + 15) / 64 Η Pixel Aspect Ratio ορίζεται ως το πηλίκο του πλάτους του pixel προς το ύψος του. Η εμβέλεια τιμών σε αυτό το πεδίο επιτρέπει τον καθορισμό του πιο πλατείου pixel 4:1 έως του πιο ψηλού pixel 1:4 με βήματα 1/64. Τιμές : 0 - Δεν παρέχονται πληροφορίες για την αναλογία διαστάσεων. 1..255 - Τιμή που χρησιμοποιείται στον υπολογισμό.
