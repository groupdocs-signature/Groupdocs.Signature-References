## include_standard_metadata_signatures property

Η σημαία που υποδεικνύει εάν οι τυπικές υπογραφές μεταδεδομένων εγγράφου όπως Συγγραφέας, Ιδιοκτήτης, ημερομηνία δημιουργίας και ημερομηνία τροποποίησης περιλαμβάνονται στη λίστα μεταδεδομένων.

Εάν οριστεί σε False (προεπιλογή), το GetDocumentInfo δεν θα περιλάβει αυτές τις υπογραφές μεταδεδομένων. Όταν οριστεί σε True, οι πληροφορίες του εγγράφου θα περιλαμβάνουν τις τυπικές υπογραφές μεταδεδομένων.
