## StampTypes class

Αντιπροσωπεύει ένα δοχείο για τύπους σφραγίδας.

Ο τύπος StampTypes εκθέτει τα ακόλουθα μέλη:

### Μέθοδοι
| Μέθοδος | Περιγραφή |
| :- | :- |
| [parse](/signature/python-net/groupdocs.signature.domain/stamptypes/parse/#parsing_type) | Επιστρέφει τον τύπο σφραγίδας που ταιριάζει με το καθορισμένο όνομα τύπου ανάλυσης. |
| [try_parse](/signature/python-net/groupdocs.signature.domain/stamptypes/try_parse/#parsing_type) | Επιστρέφει έναν τύπο σφραγίδας για το δεδομένο όνομα τύπου ανάλυσης. Εάν το όνομα της σφραγίδας είναι άγνωστο, δεν ρίχνεται εξαίρεση και η μέθοδος επιστρέφει None. |
