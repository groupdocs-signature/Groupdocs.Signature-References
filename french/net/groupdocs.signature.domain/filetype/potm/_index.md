## FileType.POTM field

Les modèles de présentation PowerPoint Open XML avec macros activées (.potm) sont des fichiers modèle Microsoft PowerPoint prenant en charge les macros. Les fichiers POTM sont créés avec PowerPoint 2007 ou une version ultérieure et contiennent des paramètres par défaut pouvant être utilisés pour créer d'autres fichiers de présentation. En savoir plus sur ce format de fichier [ici](https://wiki.fileformat.com/presentation/potm).
