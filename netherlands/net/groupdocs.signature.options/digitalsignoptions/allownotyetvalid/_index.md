## DigitalSignOptions.AllowNotYetValid property

Haalt op/zet een vlag die ondertekenen met een certificaat mogelijk maakt waarvan de geldigheidsperiode nog niet is begonnen. De standaardwaarde is false: ondertekenen met een dergelijk certificaat veroorzaakt [`GroupDocsSignatureException`](../../../groupdocs.signature/groupdocssignatureexception), en het document wordt niet ondertekend.

```csharp
public bool AllowNotYetValid { get; set; }
```

### Opmerkingen

Validators melden een handtekening die is gemaakt voordat het certificaat geldig wordt als ongeldig. Zo'n certificaat is meestal uitgegeven voor een latere datum, of de computerklok staat verkeerd. Wanneer deze eigenschap true is, wordt het document ondertekend, en wordt er een waarschuwing geschreven naar de logger die is ingesteld in [`SignatureSettings`](../../../groupdocs.signature/signaturesettings).

Het certificaat wordt vergeleken met de huidige tijd in UTC. De vlag is van toepassing op dezelfde certificaten als [`AllowExpired`](../allowexpired), die certificaten beheert waarvan de geldigheidsperiode is verlopen.
