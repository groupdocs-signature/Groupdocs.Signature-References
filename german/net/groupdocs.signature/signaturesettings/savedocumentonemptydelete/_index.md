## SignatureSettings.SaveDocumentOnEmptyDelete property

Liest oder setzt das Flag, das das erneute Speichern des Quelldokuments auslöst, wenn die Delete‑Methode keine zu entfernenden Signaturen hat. Ist dieses Flag auf true (standardmäßig) gesetzt, wird das Dokument mit dem entsprechenden Verlauf‑Protokoll (Datum und Vorgangstyp) gespeichert, selbst wenn die Delete‑Methode keine Signaturen zu entfernen hat. Wird dieses Flag auf false gesetzt, wird das Quelldokument überhaupt nicht verändert.
