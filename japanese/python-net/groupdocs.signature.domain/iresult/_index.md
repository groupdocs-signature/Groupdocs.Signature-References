## IResult class

署名プロセス結果の共通インターフェースを表します。

IResult 型は次のメンバーを公開します：

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/iresult/destin_document_size/) | 宛先ドキュメントのサイズ。 |
| [failed](/signature/python-net/groupdocs.signature.domain/iresult/failed/) | 処理されなかった署名の一覧。 |
| [processing_time](/signature/python-net/groupdocs.signature.domain/iresult/processing_time/) | プロセスの実行時間（ミリ秒）。 |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/iresult/source_document_size/) | ソースドキュメントのサイズ。 |
| [succeeded](/signature/python-net/groupdocs.signature.domain/iresult/succeeded/) | 正常に処理された署名の一覧 [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/)。 |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/iresult/total_signatures/) | 合計処理された署名。 |
