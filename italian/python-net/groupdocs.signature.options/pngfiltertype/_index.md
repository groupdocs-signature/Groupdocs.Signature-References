## PngFilterType class

Il tipo PngFilterType espone i seguenti membri:

### Campi
| Campo | Descrizione |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.options/pngfiltertype/none/) | Il filtro null, indica nessuna filtrazione per le righe dei dati immagine. |
| [SUB](/signature/python-net/groupdocs.signature.options/pngfiltertype/sub/) | Il filtro sub, indica che verrà applicata una filtrazione sottrattiva ai dati immagine. |
| [UP](/signature/python-net/groupdocs.signature.options/pngfiltertype/up/) | Il filtro up, indica che verrà applicato un filtro di sottrazione riga per riga. |
| [AVG](/signature/python-net/groupdocs.signature.options/pngfiltertype/avg/) | Il filtro avg, indica che verrà applicato un filtro medio ai dati immagine. |
| [PAETH](/signature/python-net/groupdocs.signature.options/pngfiltertype/paeth/) | Il filtro path predictor. |
| [ADAPTIVE](/signature/python-net/groupdocs.signature.options/pngfiltertype/adaptive/) | La filtrazione adattiva, indica che il processo di salvataggio sceglierà il filtro più adatto per ogni riga di dati. Migliore compressione, tempo di esecuzione più lento. |
