### メソッド
| メソッド | 説明 |
| :- | :- |
| [parse](/signature/python-net/groupdocs.signature.domain/barcodetypes/parse/#parsing_type) | 指定されたパースタイプ名に対する BarcodeType インスタンスを返します。 |
| [try_parse](/signature/python-net/groupdocs.signature.domain/barcodetypes/try_parse/#parsing_type) | 指定されたパースタイプ名に一致する Barcode タイプを返します。 |
