## PdfTextAnnotationVerifyExtensions class

Описывает расширения для проверки объектов текстовых аннотаций PDF.

Тип PdfTextAnnotationVerifyExtensions раскрывает следующие члены:

### Конструкторы
| Конструктор | Описание |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.options/pdftextannotationverifyextensions/__init__/) | Инициализирует расширения проверки подписи PDF‑аннотации текста пустыми значениями. |

### Свойства
| Свойство | Описание |
| :- | :- |
| [contents](/signature/python-net/groupdocs.signature.options/pdftextannotationverifyextensions/contents/) | Содержимое текстовой аннотации для проверки; проверка пропускается, если значение является пустой строкой или None. |
| [subject](/signature/python-net/groupdocs.signature.options/pdftextannotationverifyextensions/subject/) | Тема текстовой аннотации для проверки. |
| [title](/signature/python-net/groupdocs.signature.options/pdftextannotationverifyextensions/title/) | Заголовок текстовой аннотации для проверки. Проверка пропускается, если заголовок является пустой строкой или None. |
