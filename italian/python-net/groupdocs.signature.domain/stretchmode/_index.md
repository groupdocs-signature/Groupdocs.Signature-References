## StretchMode class

Il tipo StretchMode espone i seguenti membri:

### Campi
| Campo | Descrizione |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/stretchmode/none/) | Valore predefinito. Nessuna modalità di stretching verrà applicata. |
| [PAGE_WIDTH](/signature/python-net/groupdocs.signature.domain/stretchmode/page_width/) | Allunga l'area della firma lungo la larghezza della pagina. La proprietà Margin verrà utilizzata per applicare i valori di offset richiesti. |
| [PAGE_HEIGHT](/signature/python-net/groupdocs.signature.domain/stretchmode/page_height/) | Allunga l'area della firma lungo l'altezza della pagina. La proprietà Margin verrà utilizzata per applicare i valori di offset richiesti. |
| [PAGE_AREA](/signature/python-net/groupdocs.signature.domain/stretchmode/page_area/) | Allunga l'area della firma lungo l'altezza e la larghezza della pagina. La proprietà Margin verrà utilizzata per applicare i valori di offset richiesti. |
