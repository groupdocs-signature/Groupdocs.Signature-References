## IAlignment class

Περιγράφει την ευθυγράμμιση της περιοχής υπογραφής σε μια σελίδα εγγράφου.

Ο τύπος IAlignment εκθέτει τα ακόλουθα μέλη:

### Ιδιότητες
| Ιδιότητα | Περιγραφή |
| :- | :- |
| [horizontal_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/horizontal_alignment/) | Η οριζόντια στοίχιση της εικόνας σε μια σελίδα εγγράφου. |
| [margin](/signature/python-net/groupdocs.signature.domain/ialignment/margin/) | Ο χώρος που καθορίζεται προεπιλεγμένα μεταξύ της εικόνας και των άκρων του εγγράφου (ισχύει όταν έχει οριστεί οριζόντια ή κάθετη στοίχιση). |
| [margin_measure_type](/signature/python-net/groupdocs.signature.domain/ialignment/margin_measure_type/) | Ο τύπος μέτρησης περιθωρίου (pixel, ποσοστά ή χιλιοστά). |
| [vertical_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/vertical_alignment/) | Η κάθετη στοίχιση της εικόνας σε μια σελίδα εγγράφου. |
