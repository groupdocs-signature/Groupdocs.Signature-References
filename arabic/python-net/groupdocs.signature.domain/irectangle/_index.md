## IRectangle class

يحدد خصائص الواجهة لمنطقة التوقيع على صفحة المستند.

يعرض نوع IRectangle الأعضاء التالية:

### الخصائص
| خاصية | الوصف |
| :- | :- |
| [height](/signature/python-net/groupdocs.signature.domain/irectangle/height/) | ارتفاع منطقة التوقيع على صفحة المستند بوحدات القياس (بكسل، نسب مئوية أو مليمترات؛ راجع `MeasureType` SizeMeasureType). |
| [left](/signature/python-net/groupdocs.signature.domain/irectangle/left/) | الموضع X الأيسر لمنطقة التوقيع على صفحة المستند بوحدات القياس (بكسل، نسب مئوية أو مليمترات). راجع `MeasureType` لتعداد `LocationMeasureType`. |
| [location_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/location_measure_type/) | نوع القياس (بكسل، نسب مئوية أو مليمترات) لخصائص Left و Top. |
| [size_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/size_measure_type/) | نوع القياس (بكسل، نسب مئوية أو مليمترات) لخصائص Width و Height. |
| [stretch](/signature/python-net/groupdocs.signature.domain/irectangle/stretch/) | وضع التمدد على صفحة المستند. |
| [top](/signature/python-net/groupdocs.signature.domain/irectangle/top/) | الموضع العلوي Y لمنطقة التوقيع على صفحة المستند بوحدات القياس (بكسل، نسب مئوية، أو مليمترات). راجع `MeasureType` لنوع قياس الموقع. |
| [width](/signature/python-net/groupdocs.signature.domain/irectangle/width/) | عرض منطقة التوقيع على صفحة المستند بقيم القياس (بكسل، نسب مئوية، أو مليمترات). راجع `MeasureType` SizeMeasureType. |
