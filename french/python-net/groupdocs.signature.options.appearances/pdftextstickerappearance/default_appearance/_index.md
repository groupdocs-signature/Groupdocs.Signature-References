## DEFAULT_APPEARANCE field

Obtient l'apparence par défaut pour l'autocollant. Ces propriétés sont appliquées par défaut si la propriété Options.SignatureAppearance n'est pas spécifiée. Les propriétés peuvent être modifiées par l'utilisateur à tout moment.
