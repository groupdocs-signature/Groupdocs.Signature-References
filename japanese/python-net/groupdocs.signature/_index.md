トップレベルの API クラスを含む主要な GroupDocs.Signature 名前空間。

### クラス
| クラス | 説明 |
| :- | :- |
| [`License`](/signature/python-net/groupdocs.signature/license/) | GroupDocs.Signature のライセンス管理を行います。 |
| [`Metered`](/signature/python-net/groupdocs.signature/metered/) | 従量課金（使用量に応じた）ライセンスを管理します。 |
| [`ProcessCompleteEventArgs`](/signature/python-net/groupdocs.signature/processcompleteeventargs/) | 署名、検証、検索プロセスの完了イベントに関するデータを提供します。 |
| [`ProcessCompleteEventHandler`](/signature/python-net/groupdocs.signature/processcompleteeventhandler/) | 署名、検証、検索のプロセス完了イベントを処理するメソッドデリゲートを表します。 |
| [`ProcessEventArgs`](/signature/python-net/groupdocs.signature/processeventargs/) | 署名、検証、検索プロセスのさまざまなイベントに関するデータを提供します。 |
| [`ProcessProgressEventArgs`](/signature/python-net/groupdocs.signature/processprogresseventargs/) | 署名、検証、検索プロセスの OnProgress イベントに関するデータを提供します。 |
| [`ProcessProgressEventHandler`](/signature/python-net/groupdocs.signature/processprogresseventhandler/) | 署名、検証、検索の進行イベントを処理するメソッドデリゲートを表します。 |
| [`ProcessStartEventArgs`](/signature/python-net/groupdocs.signature/processstarteventargs/) | 署名、検証、検索プロセスの開始イベントに関するデータを提供します。 |
| [`ProcessStartEventHandler`](/signature/python-net/groupdocs.signature/processstarteventhandler/) | 署名、検証、検索のプロセス開始イベントを処理するメソッドデリゲートを表します。 |
| [`Signature`](/signature/python-net/groupdocs.signature/signature/) | ドキュメント署名プロセスを制御するメインクラスを表します。 |
| [`SignatureSettings`](/signature/python-net/groupdocs.signature/signaturesettings/) | [`Signature`](/signature/python-net/groupdocs.signature/signature/) の動作をカスタマイズする設定を表します。 |
