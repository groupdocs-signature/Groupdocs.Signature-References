## return_content property

Bendera yang menentukan apakah konten gambar dari tanda tangan dikembalikan.

Jika disetel ke True, konten tanda tangan gambar disimpan sebagai data gambar mentah dalam format yang ditentukan oleh [`ImageSearchOptions.return_content_type`](/signature/python-net/groupdocs.signature.options/imagesearchoptions/return_content_type/). Secara default opsi ini dinonaktifkan (False).
