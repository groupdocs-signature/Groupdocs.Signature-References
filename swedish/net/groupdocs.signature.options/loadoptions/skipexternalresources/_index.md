## LoadOptions.SkipExternalResources property

Hämtar eller anger en flagga som hindrar dokumentet från att ladda externa resurser. Standardvärdet är true: externa resurser laddas inte, förutom de som matchar [`WhitelistedResources`](../whitelistedresources).

```csharp
public bool SkipExternalResources { get; set; }
```

### Anmärkningar

Ett dokument kan referera till resurser som lagras utanför det: länkade bilder, bilder som infogas med ett INCLUDEPICTURE-fält, länkade bilder i presentationer och kalkylblad, samt bilder och stilmallar som en SVG-bild refererar till. Att ladda en sådan resurs får biblioteket att begära dess adress. På en server som bearbetar opålitliga dokument kan ett dokument använda detta för att få servern att skicka förfrågningar till interna adresser (server‑side request forgery), och en UNC‑ eller file://‑sökväg kan få Windows att skicka kontots NTLM‑uppgifter till en annan värd. På en offline‑ eller luftgap‑installation misslyckas förfrågningarna eller väntar på en tidsgräns.

Resurser som hoppas över ritas inte i sidoförhandsgranskningar eller i dokument som sparas som bilder, och bild‑, streckkod‑ och QR‑kod‑sökning ser dem inte. Ställ in denna egenskap till false endast för betrodda dokument, och föredra att tillåta specifika adresser med [`WhitelistedResources`](../whitelistedresources).

Inställningen gäller ordbehandlingsdokument, presentationer, kalkylblad och SVG‑bilder, inklusive dokument i arkiv. För SVG‑bilder tas referenser som inte är tillåtna bort från bilden innan den läses, och en SVG‑bild som inte är välformad XML avvisas. Inställningen styr inte certifikatåterkallningskontroller, tidsstämpelservrar eller licensiering.

Denna egenskap ersätter LoadExternalResources, som har motsatt betydelse.
