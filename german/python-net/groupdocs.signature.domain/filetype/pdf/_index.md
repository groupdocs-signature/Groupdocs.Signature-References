## PDF field

Portable Document Format Datei (.pdf) ist ein Dokumenttyp, der von Adobe in den 1990er‑Jahren erstellt wurde. Der Zweck dieses Dateiformats war es, einen Standard für die Darstellung von Dokumenten und anderem Referenzmaterial in einem Format einzuführen, das unabhängig von Anwendungssoftware, Hardware sowie Betriebssystem ist. Erfahren Sie hier mehr über dieses Dateiformat.
