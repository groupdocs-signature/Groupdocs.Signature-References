## LoadOptions.SkipExternalResources property

外部リソースの読み込みを停止するフラグを取得または設定します。デフォルト値は true です。外部リソースは読み込まれず、[`WhitelistedResources`](../whitelistedresources) と一致するものだけが読み込まれます。

```csharp
public bool SkipExternalResources { get; set; }
```

### 備考

ドキュメントは、外部に保存されているリソース（リンクされた画像、INCLUDEPICTURE フィールドで挿入された画像、プレゼンテーションやスプレッドシート内のリンク画像、SVG 画像が参照する画像やスタイルシート）を参照することができます。このようなリソースを読み込むと、ライブラリはそのアドレスにリクエストを送ります。信頼できないドキュメントを処理するサーバー上では、ドキュメントがこれを利用してサーバーに内部アドレスへのリクエスト（サーバー側リクエスト偽装）を送らせたり、UNC や file:// パスにより Windows がアカウントの NTLM 資格情報を別のホストに送信させる可能性があります。オフラインまたはエアギャップ環境では、これらのリクエストは失敗するか、タイムアウトを待ちます。

スキップされたリソースはページプレビューや画像として保存されたドキュメントに描画されず、画像、バーコード、QRコードの検索でも検出されません。このプロパティは信頼できるドキュメントの場合にのみ false に設定し、特定のアドレスを許可するには [`WhitelistedResources`](../whitelistedresources) を使用することを推奨します。

この設定はワードプロセッシング文書、プレゼンテーション、スプレッドシート、SVG 画像（アーカイブ内の文書を含む）に適用されます。SVG 画像の場合、許可されていない参照は画像が読み込まれる前に削除され、XML が正しく構成されていない SVG 画像は拒否されます。この設定は証明書失効チェック、タイムスタンプサーバー、ライセンス管理を制御しません。

このプロパティは LoadExternalResources の代わりとなりますが、意味は逆です。
