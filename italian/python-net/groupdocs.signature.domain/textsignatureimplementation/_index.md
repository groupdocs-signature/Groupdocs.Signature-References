## TextSignatureImplementation class

Il tipo TextSignatureImplementation espone i seguenti membri:

### Campi
| Campo | Descrizione |
| :- | :- |
| [NATIVE](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/native/) | Firma testuale come oggetto di testo nativo nella pagina del documento. |
| [IMAGE](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/image/) | Firma testuale come oggetto immagine nella pagina del documento. |
| [ANNOTATION](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/annotation/) | Firma testuale come oggetto di annotazione testuale nella pagina PDF. Le annotazioni sono visibili solo nella versione con licenza. |
| [STICKER](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/sticker/) | Firma testuale come oggetto adesivo nella pagina PDF. |
| [FORM_FIELD](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/form_field/) | Firma testuale come testo in un campo modulo specificato. Con questo tipo di implementazione possono essere utilizzate solo le opzioni TextSignOptions.Text, TextSignOptions.FormTextFieldType e TextSignOptions.FormTextFieldTitle. |
| [WATERMARK](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/watermark/) | Firma testuale come filigrana nella pagina del documento. |
