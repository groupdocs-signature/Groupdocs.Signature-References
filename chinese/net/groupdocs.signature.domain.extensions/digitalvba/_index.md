## DigitalVBA class

表示用于电子表格 VBA 项目的数字签名。它提供在特定的电子表格文档格式（如 Xlsm 或 Xltm）对 VBA 项目进行签名的能力。如果将多个 DigitalVBA 扩展添加到 DigitalSignOptions.Extensions 中，只有第一个会参与文档签名。

```csharp
public class DigitalVBA : SignatureExtension
```
