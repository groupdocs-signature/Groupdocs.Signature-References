## BarcodeSearchOptions.ReturnContent property

Получает или задает флаг для получения содержимого изображения штрихкода подписи на странице документа. Если этот флаг установлен в true, содержимое изображения подписи штрихкода будет сохранять необработанные данные изображения в требуемом формате [`ReturnContentType`](../returncontenttype). По умолчанию эта опция отключена.

```csharp
public bool ReturnContent { get; set; }
```
