## SaveOptions.OverwriteExistingFiles property

Obtient ou définit s'il faut écraser le fichier existant avec le nouveau fichier de sortie. Sinon, un nouveau fichier sera créé avec un numéro en suffixe. Par défaut, cette valeur est définie sur true, ce qui signifie que le fichier sera écrasé.

public bool OverwriteExistingFiles { get; set; }
