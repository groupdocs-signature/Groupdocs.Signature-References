## PPT field

PowerPoint Presentation (.ppt) rappresenta un file PowerPoint che consiste in una raccolta di diapositive da visualizzare come presentazione. Specifica il Binary File Format utilizzato da Microsoft PowerPoint 97-2003. Scopri di più su questo formato di file qui.
