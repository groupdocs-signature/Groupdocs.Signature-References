Definisce diversi formati di salvataggio per i documenti Spreadsheet.
## Campi

| Campo | Descrizione |
| --- | --- |
| [Default](#Default) | Il formato file non verrà modificato. |
| [CSV](#CSV) | Salva il documento come file a valori separati da virgola. |
| [Excel97To2003](#Excel97To2003) | Salva il documento come cartella di lavoro Microsoft Excel 97-2003 (.xls). |
| [Xlsx](#Xlsx) | Salva il documento come cartella di lavoro Microsoft Excel OpenXML. |
| [Xlsm](#Xlsm) | Salva il documento come cartella di lavoro Microsoft Excel con macro abilitate. |
| [Xltx](#Xltx) | Salva il documento come modello Microsoft Excel. |
| [Xltm](#Xltm) | Salva il documento come modello Microsoft Excel con macro abilitate. |
| [Xlam](#Xlam) | Salva il documento come componente aggiuntivo Microsoft Excel con macro abilitate. |
| [Pdf](#Pdf) | Salva il documento come file PDF. |
| [ODS](#ODS) | Salva il documento come cartella di lavoro Open Office. |
| [Xlsb](#Xlsb) | Salva il documento come cartella di lavoro Microsoft Excel Binary. |
| [XPS](#XPS) | Salva il documento come file XML Paper Specification. |
| [TIFF](#TIFF) | Salva il documento in formato Tagged Image File Format. |
| [SVG](#SVG) | Salva il documento come file Scalable Vector Graphics. |
| [Dif](#Dif) | Salva il documento in Data Interchange Format. |
| [Emf](#Emf) | Salva il documento in formato Windows Enhanced Metafile. |
| [Jpg](#Jpg) | Salva il documento in formato Jpeg. |
| [Png](#Png) | Salva il documento in formato Portable Network Graphics. |
