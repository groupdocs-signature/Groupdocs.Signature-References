## UpdateResult class

Representa el resultado de la modificación de firmas en el documento.

El tipo UpdateResult expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/updateresult/destin_document_size/) | El tamaño del documento de destino. |
| [failed](/signature/python-net/groupdocs.signature.domain/updateresult/failed/) | La lista de firmas que no se actualizaron [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [processing_time](/signature/python-net/groupdocs.signature.domain/updateresult/processing_time/) | El tiempo de ejecución del proceso en milisegundos. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/updateresult/source_document_size/) | El tamaño del documento de origen. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/updateresult/succeeded/) | La lista de firmas modificadas con éxito [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/updateresult/total_signatures/) | El total de firmas procesadas. |
