मुख्य GroupDocs.Signature नेमस्पेस जिसमें शीर्ष-स्तर के API क्लासेस हैं।

### क्लासेस
| क्लास | विवरण |
| :- | :- |
| [`License`](/signature/python-net/groupdocs.signature/license/) | GroupDocs.Signature लाइसेंसिंग को प्रबंधित करता है। |
| [`Metered`](/signature/python-net/groupdocs.signature/metered/) | मीटरड (पे-पर-यूज़) लाइसेंसिंग को प्रबंधित करता है। |
| [`ProcessCompleteEventArgs`](/signature/python-net/groupdocs.signature/processcompleteeventargs/) | साइनिंग, वेरिफिकेशन और सर्च प्रक्रियाओं के पूर्ण इवेंट पर डेटा प्रदान करता है। |
| [`ProcessCompleteEventHandler`](/signature/python-net/groupdocs.signature/processcompleteeventhandler/) | एक मेथड डेलीगेट का प्रतिनिधित्व करता है जो साइनिंग, वेरिफिकेशन और सर्च के प्रोसेस पूर्णता इवेंट्स को संभालता है। |
| [`ProcessEventArgs`](/signature/python-net/groupdocs.signature/processeventargs/) | सिग्नेचर, वेरिफिकेशन और सर्च प्रक्रियाओं के विभिन्न इवेंट्स के लिए डेटा प्रदान करता है। |
| [`ProcessProgressEventArgs`](/signature/python-net/groupdocs.signature/processprogresseventargs/) | साइनिंग, वेरिफिकेशन और सर्च प्रक्रियाओं के OnProgress इवेंट के लिए डेटा प्रदान करता है। |
| [`ProcessProgressEventHandler`](/signature/python-net/groupdocs.signature/processprogresseventhandler/) | हस्ताक्षर, सत्यापन और खोज के लिए प्रगति घटनाओं को संभालने वाले मेथड डेलीगेट का प्रतिनिधित्व करता है। |
| [`ProcessStartEventArgs`](/signature/python-net/groupdocs.signature/processstarteventargs/) | हस्ताक्षर, सत्यापन और खोज प्रक्रियाओं की प्रारंभिक घटना के लिए डेटा प्रदान करता है। |
| [`ProcessStartEventHandler`](/signature/python-net/groupdocs.signature/processstarteventhandler/) | हस्ताक्षर, सत्यापन और खोज के लिए प्रक्रिया प्रारंभ घटनाओं को संभालने वाले मेथड डेलीगेट का प्रतिनिधित्व करता है। |
| [`Signature`](/signature/python-net/groupdocs.signature/signature/) | दस्तावेज़ हस्ताक्षर प्रक्रिया को नियंत्रित करने वाली मुख्य क्लास का प्रतिनिधित्व करता है। |
| [`SignatureSettings`](/signature/python-net/groupdocs.signature/signaturesettings/) | [`Signature`](/signature/python-net/groupdocs.signature/signature/) के व्यवहार को अनुकूलित करने के लिए सेटिंग्स का प्रतिनिधित्व करता है। |
