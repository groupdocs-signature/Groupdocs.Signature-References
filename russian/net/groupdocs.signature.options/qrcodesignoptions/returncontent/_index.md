## QrCodeSignOptions.ReturnContent property

Получает или задает флаг для получения содержимого изображения QR-Code подписи, размещённой на странице документа. Если этот флаг установлен в true, содержимое изображения подписи QR-Code будет сохранять необработанные данные изображения в требуемом формате [`ReturnContentType`](../returncontenttype). По умолчанию эта опция отключена.

```csharp
public bool ReturnContent { get; set; }
```
