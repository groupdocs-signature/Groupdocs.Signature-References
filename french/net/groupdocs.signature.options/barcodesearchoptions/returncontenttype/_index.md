## BarcodeSearchOptions.ReturnContentType property

Spécifie le type de fichier du contenu image retourné de la signature Barcode lorsque la propriété ReturnContent est activée. Par défaut, il est défini sur Null. Cela signifie que le contenu image du code-barres sera retourné dans son format original. Ce format d'image est spécifié à [`Format`](../../../groupdocs.signature.domain/barcodesignature/format). Les valeurs prises en charge possibles sont : FileType.JPEG, FileType.PNG, FileType.BMP. Si le format fourni n'est pas pris en charge, le contenu image du code-barres sera retourné au format .png.
