## FileType class

파일 유형을 나타냅니다.

자세히 알아보기

- More about file types supported by GroupDocs.Signature: Document formats supported by GroupDocs.Signature (https://docs.groupdocs.com/display/signaturenet/Supported+Document+Formats)
- More about how to get supported formats list in C#: How to get supported file formats in C# code (https://docs.groupdocs.com/display/signaturenet/Get+supported+file+formats)

FileType 유형은 다음 멤버를 노출합니다:

### 메서드
| 메서드 | 설명 |
| :- | :- |
| [equals](/signature/python-net/groupdocs.signature.domain/filetype/equals/#other) | 현재 FileType이 지정된 FileType 객체와 동일한지 확인합니다. |
| [equals](/signature/python-net/groupdocs.signature.domain/filetype/equals/#obj) | 현재 [`FileType`](/signature/python-net/groupdocs.signature.domain/filetype/) 가 지정된 객체와 동일한지 확인합니다. |
| [equals_file_type](/signature/python-net/groupdocs.signature.domain/filetype/equals_file_type/) |  |
| [equals_object](/signature/python-net/groupdocs.signature.domain/filetype/equals_object/) |  |
| [from_extension](/signature/python-net/groupdocs.signature.domain/filetype/from_extension/#extension) | 파일 확장자를 파일 유형에 매핑합니다. |
| [get_hash_code](/signature/python-net/groupdocs.signature.domain/filetype/get_hash_code/) | 현재 [`FileType`](/signature/python-net/groupdocs.signature.domain/filetype/) 객체의 해시 코드를 반환합니다. |
| [get_supported_file_types](/signature/python-net/groupdocs.signature.domain/filetype/get_supported_file_types/) | 지원되는 파일 유형을 검색합니다. |
| [to_string](/signature/python-net/groupdocs.signature.domain/filetype/to_string/) | 현재 객체를 나타내는 문자열을 반환합니다. |

### 속성
| 속성 | 설명 |
| :- | :- |
| [extension](/signature/python-net/groupdocs.signature.domain/filetype/extension/) | 파일 이름 접미사(마침표 "." 포함) 예: ".doc". |
| [file_format](/signature/python-net/groupdocs.signature.domain/filetype/file_format/) | 파일 형식 이름, 예: "Microsoft Word Document". |

### 예시

```python
from groupdocs.signature.domain import FileType
import os

# 지원되는 모든 파일 유형을 나열합니다.
for ft in FileType.get_supported_file_types():
    print(f"{ft.extension}: {ft.file_format}")

# 특정 파일 확장자가 지원되는지 확인합니다.
extension = os.path.splitext("contract.pdf")[1]
if FileType.from_extension(extension) == FileType.UNKNOWN:
    print(f"{extension} files are not supported")
else:
    print(f"{extension} files are supported")
```
