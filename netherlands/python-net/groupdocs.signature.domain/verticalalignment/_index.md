## VerticalAlignment class

Het VerticalAlignment-type geeft de volgende leden weer:

### Velden
| Veld | Beschrijving |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/verticalalignment/none/) | Het object wordt expliciet gepositioneerd, meestal met behulp van de Top-eigenschap. |
| [TOP](/signature/python-net/groupdocs.signature.domain/verticalalignment/top/) | Specificeert dat het object zich bovenaan de verticale uitlijningsbasis bevindt. |
| [CENTER](/signature/python-net/groupdocs.signature.domain/verticalalignment/center/) | Specificeert dat het object gecentreerd moet zijn ten opzichte van de verticale uitlijningsbasis. |
| [BOTTOM](/signature/python-net/groupdocs.signature.domain/verticalalignment/bottom/) | Specificeert dat het object zich onderaan de verticale uitlijningsbasis bevindt. |
