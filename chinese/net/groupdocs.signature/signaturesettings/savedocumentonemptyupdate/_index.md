## SignatureSettings.SaveDocumentOnEmptyUpdate property

获取或设置标志，以在 Update 方法没有签名可更新时重新保存源文档。如果此标志设置为 true（默认），即使 Update 方法没有签名可更新，文档也会保存相应的历史处理日志（日期和操作类型）。当此标志设置为 false 时，源文档将完全不被修改。

public bool SaveDocumentOnEmptyUpdate { get; set; }
