## BarcodeSearchOptions.ReturnContent property

Obtiene o establece la bandera para capturar el contenido de imagen del código de barras de una firma en la página del documento. Si esta bandera se establece en true, el contenido de la imagen de la firma de código de barras conservará los datos de imagen sin procesar en el formato requerido [`ReturnContentType`](../returncontenttype). Por defecto, esta opción está deshabilitada.

public bool ReturnContent { get; set; }
