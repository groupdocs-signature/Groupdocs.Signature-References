## LogLevel enumeration

Gibt an, welche Arten von Nachrichten an den Logger weitergeleitet werden, der in [`SignatureSettings`](../../groupdocs.signature/signaturesettings) festgelegt ist. Die Werte sind Flags und können kombiniert werden, zum Beispiel `LogLevel.Error | LogLevel.Warning`.

```csharp
[Flags]
public enum LogLevel
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| None | `0` | Es wird nichts protokolliert. |
| Error | `1` | Fehler: Ein Vorgang ist fehlgeschlagen. |
| Warning | `2` | Warnungen: Ein Vorgang war erfolgreich, aber sein Ergebnis entspricht möglicherweise nicht Ihren Erwartungen. |
| Trace | `4` | Spuren: Die Schritte eines Vorgangs, wie dessen Beginn und Ende. |
| All | `7` | Fehler, Warnungen und Spuren. Dies ist die Standardeinstellung. |
