## IResult class

Stelt een algemene interface voor het resultaat van het handtekeningproces voor.

Het type IResult exposeert de volgende leden:

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/iresult/destin_document_size/) | De grootte van het bestemmingsdocument. |
| [failed](/signature/python-net/groupdocs.signature.domain/iresult/failed/) | De lijst met handtekeningen die niet verwerkt zijn. |
| [processing_time](/signature/python-net/groupdocs.signature.domain/iresult/processing_time/) | De uitvoeringstijd van het proces in milliseconden. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/iresult/source_document_size/) | De grootte van het brondocument. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/iresult/succeeded/) | De lijst met succesvol verwerkte handtekeningen [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/iresult/total_signatures/) | Het totale aantal verwerkte handtekeningen. |
