## LogLevel class

LogLevel 유형은 다음 멤버를 노출합니다:

### 필드
| 필드 | 설명 |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.logging/loglevel/none/) | 아무 것도 기록되지 않습니다. |
| [ERROR](/signature/python-net/groupdocs.signature.logging/loglevel/error/) | 오류: 작업이 실패했습니다. |
| [WARNING](/signature/python-net/groupdocs.signature.logging/loglevel/warning/) | 경고: 작업은 성공했지만 결과가 기대와 다를 수 있습니다. |
| [TRACE](/signature/python-net/groupdocs.signature.logging/loglevel/trace/) | 추적: 작업의 단계, 예를 들어 시작과 종료. |
| [ALL](/signature/python-net/groupdocs.signature.logging/loglevel/all/) | 오류, 경고 및 추적. 이것이 기본값입니다. |
