## PPTX field

PowerPoint Open XML Presentation (.pptx) は、一般的な Microsoft PowerPoint アプリケーションで作成されるプレゼンテーション ファイルです。従来のバイナリ形式 PPT と異なり、PPTX 形式は Microsoft PowerPoint のオープン XML プレゼンテーション ファイル形式に基づいています。このファイル形式の詳細については、こちらをご覧ください。
