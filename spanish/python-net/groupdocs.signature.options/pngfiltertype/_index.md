## PngFilterType class

El tipo PngFilterType expone los siguientes miembros:

### Campos
| Campo | Descripción |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.options/pngfiltertype/none/) | El filtro nulo, significa que no hay filtrado para las filas de datos de imagen. |
| [SUB](/signature/python-net/groupdocs.signature.options/pngfiltertype/sub/) | El filtro sub, significa que se aplicará filtrado sustractivo a los datos de imagen. |
| [UP](/signature/python-net/groupdocs.signature.options/pngfiltertype/up/) | El filtro up, significa que se aplicará un filtro de sustracción fila por fila. |
| [AVG](/signature/python-net/groupdocs.signature.options/pngfiltertype/avg/) | El filtro avg, significa que se aplicará un filtro promedio a los datos de imagen. |
| [PAETH](/signature/python-net/groupdocs.signature.options/pngfiltertype/paeth/) | El filtro predictor de ruta. |
| [ADAPTIVE](/signature/python-net/groupdocs.signature.options/pngfiltertype/adaptive/) | El filtrado adaptativo, significa que el proceso de guardado elegirá el filtro más adecuado para cada fila de datos. Mejor compresión, tiempo de ejecución más lento. |
