## TIFF field

Tagged Image File Format (.tiff) vertegenwoordigt rasterafbeeldingen die bedoeld zijn voor gebruik op diverse apparaten die voldoen aan deze bestandsformaatstandaard. Het kan bilevel-, grijswaarden-, paletkleur- en full-color-beeldgegevens beschrijven in verschillende kleurenschema's. Meer informatie over dit bestandsformaat hier.
