## ImageSearchOptions.ReturnContentType property

ReturnContent özelliği etkin olduğunda görüntü imzasının döndürülen içeriğinin dosya tipini belirtir. Varsayılan olarak Null ayarlanmıştır. Bu, görüntü içeriğinin orijinal formatta döneceği anlamına gelir. Bu görüntü formatı [`Format`](../../../groupdocs.signature.domain/imagesignature/format) adresinde belirtilir. Desteklenen olası değerler: FileType.JPEG, FileType.PNG, FileType.BMP. Sağlanan format desteklenmiyorsa, görüntü içeriği orijinal formatta dönecektir.

public FileType ReturnContentType { get; set; }
