## BitmapCompression class

Tipe BitmapCompression menampilkan anggota-anggota berikut:

### Bidang
| Bidang | Deskripsi |
| :- | :- |
| [RGB](/signature/python-net/groupdocs.signature.options/bitmapcompression/rgb/) | Tanpa kompresi. |
| [RLE8](/signature/python-net/groupdocs.signature.options/bitmapcompression/rle8/) | Kompresi RLE 8-bit/piksel. Hanya dapat digunakan dengan bitmap 8-bit/piksel. |
| [RLE4](/signature/python-net/groupdocs.signature.options/bitmapcompression/rle4/) | Kompresi RLE 4-bit/piksel. Hanya dapat digunakan dengan bitmap 4-bit/piksel. |
| [BITFIELDS](/signature/python-net/groupdocs.signature.options/bitmapcompression/bitfields/) | Bidang bit. Hanya dapat digunakan dengan bitmap 16 dan 32-bit/piksel. |
| [JPEG](/signature/python-net/groupdocs.signature.options/bitmapcompression/jpeg/) | Kompresi JPEG. Bitmap berisi gambar JPEG. |
| [PNG](/signature/python-net/groupdocs.signature.options/bitmapcompression/png/) | Kompresi PNG. Bitmap berisi gambar PNG. |
