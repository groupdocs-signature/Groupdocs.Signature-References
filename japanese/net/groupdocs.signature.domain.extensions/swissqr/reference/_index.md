## SwissQR.Reference property

債権者の支払参照を取得または設定します。この参照は SwissQR IBAN（CHxx30000xxxxxx から CHxx31999xxxxx の範囲）に必須です。指定された場合、参照は有効な SwissQR 参照（ISR 参照形式に対応）または ISO 11649（\"RFxxxx\"）に従った有効な債権者参照のいずれかでなければなりません。どちらもフォーマット用にスペースを含めることができます。

```csharp
public string Reference { get; set; }
```

### Property Value

債権者の支払参照。
