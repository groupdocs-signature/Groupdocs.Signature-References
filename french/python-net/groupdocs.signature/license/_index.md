## License class

Gère la licence de GroupDocs.Signature.

Les versions sous licence débloquent l'ensemble complet des fonctionnalités du wrapper à
l'exécution. Les versions non licenciées fonctionnent en mode d'évaluation avec la même API
mais avec des limites sur la taille de sortie et le contenu filigrané.
