## LoadOptions.WhitelistedResources property

बाहरी संसाधनों के पतों के फ्रैगमेंट प्राप्त करता है या सेट करता है जो [`SkipExternalResources`](../skipexternalresources) के true होने पर भी लोड होते हैं। डिफ़ॉल्ट मान एक खाली सूची है।

```csharp
public List<string> WhitelistedResources { get; set; }
```

### टिप्पणियाँ

जब किसी संसाधन का पूरा पता किसी फ्रैगमेंट को शामिल करता है, तो वह लोड हो जाता है। तुलना केस को अनदेखा करती है, और खाली फ्रैगमेंट को नजरअंदाज़ किया जाता है। लंबी फ्रैगमेंट जैसे "https://cdn.example.com/images/" को प्राथमिकता दें: एक छोटा फ्रैगमेंट भी उन अन्य पतों से मेल खा सकता है जिनमें वह मौजूद है।

इस प्रॉपर्टी को null सेट करने से सूची साफ़ हो जाती है। जब [`SkipExternalResources`](../skipexternalresources) false होता है, तो सूची का कोई प्रभाव नहीं रहता, क्योंकि तब सभी बाहरी संसाधन लोड हो जाते हैं।
