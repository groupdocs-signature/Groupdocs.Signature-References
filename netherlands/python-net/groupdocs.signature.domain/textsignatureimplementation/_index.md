## TextSignatureImplementation class

Het TextSignatureImplementation-type geeft de volgende leden weer:

### Velden
| Veld | Beschrijving |
| :- | :- |
| [NATIVE](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/native/) | Teksthandtekening als native tekstobject op documentpagina. |
| [IMAGE](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/image/) | Teksthandtekening als afbeeldingobject op documentpagina. |
| [ANNOTATION](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/annotation/) | Teksthandtekening als tekstannotatie-object op PDF-pagina. Annotaties zijn alleen zichtbaar in de gelicentieerde versie. |
| [STICKER](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/sticker/) | Teksthandtekening als stickerobject op PDF-pagina. |
| [FORM_FIELD](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/form_field/) | Teksthandtekening als tekst in een opgegeven formulierveld.
