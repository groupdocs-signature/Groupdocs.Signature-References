## BaseSignature class

Stellt die Basisklasse für Signaturen dar.

Der BaseSignature-Typ stellt die folgenden Mitglieder bereit:

### Methoden
| Methode | Beschreibung |
| :- | :- |
| [clone](/signature/python-net/groupdocs.signature.domain/basesignature/clone/) | Klonen Sie die Signaturinstanz. |
| [equals](/signature/python-net/groupdocs.signature.domain/basesignature/equals/#obj) | Vergleicht das gegebene Signaturobjekt mit dieser Instanz auf Gleichheit. |
| [equals_object](/signature/python-net/groupdocs.signature.domain/basesignature/equals_object/) |  |
| [get_hash_code](/signature/python-net/groupdocs.signature.domain/basesignature/get_hash_code/) | Stellt eine überschriebene Implementierung von GetHashCode bereit. |

| [page_number](/signature/python-net/groupdocs.signature.domain/basesignature/page_number/) | Die Seitenzahl, auf der die Signatur gefunden wurde. |
