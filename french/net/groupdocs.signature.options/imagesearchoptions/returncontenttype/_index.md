## ImageSearchOptions.ReturnContentType property

Spécifie le type de fichier du contenu retourné de la signature image lorsque la propriété ReturnContent est activée. Par défaut, il est défini sur Null. Cela signifie que le contenu de l'image est retourné dans son format d'origine. Ce format d'image est spécifié à [`Format`](../../../groupdocs.signature.domain/imagesignature/format). Les valeurs prises en charge possibles sont : FileType.JPEG, FileType.PNG, FileType.BMP. Si le format fourni n'est pas pris en charge, le contenu de l'image sera retourné dans son format d'origine.
