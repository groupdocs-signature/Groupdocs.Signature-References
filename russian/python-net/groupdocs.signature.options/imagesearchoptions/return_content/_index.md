## return_content property

Флаг, определяющий, будет ли возвращено содержимое изображения подписи.

Если установлено в True, содержимое подписи изображения сохраняется как необработанные данные изображения в формате, указанном в [`ImageSearchOptions.return_content_type`](/signature/python-net/groupdocs.signature.options/imagesearchoptions/return_content_type/). По умолчанию эта опция отключена (False).
