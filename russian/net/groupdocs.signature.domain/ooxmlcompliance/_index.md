## OoxmlCompliance enumeration

Указывает уровень соответствия OOXML для документов WordProcessing. При установке при сохранении переопределяет соответствие оригинального документа; в противном случае соответствие загруженного документа сохраняется при сохранении.

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Ecma | `0` | Уровень соответствия ECMA-376 1-е издание. |
| Transitional | `1` | Уровень соответствия ISO/IEC 29500:2008 Transitional. |
| Strict | `2` | Уровень соответствия ISO/IEC 29500:2008 Strict. |
