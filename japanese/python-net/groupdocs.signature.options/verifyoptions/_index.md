## VerifyOptions class

ドキュメントを検証するオプションを保持します。

VerifyOptions 型は以下のメンバーを公開します:

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [all_pages](/signature/python-net/groupdocs.signature.options/verifyoptions/all_pages/) | 各ドキュメントページを検証するかどうかを示すフラグです。デフォルトでは値は True です。 |
| [extensions](/signature/python-net/groupdocs.signature.options/verifyoptions/extensions/) | 代替署名オプションの検証用追加拡張子です。 |
| [is_valid](/signature/python-net/groupdocs.signature.options/verifyoptions/is_valid/) | 有効なプロパティフラグです。 |
| [page_number](/signature/python-net/groupdocs.signature.options/verifyoptions/page_number/) | 検証対象のドキュメントページ番号です。設定されていない場合、ドキュメントのすべてのページが最初の出現箇所について検証されます（最小値は 1）。 |
| [pages_setup](/signature/python-net/groupdocs.signature.options/verifyoptions/pages_setup/) | 検証対象ページを指定するページオプションです。 |
| [shape_position](/signature/python-net/groupdocs.signature.options/verifyoptions/shape_position/) | ヘッダー/フッター内の署名を検証するために使用される、ドキュメントレイアウト内のシェイプ位置です。 |
