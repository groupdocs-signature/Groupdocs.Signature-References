## FileType.TIFF field

Tagged Image File Format (.tiff) 表示用于在符合此文件格式标准的各种设备上使用的光栅图像。它能够在多种色彩空间中描述二值、灰度、调色板颜色和全彩图像数据。了解更多关于此文件格式的信息，请点击[此处](https://wiki.fileformat.com/image/tiff)。
