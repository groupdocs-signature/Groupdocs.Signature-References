## show_properties property

Das Flag, das die Anzeige der Signatur‑Eigenschaften erzwingt; wenn true, verwendet das Signaturfeld ein vordefiniertes Anzeigeformat (z. B. `Digitally signed by {PdfDigitalSignature.contact_info} Date: {Date} Reason: {PdfDigitalSignature.reason} Location: {PdfDigitalSignature.location}`) und ist standardmäßig auf True gesetzt.
