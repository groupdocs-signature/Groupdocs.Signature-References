## JPEG field

JPEG Image (.jpeg) — это тип формата изображения, сохраняемый с помощью метода сжатия с потерями. Получаемое изображение в результате сжатия представляет собой компромисс между размером хранения и качеством изображения. Узнайте больше об этом формате файла здесь.
