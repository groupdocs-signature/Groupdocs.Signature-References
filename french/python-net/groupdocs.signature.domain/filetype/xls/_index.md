## XLS field

Le tableau Excel (.xls) représente le format de fichier binaire Excel. De tels fichiers peuvent être créés par Microsoft Excel ainsi que par d'autres programmes de tableur similaires tels qu'OpenOffice Calc ou Apple Numbers. En savoir plus sur ce format de fichier ici.
