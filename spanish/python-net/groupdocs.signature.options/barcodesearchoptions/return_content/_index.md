## return_content property

La bandera que indica si se debe recuperar el contenido de imagen del código de barras de una firma en una página del documento.

Si se establece en `True`, el contenido de imagen de la firma de código de barras se mantiene como datos de imagen sin procesar en el formato especificado por `return_content_type`. Deshabilitado por defecto.
