## DigitalVBA class

Représente la signature numérique pour les projets VBA de Spreadsheets. Elle fournit la capacité de signer le projet VBA dans des formats de documents Spreadsheets spécifiques comme Xlsm ou Xltm. Si plusieurs extensions DigitalVBA sont ajoutées à DigitalSignOptions.Extensions, seule la première est impliquée dans la signature du document.

```csharp
public class DigitalVBA : SignatureExtension
```
