## LogLevel class

Ο τύπος LogLevel εκθέτει τα παρακάτω μέλη:

### Πεδία
| Πεδίο | Περιγραφή |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.logging/loglevel/none/) | Τίποτα δεν καταγράφεται. |
| [ERROR](/signature/python-net/groupdocs.signature.logging/loglevel/error/) | Σφάλματα: μια λειτουργία απέτυχε. |
| [WARNING](/signature/python-net/groupdocs.signature.logging/loglevel/warning/) | Προειδοποιήσεις: μια λειτουργία ολοκληρώθηκε, αλλά το αποτέλεσμα της μπορεί να μην είναι αυτό που περιμένετε. |
| [TRACE](/signature/python-net/groupdocs.signature.logging/loglevel/trace/) | Εντοπισμοί: τα βήματα μιας λειτουργίας, όπως η έναρξη και το τέλος της. |
| [ALL](/signature/python-net/groupdocs.signature.logging/loglevel/all/) | Σφάλματα, προειδοποιήσεις και εντοπισμοί. Αυτό είναι το προεπιλεγμένο. |
