Определяет различные форматы сохранения файлов.

## Поля

| Поле | Описание |
| --- | --- |
|  | [Default](#Default) | Формат файла не будет изменён. |
|
|  | [Pdf](#Pdf) | Сохраняет документ в формате PDF (Adobe Portable Document). |
|
|  | [Doc](#Doc) | Сохраняет документ в формате Microsoft Word 97-2007. |
|
|  | [Xps](#Xps) | Сохраняет документ в формате XPS (XML Paper Specification). |
|
|  | [DocX](#DocX) | Сохраняет документ в формате Microsoft Word Open XML. |
|
|  | [Svg](#Svg) | Сохраняет документ в формате SVG (Scalable Vector Graphics). |
|
|  | [Epub](#Epub) | Сохраняет документ в формате IDPF EPUB. |
|
|  | [Pptx](#Pptx) | Сохраняет документ в формате PowerPoint Open XML Presentation File |
|
