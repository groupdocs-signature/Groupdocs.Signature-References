## VerticalAlignment class

Le type VerticalAlignment expose les membres suivants :

### Champs
| Champ | Description |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/verticalalignment/none/) | L'objet est positionné explicitement, généralement en utilisant sa propriété Top. |
| [TOP](/signature/python-net/groupdocs.signature.domain/verticalalignment/top/) | Spécifie que l'objet doit être en haut de la base d'alignement vertical. |
| [CENTER](/signature/python-net/groupdocs.signature.domain/verticalalignment/center/) | Spécifie que l'objet doit être centré par rapport à la base d'alignement vertical. |
| [BOTTOM](/signature/python-net/groupdocs.signature.domain/verticalalignment/bottom/) | Spécifie que l'objet doit être en bas de la base d'alignement vertical. |
