## ProcessCompleteEventArgs class

Biedt gegevens over het voltooiings‑evenement van ondertekenings-, verificatie- en zoekprocessen.

Het ProcessCompleteEventArgs-type exposeert de volgende leden:

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [canceled](/signature/python-net/groupdocs.signature/processcompleteeventargs/canceled/) | Het proces werd geannuleerd. |
| [completed](/signature/python-net/groupdocs.signature/processcompleteeventargs/completed/) | Het tijdstempel van procesafronding. |
| [ticks](/signature/python-net/groupdocs.signature/processcompleteeventargs/ticks/) | De tijd in milliseconden die is verstreken sinds het proces Start-gebeurtenis. |
| [total_signatures](/signature/python-net/groupdocs.signature/processcompleteeventargs/total_signatures/) | De totale hoeveelheid verwerkte handtekeningen. |
| [status](/signature/python-net/groupdocs.signature/processeventargs/status/) | De huidige processtatus. (geërfd van [`ProcessEventArgs`](/signature/python-net/groupdocs.signature/processeventargs/)) |
