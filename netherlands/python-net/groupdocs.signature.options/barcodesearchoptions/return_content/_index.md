## return_content property

De vlag die aangeeft of de barcode‑afbeeldingsinhoud van een handtekening op een documentpagina moet worden opgehaald.

Indien ingesteld op `True`, wordt de barcode‑handtekening‑afbeeldingsinhoud bewaard als ruwe afbeeldingsgegevens in het formaat dat is opgegeven door `return_content_type`. Standaard uitgeschakeld.
