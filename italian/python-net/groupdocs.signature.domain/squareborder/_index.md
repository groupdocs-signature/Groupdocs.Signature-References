## SquareBorder class

Rappresenta una configurazione della linea di bordo per un timbro quadrato.

Il tipo SquareBorder espone i seguenti membri:

### Costruttori
| Costruttore | Descrizione |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.domain/squareborder/__init__/#radius) | Inizializza una SquareBorderLine con un raggio di angolo arrotondato. |
| [__init__](/signature/python-net/groupdocs.signature.domain/squareborder/__init__/#corners) | Inizializza una SquareBorder con valori di raggio degli angoli. |

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [clone](/signature/python-net/groupdocs.signature.domain/border/clone/) | Implementa l'interfaccia IClonable. (eredita da [`Border`](/signature/python-net/groupdocs.signature.domain/border/)) |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [radius](/signature/python-net/groupdocs.signature.domain/squareborder/radius/) | Il raggio degli angoli quadrati. |
| [transparency](/signature/python-net/groupdocs.signature.domain/squareborder/transparency/) | La trasparenza del bordo quadrato, compresa tra 0.0 e 1.0 con un valore predefinito di 0. |
| [color](/signature/python-net/groupdocs.signature.domain/border/color/) | Il colore del bordo della firma. (eredita da [`Border`](/signature/python-net/groupdocs.signature.domain/border/)) |
| [dash_style](/signature/python-net/groupdocs.signature.domain/border/dash_style/) | Lo stile del bordo della firma. (eredita da [`Border`](/signature/python-net/groupdocs.signature.domain/border/)) |
| [visible](/signature/python-net/groupdocs.signature.domain/border/visible/) | La visibilità del bordo. (eredita da [`Border`](/signature/python-net/groupdocs.signature.domain/border/)) |
| [weight](/signature/python-net/groupdocs.signature.domain/border/weight/) | Lo spessore del bordo della firma. (eredita da [`Border`](/signature/python-net/groupdocs.signature.domain/border/)) |
