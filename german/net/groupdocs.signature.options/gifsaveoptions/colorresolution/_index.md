## GifSaveOptions.ColorResolution property

Liest oder setzt die GIF-Farbauflösung.

```csharp
public byte ColorResolution { get; set; }
```

### Hinweise

Color Resolution - Anzahl der Bits pro Primärfarbe, die im Originalbild verfügbar sind, minus 1. Dieser Wert stellt die Größe der gesamten Palette dar, aus der die Farben in der Grafik ausgewählt wurden, nicht die tatsächlich in der Grafik verwendete Farbanzahl. Zum Beispiel, wenn der Wert in diesem Feld 3 ist, hatte die Palette des Originalbildes 4 Bits pro Primärfarbe, die zur Erstellung des Bildes verfügbar waren. Dieser Wert sollte gesetzt werden, um den Reichtum der Originalpalette anzugeben, selbst wenn nicht jede Farbe der gesamten Palette auf der Quellmaschine verfügbar ist.
