## SignatureSettings.IncludeStandardMetadataSignatures property

Obtiene o establece la bandera para incluir en la Lista de Metadatos las firmas de metadatos estándar del documento incrustadas, como Autor, Propietario, fecha de creación del documento, fecha de modificación, etc. Si esta bandera se establece en false (por defecto), GetDocumentInfo no incluirá estas firmas de metadatos. Cuando esta bandera se establece en true, la información del documento incluirá estas firmas de metadatos estándar.

```csharp
public bool IncludeStandardMetadataSignatures { get; set; }
```
