## Permissions enumeration

Menentukan izin yang dapat dikonfigurasi untuk dokumen PDF, seperti pencetakan, modifikasi konten, dan ekstraksi data. Pengaturan ini hanya berlaku untuk format PDF dan mengontrol akses serta kemampuan interaksi pengguna.

```csharp
[Flags]
public enum Permissions
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| None | `0` | Izinkan semua tindakan, termasuk pencetakan, modifikasi, dan ekstraksi data. |
| DenyPrinting | `1` | Tolak pencetakan dokumen. |
| DenyModification | `2` | Tolak modifikasi konten, termasuk mengisi formulir serta menambah atau memodifikasi anotasi. |
| DenyDataExtraction | `4` | Tolak ekstraksi teks dan grafik dari dokumen. |
| DenyAll | `7` | Tolak semua tindakan, termasuk pencetakan, modifikasi, dan ekstraksi data. |
