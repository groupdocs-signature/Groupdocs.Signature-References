## BitmapCompression class

BitmapCompression タイプは以下のメンバーを公開します：

### フィールド
| フィールド | 説明 |
| :- | :- |
| [RGB](/signature/python-net/groupdocs.signature.options/bitmapcompression/rgb/) | 圧縮なし。 |
| [RLE8](/signature/python-net/groupdocs.signature.options/bitmapcompression/rle8/) | RLE 8ビット/ピクセル圧縮。8ビット/ピクセルのビットマップでのみ使用可能です。 |
| [RLE4](/signature/python-net/groupdocs.signature.options/bitmapcompression/rle4/) | RLE 4ビット/ピクセル圧縮。4ビット/ピクセルのビットマップでのみ使用可能です。 |
| [BITFIELDS](/signature/python-net/groupdocs.signature.options/bitmapcompression/bitfields/) | ビットフィールド。16ビットおよび32ビット/ピクセルのビットマップでのみ使用可能です。 |
| [JPEG](/signature/python-net/groupdocs.signature.options/bitmapcompression/jpeg/) | JPEG 圧縮。ビットマップは JPEG 画像を含みます。 |
| [PNG](/signature/python-net/groupdocs.signature.options/bitmapcompression/png/) | PNG 圧縮。ビットマップは PNG 画像を含みます。 |
