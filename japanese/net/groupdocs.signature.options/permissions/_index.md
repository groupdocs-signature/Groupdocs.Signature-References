## Permissions enumeration

PDF ドキュメントの印刷、コンテンツ変更、データ抽出などの設定可能な権限を指定します。これらの設定は PDF フォーマットにのみ適用され、ユーザーのアクセスと操作機能を制御します。

```csharp
[Flags]
public enum Permissions
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| None | `0` | 印刷、変更、データ抽出を含むすべての操作を許可します。 |
| DenyPrinting | `1` | ドキュメントの印刷を禁止します。 |
| DenyModification | `2` | フォームへの入力や注釈の追加・変更を含むコンテンツの変更を禁止します。 |
| DenyDataExtraction | `4` | ドキュメントからのテキストおよびグラフィックの抽出を禁止します。 |
| DenyAll | `7` | 印刷、変更、データ抽出を含むすべての操作を禁止します。 |
