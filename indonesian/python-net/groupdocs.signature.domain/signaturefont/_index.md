## SignatureFont class

Kelas SignatureFont menentukan properti font untuk tanda tangan teks.

Tipe SignatureFont menampilkan anggota-anggota berikut:

### Konstruktor
| Konstruktor | Deskripsi |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.domain/signaturefont/__init__/) | Menginisialisasi SignatureFont dengan nilai default. |

### Properti
| Properti | Deskripsi |
| :- | :- |
| [bold](/signature/python-net/groupdocs.signature.domain/signaturefont/bold/) | Gaya tebal font. |
| [family_name](/signature/python-net/groupdocs.signature.domain/signaturefont/family_name/) | Nama keluarga font. |
| [italic](/signature/python-net/groupdocs.signature.domain/signaturefont/italic/) | Gaya miring font. |
| [size](/signature/python-net/groupdocs.signature.domain/signaturefont/size/) | Ukuran font. |
| [strikeout](/signature/python-net/groupdocs.signature.domain/signaturefont/strikeout/) | Gaya coret font. |
| [underline](/signature/python-net/groupdocs.signature.domain/signaturefont/underline/) | Gaya garis bawah font. |

### Contoh

```python
from groupdocs.signature.domain import SignatureFont

font = SignatureFont()
font.family_name = "Arial"
font.size = 20
font.bold = True
```
