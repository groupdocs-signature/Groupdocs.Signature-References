## return_content property

문서 페이지에 배치된 서명의 바코드 이미지 내용을 가져올지 여부를 나타내는 플래그입니다.

True로 설정하면, 바코드 서명 이미지 내용이 `return_content_type`에서 지정한 형식으로 원시 이미지 데이터로 유지됩니다. 기본적으로 이 옵션은 비활성화(False)되어 있습니다.
