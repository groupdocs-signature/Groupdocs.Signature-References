## return_content property

Das Flag, das angibt, ob der Barcode-Bildinhalt einer auf einer Dokumentenseite platzierten Signatur abgerufen werden soll.

Wenn auf True gesetzt, wird der Bildinhalt der Barcode‑Signatur als Rohbilddaten im von `return_content_type` angegebenen Format beibehalten. Standardmäßig ist diese Option deaktiviert (False).
