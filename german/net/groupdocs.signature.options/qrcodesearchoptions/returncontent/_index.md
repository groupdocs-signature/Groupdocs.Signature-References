## QrCodeSearchOptions.ReturnContent property

Liest oder setzt das Flag, um den QR‑Code‑Bildinhalt der Signatur auf der Dokumentenseite zu erfassen. Wenn dieses Flag auf true gesetzt ist, wird der QR‑Code‑Signatur‑Bildinhalt im Rohdatenformat des erforderlichen Formats [`ReturnContentType`](../returncontenttype) beibehalten. Standardmäßig ist diese Option deaktiviert.
