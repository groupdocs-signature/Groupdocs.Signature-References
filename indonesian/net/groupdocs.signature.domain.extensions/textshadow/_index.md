## TextShadow class

Mewakili properti bayangan teks untuk tanda tangan teks. Hasilnya dapat bervariasi tergantung pada tipe tanda tangan dan format dokumen. TextShadow direkomendasikan untuk digunakan dengan tanda tangan TextAsImage untuk semua tipe dokumen yang didukung, juga dengan TextSignature sederhana dan TextSignature sebagai watermark untuk Spreadsheet (.xslx) dan Presentasi (.pptx). TextSignature sederhana untuk Word (.docx) juga direkomendasikan, namun memiliki fungsionalitas terbatas.

public class TextShadow : SignatureExtension
