## Permissions class

Permissions 类型公开以下成员：

### 字段
| 字段 | 描述 |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.options/permissions/none/) | 允许所有操作，包括打印、修改和数据提取。 |
| [DENY_PRINTING](/signature/python-net/groupdocs.signature.options/permissions/deny_printing/) | 禁止文档的打印。 |
| [DENY_MODIFICATION](/signature/python-net/groupdocs.signature.options/permissions/deny_modification/) | 禁止内容修改，包括填写表单以及添加或修改批注。 |
| [DENY_DATA_EXTRACTION](/signature/python-net/groupdocs.signature.options/permissions/deny_data_extraction/) | 禁止从文档中提取文本和图形。 |
| [DENY_ALL](/signature/python-net/groupdocs.signature.options/permissions/deny_all/) | 禁止所有操作，包括打印、修改和数据提取。 |
