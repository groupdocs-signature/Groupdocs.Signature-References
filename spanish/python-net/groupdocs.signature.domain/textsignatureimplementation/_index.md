## TextSignatureImplementation class

El tipo TextSignatureImplementation expone los siguientes miembros:

### Campos
| Campo | Descripción |
| :- | :- |
| [NATIVE](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/native/) | Firma de texto como objeto de texto nativo en la página del documento. |
| [IMAGE](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/image/) | Firma de texto como objeto de imagen en la página del documento. |
| [ANNOTATION](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/annotation/) | Firma de texto como objeto de anotación de texto en la página PDF. Las anotaciones son visibles solo en la versión con licencia. |
| [STICKER](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/sticker/) | Firma de texto como objeto de sticker en la página PDF. |
| [FORM_FIELD](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/form_field/) | Firma de texto como texto en un campo de formulario especificado. Con este tipo de implementación solo pueden usarse las opciones TextSignOptions.Text, TextSignOptions.FormTextFieldType y TextSignOptions.FormTextFieldTitle. |
| [WATERMARK](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/watermark/) | Firma de texto como marca de agua en la página del documento. |
