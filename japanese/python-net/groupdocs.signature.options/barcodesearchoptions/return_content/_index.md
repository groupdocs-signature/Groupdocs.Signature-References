## return_content property

ドキュメントページ上の署名のバーコード画像コンテンツを取得するかどうかを示すフラグです。

`True` に設定すると、バーコード署名画像のコンテンツは `return_content_type` で指定された形式の生データとして保持されます。デフォルトでは無効です。
