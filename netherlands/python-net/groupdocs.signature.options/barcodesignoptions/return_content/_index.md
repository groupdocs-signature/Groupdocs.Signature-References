## return_content property

De vlag die aangeeft of de barcode‑afbeeldingsinhoud van een handtekening op een documentpagina moet worden opgehaald.

Wanneer ingesteld op True, wordt de afbeeldinginhoud van de barcodehandtekening bewaard als ruwe afbeeldingsgegevens in het formaat dat is opgegeven door `return_content_type`. Standaard is deze optie uitgeschakeld (False).
