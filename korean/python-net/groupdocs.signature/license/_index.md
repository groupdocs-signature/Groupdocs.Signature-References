## License class

GroupDocs.Signature 라이선스를 관리합니다.

라이선스가 적용된 빌드는 래퍼의 전체 기능 세트를 다음 위치에서 잠금 해제합니다.
런타임. 라이선스가 없는 빌드는 동일한 API를 사용하여 평가 모드로 실행됩니다.
하지만 출력 크기와 워터마크가 포함된 콘텐츠에 제한이 있습니다.

License 유형은 다음 멤버를 노출합니다:

### 메서드
| 메서드 | 설명 |
| :- | :- |
| [set_license](/signature/python-net/groupdocs.signature/license/set_license/#license_source) | 현재 프로세스에 라이선스를 적용합니다. |
