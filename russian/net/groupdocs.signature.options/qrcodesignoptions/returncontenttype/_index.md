## QrCodeSignOptions.ReturnContentType property

Указывает тип файла возвращаемого содержимого изображения подписи QR-Code, когда свойство ReturnContent включено. По умолчанию установлено значение Null. Это означает возврат содержимого изображения QR-Code в оригинальном формате. Этот формат изображения указывается в [`Format`](../../../groupdocs.signature.domain/qrcodesignature/format). Возможные поддерживаемые значения: FileType.JPEG, FileType.PNG, FileType.BMP. Если указанный формат не поддерживается, будет возвращено содержимое изображения QR-Code в формате .png.

public FileType ReturnContentType { get; set; }
