## Permissions enumeration

Указывает настраиваемые разрешения для PDF‑документов, такие как печать, изменение содержимого и извлечение данных. Эти настройки применимы только к формату PDF и контролируют доступ пользователей и возможности взаимодействия.

```csharp
[Flags]
public enum Permissions
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Разрешить все действия, включая печать, изменение и извлечение данных. |
| DenyPrinting | `1` | Запретить печать документа. |
| DenyModification | `2` | Запретить изменение содержимого, включая заполнение форм и добавление или изменение аннотаций. |
| DenyDataExtraction | `4` | Запретить извлечение текста и графики из документа. |
| DenyAll | `7` | Запретить все действия, включая печать, изменение и извлечение данных. |
