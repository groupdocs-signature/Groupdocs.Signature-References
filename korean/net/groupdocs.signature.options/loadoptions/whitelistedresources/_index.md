## LoadOptions.WhitelistedResources property

외부 리소스 주소의 조각을 가져오거나 설정합니다. [`SkipExternalResources`](../skipexternalresources)가 true일 때도 로드됩니다. 기본값은 빈 목록입니다.

```csharp
public List<string> WhitelistedResources { get; set; }
```

### 비고

리소스는 전체 주소에 조각 중 하나가 포함될 때 로드됩니다. 비교는 대소문자를 구분하지 않으며, 빈 조각은 무시됩니다. "https://cdn.example.com/images/"와 같은 긴 조각을 선호하십시오: 짧은 조각은 해당 조각을 포함하는 다른 주소와도 일치할 수 있습니다.

이 속성을 null로 설정하면 목록이 비워집니다. [`SkipExternalResources`](../skipexternalresources)가 false인 경우 목록은 영향을 주지 않으며, 이때 모든 외부 리소스가 로드됩니다.
