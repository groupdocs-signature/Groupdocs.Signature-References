## FileType.PPTX field

PowerPoint Open XML Presentation (.pptx) sono file di presentazione creati con la popolare applicazione Microsoft PowerPoint. A differenza della versione precedente del formato di file di presentazione PPT, che era binario, il formato PPTX si basa sul formato di presentazione open XML di Microsoft PowerPoint.
