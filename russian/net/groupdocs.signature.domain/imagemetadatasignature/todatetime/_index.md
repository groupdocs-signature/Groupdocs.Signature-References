## ToDateTime() {#todatetime}

Преобразует в DateTime.

```csharp
public override DateTime ToDateTime()
```

### Возвращаемое значение

Возвращает значение подписи Metadata в виде DateTime.

### Примечания

Выбрасывает исключение, если значение Metadata не может быть преобразовано. Если исходное значение основано на строке, будет использована информация о свойствах культуры по умолчанию из свойств SignatureSettings [`DefaultCulture`](../../../groupdocs.signature/signaturesettings/defaultculture)
