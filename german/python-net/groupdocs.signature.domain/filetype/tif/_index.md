## TIF field

Tagged Image File (.tif) stellt Rasterbilder dar, die für die Verwendung auf einer Vielzahl von Geräten gedacht sind, die diesem Dateiformatstandard entsprechen. Es kann bilevel-, Graustufen-, Palettenfarb- und Vollfarbbilddaten in mehreren Farbräumen beschreiben. Erfahren Sie hier mehr über dieses Dateiformat.
