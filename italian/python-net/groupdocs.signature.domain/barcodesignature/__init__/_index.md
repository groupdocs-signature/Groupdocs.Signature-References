## __init__ {#signature_id}

Inizializza un oggetto BarcodeSignature con un identificatore di firma ottenuto dopo un processo di ricerca. L'identificatore è usato per recuperare proprietà aggiuntive per questa firma dallo strato di informazioni sulla firma del documento.

```python
def __init__(self, signature_id):
    ...
```

| Parametro | Tipo | Descrizione |
| :- | :- | :- |
| signature_id | `str` | Identificatore di firma unico ottenuto dal metodo `Sign` o `Search` di `Signature`. |
