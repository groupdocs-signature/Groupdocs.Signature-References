## IRectangle class

Определяет свойства интерфейса для области подписи на странице документа.

Тип IRectangle раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [height](/signature/python-net/groupdocs.signature.domain/irectangle/height/) | Высота области подписи на странице документа в единицах измерения (пиксели, проценты или миллиметры; см. `MeasureType` SizeMeasureType). |
| [left](/signature/python-net/groupdocs.signature.domain/irectangle/left/) | Левая позиция X области подписи на странице документа в единицах измерения (пиксели, проценты или миллиметры). См. `MeasureType` для перечисления `LocationMeasureType`. |
| [location_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/location_measure_type/) | Тип измерения (пиксели, проценты или миллиметры) для свойств Left и Top. |
| [size_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/size_measure_type/) | Тип измерения (пиксели, проценты или миллиметры) для свойств Width и Height. |
| [stretch](/signature/python-net/groupdocs.signature.domain/irectangle/stretch/) | Режим растягивания на странице документа. |
| [top](/signature/python-net/groupdocs.signature.domain/irectangle/top/) | Верхняя позиция Y области подписи на странице документа в единицах измерения (пиксели, проценты или миллиметры). См. `MeasureType` для типа измерения местоположения. |
| [width](/signature/python-net/groupdocs.signature.domain/irectangle/width/) | Ширина области подписи на странице документа в значениях измерения (пиксели, проценты или миллиметры). См. `MeasureType` SizeMeasureType. |
