## Mailmark2D.DestinationPostCodeAndDPS property

Contient le code postal de l'adresse de livraison avec le DPS. Si l'adresse est intérieure, le code postal/DP contient le nombre de caractères suivant : Zone (1 ou 2 caractères) District (1 ou 2 caractères) Secteur (1 caractère) Unité (2 caractères) DPS (2 caractères). Le code postal et le DPS doivent être conformes à un format PAF® valide. La longueur maximale est de 9.
