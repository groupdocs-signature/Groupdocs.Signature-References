## UpdateResult class

Stelt het resultaat voor van wijziging van handtekeningen in het document.

Het UpdateResult-type geeft de volgende leden weer:

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/updateresult/destin_document_size/) | De grootte van het bestemmingsdocument. |
| [failed](/signature/python-net/groupdocs.signature.domain/updateresult/failed/) | De lijst met handtekeningen die niet zijn bijgewerkt [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [processing_time](/signature/python-net/groupdocs.signature.domain/updateresult/processing_time/) | De uitvoeringstijd van het proces in milliseconden. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/updateresult/source_document_size/) | De grootte van het brondocument. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/updateresult/succeeded/) | De lijst met succesvol gewijzigde handtekeningen [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/updateresult/total_signatures/) | Het totale aantal verwerkte handtekeningen. |
