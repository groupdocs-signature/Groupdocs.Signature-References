## ProcessCompleteEventArgs class

Tillhandahåller data om fullständiga händelser för signering, verifiering och sökprocesser.

Typen ProcessCompleteEventArgs exponerar följande medlemmar:

### Egenskaper
| Egenskap | Beskrivning |
| :- | :- |
| [canceled](/signature/python-net/groupdocs.signature/processcompleteeventargs/canceled/) | Processen avbröts. |
| [completed](/signature/python-net/groupdocs.signature/processcompleteeventargs/completed/) | Tidsstämpeln för processens slutförande. |
| [ticks](/signature/python-net/groupdocs.signature/processcompleteeventargs/ticks/) | Tiden i millisekunder som förflutit sedan processens Start-händelse. |
| [total_signatures](/signature/python-net/groupdocs.signature/processcompleteeventargs/total_signatures/) | Det totala antalet bearbetade signaturer. |
| [status](/signature/python-net/groupdocs.signature/processeventargs/status/) | Det aktuella processläget. (ärvt från [`ProcessEventArgs`](/signature/python-net/groupdocs.signature/processeventargs/)) |
