## PngColorType class

Der PngColorType‑Typ stellt die folgenden Mitglieder bereit:

### Felder
| Feld | Beschreibung |
| :- | :- |
| [GRAYSCALE](/signature/python-net/groupdocs.signature.options/pngcolortype/grayscale/) | Stellt den Farbtyp dar, bei dem jedes Pixel ein Graustufen‑Sample ist. |
| [TRUECOLOR](/signature/python-net/groupdocs.signature.options/pngcolortype/truecolor/) | Stellt den Farbtyp dar, bei dem jedes Pixel ein R,G,B‑Tripel ist. |
| [INDEXED_COLOR](/signature/python-net/groupdocs.signature.options/pngcolortype/indexed_color/) | Stellt den Farbtyp dar, bei dem jedes Pixel ein Paletten‑Index ist; ein PLTE‑Chunk muss vorkommen. |
| [GRAYSCALE_WITH_ALPHA](/signature/python-net/groupdocs.signature.options/pngcolortype/grayscale_with_alpha/) | Stellt den Farbtyp dar, bei dem jedes Pixel ein Graustufen‑Sample gefolgt von einem Alpha‑Sample ist. |
| [TRUECOLOR_WITH_ALPHA](/signature/python-net/groupdocs.signature.options/pngcolortype/truecolor_with_alpha/) | Stellt den Farbtyp dar, bei dem jedes Pixel ein R,G,B‑Tripel gefolgt von einem Alpha‑Sample ist. |
