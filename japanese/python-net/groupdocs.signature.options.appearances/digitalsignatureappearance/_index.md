## DigitalSignatureAppearance class

デジタル署名の署名ラインの外観を表します。1つのデジタル署名につき1つの署名ラインのみ適用でき、常に最初のページに配置されます。この機能は .docx、.doc、.odt、.xlsx ファイル形式で便利です。

DigitalSignatureAppearance 型は次のメンバーを公開します：

| コンストラクタ | 説明 |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.options.appearances/digitalsignatureappearance/__init__/) | 署名ラインの外観オブジェクトを初期化します。 |
| [__init__](/signature/python-net/groupdocs.signature.options.appearances/digitalsignatureappearance/__init__/#signer-title-email) | 指定された署名者、タイトル、メールアドレスで署名ラインの外観を初期化します。 |

### プロパティ
| プロパティ | 説明 |

| [email](/signature/python-net/groupdocs.signature.options.appearances/digitalsignatureappearance/email/) | 署名ラインに表示されるメールアドレスです。 |
| [signer](/signature/python-net/groupdocs.signature.options.appearances/digitalsignatureappearance/signer/) | 署名ラインの署名者名です。 |
