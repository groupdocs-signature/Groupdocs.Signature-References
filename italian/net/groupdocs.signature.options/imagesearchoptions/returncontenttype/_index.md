## ImageSearchOptions.ReturnContentType property

Specifica il tipo di file del contenuto restituito della firma immagine quando la proprietà ReturnContent è abilitata. Per impostazione predefinita è impostato a Null. Ciò significa restituire il contenuto dell'immagine nel formato originale. Questo formato immagine è specificato in [`Format`](../../../groupdocs.signature.domain/imagesignature/format). I valori supportati possibili sono: FileType.JPEG, FileType.PNG, FileType.BMP. Se il formato fornito non è supportato, verrà restituito il contenuto dell'immagine nel formato originale.

public FileType ReturnContentType { get; set; }
