## signature_id property

Уникальный идентификатор подписи, используемый для изменения подписи в документе с помощью операций обновления или удаления.

Идентификатор устанавливается автоматически после вызова методов sign или search.

Если идентификатор был сохранён ранее, его можно установить вручную для управления подписью.
