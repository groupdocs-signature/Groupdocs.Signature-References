## LogLevel class

LogLevel 类型公开以下成员：

### 字段
| 字段 | 描述 |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.logging/loglevel/none/) | 没有记录任何内容。 |
| [ERROR](/signature/python-net/groupdocs.signature.logging/loglevel/error/) | 错误：操作失败。 |

| [TRACE](/signature/python-net/groupdocs.signature.logging/loglevel/trace/) | 跟踪：操作的步骤，例如开始和结束。 |
