## IResult class

Representa una interfaz común para el resultado del proceso de firma.

El tipo IResult expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/iresult/destin_document_size/) | El tamaño del documento de destino. |
| [failed](/signature/python-net/groupdocs.signature.domain/iresult/failed/) | La lista de firmas que no fueron procesadas. |
| [processing_time](/signature/python-net/groupdocs.signature.domain/iresult/processing_time/) | El tiempo de ejecución del proceso en milisegundos. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/iresult/source_document_size/) | El tamaño del documento de origen. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/iresult/succeeded/) | La lista de firmas procesadas exitosamente [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/iresult/total_signatures/) | El total de firmas procesadas. |
