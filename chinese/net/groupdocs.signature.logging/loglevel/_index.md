## LogLevel enumeration

指定哪些类型的消息会传递给在 [`SignatureSettings`](../../groupdocs.signature/signaturesettings) 中设置的日志记录器。值是标志，可以组合，例如 `LogLevel.Error | LogLevel.Warning`。

```csharp
[Flags]
public enum LogLevel
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| None | `0` | 未记录任何内容。 |
| Error | `1` | 错误：操作失败。 |
| Warning | `2` | 警告：操作成功，但其结果可能不是您所期望的。 |
| Trace | `4` | 跟踪：操作的步骤，例如其开始和结束。 |
| All | `7` | 错误、警告和跟踪。这是默认设置。 |
