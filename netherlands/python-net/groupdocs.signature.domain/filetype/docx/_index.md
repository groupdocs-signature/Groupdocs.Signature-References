## DOCX field

Microsoft Word Open XML Document (.docx) is een bekend formaat voor Microsoft Word-documenten. Geïntroduceerd in 2007 met de release van Microsoft Office 2007, werd de structuur van dit nieuwe documentformaat gewijzigd van platte binair naar een combinatie van XML- en binaire bestanden.
