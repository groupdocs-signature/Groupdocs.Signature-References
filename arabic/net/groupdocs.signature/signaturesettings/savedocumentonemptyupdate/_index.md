## SignatureSettings.SaveDocumentOnEmptyUpdate property

يحصل أو يضبط العلامة لإعادة حفظ المستند المصدر عندما لا يحتوي أسلوب Update على توقيعات للتحديث. إذا تم ضبط هذه العلامة على true (افتراضيًا) سيتم حفظ المستند مع سجل عملية التاريخ ونوع العملية حتى إذا لم يحتوي أسلوب Update على توقيعات للتحديث. عندما يتم ضبط هذه العلامة على false لن يتم تعديل المستند المصدر على الإطلاق.

public bool SaveDocumentOnEmptyUpdate { get; set; }
