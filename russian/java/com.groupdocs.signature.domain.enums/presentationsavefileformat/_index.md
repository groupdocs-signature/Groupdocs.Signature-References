**Inheritance:**
java.lang.Object
```
public final class PresentationSaveFileFormat
```

Определяет различные форматы сохранения файлов.

## Поля

| Поле | Описание |
| --- | --- |
|  | [Default](#Default) | Формат файла не будет изменён. |
|
|  | [Pps](#Pps) | Сохраняет документ как слайд-шоу Microsoft Power Point 97-2003. |
|
|  | [Ppt](#Ppt) | Сохраняет документ как презентацию Microsoft Power Point 97-2003. |
|
|  | [Pdf](#Pdf) | Сохраняет документ в формате PDF. |
|
|  | [Xps](#Xps) | Сохраняет документ в формате XPS (XML Paper Specification). |
|
|  | [Pptx](#Pptx) | Сохраняет документ в формате Microsoft Power Point Open XML Presentation. |
|
|  | [Ppsx](#Ppsx) | Сохраняет документ в формате Microsoft Power Point Open XML Slide Show. |
|
|  | [Tiff](#Tiff) | Отображает одну или несколько страниц документа и сохраняет их в один или многостраничный файл TIFF. |
|
|  | [Odp](#Odp) | Сохраняет документ как презентацию Open Office. |
|
|  | [Pptm](#Pptm) | Сохраняет документ как презентацию Microsoft Power Point Open XML с поддержкой макросов. |
|
|  | [Ppsm](#Ppsm) | Сохраняет документ как слайд-шоу Microsoft Power Point Open XML с поддержкой макросов. |
|
|  | [Potx](#Potx) | Сохраняет документ как шаблон Microsoft Power Point. |
|
|  | [Potm](#Potm) | Сохраняет документ как шаблон Microsoft Power Point с поддержкой макросов. |
|
|  | [Html](#Html) | Сохраняет документ в формате HTML. |
|
|  | [Otp](#Otp) | Сохраняет документ как шаблон презентации Open Office. |
|
