## DigitalSignatureAppearance class

Mewakili tampilan garis tanda tangan untuk tanda tangan digital. Hanya satu garis tanda tangan yang dapat diterapkan pada satu tanda tangan digital, dan selalu ditempatkan pada halaman pertama. Fitur ini berguna untuk format file .docx, .doc, .odt, dan .xlsx.
