## SignatureSettings.SaveDocumentOnEmptyDelete property

Ανακτά ή ορίζει τη σημαία για την επαναποθήκευση του αρχικού εγγράφου όταν η μέθοδος Delete δεν έχει υπογραφές προς αφαίρεση. Εάν αυτή η σημαία οριστεί σε true (προεπιλογή) το έγγραφο θα αποθηκεύεται με το αντίστοιχο ιστορικό καταγραφής διαδικασίας (ημερομηνία και τύπος λειτουργίας) ακόμη και αν η μέθοδος Delete δεν έχει υπογραφές προς αφαίρεση. Όταν αυτή η σημαία οριστεί σε false, το αρχικό έγγραφο δεν θα τροποποιηθεί καθόλου.

public bool SaveDocumentOnEmptyDelete { get; set; }
