## FormFieldSearchOptions.Name property

Указывает шаблон регулярного выражения имени подписи поля формы, если его следует искать. Вы можете использовать простую строку, например "text", или регулярное выражение, например "abc\\d+". Значение по умолчанию — пустая строка.
