## ImageSearchOptions.MaxContentSize property

Para un valor distinto de cero, este indicador especifica el tamaño máximo de las imágenes para el criterio de búsqueda. Por defecto, este indicador está establecido en cero y no afecta el resultado de la búsqueda.

public long MaxContentSize { get; set; }
