## FileType.PPTX field

Les présentations PowerPoint Open XML (.pptx) sont des fichiers de présentation créés avec l'application Microsoft PowerPoint populaire. Contrairement à la version précédente du format de fichier de présentation PPT qui était binaire, le format PPTX repose sur le format de présentation Open XML de Microsoft PowerPoint.
