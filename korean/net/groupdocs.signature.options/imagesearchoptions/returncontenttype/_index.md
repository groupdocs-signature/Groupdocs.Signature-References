## ImageSearchOptions.ReturnContentType property

ReturnContent 속성이 활성화된 경우 이미지 서명의 반환된 콘텐츠 파일 유형을 지정합니다. 기본값은 Null로 설정됩니다. 이는 이미지 콘텐츠를 원본 형식으로 반환한다는 의미입니다. 이 이미지 형식은 [`Format`](../../../groupdocs.signature.domain/imagesignature/format)에서 지정됩니다. 지원되는 가능한 값은: FileType.JPEG, FileType.PNG, FileType.BMP. 제공된 형식이 지원되지 않으면 이미지 콘텐츠는 원본 형식으로 반환됩니다.

public FileType ReturnContentType { get; set; }
