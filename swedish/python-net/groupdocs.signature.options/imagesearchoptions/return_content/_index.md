## return_content property

Flaggan som bestämmer om bildinnehållet för en signatur returneras.

Om satt till True, behålls bildsignaturens innehåll som rå bilddata i det format som anges av [`ImageSearchOptions.return_content_type`](/signature/python-net/groupdocs.signature.options/imagesearchoptions/return_content_type/). Som standard är detta alternativ inaktiverat (False).
