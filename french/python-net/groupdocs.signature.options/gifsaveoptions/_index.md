## GifSaveOptions class

Représente les options d’enregistrement au format GIF pour les documents image.

Le type GifSaveOptions expose les membres suivants :

### Constructeurs
| Constructeur | Description |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.options/gifsaveoptions/__init__/) | Initialise GifSaveOptions avec les valeurs par défaut. |

| Propriété | Description |
| :- | :- |
| [background_color_index](/signature/python-net/groupdocs.signature.options/gifsaveoptions/background_color_index/) | L'index de couleur d'arrière-plan du GIF. |
| [color_resolution](/signature/python-net/groupdocs.signature.options/gifsaveoptions/color_resolution/) | La résolution de couleur du GIF. |
| [do_palette_correction](/signature/python-net/groupdocs.signature.options/gifsaveoptions/do_palette_correction/) | Le drapeau indiquant si la correction de palette est appliquée. |

| [is_palette_sorted](/signature/python-net/groupdocs.signature.options/gifsaveoptions/is_palette_sorted/) | La valeur indiquant si les entrées de palette sont triées. |

| [password](/signature/python-net/groupdocs.signature.options/saveoptions/password/) | Le mot de passe utilisé pour protéger le document signé enregistré. Non pris en charge pour les documents Image. (hérité de [`SaveOptions`](/signature/python-net/groupdocs.signature.options/saveoptions/)) |
| [use_original_password](/signature/python-net/groupdocs.signature.options/saveoptions/use_original_password/) | Le drapeau indiquant s'il faut utiliser le mot de passe de [`LoadOptions`](/signature/python-net/groupdocs.signature.options/loadoptions/) lors de l'enregistrement du document signé en tant que protégé.
