## include_standard_metadata_signatures property

Das Flag, das angibt, ob standardmäßige Dokumentmetadaten‑Signaturen wie Autor, Eigentümer, Erstellungsdatum und Änderungsdatum in der Metadatenliste enthalten sind.

Wenn auf False (Standard) gesetzt, wird GetDocumentInfo diese Metadaten-Signaturen nicht einbeziehen. Wenn auf True gesetzt, wird die Dokumentinformation die Standard-Metadaten-Signaturen enthalten.
