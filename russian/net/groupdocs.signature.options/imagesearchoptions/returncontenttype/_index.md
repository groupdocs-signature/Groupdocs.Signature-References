## ImageSearchOptions.ReturnContentType property

Указывает тип файла возвращаемого содержимого подписи изображения, когда свойство ReturnContent включено. По умолчанию установлено Null. Это означает возврат содержимого изображения в оригинальном формате. Этот формат изображения задаётся в [`Format`](../../../groupdocs.signature.domain/imagesignature/format). Возможные поддерживаемые значения: FileType.JPEG, FileType.PNG, FileType.BMP. Если указанный формат не поддерживается, будет возвращено содержимое изображения в оригинальном формате.

public FileType ReturnContentType { get; set; }
