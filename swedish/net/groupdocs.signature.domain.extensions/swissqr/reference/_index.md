## SwissQR.Reference property

Hämtar eller anger borgenärens betalningsreferens. Referensen är obligatorisk för SwissQR‑IBAN‑nummer, d.v.s. IBAN‑nummer i intervallet CHxx30000xxxxxx till CHxx31999xxxxx. Om den anges måste referensen vara antingen en giltig SwissQR‑referens (motsvarande ISR‑referensform) eller en giltig borgenärsreferens enligt ISO 11649 ("RFxxxx"). Båda kan innehålla mellanslag för formatering.

```csharp
public string Reference { get; set; }
```

### Property Value

Kreditörens betalningsreferens.
