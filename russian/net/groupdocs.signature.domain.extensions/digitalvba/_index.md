## DigitalVBA class

Представляет цифровую подпись для проектов VBA в Spreadsheets. Обеспечивает возможность подписать проект VBA в конкретных форматах документов Spreadsheets, таких как Xlsm или Xltm. Если к DigitalSignOptions.Extensions добавлено несколько расширений DigitalVBA, только первое участвует в подписании документа.

```csharp
public class DigitalVBA : SignatureExtension
```
