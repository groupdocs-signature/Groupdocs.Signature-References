## DataMatrixEncodeMode enumeration

Режим кодирования кодировщика DataMatrix, по умолчанию Auto

```csharp
public enum DataMatrixEncodeMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Auto | `0` | Автоматически выбирает лучший режим кодирования для DataMatrix |
| ASCII | `1` | Кодирует один алфавитно-цифровой или два цифровых символа на байт |
| Full | `6` | Кодирует 8‑битные значения |
| Custom | `7` | Кодировать с кодировкой, указанной в BarcodeGenerator.Parameters.Barcode.DataMatrix.CodeTextEncoding |
| C40 | `8` | Использует кодировку C40. Кодирует заглавные алфавитно-цифровые, строчные и специальные символы |
| Text | `9` | Использует кодировку Text. Кодирует строчные алфавитно-цифровые, заглавные и специальные символы. |
| EDIFACT | `10` | Использует кодировку EDIFACT. Использует шесть бит на символ, кодирует цифры, заглавные буквы и многие знаки пунктуации, но не поддерживает строчные буквы. |
| ANSIX12 | `11` | Использует кодировку ANSI X12. |
| ExtendedCodetext | `12` | Режим ExtendedCodetext позволяет вручную переключать схемы кодирования в код‑тексте. Формат: "\\Encodation_scheme_name:text\\Encodation_scheme_name:text". Допустимые схемы кодирования: EDIFACT, ANSIX12, ASCII, C40, Text, Auto. Пример расширенного код‑текста: @"\\ansix12:ANSIX12TEXT\\ascii:backslash must be \\\\ doubled\\edifact:EdifactEncodedText". Все обратные слеши (\\) должны быть удвоены в тексте. |
