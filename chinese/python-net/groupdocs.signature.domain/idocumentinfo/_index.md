## IDocumentInfo class

文档描述属性。

IDocumentInfo 类型公开以下成员：

### 属性
| 属性 | 描述 |
| :- | :- |
| [barcode_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/barcode_signatures/) | 通过 [`Signature`](/signature/python-net/groupdocs.signature/signature/) 方法添加或更新的文档条形码签名集合。 |
| [digital_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/digital_signatures/) | 通过 [`Signature`](/signature/python-net/groupdocs.signature/signature/) 方法添加或更新的文档数字签名集合。 |
| [documents](/signature/python-net/groupdocs.signature.domain/idocumentinfo/documents/) | 归档文件中所有现有文档的集合。此属性仅支持归档文档类型。 |
| [file_type](/signature/python-net/groupdocs.signature.domain/idocumentinfo/file_type/) | 文件格式类型。 |
| [form_field_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/form_field_signatures/) | 通过 [`Signature`](/signature/python-net/groupdocs.signature/signature/) 方法添加或更新的文档表单字段签名集合。 |
| [form_fields](/signature/python-net/groupdocs.signature.domain/idocumentinfo/form_fields/) | 文档中所有现有受支持的表单字段的集合。此属性仅支持 PDF 和 Word 处理文档类型。 |
| [image_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/image_signatures/) | 通过 [`Signature`](/signature/python-net/groupdocs.signature/signature/) 方法添加或更新的文档图像签名集合。 |
| [max_page_height](/signature/python-net/groupdocs.signature.domain/idocumentinfo/max_page_height/) | 最大页面高度。 |
| [metadata_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/metadata_signatures/) | 文档元数据签名集合。 |
| [page_count](/signature/python-net/groupdocs.signature.domain/idocumentinfo/page_count/) | 文档页数。 |
| [pages](/signature/python-net/groupdocs.signature.domain/idocumentinfo/pages/) | 文档页面描述的集合。 |
| [process_logs](/signature/python-net/groupdocs.signature.domain/idocumentinfo/process_logs/) | 文档历史过程日志的集合。 |
| [qr_code_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/qr_code_signatures/) | 通过 [`Signature`](/signature/python-net/groupdocs.signature/signature/) 方法添加或更新的文档 QR 码签名的集合。 |
| [signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/signatures/) | 文档中以 [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/) 对象形式存在的所有签名类型的集合。 |
| [size](/signature/python-net/groupdocs.signature.domain/idocumentinfo/size/) | 文档的字节大小。 |
| [text_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/text_signatures/) | 通过 [`Signature`](/signature/python-net/groupdocs.signature/signature/) 方法添加或更新的文档文本签名的集合。 |
| [width_for_max_height](/signature/python-net/groupdocs.signature.domain/idocumentinfo/width_for_max_height/) | 最大页面高度的宽度。 |
