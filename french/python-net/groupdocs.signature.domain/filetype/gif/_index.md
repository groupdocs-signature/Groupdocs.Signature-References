## GIF field

Le fichier Graphical Interchange Format (.gif) est un type d'image fortement compressée. Pour chaque image, le GIF permet généralement jusqu'à 8 bits par pixel et jusqu'à 256 couleurs sont autorisées dans l'image. En savoir plus sur ce format de fichier ici.
