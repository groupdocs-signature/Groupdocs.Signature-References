## Permissions class

El tipo Permissions expone los siguientes miembros:

### Campos
| Campo | Descripción |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.options/permissions/none/) | Permitir todas las acciones, incluyendo la impresión, la modificación y la extracción de datos. |
| [DENY_PRINTING](/signature/python-net/groupdocs.signature.options/permissions/deny_printing/) | Denegar la impresión del documento. |
| [DENY_MODIFICATION](/signature/python-net/groupdocs.signature.options/permissions/deny_modification/) | Denegar la modificación del contenido, incluyendo rellenar formularios y agregar o modificar anotaciones. |
| [DENY_DATA_EXTRACTION](/signature/python-net/groupdocs.signature.options/permissions/deny_data_extraction/) | Denegar la extracción de texto y gráficos del documento. |
| [DENY_ALL](/signature/python-net/groupdocs.signature.options/permissions/deny_all/) | Denegar todas las acciones, incluyendo la impresión, la modificación y la extracción de datos. |
