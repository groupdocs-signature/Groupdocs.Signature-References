## SignResult class

새로 생성된 서명이 포함된 문서에 대한 서명 프로세스 결과를 나타냅니다.

SignResult 유형은 다음 멤버를 노출합니다:

### 속성
| 속성 | 설명 |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/signresult/destin_document_size/) | 대상 문서 크기. |
| [failed](/signature/python-net/groupdocs.signature.domain/signresult/failed/) | 생성에 실패한 서명의 목록입니다. |
| [processing_time](/signature/python-net/groupdocs.signature.domain/signresult/processing_time/) | 프로세스 실행 시간(밀리초). |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/signresult/source_document_size/) | 원본 문서 크기. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/signresult/succeeded/) | 새로 생성된 서명의 목록 [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/signresult/total_signatures/) | 전체 처리된 서명 수. |
