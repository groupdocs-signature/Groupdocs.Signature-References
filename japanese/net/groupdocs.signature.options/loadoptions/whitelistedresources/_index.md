## LoadOptions.WhitelistedResources property

`[`SkipExternalResources`](../skipexternalresources)` が true の場合でもロードされる外部リソースのアドレスフラグメントを取得または設定します。デフォルト値は空のリストです。

```csharp
public List<string> WhitelistedResources { get; set; }
```

### 備考

リソースは、完全なアドレスがフラグメントのいずれかを含む場合にロードされます。比較は大文字小文字を区別せず、空のフラグメントは無視されます。\"https://cdn.example.com/images/\" のような長いフラグメントを優先してください。短いフラグメントは、それを含む他のアドレスにも一致してしまう可能性があります。

このプロパティを null に設定するとリストがクリアされます。[`SkipExternalResources`](../skipexternalresources) が false の場合、リストは効果がなく、すべての外部リソースがロードされます。
