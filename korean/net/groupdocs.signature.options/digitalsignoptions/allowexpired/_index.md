## DigitalSignOptions.AllowExpired property

유효 기간이 끝난 인증서로 서명할 수 있도록 하는 플래그를 가져오거나 설정합니다. 기본값은 false이며, 만료된 인증서로 서명하면 [`GroupDocsSignatureException`](../../../groupdocs.signature/groupdocssignatureexception)이 발생하고 문서가 서명되지 않습니다.

```csharp
public bool AllowExpired { get; set; }
```

### 비고

검증자는 만료된 인증서로 만든 서명을 유효하지 않다고 보고합니다. 이 속성을 true로 설정하는 경우는 해당 서명이 필요할 때만, 예를 들어 오래된 인증서로 테스트할 때와 같습니다. 문서는 서명되며, [`SignatureSettings`](../../../groupdocs.signature/signaturesettings)에서 설정된 로거에 경고가 기록됩니다.

인증서는 UTC 기준 현재 시간과 비교되며, [`SignTime`](../../../groupdocs.signature.domain/digitalsignature/signtime)과는 비교되지 않습니다. 이 플래그는 [`CertificateFilePath`](../certificatefilepath), [`CertificateStream`](../certificatestream) 또는 [`Signature`](../signature)으로 제공된 인증서에 적용되며, 스프레드시트에 서명할 경우 첫 번째 [`DigitalVBA`](../../../groupdocs.signature.domain.extensions/digitalvba) 확장의 인증서에도 적용됩니다. 이미지의 디지털 서명은 인증서를 사용하지 않으며 검증되지 않습니다. 아직 유효 기간이 시작되지 않은 인증서는 [`AllowNotYetValid`](../allownotyetvalid)으로 제어됩니다.
