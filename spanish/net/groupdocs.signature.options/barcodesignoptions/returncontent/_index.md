## BarcodeSignOptions.ReturnContent property

Obtiene o establece la bandera para obtener el contenido de imagen Barcode de una firma que se colocó en la página del documento. Si esta bandera se establece en true, el contenido de imagen de la firma Barcode mantendrá los datos de imagen sin procesar según el formato requerido [`ReturnContentType`](../returncontenttype). Por defecto, esta opción está deshabilitada.

public bool ReturnContent { get; set; }
