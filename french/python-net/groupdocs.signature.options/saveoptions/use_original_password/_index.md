## use_original_password property

L'indicateur indiquant s'il faut utiliser le mot de passe provenant de [`LoadOptions`](/signature/python-net/groupdocs.signature.options/loadoptions/) lors de l'enregistrement du document signé en tant que protégé. La valeur par défaut est True. Non pris en charge pour les documents Image.
