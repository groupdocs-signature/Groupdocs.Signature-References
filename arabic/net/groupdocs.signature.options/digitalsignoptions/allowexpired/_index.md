## DigitalSignOptions.AllowExpired property

الحصول أو التعيين لعلم يسمح بالتوقيع بشهادة انتهت فترة صلاحيتها. القيمة الافتراضية هي false: التوقيع بشهادة منتهية يرمي استثناء [`GroupDocsSignatureException`](../../../groupdocs.signature/groupdocssignatureexception)، ولا يتم توقيع المستند.

```csharp
public bool AllowExpired { get; set; }
```

### ملاحظات

المصادقون يُبلغون عن توقيع تم بشهادة منتهية كغير صالح. اضبط هذه الخاصية إلى true فقط عندما تحتاج إلى مثل هذا التوقيع بأي حال، على سبيل المثال لاختبار بشهادة قديمة. عندها يتم توقيع المستند، وتُكتب تحذير إلى السجل المُحدد في [`SignatureSettings`](../../../groupdocs.signature/signaturesettings).

يتم مقارنة الشهادة بالوقت الحالي بتوقيت UTC، وليس بـ[`SignTime`](../../../groupdocs.signature.domain/digitalsignature/signtime). ينطبق العلم على الشهادة المقدمة عبر [`CertificateFilePath`](../certificatefilepath)، [`CertificateStream`](../certificatestream) أو [`Signature`](../signature)، وعند توقيع جدول بيانات، على شهادة أول امتداد [`DigitalVBA`](../../../groupdocs.signature.domain.extensions/digitalvba). التوقيعات الرقمية للصور لا تستخدم شهادة ولا يتم فحصها. الشهادة التي لم يبدأ بعد فترة صلاحيتها يتم التحكم فيها عبر [`AllowNotYetValid`](../allownotyetvalid).
