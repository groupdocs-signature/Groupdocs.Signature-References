## try_parse {#parsing_type}

Gibt einen Stempeltyp für den angegebenen Parsings‑Typnamen zurück. Wenn der Stempelname unbekannt ist, wird keine Ausnahme ausgelöst und die Methode gibt None zurück.

```python
def try_parse(cls, parsing_type):
    ...
```

| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| parsing_type | `str` | Quellzeichenkette des Stempeltypnamens. |

**Returns:** StampType: StampType instance.
