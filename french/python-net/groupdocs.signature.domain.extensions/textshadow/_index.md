## TextShadow class

Représente les propriétés d'ombre du texte pour les signatures texte.

Le résultat peut varier en fonction du type de signature et du format du document.

TextShadow est recommandé pour une utilisation avec la signature `TextAsImage` pour tous les types de documents pris en charge, ainsi qu'avec la simple [`TextSignature`](/signature/python-net/groupdocs.signature.domain/textsignature/) et [`TextSignature`](/signature/python-net/groupdocs.signature.domain/textsignature/) comme filigrane pour les feuilles de calcul (`.xslx`) et les présentations (`.pptx`).

Simple [`TextSignature`](/signature/python-net/groupdocs.signature.domain/textsignature/) pour les documents Word (`.docx`) est également recommandé, mais possède une fonctionnalité limitée.

### Propriétés
| Propriété | Description |
| :- | :- |
| [angle](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/angle/) | L'angle de placement de l'ombre par rapport au texte. La valeur par défaut est 0. |
| [blur](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/blur/) | Le flou de l'ombre. La valeur par défaut est 4. |
| [color](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/color/) | La couleur de l'ombre. La valeur par défaut est Black. |
| [distance](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/distance/) | La distance du texte à l'ombre. |
| [transparency](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/transparency/) | La transparence de l'ombre. |
