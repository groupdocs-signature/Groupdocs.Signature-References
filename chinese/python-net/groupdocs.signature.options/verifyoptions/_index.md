## VerifyOptions class

保留用于验证文档的选项。

VerifyOptions 类型公开以下成员：

### 属性
| 属性 | 描述 |
| :- | :- |
| [all_pages](/signature/python-net/groupdocs.signature.options/verifyoptions/all_pages/) | 指示是否应验证每个文档页的标志。默认值为 True。 |
| [extensions](/signature/python-net/groupdocs.signature.options/verifyoptions/extensions/) | 用于替代签名选项验证的附加扩展。 |
| [is_valid](/signature/python-net/groupdocs.signature.options/verifyoptions/is_valid/) | 有效属性标志。 |
| [page_number](/signature/python-net/groupdocs.signature.options/verifyoptions/page_number/) | 要验证的文档页码；如果未设置，则对文档的所有页进行首次出现的验证（最小值为 1）。 |
| [pages_setup](/signature/python-net/groupdocs.signature.options/verifyoptions/pages_setup/) | 用于指定要验证的页面的页面选项。 |
| [shape_position](/signature/python-net/groupdocs.signature.options/verifyoptions/shape_position/) | 用于在页眉/页脚中验证签名的文档布局中的形状位置。 |
