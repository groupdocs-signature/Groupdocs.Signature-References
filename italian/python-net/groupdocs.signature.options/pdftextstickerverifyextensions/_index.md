## PdfTextStickerVerifyExtensions class

Fornisce estensioni per la verifica degli oggetti adesivo PDF.

Il tipo PdfTextStickerVerifyExtensions espone i seguenti membri:

### Costruttori
| Costruttore | Descrizione |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.options/pdftextstickerverifyextensions/__init__/) | Inizializza le estensioni di verifica della firma sticker di testo PDF con valori vuoti. |

| :- | :- |
| [contents](/signature/python-net/groupdocs.signature.options/pdftextstickerverifyextensions/contents/) | Il contenuto dello sticker da verificare. |
