## GifSaveOptions.DoPaletteCorrection property

팔레트 보정이 적용되는지 여부를 나타내는 값을 가져오거나 설정합니다.

```csharp
public bool DoPaletteCorrection { get; set; }
```

### 비고

Palette correction은 이미지가 GIF로 내보내질 때마다 원본 이미지 색상을 분석하여 최적의 팔레트를 구축한다는 의미입니다(이미지 Palette가 없거나 옵션에 지정되지 않은 경우). 분석 과정은 다소 시간이 걸리지만, 출력 이미지가 최적의 색상 팔레트를 갖게 되어 시각적으로 더 나은 결과를 제공합니다.
