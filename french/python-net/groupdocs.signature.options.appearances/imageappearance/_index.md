## ImageAppearance class

Représente les fonctionnalités d'apparence étendues pour une signature d'image.

Le type ImageAppearance expose les membres suivants :

### Constructeurs
| Constructeur | Description |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.options.appearances/imageappearance/__init__/) | Initialise une nouvelle instance ImageAppearance avec des valeurs par défaut. |

### Propriétés
| Propriété | Description |
| :- | :- |
| [brightness](/signature/python-net/groupdocs.signature.options.appearances/imageappearance/brightness/) | La luminosité de l'image, avec une valeur par défaut de 1 correspondant à la luminosité originale de l'image. |
| [contrast](/signature/python-net/groupdocs.signature.options.appearances/imageappearance/contrast/) | Le contraste de l'image. La valeur par défaut est 1, ce qui correspond au contraste original de l'image. |
| [gamma_correction](/signature/python-net/groupdocs.signature.options.appearances/imageappearance/gamma_correction/) | Le gamma de l'image. |
| [grayscale](/signature/python-net/groupdocs.signature.options.appearances/imageappearance/grayscale/) | Le drapeau en niveaux de gris ; définissez-le sur True pour appliquer un filtre en niveaux de gris. |
