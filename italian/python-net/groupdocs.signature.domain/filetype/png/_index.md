## PNG field

Il Portable Network Graphic (.png) è un tipo di formato file immagine raster che utilizza compressione senza perdita. Questo formato file è stato creato come sostituto del Graphics Interchange Format (GIF) e non ha limitazioni di copyright. Scopri di più su questo formato file qui.
