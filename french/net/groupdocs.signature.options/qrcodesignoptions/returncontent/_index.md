## QrCodeSignOptions.ReturnContent property

Obtient ou définit le drapeau permettant d'obtenir le contenu d'image QR-Code d'une signature placée sur la page du document. Si ce drapeau est défini sur true, le contenu d'image de la signature QR-Code conservera les données d'image brutes au format requis [`ReturnContentType`](../returncontenttype). Par défaut, cette option est désactivée.

public bool ReturnContent { get; set; }
