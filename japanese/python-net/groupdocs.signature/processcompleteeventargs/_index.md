## ProcessCompleteEventArgs class

署名、検証、検索プロセスの完了イベントに関するデータを提供します。

ProcessCompleteEventArgs 型は次のメンバーを公開します：

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [canceled](/signature/python-net/groupdocs.signature/processcompleteeventargs/canceled/) | プロセスはキャンセルされました。 |
| [completed](/signature/python-net/groupdocs.signature/processcompleteeventargs/completed/) | プロセス完了のタイムスタンプです。 |
| [ticks](/signature/python-net/groupdocs.signature/processcompleteeventargs/ticks/) | プロセス開始イベント以降に経過したミリ秒単位の時間です。 |
| [total_signatures](/signature/python-net/groupdocs.signature/processcompleteeventargs/total_signatures/) | 処理された署名の総数です。 |
| [status](/signature/python-net/groupdocs.signature/processeventargs/status/) | 現在のプロセス状態です。（[`ProcessEventArgs`](/signature/python-net/groupdocs.signature/processeventargs/) から継承） |
