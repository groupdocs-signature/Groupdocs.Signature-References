| Поле | Описание |
| :- | :- |
| [SOLID](/signature/python-net/groupdocs.signature.domain/dashstyle/solid/) | Представляет сплошную линию. |
| [SHORT_DASH](/signature/python-net/groupdocs.signature.domain/dashstyle/short_dash/) | Представляет короткую пунктирную линию. |
| [SHORT_DOT](/signature/python-net/groupdocs.signature.domain/dashstyle/short_dot/) | Представляет короткую точечную линию. |
| [SHORT_DASH_DOT](/signature/python-net/groupdocs.signature.domain/dashstyle/short_dash_dot/) | Представляет короткую пунктирно-точечную линию. |
| [SHORT_DASH_DOT_DOT](/signature/python-net/groupdocs.signature.domain/dashstyle/short_dash_dot_dot/) | Представляет короткую пунктирно-точечно-точечную линию. |
| [DOT](/signature/python-net/groupdocs.signature.domain/dashstyle/dot/) | Представляет стиль квадратных точек. |
| [DASH](/signature/python-net/groupdocs.signature.domain/dashstyle/dash/) | Представляет стиль пунктирной линии. |
| [LONG_DASH](/signature/python-net/groupdocs.signature.domain/dashstyle/long_dash/) | Представляет стиль длинного тире. |
| [DASH_DOT](/signature/python-net/groupdocs.signature.domain/dashstyle/dash_dot/) | Тире короткое тире. |

| [ROUND_DOT](/signature/python-net/groupdocs.signature.domain/dashstyle/round_dot/) | Представляет линию с круглыми точками. |
| [SQUARE_DOT](/signature/python-net/groupdocs.signature.domain/dashstyle/square_dot/) | Представляет линию с квадратными точками. |
| [DASH_DOT_DOT](/signature/python-net/groupdocs.signature.domain/dashstyle/dash_dot_dot/) | Представляет линию пунктир-точка-точка. |
