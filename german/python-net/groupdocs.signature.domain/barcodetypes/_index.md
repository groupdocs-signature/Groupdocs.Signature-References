## BarcodeTypes class

Der BarcodeTypes‑Typ stellt die folgenden Mitglieder bereit:

### Methoden
| Methode | Beschreibung |
| :- | :- |
| [parse](/signature/python-net/groupdocs.signature.domain/barcodetypes/parse/#parsing_type) | Gibt eine BarcodeType‑Instanz für den angegebenen Parsertypnamen zurück. |
| [try_parse](/signature/python-net/groupdocs.signature.domain/barcodetypes/try_parse/#parsing_type) | Gibt den Barcode‑Typ zurück, der dem angegebenen Parsertypnamen entspricht. |
