## FileType.GIF field

El archivo Graphical Interchange Format (.gif) es un tipo de imagen altamente comprimida. Para cada imagen, GIF normalmente permite hasta 8 bits por píxel y se permiten hasta 256 colores en la imagen. Obtenga más información sobre este formato de archivo [aquí](https://wiki.fileformat.com/image/gif).
