## IDocumentInfo class

Les propriétés de description du document.

Le type IDocumentInfo expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [barcode_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/barcode_signatures/) | La collection des signatures de code-barres du document ajoutées ou mises à jour par les méthodes [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [digital_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/digital_signatures/) | La collection des signatures numériques du document ajoutées ou mises à jour par les méthodes [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [documents](/signature/python-net/groupdocs.signature.domain/idocumentinfo/documents/) | La collection de tous les documents existants dans les fichiers d'archive. Cette propriété n'est prise en charge que pour les types de documents d'archive. |
| [file_type](/signature/python-net/groupdocs.signature.domain/idocumentinfo/file_type/) | Le type de format de fichier. |
| [form_field_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/form_field_signatures/) | La collection des signatures de champs de formulaire du document ajoutées ou mises à jour par les méthodes [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [form_fields](/signature/python-net/groupdocs.signature.domain/idocumentinfo/form_fields/) | La collection de tous les champs de formulaire pris en charge existants dans le document. Cette propriété n'est prise en charge que pour les types de documents PDF et de traitement de texte. |
| [image_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/image_signatures/) | La collection des signatures d'image du document ajoutées ou mises à jour par les méthodes [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [max_page_height](/signature/python-net/groupdocs.signature.domain/idocumentinfo/max_page_height/) | La hauteur maximale de la page. |
| [metadata_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/metadata_signatures/) | La collection des signatures de métadonnées du document. |
| [page_count](/signature/python-net/groupdocs.signature.domain/idocumentinfo/page_count/) | Le nombre de pages du document. |
| [pages](/signature/python-net/groupdocs.signature.domain/idocumentinfo/pages/) | La collection des descriptions des pages du document. |
| [process_logs](/signature/python-net/groupdocs.signature.domain/idocumentinfo/process_logs/) | La collection des journaux de processus d'historique du document. |
| [qr_code_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/qr_code_signatures/) | La collection des signatures de code QR du document ajoutées ou mises à jour par les méthodes [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/signatures/) | La collection de tous les types de signatures présents dans le document sous forme d'objets [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [size](/signature/python-net/groupdocs.signature.domain/idocumentinfo/size/) | La taille du document en octets. |
| [text_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/text_signatures/) | La collection des signatures de texte du document ajoutées ou mises à jour par les méthodes [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [width_for_max_height](/signature/python-net/groupdocs.signature.domain/idocumentinfo/width_for_max_height/) | La largeur pour la hauteur maximale de la page. |
