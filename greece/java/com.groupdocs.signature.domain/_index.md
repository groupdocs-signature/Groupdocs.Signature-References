Το χώρο ονομάτων **GroupDocs.Signature.Domain** παρέχει κλάσεις για εργασία με την αναπαράσταση εγγράφων.



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [Background](../com.groupdocs.signature.domain/background) | Αναπαριστά την εμφάνιση φόντου |
| [Border](../com.groupdocs.signature.domain/border) | Παράδειγμα για διατήρηση ιδιοτήτων γραμμής περιγράμματος. |
| [DeleteResult](../com.groupdocs.signature.domain/deleteresult) | Αποτέλεσμα διαγραφής υπογραφής(ών) από το έγγραφο. |
| [Padding](../com.groupdocs.signature.domain/padding) | Αναπαριστά πληροφορίες γεμίσματος ή περιθωρίου που σχετίζονται με το στοιχείο. |
| [PageInfo](../com.groupdocs.signature.domain/pageinfo) | Κλάση περιγραφής σελίδας εγγράφου |
| [ProcessLog](../com.groupdocs.signature.domain/processlog) | Αναπαριστά λεπτομέρειες διαδικασίας εγγράφου. |
| [SearchResult](../com.groupdocs.signature.domain/searchresult) | Αποτέλεσμα αναζήτησης υπογραφών στο καθορισμένο έγγραφο. |
| [SignResult](../com.groupdocs.signature.domain/signresult) | Αποτέλεσμα της διαδικασίας υπογραφής εγγράφου με νέες δημιουργημένες υπογραφές. |
| [SignatureFont](../com.groupdocs.signature.domain/signaturefont) | Δημιουργήστε ένα παράδειγμα της κλάσης SignatureFont για να καθορίσετε τις ιδιότητες της γραμματοσειράς. |
| [UpdateResult](../com.groupdocs.signature.domain/updateresult) | Αποτέλεσμα τροποποίησης υπογραφών στο έγγραφο. |
| [VerificationResult](../com.groupdocs.signature.domain/verificationresult) | Παράδειγμα για διατήρηση αποτελεσμάτων της διαδικασίας επαλήθευσης. |
