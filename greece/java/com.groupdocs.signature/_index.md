Το χώρο ονομάτων **GroupDocs.Signature** παρέχει κλάσεις για την υπογραφή εγγράφων διαφορετικών μορφών με σφραγίδες, γραμμωτούς κώδικες, QR-codes, κείμενο, εικόνα, μεταδεδομένα, πεδία φόρμας και ψηφιακές υπογραφές.

| Κλάση | Περιγραφή |
| --- | --- |
| [Signature](../com.groupdocs.signature/signature) | Αντιπροσωπεύει την κύρια κλάση που ελέγχει τη διαδικασία υπογραφής εγγράφων. |
| [SignatureSettings](../com.groupdocs.signature/signaturesettings) | Ορίζει ρυθμίσεις για την προσαρμογή της συμπεριφοράς του [Signature](../com.groupdocs.signature/signature). |
