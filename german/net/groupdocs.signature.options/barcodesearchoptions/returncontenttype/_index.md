## BarcodeSearchOptions.ReturnContentType property

Legt den Dateityp des zurückgegebenen Bildinhalts der Barcode‑Signatur fest, wenn die ReturnContent‑Eigenschaft aktiviert ist. Standardmäßig ist er auf Null gesetzt. Das bedeutet, dass der Barcode‑Bildinhalt im Originalformat zurückgegeben wird. Dieses Bildformat ist bei [`Format`](../../../groupdocs.signature.domain/barcodesignature/format) angegeben. Mögliche unterstützte Werte sind: FileType.JPEG, FileType.PNG, FileType.BMP. Wenn das angegebene Format nicht unterstützt wird, wird der Barcode‑Bildinhalt im .png‑Format zurückgegeben.

public FileType ReturnContentType { get; set; }
