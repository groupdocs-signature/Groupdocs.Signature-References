## ImageSearchOptions.ReturnContent property

Liest oder setzt das Flag, um den Bildinhalt der Signatur auf der Dokumentseite zu erfassen. Wenn dieses Flag auf true gesetzt ist, behält der Bildsignaturinhalt die Rohbilddaten im erforderlichen Format [`ReturnContentType`](../returncontenttype). Standardmäßig ist diese Option deaktiviert.

public bool ReturnContent { get; set; }
