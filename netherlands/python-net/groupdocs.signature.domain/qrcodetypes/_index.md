## QrCodeTypes class

De QR-code typecontainer.

Het QrCodeTypes-type geeft de volgende leden weer:

### Methoden
| Methode | Beschrijving |
| :- | :- |
| [parse](/signature/python-net/groupdocs.signature.domain/qrcodetypes/parse/#parsing_type) | Parseert een QR-code type naam en retourneert de overeenkomstige QRCodeType-instantie. |
| [try_parse](/signature/python-net/groupdocs.signature.domain/qrcodetypes/try_parse/#parsing_type) | Retourneert het QRCode-type dat overeenkomt met de opgegeven parseernaam, of None als de naam onbekend is. |
