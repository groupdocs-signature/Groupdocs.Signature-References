## DigitalSignatureAppearance class

Beschrijft het uiterlijk van de handtekeninglijn voor digitale handtekening. Eén handtekeninglijn kan alleen op één digitale handtekening worden toegepast. De handtekeninglijn staat altijd op de eerste pagina. Deze functie kan nuttig zijn voor .docx-, .doc-, .odt- en .xlsx-bestandsformaten.
