## EXTENDED_CODETEXT field

Η λειτουργία ExtendedCodetext επιτρέπει την χειροκίνητη εναλλαγή σχήματος κωδικοποίησης στο code-text. Μορφή : \"\\Encodation_scheme_name:text\\Encodation_scheme_name:text\". Τα επιτρεπόμενα σχήματα κωδικοποίησης είναι: EDIFACT, ANSIX12, ASCII, C40, Text, Auto. Παράδειγμα εκτεταμένου code-text: @\"\\ansix12:ANSIX12TEXT\\ascii:backslash must be \\\\ doubled\\edifact:EdifactEncodedText\" Όλες οι ανάποδες κάθετες (\\) πρέπει να διπλασιαστούν στο κείμενο.
