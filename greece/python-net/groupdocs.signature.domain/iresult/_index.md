## IResult class

Αναπαριστά μια κοινή διεπαφή για το αποτέλεσμα της διαδικασίας υπογραφής.

Ο τύπος IResult εκθέτει τα παρακάτω μέλη:

### Ιδιότητες
| Ιδιότητα | Περιγραφή |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/iresult/destin_document_size/) | Το μέγεθος του προορισμού εγγράφου. |
| [failed](/signature/python-net/groupdocs.signature.domain/iresult/failed/) | Η λίστα των υπογραφών που δεν επεξεργάστηκαν. |
| [processing_time](/signature/python-net/groupdocs.signature.domain/iresult/processing_time/) | Ο χρόνος εκτέλεσης της διαδικασίας σε χιλιοστά του δευτερολέπτου. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/iresult/source_document_size/) | Το μέγεθος του πηγαίου εγγράφου. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/iresult/succeeded/) | Η λίστα των υπογραφών που επεξεργάστηκαν επιτυχώς [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/iresult/total_signatures/) | Συνολικές επεξεργασμένες υπογραφές. |
