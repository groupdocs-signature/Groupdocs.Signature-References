## IAlignment class

Beskriver signaturområdets justering på en dokumentsida.

IAlignment-typen exponerar följande medlemmar:

### Egenskaper
| Egenskap | Beskrivning |
| :- | :- |
| [horizontal_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/horizontal_alignment/) | Den horisontella justeringen av bilden på en dokumentsida. |
| [margin](/signature/python-net/groupdocs.signature.domain/ialignment/margin/) | Det utrymme som som standard anges mellan bilden och dokumentets kanter (gäller när horisontell eller vertikal justering är inställd). |
| [margin_measure_type](/signature/python-net/groupdocs.signature.domain/ialignment/margin_measure_type/) | Måtttypen för marginalen (pixlar, procent eller millimeter). |
| [vertical_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/vertical_alignment/) | Den vertikala justeringen av bilden på en dokumentsida. |
