## BarcodeSignature class

Stellt eine Barcode‑Signatur dar.

Der BarcodeSignature-Typ stellt die folgenden Mitglieder bereit:

| Konstruktor | Beschreibung |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.domain/barcodesignature/__init__/#signature_id) | Initialisiert ein BarcodeSignature-Objekt mit einem Signatur‑Identifikator, der nach einem Suchvorgang erhalten wurde.
