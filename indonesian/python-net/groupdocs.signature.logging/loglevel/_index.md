## LogLevel class

Tipe LogLevel menampilkan anggota-anggota berikut:

### Bidang
| Bidang | Deskripsi |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.logging/loglevel/none/) | Tidak ada yang dicatat. |
| [ERROR](/signature/python-net/groupdocs.signature.logging/loglevel/error/) | Kesalahan: operasi gagal. |
| [WARNING](/signature/python-net/groupdocs.signature.logging/loglevel/warning/) | Peringatan: operasi berhasil, tetapi hasilnya mungkin tidak seperti yang Anda harapkan. |
| [TRACE](/signature/python-net/groupdocs.signature.logging/loglevel/trace/) | Jejak: langkah-langkah sebuah operasi, seperti awal dan akhirnya. |
| [ALL](/signature/python-net/groupdocs.signature.logging/loglevel/all/) | Kesalahan, peringatan, dan jejak. Ini adalah default. |
