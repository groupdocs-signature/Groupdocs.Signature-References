## ProcessCompleteEventArgs class

Proporciona datos sobre el evento completo de los procesos de firma, verificación y búsqueda.

El tipo ProcessCompleteEventArgs expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [canceled](/signature/python-net/groupdocs.signature/processcompleteeventargs/canceled/) | El proceso fue cancelado. |
| [completed](/signature/python-net/groupdocs.signature/processcompleteeventargs/completed/) | La marca de tiempo de finalización del proceso. |
| [ticks](/signature/python-net/groupdocs.signature/processcompleteeventargs/ticks/) | El tiempo en milisegundos transcurrido desde el evento de inicio del proceso. |
| [total_signatures](/signature/python-net/groupdocs.signature/processcompleteeventargs/total_signatures/) | La cantidad total de firmas procesadas. |
| [status](/signature/python-net/groupdocs.signature/processeventargs/status/) | El estado actual del proceso. (heredado de [`ProcessEventArgs`](/signature/python-net/groupdocs.signature/processeventargs/)) |
