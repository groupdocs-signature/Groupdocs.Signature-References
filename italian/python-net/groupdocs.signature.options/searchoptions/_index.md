## SearchOptions class

Rappresenta le opzioni per estrarre le firme da un documento.

Maggiori informazioni

- See more simple examples on searching for various electronic signatures with GroupDocs.Signature: https://docs.groupdocs.com/signature/net/search-for-electronic-signatures-in-document/
- See more advanced examples of searching for various electronic signature with GroupDocs.Signature: https://docs.groupdocs.com/signature/net/searching/

Il tipo SearchOptions espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [all_pages](/signature/python-net/groupdocs.signature.options/searchoptions/all_pages/) | Il flag che indica se cercare su ogni pagina del documento. Per impostazione predefinita questo valore è True. |
| [page_number](/signature/python-net/groupdocs.signature.options/searchoptions/page_number/) | Il numero di pagina del documento per la ricerca (opzionale). |
| [pages_setup](/signature/python-net/groupdocs.signature.options/searchoptions/pages_setup/) | Le opzioni per specificare le pagine per la ricerca delle firme. |
| [shape_position](/signature/python-net/groupdocs.signature.options/searchoptions/shape_position/) | Il flag che indica se restituire la posizione della forma nel layout del documento. Disponibile solo per documenti Word. |
| [skip_external](/signature/python-net/groupdocs.signature.options/searchoptions/skip_external/) | Il flag per restituire solo le firme contrassegnate come `IsSignature`. Per impostazione predefinita il valore è `False`, il che indica che vengono restituite tutte le firme che corrispondono ai criteri specificati. |
