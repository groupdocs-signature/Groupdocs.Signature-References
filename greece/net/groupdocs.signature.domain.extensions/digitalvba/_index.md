## DigitalVBA class

Αναπαριστά ψηφιακή υπογραφή για έργα VBA των Spreadsheets. Παρέχει τη δυνατότητα υπογραφής του έργου VBA σε συγκεκριμένες μορφές εγγράφων Spreadsheets όπως Xlsm ή Xltm. Εάν προστεθούν πολλές επεκτάσεις DigitalVBA στο DigitalSignOptions.Extensions, μόνο η πρώτη συμμετέχει στην υπογραφή του εγγράφου.

```csharp
public class DigitalVBA : SignatureExtension
```
