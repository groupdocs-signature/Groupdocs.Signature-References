## DigitalSignOptions.AllowExpired property

Obtient ou définit un drapeau qui permet de signer avec un certificat dont la période de validité est terminée. La valeur par défaut est false : signer avec un certificat expiré lève [`GroupDocsSignatureException`](../../../groupdocs.signature/groupdocssignatureexception), et le document n'est pas signé.

```csharp
public bool AllowExpired { get; set; }
```

### Remarques

Les validateurs signalent une signature réalisée avec un certificat expiré comme non valide. Réglez cette propriété sur true uniquement lorsque vous avez tout de même besoin d'une telle signature, par exemple pour tester avec un ancien certificat. Le document est alors signé, et un avertissement est écrit dans le journal configuré dans [`SignatureSettings`](../../../groupdocs.signature/signaturesettings).

Le certificat est comparé à l'heure actuelle en UTC, et non à [`SignTime`](../../../groupdocs.signature.domain/digitalsignature/signtime). Le drapeau s'applique au certificat fourni par [`CertificateFilePath`](../certificatefilepath), [`CertificateStream`](../certificatestream) ou [`Signature`](../signature), et, lorsqu'une feuille de calcul est signée, au certificat de la première extension [`DigitalVBA`](../../../groupdocs.signature.domain.extensions/digitalvba). Les signatures numériques d'images n'utilisent pas de certificat et ne sont pas vérifiées. Un certificat dont la période de validité n'a pas encore commencé est contrôlé par [`AllowNotYetValid`](../allownotyetvalid).
