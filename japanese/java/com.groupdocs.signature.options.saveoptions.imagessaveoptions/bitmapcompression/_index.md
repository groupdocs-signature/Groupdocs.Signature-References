さまざまなビットマップ圧縮方式を指定します。

## フィールド

| フィールド | 説明 |
| --- | --- |
|  | [Rgb](#Rgb) | 圧縮なし。 |
|
|  | [Rle8](#Rle8) | RLE 8 ビット/ピクセル 圧縮。 |
|
|  | [Rle4](#Rle4) | RLE 4 ビット/ピクセル 圧縮。 |
|
|  | [Bitfields](#Bitfields) | ビットフィールド。 |
|
|  | [Jpeg](#Jpeg) | JPEG 圧縮。 |
|
|  | [Png](#Png) | PNG 圧縮。 |
|
### Rgb {#Rgb}
```
public static final int Rgb
```


圧縮なし。


### Rle8 {#Rle8}
```
public static final int Rle8
```


RLE 8 ビット/ピクセル 圧縮。8 ビット/ピクセル ビットマップでのみ使用できます。


### Rle4 {#Rle4}
```
public static final int Rle4
```


RLE 4 ビット/ピクセル 圧縮。4 ビット/ピクセル ビットマップでのみ使用できます。


### Bitfields {#Bitfields}
```
public static final int Bitfields
```


ビットフィールド。16 ビットおよび 32 ビット/ピクセル ビットマップでのみ使用できます。


### Jpeg {#Jpeg}
```
public static final int Jpeg
```


JPEG 圧縮。ビットマップに JPEG 画像が含まれています。


### Png {#Png}
```
public static final int Png
```


PNG 圧縮。ビットマップに PNG 画像が含まれています。
