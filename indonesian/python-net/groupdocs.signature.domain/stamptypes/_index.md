## StampTypes class

Mewakili kontainer untuk tipe stempel.

Tipe StampTypes menampilkan anggota-anggota berikut:

### Metode
| Metode | Deskripsi |
| :- | :- |
| [parse](/signature/python-net/groupdocs.signature.domain/stamptypes/parse/#parsing_type) | Mengembalikan tipe stempel yang cocok dengan nama tipe parsing yang ditentukan. |
| [try_parse](/signature/python-net/groupdocs.signature.domain/stamptypes/try_parse/#parsing_type) | Mengembalikan tipe stempel untuk nama tipe parsing yang diberikan. Jika nama stempel tidak dikenal, tidak ada pengecualian yang dilemparkan dan metode mengembalikan None. |

### Bidang
| Bidang | Deskripsi |
| :- | :- |
| [ALL_TYPES](/signature/python-net/groupdocs.signature.domain/stamptypes/all_types/) | Semua tipe stempel. |
