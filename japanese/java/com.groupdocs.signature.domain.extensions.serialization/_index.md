**GroupDocs.Signature.Domain.Extensions** 名前空間は、署名の外観と追加機能のための拡張機能を提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [Address](../com.groupdocs.signature.domain.extensions.serialization/address) | VCard 連絡先詳細の住所を表します。 |
| [CryptoCurrencyTransfer](../com.groupdocs.signature.domain.extensions.serialization/cryptocurrencytransfer) | QRコード用の暗号通貨転送（受取人または送金）を表します。 |
| [CryptoCurrencyType](../com.groupdocs.signature.domain.extensions.serialization/cryptocurrencytype) | 暗号通貨の種類を表します。 |
| [DataMatrixEncodeMode](../com.groupdocs.signature.domain.extensions.serialization/datamatrixencodemode) | DataMatrix エンコーダのエンコーディングモード（デフォルトは Auto） |
| [EPC](../com.groupdocs.signature.domain.extensions.serialization/epc) | 欧州支払委員会のクイックレスポンスコードを表します。 |
| [Email](../com.groupdocs.signature.domain.extensions.serialization/email) | QRコード用のメール形式を表します。 |
| [Event](../com.groupdocs.signature.domain.extensions.serialization/event) | 標準 QRコード イベントの詳細を表します。 |
| [MeCard](../com.groupdocs.signature.domain.extensions.serialization/mecard) | MeCard 標準連絡先詳細を表します。 |
| [SMS](../com.groupdocs.signature.domain.extensions.serialization/sms) | SMS 短信サービスの詳細を表します。 |
| [VCard](../com.groupdocs.signature.domain.extensions.serialization/vcard) | VCard 標準の連絡先情報を表します。 |
| [WiFi](../com.groupdocs.signature.domain.extensions.serialization/wifi) | WiFi ネットワーク接続の詳細を表します。 |
| [WiFiEncryptionType](../com.groupdocs.signature.domain.extensions.serialization/wifiencryptiontype) | WiFi 暗号化タイプを表します。 |
