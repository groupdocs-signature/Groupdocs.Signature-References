## BMP field

Bitmap Image File (.bmp) digunakan untuk menyimpan gambar bitmap digital. Gambar ini independen dari adaptor grafis dan juga disebut format file device independent bitmap (DIB). Pelajari lebih lanjut tentang format file ini di sini.
