## trace {#message}

Записывает трассировочное сообщение в консоль.

Сообщения журнала Trace обычно предоставляют полезную информацию о потоке выполнения приложения.

```python
def trace(self, message):
    ...
```

| Параметр | Тип | Описание |
| :- | :- | :- |
| message | `str` | Сообщение trace. |

| Вызывает | Описание |
| :- | :- |
| `ValueError` | Вызывается, когда `message` равно None. |
