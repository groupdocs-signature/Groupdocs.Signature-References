## SignatureSettings.SaveDocumentOnEmptyUpdate property

Liest oder setzt das Flag, um das Quelldokument erneut zu speichern, wenn die Update‑Methode keine Signaturen zum Aktualisieren hat. Wenn dieses Flag auf true (standardmäßig) gesetzt ist, wird das Dokument mit dem entsprechenden Verlauf‑Protokoll (Datum und Vorgangstyp) gespeichert, selbst wenn die Update‑Methode keine Signaturen zum Aktualisieren hat. Wenn dieses Flag auf false gesetzt ist, wird das Quelldokument überhaupt nicht geändert.
