## DigitalSignOptions.AllowExpired property

Получает или задает флаг, позволяющий подписывать сертификатом, срок действия которого истек. Значение по умолчанию — false: подпись с просроченным сертификатом вызывает [`GroupDocsSignatureException`](../../../groupdocs.signature/groupdocssignatureexception), и документ не подписывается.

```csharp
public bool AllowExpired { get; set; }
```

### Примечания

Проверяющие считают подпись, выполненную с просроченным сертификатом, недействительной. Установите это свойство в true только тогда, когда такая подпись всё равно необходима, например для тестирования со старым сертификатом. В этом случае документ подписывается, и в журнал, настроенный в [`SignatureSettings`](../../../groupdocs.signature/signaturesettings), записывается предупреждение.

Сертификат сравнивается с текущим временем в UTC, а не с [`SignTime`](../../../groupdocs.signature.domain/digitalsignature/signtime). Флаг применяется к сертификату, указанному в [`CertificateFilePath`](../certificatefilepath), [`CertificateStream`](../certificatestream) или [`Signature`](../signature), а при подписи электронной таблицы — к сертификату первого расширения [`DigitalVBA`](../../../groupdocs.signature.domain.extensions/digitalvba). Цифровые подписи изображений не используют сертификат и не проверяются. Сертификат, срок действия которого еще не начался, контролируется параметром [`AllowNotYetValid`](../allownotyetvalid).
