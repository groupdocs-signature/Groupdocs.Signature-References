## PngFilterType class

PngFilterType 型は次のメンバーを公開します:

### フィールド
| フィールド | 説明 |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.options/pngfiltertype/none/) | null フィルターは、画像データ行に対してフィルタリングを行わないことを意味します。 |
| [SUB](/signature/python-net/groupdocs.signature.options/pngfiltertype/sub/) | sub フィルターは、画像データに減算フィルタリングが適用されることを意味します。 |
| [UP](/signature/python-net/groupdocs.signature.options/pngfiltertype/up/) | up フィルターは、行ごとの減算フィルタが適用されることを意味します。 |
| [AVG](/signature/python-net/groupdocs.signature.options/pngfiltertype/avg/) | avg フィルターは、画像データに平均フィルターが適用されることを意味します。 |
| [PAETH](/signature/python-net/groupdocs.signature.options/pngfiltertype/paeth/) | パス予測フィルターです。 |
| [ADAPTIVE](/signature/python-net/groupdocs.signature.options/pngfiltertype/adaptive/) | 適応フィルタリングは、保存プロセスが各データ行に最適なフィルタを選択することを意味します。最高の圧縮率ですが、実行時間は最も遅くなります。 |
