Definisce diversi formati di salvataggio file.
## Campi

| Campo | Descrizione |
| --- | --- |
| [Default](#Default) | Il formato del file non verrà modificato. |
| [Pps](#Pps) | Salva il documento come presentazione Microsoft Power Point 97-2003. |
| [Ppt](#Ppt) | Salva il documento come presentazione Microsoft Power Point 97-2003. |
| [Pdf](#Pdf) | Salva il documento in formato PDF. |
| [Xps](#Xps) | Salva il documento nel formato XPS (XML Paper Specification). |
| [Pptx](#Pptx) | Salva il documento nel formato Microsoft Power Point Open XML Presentation. |
| [Ppsx](#Ppsx) | Salva il documento nel formato Microsoft Power Point Open XML Slide Show. |
| [Tiff](#Tiff) | Renderizza una o più pagine del documento e le salva in un file TIFF a pagina singola o multipagina. |
| [Odp](#Odp) | Salva il documento come presentazione Open Office. |
| [Pptm](#Pptm) | Salva il documento come presentazione Microsoft Power Point Open XML con macro. |
| [Ppsm](#Ppsm) | Salva il documento come presentazione Microsoft Power Point Open XML Slide Show con macro. |
| [Potx](#Potx) | Salva il documento come modello Microsoft Power Point. |
| [Potm](#Potm) | Salva il documento come modello Microsoft Power Point con macro. |
| [Html](#Html) | Salva il documento nel formato HTML. |
| [Otp](#Otp) | Salva il documento come modello di presentazione Open Office. |
