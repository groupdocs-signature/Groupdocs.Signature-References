## VerticalAlignment class

VerticalAlignment 型は次のメンバーを公開します:

### フィールド
| フィールド | 説明 |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/verticalalignment/none/) | オブジェクトは明示的に配置され、通常は Top プロパティを使用します。 |
| [TOP](/signature/python-net/groupdocs.signature.domain/verticalalignment/top/) | オブジェクトが垂直配置基準の上部にあることを指定します。 |
| [CENTER](/signature/python-net/groupdocs.signature.domain/verticalalignment/center/) | オブジェクトが垂直配置基準の中央に配置されることを指定します。 |
| [BOTTOM](/signature/python-net/groupdocs.signature.domain/verticalalignment/bottom/) | オブジェクトが垂直配置基準の下部にあることを指定します。 |
