Représente le mode d’étirement de la zone de signature sur la page du document.
## Champs

| Champ | Description |
| --- | --- |
| [None](#None) | Valeur par défaut. |
| [PageWidth](#PageWidth) | Étendre la zone de signature le long de la largeur de la page. |
| [PageHeight](#PageHeight) | Étendre la zone de signature le long de la hauteur de la page. |
| [PageArea](#PageArea) | Étendre la zone de signature le long de la hauteur et de la largeur de la page. |
### None {#None}
```
public static final int None
```


Valeur par défaut. Aucun mode d'étirement ne sera appliqué.

### PageWidth {#PageWidth}
```
public static final int PageWidth
```


Étendre la zone de signature le long de la largeur de la page. La propriété Margin sera utilisée pour appliquer les valeurs de décalage requises

### PageHeight {#PageHeight}
```
public static final int PageHeight
```


Étendre la zone de signature le long de la hauteur de la page. La propriété Margin sera utilisée pour appliquer les valeurs de décalage requises.

### PageArea {#PageArea}
```
public static final int PageArea
```


Étendre la zone de signature le long de la hauteur et de la largeur de la page. La propriété Margin sera utilisée pour appliquer les valeurs de décalage requises.
