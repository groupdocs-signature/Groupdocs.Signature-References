## BMP field

Bitmap Image File (.bmp) χρησιμοποιείται για την αποθήκευση ψηφιακών bitmap εικόνων. Αυτές οι εικόνες είναι ανεξάρτητες από την κάρτα γραφικών και ονομάζονται επίσης μορφή αρχείου device independent bitmap (DIB). Μάθετε περισσότερα για αυτή τη μορφή αρχείου εδώ.
