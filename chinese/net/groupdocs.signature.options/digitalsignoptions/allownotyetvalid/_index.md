## DigitalSignOptions.AllowNotYetValid property

获取或设置一个标志，允许使用尚未开始有效期的证书进行签名。默认值为 false：使用此类证书签名会抛出 [`GroupDocsSignatureException`](../../../groupdocs.signature/groupdocssignatureexception)，文档不会被签名。

```csharp
public bool AllowNotYetValid { get; set; }
```

### 备注

验证器会将证书尚未生效前创建的签名报告为无效。此类证书通常是为以后日期签发的，或是计算机时钟错误。当此属性为 true 时，文档仍会被签名，并向在 [`SignatureSettings`](../../../groupdocs.signature/signaturesettings) 中设置的日志记录器写入警告。

证书会与 UTC 当前时间进行比较。该标志适用于与 [`AllowExpired`](../allowexpired) 相同的证书，后者控制已超过有效期的证书。
