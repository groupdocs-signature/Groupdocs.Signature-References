## StampTypes class

Représente un conteneur pour les types de tampon.

Le type StampTypes expose les membres suivants :

### Méthodes
| Méthode | Description |
| :- | :- |
| [parse](/signature/python-net/groupdocs.signature.domain/stamptypes/parse/#parsing_type) | Renvoie le type de tampon correspondant au nom de type d'analyse spécifié. |
| [try_parse](/signature/python-net/groupdocs.signature.domain/stamptypes/try_parse/#parsing_type) | Renvoie un type de tampon pour le nom de type d'analyse donné. Si le nom du tampon est inconnu, aucune exception n'est levée et la méthode renvoie None. |
