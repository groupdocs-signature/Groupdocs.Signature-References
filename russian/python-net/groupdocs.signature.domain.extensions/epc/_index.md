| Свойство | Описание |

| [remittance](/signature/python-net/groupdocs.signature.domain.extensions/epc/remittance/) | Информация о платеже (максимум 140 символов). |
| [version](/signature/python-net/groupdocs.signature.domain.extensions/epc/version/) | Реализация версии EPC / SEPA QR‑Code, по умолчанию "002". |
