## DigitalSignatureAppearance class

Описывает внешний вид строки подписи для цифровой подписи. Одна строка подписи может быть применена только к одной цифровой подписи. Строка подписи всегда находится на первой странице. Эта функция может быть полезна для форматов файлов .docx, .doc, .odt и .xlsx.

```csharp
public sealed class DigitalSignatureAppearance : SignatureAppearance
```
