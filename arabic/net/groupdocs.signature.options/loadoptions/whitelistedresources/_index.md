## LoadOptions.WhitelistedResources property

يحصل أو يضبط أجزاء من عناوين الموارد الخارجية التي يتم تحميلها حتى عندما تكون [`SkipExternalResources`](../skipexternalresources) صحيحة. القيمة الافتراضية هي قائمة فارغة.

```csharp
public List<string> WhitelistedResources { get; set; }
```

### ملاحظات

يتم تحميل المورد عندما يحتوي عنوانه الكامل على أحد الأجزاء. المقارنة تتجاهل حالة الأحرف، وتُهمل الأجزاء الفارغة. يفضَّل استخدام أجزاء طويلة مثل \"https://cdn.example.com/images/\": الجزء القصير يطابق أيضًا عناوين أخرى قد تحتوي عليه.

ضبط هذه الخاصية على null يمسح القائمة. لا تؤثر القائمة عندما تكون [`SkipExternalResources`](../skipexternalresources) false، لأن جميع الموارد الخارجية تُحمَّل في هذه الحالة.
