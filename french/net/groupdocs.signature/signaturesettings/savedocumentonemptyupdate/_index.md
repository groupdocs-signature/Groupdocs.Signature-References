## SignatureSettings.SaveDocumentOnEmptyUpdate property

Obtient ou définit le drapeau pour réenregistrer le document source lorsque la méthode Update n’a aucune signature à mettre à jour. Si ce drapeau est défini sur true (par défaut), le document sera enregistré avec le journal du processus d’historique correspondant (date et type d’opération) même si la méthode Update n’a aucune signature à mettre à jour. Lorsque ce drapeau est défini sur false, le document source ne sera pas du tout modifié.
