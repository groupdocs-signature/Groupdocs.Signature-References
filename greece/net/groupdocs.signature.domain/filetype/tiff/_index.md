## FileType.TIFF field

Το Tagged Image File Format (.tiff) αντιπροσωπεύει εικόνες raster που προορίζονται για χρήση σε ποικίλες συσκευές που συμμορφώνονται με αυτό το πρότυπο μορφής αρχείου. Μπορεί να περιγράψει δεδομένα εικόνας διπλού επιπέδου, σε κλίμακα του γκρι, με παλέτα χρωμάτων και πλήρους χρώματος σε διάφορους χρωματικούς χώρους. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](https://wiki.fileformat.com/image/tiff).
