## LoadOptions.WhitelistedResources property

Получает или задаёт фрагменты адресов внешних ресурсов, которые загружаются даже когда [`SkipExternalResources`](../skipexternalresources) имеет значение true. Значение по умолчанию — пустой список.

```csharp
public List<string> WhitelistedResources { get; set; }
```

### Примечания

Ресурс загружается, когда его полный адрес содержит один из фрагментов. Сравнение игнорирует регистр, пустые фрагменты игнорируются. Предпочтительно использовать длинные фрагменты, например "https://cdn.example.com/images/": короткий фрагмент также совпадает с другими адресами, которые случайно его содержат.

Установка этого свойства в null очищает список. Список не оказывает влияния, когда [`SkipExternalResources`](../skipexternalresources) имеет значение false, потому что в этом случае загружается каждый внешний ресурс.
