## DigitalSignOptions.AllowNotYetValid property

Liest oder schreibt ein Flag, das das Signieren mit einem Zertifikat erlaubt, dessen Gültigkeitszeitraum noch nicht begonnen hat. Der Standardwert ist false: Das Signieren mit einem solchen Zertifikat löst [`GroupDocsSignatureException`](../../../groupdocs.signature/groupdocssignatureexception) aus, und das Dokument wird nicht signiert.

```csharp
public bool AllowNotYetValid { get; set; }
```

### Hinweise

Validatoren melden eine Signatur, die vor dem Gültigkeitsbeginn des Zertifikats erstellt wurde, als ungültig. Ein solches Zertifikat wurde normalerweise für ein späteres Datum ausgestellt, oder die Systemuhr ist falsch. Wenn diese Eigenschaft true ist, wird das Dokument signiert und eine Warnung in den Logger geschrieben, der in [`SignatureSettings`](../../../groupdocs.signature/signaturesettings) festgelegt ist.

Das Zertifikat wird mit der aktuellen Zeit in UTC verglichen. Das Flag gilt für dieselben Zertifikate wie [`AllowExpired`](../allowexpired), das Zertifikate steuert, deren Gültigkeitszeitraum beendet ist.
