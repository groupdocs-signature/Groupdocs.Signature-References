Το χώρο ονομάτων **GroupDocs.Signature.Domain.Interfaces** παρέχει κλάσεις για εργασία με διεπαφές.



## Διεπαφές

| Διεπαφή | Περιγραφή |
| --- | --- |
| [IAlignment](../com.groupdocs.signature.domain.interfaces/ialignment) | Η διεπαφή περιγράφει την ευθυγράμμιση της περιοχής υπογραφής στη σελίδα του εγγράφου. |
| [IRectangle](../com.groupdocs.signature.domain.interfaces/irectangle) | Η διεπαφή ορίζει ιδιότητες για την περιοχή υπογραφής στη σελίδα του εγγράφου. |
| [IRotation](../com.groupdocs.signature.domain.interfaces/irotation) | Η διεπαφή ορίζει ιδιότητες για την περιστροφή της υπογραφής. |
| [ITextAlignment](../com.groupdocs.signature.domain.interfaces/itextalignment) | Η διεπαφή ορίζει ιδιότητες ευθυγράμμισης για κείμενο σε κειμενικές υπογραφές. |
| [ITransparency](../com.groupdocs.signature.domain.interfaces/itransparency) | Ορίστε την ιδιότητα Διαφάνειας για διαφορετικές εμφανίσεις αντικειμένων |
