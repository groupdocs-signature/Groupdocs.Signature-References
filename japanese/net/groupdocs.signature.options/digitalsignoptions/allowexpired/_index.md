## DigitalSignOptions.AllowExpired property

有効期間が終了した証明書での署名を許可するフラグを取得または設定します。デフォルト値は false です。期限切れの証明書で署名すると [`GroupDocsSignatureException`](../../../groupdocs.signature/groupdocssignatureexception) がスローされ、ドキュメントは署名されません。

```csharp
public bool AllowExpired { get; set; }
```

### 備考

バリデータは、期限切れの証明書で作成された署名を無効として報告します。このプロパティは、どうしてもそのような署名が必要な場合、例えば古い証明書でテストする場合にのみ true に設定してください。ドキュメントは署名され、[`SignatureSettings`](../../../groupdocs.signature/signaturesettings) で設定されたロガーに警告が書き込まれます。

証明書は UTC の現在時刻と比較され、[`SignTime`](../../../groupdocs.signature.domain/digitalsignature/signtime) とは比較されません。このフラグは、[`CertificateFilePath`](../certificatefilepath)、[`CertificateStream`](../certificatestream) または [`Signature`](../signature) で指定された証明書に適用され、スプレッドシートが署名される場合は最初の [`DigitalVBA`](../../../groupdocs.signature.domain.extensions/digitalvba) 拡張機能の証明書にも適用されます。画像のデジタル署名は証明書を使用せず、チェックされません。有効期間がまだ開始されていない証明書は [`AllowNotYetValid`](../allownotyetvalid) によって制御されます。
