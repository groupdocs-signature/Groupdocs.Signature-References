## StampTypes class

Stellt einen Container für Stempeltypen dar.

Der Typ StampTypes stellt die folgenden Mitglieder bereit:

### Methoden
| Methode | Beschreibung |
| :- | :- |
| [parse](/signature/python-net/groupdocs.signature.domain/stamptypes/parse/#parsing_type) | Gibt den Stempeltyp zurück, der dem angegebenen Parsings‑Typnamen entspricht. |
| [try_parse](/signature/python-net/groupdocs.signature.domain/stamptypes/try_parse/#parsing_type) | Gibt einen Stempeltyp für den angegebenen Parsings‑Typnamen zurück. Wenn der Stempelname unbekannt ist, wird keine Ausnahme ausgelöst und die Methode gibt None zurück. |

### Felder
| Feld | Beschreibung |
| :- | :- |
| [ALL_TYPES](/signature/python-net/groupdocs.signature.domain/stamptypes/all_types/) | Alle Stempeltypen. |

| [SQUARE](/signature/python-net/groupdocs.signature.domain/stamptypes/square/) | Quadratisches Stempeltyp‑Objekt. |
