## IAlignment class

Menjelaskan perataan area tanda tangan pada halaman dokumen.

Tipe IAlignment menampilkan anggota-anggota berikut:

### Properti
| Properti | Deskripsi |
| :- | :- |
| [horizontal_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/horizontal_alignment/) | Perataan horizontal gambar pada halaman dokumen. |
| [margin](/signature/python-net/groupdocs.signature.domain/ialignment/margin/) | Ruang yang secara default ditentukan antara gambar dan tepi dokumen (berlaku ketika perataan horizontal atau vertikal diatur). |
| [margin_measure_type](/signature/python-net/groupdocs.signature.domain/ialignment/margin_measure_type/) | Jenis pengukuran margin (piksel, persen, atau milimeter). |
| [vertical_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/vertical_alignment/) | Perataan vertikal gambar pada halaman dokumen. |
