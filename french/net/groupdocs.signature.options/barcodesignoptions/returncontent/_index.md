## BarcodeSignOptions.ReturnContent property

Obtient ou définit le drapeau pour récupérer le contenu image du code-barres d'une signature placée sur la page du document. Si ce drapeau est défini sur true, le contenu image de la signature Barcode conservera les données d'image brutes selon le format requis [`ReturnContentType`](../returncontenttype). Par défaut, cette option est désactivée.
