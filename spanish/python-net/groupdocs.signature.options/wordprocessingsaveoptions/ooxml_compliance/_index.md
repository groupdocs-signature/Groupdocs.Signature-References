## ooxml_compliance property

El nivel opcional de cumplimiento OOXML para el documento firmado.

Cuando se establece, sobrescribe el cumplimiento del documento original. Cuando es None (por defecto), se conserva el cumplimiento del documento cargado. Solo se aplica a formatos OOXML (Docx, Docm, Dotx, Dotm, FlatOpc y variantes FlatOpc).
