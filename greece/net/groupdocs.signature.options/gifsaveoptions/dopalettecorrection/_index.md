## GifSaveOptions.DoPaletteCorrection property

Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν εφαρμόζεται διόρθωση παλέτας.

```csharp
public bool DoPaletteCorrection { get; set; }
```

### Παρατηρήσεις

Η διόρθωση Palette σημαίνει ότι κάθε φορά που η εικόνα εξάγεται σε GIF, τα χρώματα της αρχικής εικόνας θα αναλυθούν προκειμένου να δημιουργηθεί η πιο κατάλληλη παλέτα (σε περίπτωση που η Palette της εικόνας δεν υπάρχει ή δεν έχει καθοριστεί στις επιλογές). Η διαδικασία ανάλυσης διαρκεί κάποιο χρόνο, ωστόσο η εξαγόμενη εικόνα θα έχει την πιο κατάλληλη παλέτα χρωμάτων και το αποτέλεσμα θα είναι οπτικά καλύτερο.
