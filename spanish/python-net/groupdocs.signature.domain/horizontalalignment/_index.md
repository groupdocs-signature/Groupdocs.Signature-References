## HorizontalAlignment class

El tipo HorizontalAlignment expone los siguientes miembros:

### Campos
| Campo | Descripción |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/horizontalalignment/none/) | El objeto está posicionado explícitamente, generalmente usando su propiedad Left. |
| [LEFT](/signature/python-net/groupdocs.signature.domain/horizontalalignment/left/) | Especifica que el objeto debe alinearse a la izquierda con respecto a la base de alineación horizontal. |
| [CENTER](/signature/python-net/groupdocs.signature.domain/horizontalalignment/center/) | Especifica que el objeto debe centrarse con respecto a la base de alineación horizontal. |
| [RIGHT](/signature/python-net/groupdocs.signature.domain/horizontalalignment/right/) | Especifica que el objeto debe alinearse a la derecha con respecto a la base de alineación horizontal. |
