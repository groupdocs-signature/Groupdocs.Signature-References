Το χώρο ονομάτων **GroupDocs.Signature.Handler.Events** παρέχει κλάσεις για εισόδους και εξόδους Data Handlers.



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [ProcessCompleteEventArgs](../com.groupdocs.signature.handler.events/processcompleteeventargs) | Παρέχει δεδομένα για το γεγονός ολοκλήρωσης των διαδικασιών υπογραφής, επαλήθευσης και αναζήτησης. |
| [ProcessCompleteEventHandler](../com.groupdocs.signature.handler.events/processcompleteeventhandler) | Αντιπροσωπεύει έναν αντιπρόσωπο μεθόδου που θα διαχειρίζεται τις διαδικασίες στα γεγονότα ολοκλήρωσης για υπογραφή, επαλήθευση και αναζήτηση. |
| [ProcessEventArgs](../com.groupdocs.signature.handler.events/processeventargs) | Παρέχει δεδομένα για διαφορετικά γεγονότα των διαδικασιών υπογραφής, επαλήθευσης και αναζήτησης. |
| [ProcessProgressEventArgs](../com.groupdocs.signature.handler.events/processprogresseventargs) | Παρέχει δεδομένα για το γεγονός OnProgress των διαδικασιών υπογραφής, επαλήθευσης και αναζήτησης. |
| [ProcessProgressEventHandler](../com.groupdocs.signature.handler.events/processprogresseventhandler) | Αντιπροσωπεύει έναν αντιπρόσωπο μεθόδου που θα διαχειρίζεται τις διαδικασίες στα γεγονότα προόδου για υπογραφή, επαλήθευση και αναζήτηση. |
| [ProcessStartEventArgs](../com.groupdocs.signature.handler.events/processstarteventargs) | Παρέχει δεδομένα για το γεγονός Start των διαδικασιών υπογραφής, επαλήθευσης και αναζήτησης |
| [ProcessStartEventHandler](../com.groupdocs.signature.handler.events/processstarteventhandler) | Αντιπροσωπεύει έναν αντιπρόσωπο μεθόδου που θα διαχειρίζεται τις διαδικασίες στα γεγονότα έναρξης για υπογραφή, επαλήθευση και αναζήτηση. |
