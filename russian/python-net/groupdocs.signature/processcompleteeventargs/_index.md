## ProcessCompleteEventArgs class

Предоставляет данные о завершении событий подписи, проверки и поиска.

Тип ProcessCompleteEventArgs раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [canceled](/signature/python-net/groupdocs.signature/processcompleteeventargs/canceled/) | Процесс был отменён. |
| [completed](/signature/python-net/groupdocs.signature/processcompleteeventargs/completed/) | Метка времени завершения процесса. |
| [ticks](/signature/python-net/groupdocs.signature/processcompleteeventargs/ticks/) | Время в миллисекундах, затраченное с момента события начала процесса. |
| [total_signatures](/signature/python-net/groupdocs.signature/processcompleteeventargs/total_signatures/) | Общее количество обработанных подписей. |
| [status](/signature/python-net/groupdocs.signature/processeventargs/status/) | Текущее состояние процесса. (унаследовано от [`ProcessEventArgs`](/signature/python-net/groupdocs.signature/processeventargs/)) |
