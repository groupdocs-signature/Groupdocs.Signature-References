## SignatureSettings.IncludeStandardMetadataSignatures property

Mendapatkan atau mengatur flag untuk menyertakan ke dalam Daftar Metadata tanda tangan metadata dokumen standar yang tersemat seperti Penulis, Pemilik, tanggal pembuatan dokumen, tanggal modifikasi, dll. Jika flag ini diatur ke false (secara default) GetDocumentInfo tidak akan menyertakan tanda tangan metadata ini. Ketika flag ini diatur ke true, informasi dokumen akan menyertakan tanda tangan metadata standar ini.

```csharp
public bool IncludeStandardMetadataSignatures { get; set; }
```
