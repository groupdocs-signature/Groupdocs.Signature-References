## FileType.TIFF field

Tagged Image File Format (.tiff) representerar rasterbilder som är avsedda för användning på en mängd olika enheter som följer denna filformatstandard. Det kan beskriva tvånivå-, gråskala-, palettfärg- och fullfärgsbilddata i flera färgrymder. Läs mer om detta filformat [här](https://wiki.fileformat.com/image/tiff).
