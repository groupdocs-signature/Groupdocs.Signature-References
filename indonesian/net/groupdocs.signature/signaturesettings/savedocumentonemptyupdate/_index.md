## SignatureSettings.SaveDocumentOnEmptyUpdate property

Mendapatkan atau mengatur flag untuk menyimpan ulang dokumen sumber ketika metode Update tidak memiliki tanda tangan untuk diperbarui. Jika flag ini diatur ke true (secara default) dokumen akan disimpan dengan log proses riwayat yang sesuai (tanggal dan jenis operasi) bahkan jika metode Update tidak memiliki tanda tangan untuk diperbarui. Ketika flag ini diatur ke false dokumen sumber tidak akan dimodifikasi sama sekali.

public bool SaveDocumentOnEmptyUpdate { get; set; }
