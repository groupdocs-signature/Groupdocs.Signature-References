## BarcodeSignature class

Représente une signature de code-barres.

Le type BarcodeSignature expose les membres suivants :

### Constructeurs
| Constructeur | Description |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.domain/barcodesignature/__init__/#signature_id) | Initialise un objet BarcodeSignature avec un identifiant de signature obtenu après un processus de recherche. L'identifiant est utilisé pour récupérer des propriétés supplémentaires pour cette signature à partir de la couche d'informations de signature du document. |
