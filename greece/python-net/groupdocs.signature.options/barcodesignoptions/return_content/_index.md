## return_content property

Η σημαία που υποδεικνύει αν θα ανακτηθεί το περιεχόμενο της εικόνας barcode μιας υπογραφής που τοποθετήθηκε σε μια σελίδα εγγράφου.

Όταν ορίζεται σε True, το περιεχόμενο της εικόνας της υπογραφής barcode διατηρείται ως ακατέργαστα δεδομένα εικόνας στη μορφή που καθορίζεται από `return_content_type`. Από προεπιλογή, αυτή η επιλογή είναι απενεργοποιημένη (False).
