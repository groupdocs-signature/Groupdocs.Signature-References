## StampTypes class

Представляет контейнер для типов печати.

Тип StampTypes раскрывает следующие члены:

### Методы
| Метод | Описание |
| :- | :- |
| [parse](/signature/python-net/groupdocs.signature.domain/stamptypes/parse/#parsing_type) | Возвращает тип штампа, соответствующий указанному имени типа разбора. |
| [try_parse](/signature/python-net/groupdocs.signature.domain/stamptypes/try_parse/#parsing_type) | Возвращает тип штампа для заданного имени типа разбора. Если имя штампа неизвестно, исключение не выбрасывается, и метод возвращает None. |

### Поля
| Поле | Описание |
| :- | :- |
| [ALL_TYPES](/signature/python-net/groupdocs.signature.domain/stamptypes/all_types/) | Все типы штампов. |
| [ROUND](/signature/python-net/groupdocs.signature.domain/stamptypes/round/) | Объект круглого типа штампа. |
| [SQUARE](/signature/python-net/groupdocs.signature.domain/stamptypes/square/) | Объект квадратного типа штампа. |
