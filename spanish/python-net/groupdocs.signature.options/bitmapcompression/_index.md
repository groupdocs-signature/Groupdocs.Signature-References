## BitmapCompression class

El tipo BitmapCompression expone los siguientes miembros:

### Campos
| Campo | Descripción |
| :- | :- |
| [RGB](/signature/python-net/groupdocs.signature.options/bitmapcompression/rgb/) | Sin compresión. |
| [RLE8](/signature/python-net/groupdocs.signature.options/bitmapcompression/rle8/) | Compresión RLE de 8 bits/píxel. Solo se puede usar con mapas de bits de 8 bits/píxel. |
| [RLE4](/signature/python-net/groupdocs.signature.options/bitmapcompression/rle4/) | Compresión RLE de 4 bits/píxel. Solo se puede usar con mapas de bits de 4 bits/píxel. |
| [BITFIELDS](/signature/python-net/groupdocs.signature.options/bitmapcompression/bitfields/) | Campos de bits. Solo se puede usar con mapas de bits de 16 y 32 bits/píxel. |
| [JPEG](/signature/python-net/groupdocs.signature.options/bitmapcompression/jpeg/) | Compresión JPEG. El mapa de bits contiene una imagen JPEG. |
| [PNG](/signature/python-net/groupdocs.signature.options/bitmapcompression/png/) | Compresión PNG. El mapa de bits contiene una imagen PNG. |
