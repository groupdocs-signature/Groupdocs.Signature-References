## QrCodeSignOptions.ReturnContentType property

Specifica il tipo di file del contenuto immagine restituito della firma QR-Code quando la proprietà ReturnContent è abilitata. Per impostazione predefinita è impostata a Null. Ciò significa restituire il contenuto immagine QR-Code nel formato originale. Questo formato immagine è specificato in [`Format`](../../../groupdocs.signature.domain/qrcodesignature/format). I valori supportati possibili sono: FileType.JPEG, FileType.PNG, FileType.BMP. Se il formato fornito non è supportato, verrà restituito il contenuto immagine QR-Code in formato .png.

public FileType ReturnContentType { get; set; }
