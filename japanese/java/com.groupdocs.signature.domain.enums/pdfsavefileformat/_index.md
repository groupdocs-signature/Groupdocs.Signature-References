## フィールド

| フィールド | 説明 |
| --- | --- |
|  | [Default](#Default) | ファイル形式は変更されません。 |
|
|  | [Pdf](#Pdf) | ドキュメントを PDF（Adobe Portable Document）形式として保存します。 |
|
|  | [Doc](#Doc) | ドキュメントを Microsoft Word 97-2007 ドキュメント形式で保存します。 |
|
|  | [Xps](#Xps) | ドキュメントを XPS（XML Paper Specification）形式で保存します。 |
|
|  | [DocX](#DocX) | ドキュメントを Microsoft Word Open XML ファイル形式で保存します。 |
|
|  | [Svg](#Svg) | ドキュメントを SVG（Scalable Vector Graphics）形式で保存します。 |
|
|  | [Epub](#Epub) | ドキュメントを IDPF EPUB 形式で保存します。 |
|
|  | [Pptx](#Pptx) | ドキュメントを PowerPoint Open XML プレゼンテーションファイル形式で保存します。 |
|
