## SignResult class

Mewakili hasil proses penandatanganan dokumen dengan tanda tangan yang baru dibuat.

Tipe SignResult mengekspos anggota-anggota berikut:

### Properti
| Properti | Deskripsi |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/signresult/destin_document_size/) | Ukuran dokumen tujuan. |
| [failed](/signature/python-net/groupdocs.signature.domain/signresult/failed/) | Daftar tanda tangan yang gagal dibuat. |
| [processing_time](/signature/python-net/groupdocs.signature.domain/signresult/processing_time/) | Waktu eksekusi proses dalam milidetik. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/signresult/source_document_size/) | Ukuran dokumen sumber. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/signresult/succeeded/) | Daftar tanda tangan yang baru dibuat [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/signresult/total_signatures/) | Total tanda tangan yang diproses. |
