## FileType.POTM field

PowerPoint Open XML Macro-Enabled Presentation Template (.potm) — это файлы шаблонов Microsoft PowerPoint с поддержкой макросов. Файлы POTM создаются в PowerPoint 2007 и новее и содержат настройки по умолчанию, которые можно использовать для создания последующих файлов презентаций. Узнайте больше о этом формате файлов [здесь](https://wiki.fileformat.com/presentation/potm).
