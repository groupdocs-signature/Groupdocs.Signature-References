## DigitalSignatureAppearance class

Descrive l'aspetto della linea di firma per la firma digitale. Una linea di firma può essere applicata solo a una firma digitale. La linea di firma è sempre sulla prima pagina. Questa funzionalità può essere utile per i formati di file .docx, .doc, .odt e .xlsx.

public sealed class DigitalSignatureAppearance : SignatureAppearance
