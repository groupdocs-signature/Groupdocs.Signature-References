## ImageSearchOptions.ReturnContent property

Obtient ou définit le drapeau permettant de récupérer le contenu image de la signature sur la page du document. Si ce drapeau est vrai, le contenu de la signature image conservera les données brutes de l'image selon le format requis [`ReturnContentType`](../returncontenttype). Par défaut, cette option est désactivée.
