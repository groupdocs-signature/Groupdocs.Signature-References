## SignatureSettings.IncludeStandardMetadataSignatures property

Ottiene o imposta il flag per includere nella Lista dei Metadati le firme di metadati standard del documento incorporate, come Autore, Proprietario, data di creazione del documento, data di modifica, ecc. Se questo flag è impostato su false (per impostazione predefinita) GetDocumentInfo non includerà queste firme di metadati. Quando questo flag è impostato su true le informazioni del documento includeranno queste firme di metadati standard.

```csharp
public bool IncludeStandardMetadataSignatures { get; set; }
```
