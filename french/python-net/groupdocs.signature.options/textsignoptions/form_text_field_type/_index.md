## form_text_field_type property

Le type de champ de formulaire dans lequel placer la signature texte. Cette propriété n'est applicable que lorsque `signature_implementation` est définie sur `TextSignatureImplementation.FORM_FIELD` (c’est‑à‑dire TextToFormField). La valeur par défaut est `FormTextFieldType.ALL_TEXT_TYPES`.
