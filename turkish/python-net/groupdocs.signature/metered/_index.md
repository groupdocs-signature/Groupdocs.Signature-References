## Metered class

Ölçülen (kullanım başına ödeme) lisanslamayı yönetir.

Metered lisanslar gerçek tüketim üzerinden faturalandırılır (genellikle sayfalar veya
işlenen belgeler). Genel/özel anahtar çiftini bir kez ayarlayın
uygulama başlangıcında; sarmalayıcı kullanımı GroupDocs'e geri bildirir
lisans sunucusuna arka planda.

Metered türü aşağıdaki üyeleri sunar:

### Yöntemler
| Yöntem | Açıklama |
| :- | :- |
| [get_consumption_credit](/signature/python-net/groupdocs.signature/metered/get_consumption_credit/) | Şu ana kadar tüketilen kredi sayısını döndürür. |
| [get_consumption_quantity](/signature/python-net/groupdocs.signature/metered/get_consumption_quantity/) | Şu ana kadar işlenen veri miktarını döndürür. |
| [set_metered_key](/signature/python-net/groupdocs.signature/metered/set_metered_key/#public_key-private_key) | Verilen genel/özel anahtar çiftiyle ölçümlü faturalandırmayı etkinleştirin. |
