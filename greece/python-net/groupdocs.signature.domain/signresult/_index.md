## SignResult class

Αντιπροσωπεύει το αποτέλεσμα της διαδικασίας υπογραφής για ένα έγγραφο με νεοδημιουργημένες υπογραφές.

Ο τύπος SignResult εκθέτει τα ακόλουθα μέλη:

### Ιδιότητες
| Ιδιότητα | Περιγραφή |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/signresult/destin_document_size/) | Το μέγεθος του προορισμού εγγράφου. |
| [failed](/signature/python-net/groupdocs.signature.domain/signresult/failed/) | Η λίστα των υπογραφών που απέτυχαν να δημιουργηθούν. |
| [processing_time](/signature/python-net/groupdocs.signature.domain/signresult/processing_time/) | Ο χρόνος εκτέλεσης της διαδικασίας σε χιλιοστά του δευτερολέπτου. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/signresult/source_document_size/) | Το μέγεθος του πηγαίου εγγράφου. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/signresult/succeeded/) | Η λίστα των νέων δημιουργημένων υπογραφών [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/signresult/total_signatures/) | Συνολικές επεξεργασμένες υπογραφές. |
