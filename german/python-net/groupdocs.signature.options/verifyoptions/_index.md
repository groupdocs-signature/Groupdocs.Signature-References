## VerifyOptions class

Enthält Optionen zur Verifizierung eines Dokuments.

Der VerifyOptions‑Typ stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [all_pages](/signature/python-net/groupdocs.signature.options/verifyoptions/all_pages/) | Das Flag, das angibt, ob jede Dokumentseite verifiziert werden soll. Standardmäßig ist der Wert True. |
| [extensions](/signature/python-net/groupdocs.signature.options/verifyoptions/extensions/) | Die zusätzlichen Erweiterungen für die Verifizierung alternativer Signaturoptionen. |
| [is_valid](/signature/python-net/groupdocs.signature.options/verifyoptions/is_valid/) | Das gültige Eigenschafts-Flag. |
| [page_number](/signature/python-net/groupdocs.signature.options/verifyoptions/page_number/) | Die zu überprüfende Dokumentseitennummer; wenn nicht festgelegt, werden alle Seiten des Dokuments für das erste Vorkommen überprüft (Mindestwert ist 1). |
| [pages_setup](/signature/python-net/groupdocs.signature.options/verifyoptions/pages_setup/) | Die Seitenoptionen zum Festlegen der zu überprüfenden Seiten. |
| [shape_position](/signature/python-net/groupdocs.signature.options/verifyoptions/shape_position/) | Die Formposition im Dokumentlayout, die zum Überprüfen von Signaturen in Kopf‑/Fußzeilen verwendet wird. |
