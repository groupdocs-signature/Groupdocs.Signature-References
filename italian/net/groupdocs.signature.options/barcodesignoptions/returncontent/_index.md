## BarcodeSignOptions.ReturnContent property

Ottiene o imposta il flag per ottenere il contenuto immagine del codice a barre di una firma inserita nella pagina del documento. Se questo flag è impostato su true, il contenuto immagine della firma Barcode manterrà i dati immagine grezzi nel formato richiesto [`ReturnContentType`](../returncontenttype). Per impostazione predefinita questa opzione è disabilitata.

public bool ReturnContent { get; set; }
