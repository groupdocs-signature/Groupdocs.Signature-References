## QrCodeSignOptions.ReturnContent property

Λαμβάνει ή ορίζει τη σημαία για λήψη του περιεχομένου εικόνας QR-Code μιας υπογραφής που τοποθετήθηκε στη σελίδα του εγγράφου. Εάν αυτή η σημαία οριστεί σε true, το περιεχόμενο εικόνας QR-Code της υπογραφής θα διατηρήσει τα ακατέργαστα δεδομένα εικόνας με τη απαιτούμενη μορφή [`ReturnContentType`](../returncontenttype). Από προεπιλογή αυτή η επιλογή είναι απενεργοποιημένη.

public bool ReturnContent { get; set; }
