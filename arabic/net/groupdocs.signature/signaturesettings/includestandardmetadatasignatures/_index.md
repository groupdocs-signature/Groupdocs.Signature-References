## SignatureSettings.IncludeStandardMetadataSignatures property

يحصل أو يضبط علامة لتضمين توقيعات بيانات التعريف المدمجة القياسية في قائمة Metadata مثل المؤلف، المالك، تاريخ إنشاء المستند، تاريخ التعديل، إلخ. إذا تم تعيين هذه العلامة إلى false (افتراضيًا) فإن GetDocumentInfo لن يتضمن هذه التوقيعات. عندما يتم تعيين العلامة إلى true ستتضمن معلومات المستند هذه التوقيعات القياسية لبيانات التعريف.

```csharp
public bool IncludeStandardMetadataSignatures { get; set; }
```
