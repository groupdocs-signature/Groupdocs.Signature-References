## content property

Der binäre Bilddateninhalt des Barcodes im von [`BarcodeSignature.format`](/signature/python-net/groupdocs.signature.domain/barcodesignature/format/) angegebenen Format.

Standardmäßig ist diese Eigenschaft nicht gesetzt. Aktivieren Sie sie, indem Sie [`BarcodeSearchOptions.return_content`](/signature/python-net/groupdocs.signature.options/barcodesearchoptions/return_content/) auf True setzen.
