## SignatureSettings.IncludeStandardMetadataSignatures property

获取或设置是否将嵌入的标准文档元数据签名（如 Author、Owner、文档创建日期、修改日期等）包含到 Metadata List 中的标志。如果此标志设置为 false（默认），GetDocumentInfo 将不包括这些元数据签名。当此标志设置为 true 时，文档信息将包含这些标准元数据签名。

```csharp
public bool IncludeStandardMetadataSignatures { get; set; }
```
