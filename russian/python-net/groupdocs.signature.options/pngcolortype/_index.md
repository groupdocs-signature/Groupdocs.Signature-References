## PngColorType class

Тип PngColorType раскрывает следующие члены:

### Поля
| Поле | Описание |
| :- | :- |
| [GRAYSCALE](/signature/python-net/groupdocs.signature.options/pngcolortype/grayscale/) | Представляет тип цвета, где каждый пиксель — образец в градациях серого. |
| [TRUECOLOR](/signature/python-net/groupdocs.signature.options/pngcolortype/truecolor/) | Представляет тип цвета, где каждый пиксель — тройка R,G,B. |
| [INDEXED_COLOR](/signature/python-net/groupdocs.signature.options/pngcolortype/indexed_color/) | Представляет тип цвета, где каждый пиксель — индекс палитры; должен присутствовать блок PLTE. |
| [GRAYSCALE_WITH_ALPHA](/signature/python-net/groupdocs.signature.options/pngcolortype/grayscale_with_alpha/) | Представляет тип цвета, где каждый пиксель — образец в градациях серого, за которым следует альфа-образец. |
| [TRUECOLOR_WITH_ALPHA](/signature/python-net/groupdocs.signature.options/pngcolortype/truecolor_with_alpha/) | Представляет тип цвета, где каждый пиксель — тройка R,G,B, за которой следует альфа-образец. |
