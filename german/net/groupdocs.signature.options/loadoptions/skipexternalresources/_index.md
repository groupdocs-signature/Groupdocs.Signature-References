## LoadOptions.SkipExternalResources property

Liest oder setzt ein Flag, das das Laden externer Ressourcen durch das Dokument verhindert. Der Standardwert ist true: Externe Ressourcen werden nicht geladen, außer denen, die mit [`WhitelistedResources`](../whitelistedresources) übereinstimmen.

```csharp
public bool SkipExternalResources { get; set; }
```

### Hinweise

Ein Dokument kann auf Ressourcen verweisen, die außerhalb gespeichert sind: verknüpfte Bilder, Bilder, die über ein INCLUDEPICTURE‑Feld eingefügt werden, verknüpfte Bilder in Präsentationen und Tabellenkalkulationen sowie Bilder und Stylesheets, auf die ein SVG‑Bild verweist. Das Laden einer solchen Ressource veranlasst die Bibliothek, deren Adresse anzufordern. Auf einem Server, der nicht vertrauenswürdige Dokumente verarbeitet, könnte ein Dokument dies nutzen, um den Server Anfragen an interne Adressen senden zu lassen (Server‑Side‑Request‑Forgery), und ein UNC‑ oder file://‑Pfad könnte Windows veranlassen, die NTLM‑Anmeldeinformationen des Kontos an einen anderen Host zu senden. Bei einer Offline‑ oder luftisolierten Installation schlagen die Anfragen fehl oder warten auf einen Timeout.

Ressourcen, die übersprungen werden, werden weder in Seitenvorschauen noch in als Bilder gespeicherten Dokumenten dargestellt, und die Bild‑, Barcode‑ und QR‑Code‑Suche erkennt sie nicht. Setzen Sie diese Eigenschaft nur für vertrauenswürdige Dokumente auf false und bevorzugen Sie das Zulassen spezifischer Adressen mit [`WhitelistedResources`](../whitelistedresources).

Die Einstellung gilt für Textverarbeitungsdokumente, Präsentationen, Tabellenkalkulationen und SVG‑Bilder, einschließlich Dokumenten in Archiven. Bei SVG‑Bildern werden nicht zulässige Verweise vor dem Einlesen aus dem Bild entfernt, und ein SVG‑Bild, das kein wohlgeformtes XML ist, wird abgelehnt. Die Einstellung steuert keine Zertifikatswiderrufsprüfungen, Zeitstempel‑Server oder Lizenzierung.

Diese Eigenschaft ersetzt LoadExternalResources, das die gegenteilige Bedeutung hat.
