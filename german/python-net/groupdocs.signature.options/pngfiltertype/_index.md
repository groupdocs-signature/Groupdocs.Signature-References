## PngFilterType class

Der PngFilterType‑Typ stellt die folgenden Mitglieder bereit:

### Felder
| Feld | Beschreibung |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.options/pngfiltertype/none/) | Der Null‑Filter bedeutet, dass keine Filterung für Bilddatenzeilen erfolgt. |
| [SUB](/signature/python-net/groupdocs.signature.options/pngfiltertype/sub/) | Der Sub‑Filter bedeutet, dass eine subtraktive Filterung auf Bilddaten angewendet wird. |
| [UP](/signature/python-net/groupdocs.signature.options/pngfiltertype/up/) | Der Up‑Filter bedeutet, dass ein zeilenweises Subtraktionsfilter angewendet wird. |
| [AVG](/signature/python-net/groupdocs.signature.options/pngfiltertype/avg/) | Der Avg‑Filter bedeutet, dass ein Durchschnittsfilter auf Bilddaten angewendet wird. |
| [PAETH](/signature/python-net/groupdocs.signature.options/pngfiltertype/paeth/) | Der Pfad‑Prädiktor‑Filter. |
| [ADAPTIVE](/signature/python-net/groupdocs.signature.options/pngfiltertype/adaptive/) | Adaptive Filterung bedeutet, dass der Speicherprozess für jede Datenzeile den am besten geeigneten Filter auswählt. Beste Kompression, langsamste Ausführungszeit. |
