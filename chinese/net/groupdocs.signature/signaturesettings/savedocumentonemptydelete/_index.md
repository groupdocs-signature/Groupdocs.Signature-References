## SignatureSettings.SaveDocumentOnEmptyDelete property

获取或设置在 Delete 方法没有受影响的签名可删除时是否重新保存源文档。如果此标志设置为 true（默认），即使 Delete 方法没有签名可删除，文档也会连同相应的历史处理日志（日期和操作类型）一起保存。当此标志设置为 false 时，源文档将完全不被修改。

public bool SaveDocumentOnEmptyDelete { get; set; }
