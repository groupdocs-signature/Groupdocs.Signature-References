## LogLevel class

نوع LogLevel يعرض الأعضاء التالية:

### الحقول
| حقل | الوصف |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.logging/loglevel/none/) | لا يتم تسجيل أي شيء. |
| [ERROR](/signature/python-net/groupdocs.signature.logging/loglevel/error/) | الأخطاء: فشل عملية. |
| [WARNING](/signature/python-net/groupdocs.signature.logging/loglevel/warning/) | التحذيرات: نجحت عملية، لكن قد لا يكون نتيجتها ما تتوقعه. |
| [TRACE](/signature/python-net/groupdocs.signature.logging/loglevel/trace/) | التتبع: خطوات عملية، مثل بدايتها ونهايتها. |
| [ALL](/signature/python-net/groupdocs.signature.logging/loglevel/all/) | الأخطاء، التحذيرات والتتبع. هذا هو الإعداد الافتراضي. |
