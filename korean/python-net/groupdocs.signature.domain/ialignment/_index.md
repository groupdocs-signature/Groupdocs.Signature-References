## IAlignment class

문서 페이지에서 서명 영역 정렬을 설명합니다.

IAlignment 유형은 다음 멤버를 노출합니다:

### 속성
| 속성 | 설명 |
| :- | :- |
| [horizontal_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/horizontal_alignment/) | 문서 페이지에서 이미지의 수평 정렬. |
| [margin](/signature/python-net/groupdocs.signature.domain/ialignment/margin/) | 이미지와 문서 가장자리 사이에 기본적으로 지정되는 공간(수평 또는 수직 정렬이 설정된 경우 적용됩니다). |
| [margin_measure_type](/signature/python-net/groupdocs.signature.domain/ialignment/margin_measure_type/) | 여백 측정 유형(픽셀, 퍼센트 또는 밀리미터). |
| [vertical_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/vertical_alignment/) | 문서 페이지에서 이미지의 수직 정렬. |
