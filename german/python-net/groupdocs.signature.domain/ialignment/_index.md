## IAlignment class

Beschreibt die Ausrichtung des Signaturbereichs auf einer Dokumentseite.

Der Typ IAlignment stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [horizontal_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/horizontal_alignment/) | Die horizontale Ausrichtung des Bildes auf einer Dokumentseite. |
| [margin](/signature/python-net/groupdocs.signature.domain/ialignment/margin/) | Der standardmäßig zwischen dem Bild und den Dokumenträndern angegebene Abstand (gilt, wenn horizontale oder vertikale Ausrichtung festgelegt ist). |
| [margin_measure_type](/signature/python-net/groupdocs.signature.domain/ialignment/margin_measure_type/) | Der Messungstyp für den Rand (Pixel, Prozente oder Millimeter). |
| [vertical_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/vertical_alignment/) | Die vertikale Ausrichtung des Bildes auf einer Dokumentseite. |
