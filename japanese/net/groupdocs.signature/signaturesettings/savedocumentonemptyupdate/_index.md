## SignatureSettings.SaveDocumentOnEmptyUpdate property

Update メソッドに更新する署名がない場合に、ソース ドキュメントを再保存するかどうかのフラグを取得または設定します。このフラグが true（デフォルト）に設定されていると、Update メソッドに署名がなくても、ドキュメントは対応する履歴プロセスログ（日付と操作タイプ）と共に保存されます。このフラグが false に設定された場合、ソース ドキュメントはまったく変更されません。

```csharp
public bool SaveDocumentOnEmptyUpdate { get; set; }
```
