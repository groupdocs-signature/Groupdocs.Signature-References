## DigitalSignatureAppearance class

Представляет внешний вид строки подписи для цифровой подписи. На одну цифровую подпись может быть применена только одна строка подписи, и она всегда размещается на первой странице. Эта функция полезна для форматов файлов .docx, .doc, .odt и .xlsx.
