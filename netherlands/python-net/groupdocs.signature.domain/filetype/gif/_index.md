## GIF field

Graphical Interchange Format File (.gif) is een type sterk gecomprimeerde afbeelding. Voor elke afbeelding staat GIF doorgaans tot 8 bits per pixel toe en tot 256 kleuren zijn toegestaan in de afbeelding. Meer informatie over dit bestandsformaat hier.
