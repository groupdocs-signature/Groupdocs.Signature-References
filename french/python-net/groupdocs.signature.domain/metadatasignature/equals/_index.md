## equals {#obj}

Détermine si la signature spécifiée est égale à cette instance.

```python
def equals(self, obj):
    ...
```

| Paramètre | Type | Description |
| :- | :- | :- |
| obj | `Any` | Objet de signature avec lequel comparer. |

**Returns:** bool: True if the passed signature has the same type and all its properties are equal to this instance's properties.
