## SignOptions class

Mewakili opsi tanda tangan.

Pelajari lebih lanjut

- See more simple examples on creating various electronic signatures with GroupDocs.Signature: https://docs.groupdocs.com/signature/net/electronic-signature-types/
- See more advanced examples of settings of various electronic signature with GroupDocs.Signature: https://docs.groupdocs.com/signature/net/signing/

Tipe SignOptions menampilkan anggota-anggota berikut:

### Properti
| Properti | Deskripsi |
| :- | :- |
| [all_pages](/signature/python-net/groupdocs.signature.options/signoptions/all_pages/) | Tanda tangan akan ditempatkan pada semua halaman dokumen. |

| [document_type](/signature/python-net/groupdocs.signature.options/signoptions/document_type/) | Tipe dokumen dari opsi tanda tangan (`DocumentType`). |
| [extensions](/signature/python-net/groupdocs.signature.options/signoptions/extensions/) | Ekstensi tanda tangan. |
| [hash_algorithm](/signature/python-net/groupdocs.signature.options/signoptions/hash_algorithm/) | Algoritma hash yang akan digunakan untuk operasi kriptografi. Didukung secara eksklusif untuk tanda tangan digital dalam file PDF. |
| [page_number](/signature/python-net/groupdocs.signature.options/signoptions/page_number/) | Nomor halaman dokumen untuk penandatanganan. |
| [pages_setup](/signature/python-net/groupdocs.signature.options/signoptions/pages_setup/) | Opsi untuk menentukan halaman yang akan ditandatangani. |
| [signature_type](/signature/python-net/groupdocs.signature.options/signoptions/signature_type/) | Tipe tanda tangan (`SignatureType`). |
| [zorder](/signature/python-net/groupdocs.signature.options/signoptions/zorder/) | Posisi Z-order dari tanda tangan teks, yang menentukan urutan tampilan tanda tangan yang tumpang tindih. |
