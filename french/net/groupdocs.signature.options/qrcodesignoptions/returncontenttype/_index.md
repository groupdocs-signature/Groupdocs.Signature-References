## QrCodeSignOptions.ReturnContentType property

Spécifie le type de fichier du contenu d'image retourné de la signature QR-Code lorsque la propriété ReturnContent est activée. Par défaut, il est réglé sur Null. Cela signifie que le contenu d'image QR-Code est renvoyé dans son format d'origine. Ce format d'image est indiqué à [`Format`](../../../groupdocs.signature.domain/qrcodesignature/format). Les valeurs prises en charge possibles sont : FileType.JPEG, FileType.PNG, FileType.BMP. Si le format fourni n'est pas pris en charge, le contenu d'image QR-Code sera renvoyé au format .png.
