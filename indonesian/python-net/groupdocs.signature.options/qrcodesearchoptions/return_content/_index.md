## return_content property

Flag yang menentukan apakah konten gambar QR‑Code dikembalikan untuk setiap tanda tangan pada halaman dokumen. Ketika diatur ke True, data gambar mentah disimpan dalam properti `content` tanda tangan menggunakan format yang ditentukan oleh `return_content_type`. Dinonaktifkan secara default.
