## BMP field

Bitmap Image File (.bmp) wird verwendet, um Bitmap‑Digitale Bilder zu speichern. Diese Bilder sind unabhängig vom Grafikadapter und werden auch als device independent bitmap (DIB) Dateiformat bezeichnet. Erfahren Sie hier mehr über dieses Dateiformat.
