## FileType.CDR field

CorelDraw Vector Graphic Drawing (.cdr) — векторный файл рисунка, изначально создаваемый в CorelDRAW для хранения закодированных и сжатых цифровых изображений. Такой файл рисунка содержит текст, линии, формы, изображения, цвета и эффекты для векторного представления содержимого изображения. Узнайте больше о этом формате файлов [здесь](https://wiki.fileformat.com/image/cdr).
