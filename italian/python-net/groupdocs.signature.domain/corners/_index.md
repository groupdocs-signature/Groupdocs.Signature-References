## Corners class

Rappresenta gli angoli di un oggetto grafico quadrato.

Il tipo Corners espone i seguenti membri:

### Costruttori
| Costruttore | Descrizione |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.domain/corners/__init__/) | Inizializza una nuova istanza della classe Corners usando valori zero. |
| [__init__](/signature/python-net/groupdocs.signature.domain/corners/__init__/#all) | Inizializza una nuova istanza della classe Corners usando il valore fornito per tutti gli angoli. |
| [__init__](/signature/python-net/groupdocs.signature.domain/corners/__init__/#top_left-top_right-bottom_left-bottom_right) | Inizializza una nuova istanza della classe Corners usando i valori forniti. |

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [clone](/signature/python-net/groupdocs.signature.domain/corners/clone/) | Restituisce una copia dell'oggetto. |
| [equals](/signature/python-net/groupdocs.signature.domain/corners/equals/#obj) | Determina se l'oggetto fornito è uguale all'istanza corrente. |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [all](/signature/python-net/groupdocs.signature.domain/corners/all/) | Il valore per tutti gli angoli. Modificando un singolo angolo (ad es., in alto a destra) questa proprietà viene impostata a 0. |
| [bottom_left](/signature/python-net/groupdocs.signature.domain/corners/bottom_left/) | Il valore dell'angolo in basso a sinistra. |
| [bottom_right](/signature/python-net/groupdocs.signature.domain/corners/bottom_right/) | Il valore dell'angolo in basso a destra. |
| [top_left](/signature/python-net/groupdocs.signature.domain/corners/top_left/) | Il valore dell'angolo in alto a sinistra. |
| [top_right](/signature/python-net/groupdocs.signature.domain/corners/top_right/) | Il valore dell'angolo in alto a destra. |

### Campi
| Campo | Descrizione |
| :- | :- |
