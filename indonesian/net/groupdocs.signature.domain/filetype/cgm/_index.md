## FileType.CGM field

Computer Graphics Metafile (.cgm) adalah format metafile standar internasional yang gratis, platform-independen, untuk menyimpan dan menukar grafik vektor (2D), grafik raster, dan teks. CGM menggunakan pendekatan berorientasi objek dan banyak fungsi untuk produksi gambar. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/page-description-language/cgm).
