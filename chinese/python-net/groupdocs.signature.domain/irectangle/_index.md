## IRectangle class

定义文档页面上签名区域的接口属性。

IRectangle 类型公开以下成员：

### 属性
| 属性 | 描述 |
| :- | :- |
| [height](/signature/python-net/groupdocs.signature.domain/irectangle/height/) | 文档页上签名区域的高度，使用测量单位（像素、百分比或毫米；参见 `MeasureType` SizeMeasureType）。 |
| [left](/signature/python-net/groupdocs.signature.domain/irectangle/left/) | 文档页上签名区域的左侧 X 位置，使用测量单位（像素、百分比或毫米）。参见 `MeasureType` 获取 `LocationMeasureType` 枚举。 |
| [location_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/location_measure_type/) | Left 和 Top 属性的测量类型（像素、百分比或毫米）。 |
| [size_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/size_measure_type/) | Width 和 Height 属性的测量类型（像素、百分比或毫米）。 |
| [stretch](/signature/python-net/groupdocs.signature.domain/irectangle/stretch/) | 文档页上的拉伸模式。 |
| [top](/signature/python-net/groupdocs.signature.domain/irectangle/top/) | 文档页面上签名区域的顶部 Y 位置，使用测量单位（像素、百分比或毫米）。请参阅 `MeasureType` 了解位置测量类型。 |
| [width](/signature/python-net/groupdocs.signature.domain/irectangle/width/) | 文档页面上签名区域的宽度，使用测量值（像素、百分比或毫米）。请参阅 `MeasureType` SizeMeasureType。 |
