## warning {#message}

Записывает предупреждающее сообщение в журнал. Предупреждающие сообщения предоставляют информацию о неожиданных и восстанавливаемых событиях в потоке приложения.

```python
def warning(self, message):
    ...
```

| Параметр | Тип | Описание |
| :- | :- | :- |
| message | `str` | Сообщение warning. |
