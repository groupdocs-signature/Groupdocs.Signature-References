## GifSaveOptions.ColorResolution property

Hämtar eller anger GIF:s färgupplösning.

```csharp
public byte ColorResolution { get; set; }
```

### Anmärkningar

Color Resolution – Antalet bitar per primärfärg som är tillgängliga i originalbilden, minus 1. Detta värde representerar storleken på hela paletten som färgerna i grafiken valdes från, inte antalet färger som faktiskt används i grafiken. Till exempel, om värdet i detta fält är 3, hade originalbildens palett 4 bitar per primärfärg tillgängliga för att skapa bilden. Detta värde bör anges för att indikera rikedomet i originalpaletten, även om inte varje färg från hela paletten är tillgänglig på källmaskinen.
