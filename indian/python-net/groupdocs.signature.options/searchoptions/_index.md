## SearchOptions class

एक दस्तावेज़ से हस्ताक्षर निकालने के विकल्पों का प्रतिनिधित्व करता है।

और अधिक जानें

- See more simple examples on searching for various electronic signatures with GroupDocs.Signature: https://docs.groupdocs.com/signature/net/search-for-electronic-signatures-in-document/
- See more advanced examples of searching for various electronic signature with GroupDocs.Signature: https://docs.groupdocs.com/signature/net/searching/

SearchOptions प्रकार निम्नलिखित सदस्यों को उजागर करता है:

### गुण
| गुण | विवरण |
| :- | :- |
| [all_pages](/signature/python-net/groupdocs.signature.options/searchoptions/all_pages/) | फ़्लैग जो दर्शाता है कि प्रत्येक दस्तावेज़ पृष्ठ पर खोज करनी है या नहीं। डिफ़ॉल्ट रूप से यह मान True है। |
| [page_number](/signature/python-net/groupdocs.signature.options/searchoptions/page_number/) | खोज के लिए दस्तावेज़ पृष्ठ संख्या (वैकल्पिक)। |
| [pages_setup](/signature/python-net/groupdocs.signature.options/searchoptions/pages_setup/) | हस्ताक्षर खोज के लिए पृष्ठ निर्दिष्ट करने के विकल्प। |
| [shape_position](/signature/python-net/groupdocs.signature.options/searchoptions/shape_position/) | फ़्लैग जो दर्शाता है कि दस्तावेज़ लेआउट में आकार की स्थिति लौटानी है या नहीं। यह केवल Word दस्तावेज़ों के लिए उपलब्ध है। |
| [skip_external](/signature/python-net/groupdocs.signature.options/searchoptions/skip_external/) | फ़्लैग जो केवल `IsSignature` के रूप में चिह्नित हस्ताक्षर लौटाता है। डिफ़ॉल्ट रूप से मान `False` है, जिसका अर्थ है कि निर्दिष्ट मानदंडों से मेल खाने वाले सभी हस्ताक्षर लौटाए जाते हैं। |
