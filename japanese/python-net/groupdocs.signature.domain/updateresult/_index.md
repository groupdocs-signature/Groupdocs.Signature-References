## UpdateResult class

ドキュメント内の署名の変更結果を表します。

UpdateResult 型は次のメンバーを公開します:

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/updateresult/destin_document_size/) | 宛先ドキュメントのサイズ。 |
| [failed](/signature/python-net/groupdocs.signature.domain/updateresult/failed/) | 更新されなかった署名の一覧 [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/)。 |
| [processing_time](/signature/python-net/groupdocs.signature.domain/updateresult/processing_time/) | プロセスの実行時間（ミリ秒）。 |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/updateresult/source_document_size/) | ソースドキュメントのサイズ。 |
| [succeeded](/signature/python-net/groupdocs.signature.domain/updateresult/succeeded/) | 正常に変更された署名の一覧 [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/)。 |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/updateresult/total_signatures/) | 合計処理された署名。 |
