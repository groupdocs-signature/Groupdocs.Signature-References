## IRectangle class

दस्तावेज़ पृष्ठ पर सिग्नेचर क्षेत्र के लिए इंटरफ़ेस गुणों को परिभाषित करता है।

IRectangle प्रकार निम्नलिखित सदस्यों को उजागर करता है:

### गुण
| गुण | विवरण |
| :- | :- |
| [height](/signature/python-net/groupdocs.signature.domain/irectangle/height/) | दस्तावेज़ पृष्ठ पर हस्ताक्षर क्षेत्र की ऊँचाई माप इकाइयों (पिक्सेल, प्रतिशत, या मिलीमीटर) में; `MeasureType` SizeMeasureType देखें। |
| [left](/signature/python-net/groupdocs.signature.domain/irectangle/left/) | दस्तावेज़ पृष्ठ पर हस्ताक्षर क्षेत्र की बायाँ X स्थिति माप इकाइयों (पिक्सेल, प्रतिशत, या मिलीमीटर) में। `LocationMeasureType` एन्क्यूमरेशन के लिए `MeasureType` देखें। |
| [location_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/location_measure_type/) | बाएँ और ऊपर गुणों के लिए माप प्रकार (पिक्सेल, प्रतिशत, या मिलीमीटर)। |
| [size_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/size_measure_type/) | चौड़ाई और ऊँचाई गुणों के लिए माप प्रकार (पिक्सेल, प्रतिशत या मिलीमीटर)। |
| [stretch](/signature/python-net/groupdocs.signature.domain/irectangle/stretch/) | दस्तावेज़ पृष्ठ पर स्ट्रेच मोड। |
| [top](/signature/python-net/groupdocs.signature.domain/irectangle/top/) | दस्तावेज़ पृष्ठ पर हस्ताक्षर क्षेत्र की शीर्ष Y स्थिति माप इकाइयों (पिक्सेल, प्रतिशत, या मिलीमीटर) में है। स्थान माप प्रकार के लिए `MeasureType` देखें। |
| [width](/signature/python-net/groupdocs.signature.domain/irectangle/width/) | दस्तावेज़ पृष्ठ पर हस्ताक्षर क्षेत्र की चौड़ाई माप मानों (पिक्सेल, प्रतिशत, या मिलीमीटर) में है। `MeasureType` SizeMeasureType देखें। |
