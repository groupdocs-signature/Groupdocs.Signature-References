## FileType.PPT field

PowerPoint Presentation (.ppt) representa un archivo de PowerPoint que consta de una colección de diapositivas para mostrarse como presentación. Especifica el formato binario de archivo usado por Microsoft PowerPoint 97-2003. Obtén más información sobre este formato de archivo [aquí](https://wiki.fileformat.com/presentation/ppt).
