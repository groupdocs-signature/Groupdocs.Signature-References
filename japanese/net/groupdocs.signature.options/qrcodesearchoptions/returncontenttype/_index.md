## QrCodeSearchOptions.ReturnContentType property

ReturnContent プロパティが有効な場合の QR-Code 署名の返却画像コンテンツのファイルタイプを指定します。デフォルトでは Null に設定されています。これは QR-Code 画像コンテンツを元の形式で返すことを意味します。この画像形式は [`Format`](../../../groupdocs.signature.domain/qrcodesignature/format) で指定されます。サポートされている可能な値は: FileType.JPEG、FileType.PNG、FileType.BMP です。指定された形式がサポートされていない場合、元の .png 形式の QR-Code 画像コンテンツが返されます。

public FileType ReturnContentType { get; set; }
