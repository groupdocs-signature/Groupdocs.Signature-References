## LogLevel class

Het LogLevel-type exposeert de volgende leden:

### Velden
| Veld | Beschrijving |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.logging/loglevel/none/) | Er wordt niets gelogd. |
| [ERROR](/signature/python-net/groupdocs.signature.logging/loglevel/error/) | Fouten: een bewerking is mislukt. |
| [WARNING](/signature/python-net/groupdocs.signature.logging/loglevel/warning/) | Waarschuwingen: een bewerking is geslaagd, maar het resultaat is mogelijk niet wat u verwacht. |
| [TRACE](/signature/python-net/groupdocs.signature.logging/loglevel/trace/) | Traces: de stappen van een bewerking, zoals het begin en het einde. |
| [ALL](/signature/python-net/groupdocs.signature.logging/loglevel/all/) | Fouten, waarschuwingen en traces. Dit is de standaard. |
