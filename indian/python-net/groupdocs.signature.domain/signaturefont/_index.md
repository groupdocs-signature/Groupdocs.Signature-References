## SignatureFont class

SignatureFont क्लास टेक्स्ट हस्ताक्षर के लिए फ़ॉन्ट गुण निर्दिष्ट करती है।

SignatureFont प्रकार निम्नलिखित सदस्यों को उजागर करता है:

### कंस्ट्रक्टर
| कंस्ट्रक्टर | विवरण |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.domain/signaturefont/__init__/) | डिफ़ॉल्ट मानों के साथ एक SignatureFont को प्रारंभ करता है। |

### गुण
| गुण | विवरण |
| :- | :- |
| [bold](/signature/python-net/groupdocs.signature.domain/signaturefont/bold/) | फ़ॉन्ट बोल्ड शैली। |
| [family_name](/signature/python-net/groupdocs.signature.domain/signaturefont/family_name/) | फ़ॉन्ट फ़ैमिली नाम। |
| [italic](/signature/python-net/groupdocs.signature.domain/signaturefont/italic/) | फ़ॉन्ट इटैलिक शैली। |
| [size](/signature/python-net/groupdocs.signature.domain/signaturefont/size/) | फ़ॉन्ट आकार। |
| [strikeout](/signature/python-net/groupdocs.signature.domain/signaturefont/strikeout/) | फ़ॉन्ट स्ट्राइकआउट शैली। |
| [underline](/signature/python-net/groupdocs.signature.domain/signaturefont/underline/) | फ़ॉन्ट की अंडरलाइन शैली। |

### उदाहरण

```python
from groupdocs.signature.domain import SignatureFont

font = SignatureFont()
font.family_name = "Arial"
font.size = 20
font.bold = True
```
