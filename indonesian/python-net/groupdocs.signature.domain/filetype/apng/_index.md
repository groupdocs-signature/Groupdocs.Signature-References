## APNG field

Animated Portable Network Graphics (.png) adalah format file gambar raster yang menggunakan kompresi lossless. Format ini dikembangkan sebagai ekstensi PNG untuk mendukung animasi, berfungsi sebagai alternatif format GIF tanpa batasan hak cipta. Pelajari lebih lanjut tentang format file ini di sini.
