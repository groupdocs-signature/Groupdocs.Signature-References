## QrCodeSignOptions.ReturnContent property

ドキュメントページに配置された署名の QR-Code 画像コンテンツを取得するフラグを取得または設定します。このフラグが true に設定されている場合、QR-Code 署名画像コンテンツは必要な形式 [`ReturnContentType`](../returncontenttype) によって生の画像データを保持します。デフォルトではこのオプションは無効です。

public bool ReturnContent { get; set; }
