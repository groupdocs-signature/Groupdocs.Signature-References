## DicomSaveOptions class

Αναπαριστά τις επιλογές αποθήκευσης για έγγραφα εικόνας DICOM.

Ο τύπος DicomSaveOptions εκθέτει τα ακόλουθα μέλη:

### Κατασκευαστές
| Κατασκευαστής | Περιγραφή |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.options/dicomsaveoptions/__init__/) | Αρχικοποιεί το DicomSaveOptions με προεπιλεγμένες τιμές. |

Η προεπιλεγμένη τιμή είναι True. Δεν υποστηρίζεται για έγγραφα εικόνας. (κληρονομείται από [`SaveOptions`](/signature/python-net/groupdocs.signature.options/saveoptions/)) |
