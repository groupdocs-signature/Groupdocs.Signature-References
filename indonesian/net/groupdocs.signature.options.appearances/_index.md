Namespace menyediakan kelas untuk tampilan tanda tangan tambahan.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [DigitalSignatureAppearance](./digitalsignatureappearance) | Menjelaskan tampilan Garis Tanda Tangan untuk Tanda Tangan Digital. Satu Garis Tanda Tangan hanya dapat diterapkan untuk satu Tanda Tangan Digital. Garis Tanda Tangan selalu berada di halaman pertama. Fitur ini mungkin berguna untuk format file .docx, .doc, .odt, dan .xlsx. |
| [ImageAppearance](./imageappearance) | Menjelaskan fitur tampilan lanjutan untuk Tanda Tangan Gambar. |
| [PdfDigitalSignatureAppearance](./pdfdigitalsignatureappearance) | Menjelaskan tampilan Tanda Tangan Digital pada dokumen PDF. |
| [PdfTextAnnotationAppearance](./pdftextannotationappearance) | Menjelaskan tampilan objek anotasi teks PDF (Judul, Subjek, Konten). |
| [PdfTextStickerAppearance](./pdftextstickerappearance) | Menjelaskan tampilan objek stiker anotasi teks PDF dan jendela pop-up stiker. |
| [SignatureAppearance](./signatureappearance) | Mewakili tampilan tanda tangan - opsi tambahan untuk implementasi alternatif penandatanganan pada halaman dokumen. |
