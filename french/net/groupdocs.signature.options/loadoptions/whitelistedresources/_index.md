## LoadOptions.WhitelistedResources property

Obtient ou définit les fragments d'adresses des ressources externes qui sont chargées même lorsque [`SkipExternalResources`](../skipexternalresources) est vrai. La valeur par défaut est une liste vide.

```csharp
public List<string> WhitelistedResources { get; set; }
```

### Remarques

Une ressource est chargée lorsque son adresse complète contient l'un des fragments. La comparaison ignore la casse, et les fragments vides sont ignorés. Privilégiez les fragments longs tels que "https://cdn.example.com/images/" : un fragment court correspond également à d'autres adresses qui le contiennent par hasard.

Définir cette propriété sur null vide la liste. La liste n'a aucun effet lorsque [`SkipExternalResources`](../skipexternalresources) est false, car alors chaque ressource externe est chargée.
