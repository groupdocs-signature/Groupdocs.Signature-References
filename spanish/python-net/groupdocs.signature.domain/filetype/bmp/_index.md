## BMP field

Bitmap Image File (.bmp) se utiliza para almacenar imágenes digitales bitmap. Estas imágenes son independientes del adaptador gráfico y también se denominan formato de archivo device independent bitmap (DIB). Obtenga más información sobre este formato de archivo aquí.
