## LogLevel enumeration

يحدد أي أنواع الرسائل يتم تمريرها إلى المسجل المحدد في [`SignatureSettings`](../../groupdocs.signature/signaturesettings). القيم هي أعلام ويمكن دمجها، على سبيل المثال `LogLevel.Error | LogLevel.Warning`.

```csharp
[Flags]
public enum LogLevel
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| None | `0` | لم يتم تسجيل أي شيء. |
| Error | `1` | الأخطاء: فشلت عملية. |
| Warning | `2` | التحذيرات: نجحت عملية، لكن نتيجتها قد لا تكون كما تتوقع. |
| Trace | `4` | التتبع: خطوات عملية، مثل بدايتها ونهايتها. |
| All | `7` | الأخطاء، التحذيرات والتتبع. هذا هو الإعداد الافتراضي. |
