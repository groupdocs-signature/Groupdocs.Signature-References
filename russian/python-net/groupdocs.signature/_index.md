| [`ProcessCompleteEventHandler`](/signature/python-net/groupdocs.signature/processcompleteeventhandler/) | Представляет делегат метода, который обрабатывает события завершения процессов подписи, проверки и поиска. |

| [`ProcessProgressEventArgs`](/signature/python-net/groupdocs.signature/processprogresseventargs/) | Предоставляет данные для события OnProgress процессов подписи, проверки и поиска. |
| [`ProcessProgressEventHandler`](/signature/python-net/groupdocs.signature/processprogresseventhandler/) | Представляет делегат метода, который обрабатывает события прогресса для подписи, проверки и поиска. |

| [`Signature`](/signature/python-net/groupdocs.signature/signature/) | Представляет основной класс, который контролирует процесс подписи документа. |
| [`SignatureSettings`](/signature/python-net/groupdocs.signature/signaturesettings/) | Представляет настройки для настройки поведения [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
