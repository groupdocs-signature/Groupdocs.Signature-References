## SignatureSettings.SaveDocumentOnEmptyUpdate property

Получает или задает флаг для повторного сохранения исходного документа, когда метод Update не имеет подписей для обновления. Если этот флаг установлен в true (по умолчанию), документ будет сохраняться с соответствующим журналом процесса истории (датой и типом операции), даже если метод Update не имеет подписей для обновления. Когда этот флаг установлен в false, исходный документ не будет изменён вовсе.

```csharp
public bool SaveDocumentOnEmptyUpdate { get; set; }
```
