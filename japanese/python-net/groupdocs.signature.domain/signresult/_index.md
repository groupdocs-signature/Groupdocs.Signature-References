## SignResult class

新しく作成された署名を含むドキュメントの署名プロセスの結果を表します。

SignResult 型は次のメンバーを公開します:

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/signresult/destin_document_size/) | 宛先ドキュメントのサイズ。 |
| [failed](/signature/python-net/groupdocs.signature.domain/signresult/failed/) | 作成に失敗した署名の一覧です。 |
| [processing_time](/signature/python-net/groupdocs.signature.domain/signresult/processing_time/) | プロセスの実行時間（ミリ秒）。 |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/signresult/source_document_size/) | ソースドキュメントのサイズ。 |
| [succeeded](/signature/python-net/groupdocs.signature.domain/signresult/succeeded/) | 新しく作成された署名の一覧 [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/)。 |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/signresult/total_signatures/) | 合計処理された署名。 |
