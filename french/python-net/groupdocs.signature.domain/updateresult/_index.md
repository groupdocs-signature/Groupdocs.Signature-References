## UpdateResult class

Représente le résultat de la modification des signatures dans le document.

Le type UpdateResult expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/updateresult/destin_document_size/) | La taille du document de destination. |
| [failed](/signature/python-net/groupdocs.signature.domain/updateresult/failed/) | La liste des signatures qui n'ont pas été mises à jour [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [processing_time](/signature/python-net/groupdocs.signature.domain/updateresult/processing_time/) | Le temps d'exécution du processus en millisecondes. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/updateresult/source_document_size/) | La taille du document source. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/updateresult/succeeded/) | La liste des signatures modifiées avec succès [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/updateresult/total_signatures/) | Le total des signatures traitées. |
