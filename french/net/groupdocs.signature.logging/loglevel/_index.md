## LogLevel enumeration

Spécifie quels types de messages sont transmis au logger défini dans [`SignatureSettings`](../../groupdocs.signature/signaturesettings). Les valeurs sont des indicateurs et peuvent être combinées, par exemple `LogLevel.Error | LogLevel.Warning`.

```csharp
[Flags]
public enum LogLevel
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Rien n'est journalisé. |
| Error | `1` | Erreurs : une opération a échoué. |
| Warning | `2` | Avertissements : une opération a réussi, mais son résultat peut ne pas être celui attendu. |
| Trace | `4` | Traces : les étapes d'une opération, comme son début et sa fin. |
| All | `7` | Erreurs, avertissements et traces. C’est la valeur par défaut. |
