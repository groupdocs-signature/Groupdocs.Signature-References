## EMF field

Enhanced Windows Metafile (.emf) representerar grafiska bilder enhetsoberoende. Metafiler för EMF består av variabelängdliga poster i kronologisk ordning som kan återge den lagrade bilden efter parsning på vilken utskriftsenhet som helst. Läs mer om detta filformat här.
