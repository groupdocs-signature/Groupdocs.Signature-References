## HorizontalAlignment class

Ο τύπος HorizontalAlignment εκθέτει τα ακόλουθα μέλη:

### Πεδία
| Πεδίο | Περιγραφή |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/horizontalalignment/none/) | Το αντικείμενο τοποθετείται ρητά, συνήθως χρησιμοποιώντας την ιδιότητα Left του. |
| [LEFT](/signature/python-net/groupdocs.signature.domain/horizontalalignment/left/) | Καθορίζει ότι το αντικείμενο θα ευθυγραμμιστεί αριστερά με τη βάση οριζόντιας ευθυγράμμισης. |
| [CENTER](/signature/python-net/groupdocs.signature.domain/horizontalalignment/center/) | Καθορίζει ότι το αντικείμενο θα κεντραριστεί σε σχέση με τη βάση οριζόντιας ευθυγράμμισης. |
| [RIGHT](/signature/python-net/groupdocs.signature.domain/horizontalalignment/right/) | Καθορίζει ότι το αντικείμενο θα ευθυγραμμιστεί δεξιά με τη βάση οριζόντιας ευθυγράμμισης. |
