## DataMatrixEncodeMode enumeration

Mode pengkodean encoder DataMatrix, default ke Auto.

```csharp
public enum DataMatrixEncodeMode
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Auto | `0` | Secara otomatis memilih mode enkode terbaik untuk enkoding DataMatrix |
| ASCII | `1` | Menkode satu karakter alfanumerik atau dua karakter numerik per byte |
| Full | `6` | Enkode nilai 8 bit |
| Custom | `7` | Enkode dengan enkoding yang ditentukan dalam BarcodeGenerator.Parameters.Barcode.DataMatrix.CodeTextEncoding |
| C40 | `8` | Menggunakan enkoding C40. Mengenkripsi alfanumerik huruf besar, huruf kecil, dan karakter khusus |
| Text | `9` | Menggunakan enkoding Text. Mengenkripsi alfanumerik huruf kecil, huruf besar, dan karakter khusus. |
| EDIFACT | `10` | Menggunakan enkoding EDIFACT. Menggunakan enam bit per karakter, mengenkripsi digit, huruf besar, dan banyak tanda baca, tetapi tidak mendukung huruf kecil. |
| ANSIX12 | `11` | Menggunakan enkoding ANSI X12. |
| ExtendedCodetext | `12` | Mode ExtendedCodetext memungkinkan untuk secara manual mengubah skema enkoding dalam code-text. Format : "\Encodation_scheme_name:text\Encodation_scheme_name:text". Skema enkoding yang diizinkan adalah: EDIFACT, ANSIX12, ASCII, C40, Text, Auto. Contoh code-text yang diperluas: @"\ansix12:ANSIX12TEXT\ascii:backslash must be \\ doubled\edifact:EdifactEncodedText" Semua backslash (\\) harus digandakan dalam teks. |
