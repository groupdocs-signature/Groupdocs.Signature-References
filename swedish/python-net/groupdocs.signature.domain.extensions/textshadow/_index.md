## TextShadow class

Representerar egenskaper för textskugga för textsignaturer.

Resultatet kan variera beroende på signaturtyp och dokumentformat.

TextShadow rekommenderas för användning med `TextAsImage`-signatur för alla stödda dokumenttyper, även med enkla [`TextSignature`](/signature/python-net/groupdocs.signature.domain/textsignature/) och [`TextSignature`](/signature/python-net/groupdocs.signature.domain/textsignature/) som vattenstämpel för kalkylblad (`.xslx`) och presentationer (`.pptx`).

Enkel [`TextSignature`](/signature/python-net/groupdocs.signature.domain/textsignature/) för Word-dokument (`.docx`) rekommenderas också, men har begränsad funktionalitet.
