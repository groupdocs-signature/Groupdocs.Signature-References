## PDF field

Portable Document Format File (.pdf) is een type document dat in de jaren 1990 door Adobe is gemaakt. Het doel van dit bestandsformaat was het introduceren van een standaard voor de weergave van documenten en ander referentiemateriaal in een formaat dat onafhankelijk is van toepassingssoftware, hardware en besturingssysteem.
