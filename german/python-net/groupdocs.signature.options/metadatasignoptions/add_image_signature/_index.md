## add_image_signature {#id-value}

Erstellt eine neue ImageMetadataSignature mit den angegebenen Argumenten und fügt sie zur Sammlung hinzu.

```python
def add_image_signature(self, id, value):
    ...
```

| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| id | `System.UInt16` | Eindeutiger Bezeichner für den Namen der Image Metadata Signature. Siehe Referenzen für Exif‑Tag‑Spezifikationen für mögliche ID‑Werte. |
| value | `Any` | Metadatenwert. |

**Returns:** ImageMetadataSignature: The newly created signature that was added to the MetadataSignatures collection.
