## PPTX field

PowerPoint Open XML Presentation (.pptx) sont des fichiers de présentation créés avec l'application populaire Microsoft PowerPoint. Contrairement à la version précédente du format de fichier de présentation PPT qui était binaire, le format PPTX est basé sur le format de fichier de présentation Open XML de Microsoft PowerPoint. En savoir plus sur ce format de fichier ici.
