## EMF field

Enhanced Windows Metafile (.emf)은 그래픽 이미지를 장치 독립적으로 나타냅니다. EMF 메타파일은 순차적인 가변 길이 레코드로 구성되어 파싱 후 어떤 출력 장치에서도 저장된 이미지를 렌더링할 수 있습니다. 여기에서 이 파일 형식에 대해 자세히 알아보세요.
