## DEFAULT_APPEARANCE field

Haalt de standaardweergave voor de sticker op. Deze eigenschappen worden als standaard toegepast als de eigenschap Options.SignatureAppearance niet is opgegeven. De eigenschappen kunnen door de gebruiker op elk moment worden gewijzigd.
