## IAlignment class

Describe la alineación del área de firma en una página del documento.

El tipo IAlignment expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [horizontal_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/horizontal_alignment/) | La alineación horizontal de la imagen en una página de documento. |
| [margin](/signature/python-net/groupdocs.signature.domain/ialignment/margin/) | El espacio que se especifica por defecto entre la imagen y los bordes del documento (se aplica cuando la alineación horizontal o vertical está establecida). |
| [margin_measure_type](/signature/python-net/groupdocs.signature.domain/ialignment/margin_measure_type/) | El tipo de medida del margen (píxeles, porcentajes o milímetros). |
| [vertical_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/vertical_alignment/) | La alineación vertical de la imagen en una página de documento. |
