## Permissions enumeration

指定 PDF 文档的可配置权限，例如打印、内容修改和数据提取。这些设置仅适用于 PDF 格式，并控制用户的访问和交互功能。

```csharp
[Flags]
public enum Permissions
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| None | `0` | 允许所有操作，包括打印、修改和数据提取。 |
| DenyPrinting | `1` | 禁止文档的打印。 |
| DenyModification | `2` | 禁止内容修改，包括填写表单以及添加或修改注释。 |
| DenyDataExtraction | `4` | 禁止从文档中提取文本和图形。 |
| DenyAll | `7` | 禁止所有操作，包括打印、修改和数据提取。 |
