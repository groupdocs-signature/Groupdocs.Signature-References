## Propriétés

| Nom | Description |
| --- | --- |
| [AllPages](../../groupdocs.signature.options/searchoptions/allpages) { get; set; } | Indicateur pour rechercher sur chaque page du document. Par défaut, cette valeur est définie sur true. |
| [MaxContentSize](../../groupdocs.signature.options/imagesearchoptions/maxcontentsize) { get; set; } | Pour une valeur non nulle, cet indicateur spécifie la taille maximale des images pour le critère de recherche. Par défaut, cet indicateur est fixé à zéro et n'affecte pas le résultat de la recherche. |
| [MinContentSize](../../groupdocs.signature.options/imagesearchoptions/mincontentsize) { get; set; } | Pour une valeur non nulle, cet indicateur spécifie la taille minimale des images pour le critère de recherche. Par défaut, cet indicateur est fixé à zéro et n'affecte pas le résultat de la recherche. |
| [PageNumber](../../groupdocs.signature.options/searchoptions/pagenumber) { get; set; } | Obtient ou définit le numéro de page du document pour la recherche. La valeur est facultative. |
| [PagesSetup](../../groupdocs.signature.options/searchoptions/pagessetup) { get; set; } | Options pour spécifier les pages pour la recherche de signature. |
| [ReturnContent](../../groupdocs.signature.options/imagesearchoptions/returncontent) { get; set; } | Obtient ou définit l'indicateur pour récupérer le contenu image de la signature sur la page du document. Si cet indicateur est défini sur true, le contenu image de la signature conservera les données d'image brutes selon le format requis [`ReturnContentType`](./returncontenttype). Par défaut, cette option est désactivée. |
| [ReturnContentType](../../groupdocs.signature.options/imagesearchoptions/returncontenttype) { get; set; } | Spécifie le type de fichier du contenu retourné de la signature image lorsque la propriété ReturnContent est activée. Par défaut, il est défini sur Null. Cela signifie que le contenu image sera retourné dans son format original. Ce format d'image est spécifié à [`Format`](../../groupdocs.signature.domain/imagesignature/format). Les valeurs prises en charge possibles sont : FileType.JPEG, FileType.PNG, FileType.BMP. Si le format fourni n'est pas pris en charge, le contenu image sera retourné dans son format original. |
| [ShapePosition](../../groupdocs.signature.options/searchoptions/shapeposition) { get; set; } | Indicateur pour retourner la position de forme spécifiée dans la mise en page du document. Disponible uniquement pour les documents Word. |
| [SkipExternal](../../groupdocs.signature.options/searchoptions/skipexternal) { get; set; } | Indicateur pour ne retourner que les signatures marquées comme IsSignature. Par défaut, la valeur est false, ce qui indique de retourner toutes les signatures qui correspondent aux critères spécifiés. |
