```
public final class WordProcessingSaveFileFormat
```

WordProcessing ドキュメントのさまざまな保存ファイル形式を定義します。

## フィールド

| フィールド | 説明 |
| --- | --- |
|  | [Default](#Default) | ファイル形式は変更されません。 |
|
|  | [Doc](#Doc) | 文書を Microsoft Word 97-2003 文書として保存します。 |
|
|  | [Dot](#Dot) | 文書を Microsoft Word 97-2003 テンプレートとして保存します。 |
|
|  | [Docx](#Docx) | 文書を Microsoft Word OpenXML 文書として保存します。 |
|
|  | [Docm](#Docm) | 文書を Microsoft Word OpenXML マクロ有効文書として保存します。 |
|
|  | [Dotx](#Dotx) | 文書を Microsoft Word OpenXML テンプレートとして保存します。 |
|
|  | [Dotm](#Dotm) | 文書を Microsoft Word OpenXML マクロ有効テンプレートとして保存します。 |
|
|  | [FlatOpc](#FlatOpc) | 文書を Office Open XML WordprocessingML として保存します |
ZIP パッケージの代わりにフラット XML ファイルに格納されます。
|
|  | [FlatOpcMacroEnabled](#FlatOpcMacroEnabled) | 文書を Office Open XML WordprocessingML として保存します |
マクロ有効文書が ZIP パッケージの代わりにフラット XML ファイルに格納されます。
|
|  | [FlatOpcTemplate](#FlatOpcTemplate) | 文書を Office Open XML WordprocessingML として保存します |
テンプレート（マクロなし）が ZIP パッケージの代わりにフラット XML ファイルに格納されます。
|
|  | [FlatOpcTemplateMacroEnabled](#FlatOpcTemplateMacroEnabled) | 文書を Office Open XML WordprocessingML として保存します |
マクロ有効テンプレートが ZIP パッケージの代わりにフラット XML ファイルに格納されます。
|
|  | [Rtf](#Rtf) | ドキュメントをRTF形式で保存します。 |
|
|  | [WordML](#WordML) | ドキュメントをMicrosoft Word 2003 WordprocessingML形式で保存します。 |
|
|  | [Pdf](#Pdf) | ドキュメントを PDF（Adobe Portable Document）形式として保存します。 |
|
|  | [Xps](#Xps) | ドキュメントを XPS（XML Paper Specification）形式で保存します。 |
|
|  | [Ps](#Ps) | ドキュメントをPS（PostScript）形式で保存します。 |
|
|  | [Mhtml](#Mhtml) | ドキュメントをMHTML（Webアーカイブ）形式で保存します。 |
|
|  | [Epub](#Epub) | ドキュメントをIDPF EPUB形式で保存します。 |
|
|  | [Odt](#Odt) | ドキュメントをOpen Office文書として保存します。 |
|
|  | [Ott](#Ott) | ドキュメントをOpen Office文書テンプレートとして保存します。 |
|
|  | [Text](#Text) | ドキュメントをプレーンテキスト形式で保存します。 |
|
|  | [Tiff](#Tiff) | ドキュメントのページまたは複数ページをレンダリングし、単一または複数ページの TIFF ファイルに保存します。 |
|
|  | [Png](#Png) | ドキュメントのページをレンダリングし、PNGファイルとして保存します。 |
|
|  | [Bmp](#Bmp) | ドキュメントのページをレンダリングし、BMPファイルとして保存します。 |
|
|  | [Emf](#Emf) | ドキュメントのページをレンダリングし、ベクターEMF（Enhanced Meta File）ファイルとして保存します。 |
|
|  | [Jpeg](#Jpeg) | ドキュメントのページをレンダリングし、JPEGファイルとして保存します。 |
|
|  | [Azw3](#Azw3) | ドキュメントのページをレンダリングし、Azw3ファイルとして保存します。 |
|
