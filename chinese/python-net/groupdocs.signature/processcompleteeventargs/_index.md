## ProcessCompleteEventArgs class

提供签名、验证和搜索过程完成事件的数据。

ProcessCompleteEventArgs 类型公开以下成员：

### 属性
| 属性 | 描述 |
| :- | :- |
| [canceled](/signature/python-net/groupdocs.signature/processcompleteeventargs/canceled/) | 进程已取消。 |
| [completed](/signature/python-net/groupdocs.signature/processcompleteeventargs/completed/) | 进程完成的时间标记。 |
| [ticks](/signature/python-net/groupdocs.signature/processcompleteeventargs/ticks/) | 自进程 Start 事件以来耗费的毫秒时间。 |
| [total_signatures](/signature/python-net/groupdocs.signature/processcompleteeventargs/total_signatures/) | 已处理签名的总数量。 |
| [status](/signature/python-net/groupdocs.signature/processeventargs/status/) | 当前进程状态。（继承自 [`ProcessEventArgs`](/signature/python-net/groupdocs.signature/processeventargs/)） |
