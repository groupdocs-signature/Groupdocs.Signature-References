## content property

The barcode binary data image content in the format specified by [`BarcodeSignature.format`](/signature/python-net/groupdocs.signature.domain/barcodesignature/format/).

By default this property is not set. Enable it by setting [`BarcodeSearchOptions.return_content`](/signature/python-net/groupdocs.signature.options/barcodesearchoptions/return_content/) to True.
