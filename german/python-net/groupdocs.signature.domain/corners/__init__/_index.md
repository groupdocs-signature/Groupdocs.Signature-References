
## __init__ {#all}

Initialisiert eine neue Instanz der Corners Klasse mit dem angegebenen Wert für alle Ecken.

```python
def __init__(self, all):
    ...
```

| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| all | `float` | Der Wert, der für das Padding aller Ecken verwendet wird. |

## __init__ {#top_left-top_right-bottom_left-bottom_right}

Initialisiert eine neue Instanz der Corners Klasse mit den angegebenen Werten.

```python
def __init__(self, top_left, top_right, bottom_left, bottom_right):
    ...
```

| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| top_left | `float` | Wert der oberen linken Ecke. |
| top_right | `float` | Wert der oberen rechten Ecke. |
| bottom_left | `float` | Wert der unteren linken Ecke. |
| bottom_right | `float` | Wert der unteren rechten Ecke. |
