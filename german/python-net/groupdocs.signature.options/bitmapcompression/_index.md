## BitmapCompression class

Der BitmapCompression‑Typ stellt die folgenden Mitglieder bereit:

### Felder
| Feld | Beschreibung |
| :- | :- |
| [RGB](/signature/python-net/groupdocs.signature.options/bitmapcompression/rgb/) | Keine Kompression. |
| [RLE8](/signature/python-net/groupdocs.signature.options/bitmapcompression/rle8/) | RLE 8‑Bit/Pixel‑Kompression. Kann nur mit 8‑Bit/Pixel‑Bitmaps verwendet werden. |
| [RLE4](/signature/python-net/groupdocs.signature.options/bitmapcompression/rle4/) | RLE 4‑Bit/Pixel‑Kompression. Kann nur mit 4‑Bit/Pixel‑Bitmaps verwendet werden. |
| [BITFIELDS](/signature/python-net/groupdocs.signature.options/bitmapcompression/bitfields/) | Bitfelder. Kann nur mit 16‑ und 32‑Bit/Pixel‑Bitmaps verwendet werden. |
| [JPEG](/signature/python-net/groupdocs.signature.options/bitmapcompression/jpeg/) | JPEG‑Kompression. Das Bitmap enthält ein JPEG‑Bild. |
| [PNG](/signature/python-net/groupdocs.signature.options/bitmapcompression/png/) | PNG‑Kompression. Das Bitmap enthält ein PNG‑Bild. |
