## DigitalSignatureAppearance class

Menjelaskan tampilan Garis Tanda Tangan untuk Tanda Tangan Digital. Satu Garis Tanda Tangan hanya dapat diterapkan untuk satu Tanda Tangan Digital. Garis Tanda Tangan selalu berada di halaman pertama. Fitur ini mungkin berguna untuk format file .docx, .doc, .odt, dan .xlsx.
