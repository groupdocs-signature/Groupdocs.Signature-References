## BarcodeSignOptions.ReturnContentType property

Menentukan jenis file dari konten gambar yang dikembalikan dari tanda tangan Barcode ketika properti ReturnContent diaktifkan. Secara default diatur ke Null. Itu berarti mengembalikan konten gambar Barcode dalam format asli. Format gambar ini ditentukan di [`Format`](../../../groupdocs.signature.domain/barcodesignature/format). Nilai yang didukung antara lain: FileType.JPEG, FileType.PNG, FileType.BMP. Jika format yang diberikan tidak didukung, maka konten gambar Barcode dalam format .png akan dikembalikan.

public FileType ReturnContentType { get; set; }
