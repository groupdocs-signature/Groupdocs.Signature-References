## LoadOptions.WhitelistedResources property

获取或设置外部资源地址的片段，即使在 [`SkipExternalResources`](../skipexternalresources) 为 true 时也会加载这些资源。默认值为空列表。

```csharp
public List<string> WhitelistedResources { get; set; }
```

### 备注

当资源的完整地址包含其中一个片段时即会加载该资源。比较时忽略大小写，空片段会被忽略。建议使用较长的片段，例如 "https://cdn.example.com/images/"：较短的片段也会匹配其他恰好包含该片段的地址。

将此属性设置为 null 会清空列表。当 [`SkipExternalResources`](../skipexternalresources) 为 false 时，该列表不起作用，因为此时会加载所有外部资源。
