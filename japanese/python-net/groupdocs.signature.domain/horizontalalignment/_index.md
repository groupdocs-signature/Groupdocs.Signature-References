## HorizontalAlignment class

HorizontalAlignment 型は次のメンバーを公開します:

### フィールド
| フィールド | 説明 |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/horizontalalignment/none/) | オブジェクトは明示的に配置され、通常は Left プロパティを使用します。 |
| [LEFT](/signature/python-net/groupdocs.signature.domain/horizontalalignment/left/) | オブジェクトが水平揃え基準の左側に揃えられることを指定します。 |
| [CENTER](/signature/python-net/groupdocs.signature.domain/horizontalalignment/center/) | オブジェクトが水平揃え基準に対して中央に配置されることを指定します。 |
| [RIGHT](/signature/python-net/groupdocs.signature.domain/horizontalalignment/right/) | オブジェクトが水平揃え基準の右側に揃えられることを指定します。 |
