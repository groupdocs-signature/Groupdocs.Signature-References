## GIF field

Il Graphical Interchange Format File (.gif) è un tipo di immagine altamente compressa. Per ogni immagine GIF tipicamente consente fino a 8 bit per pixel e sono consentiti fino a 256 colori nell'intera immagine. Scopri di più su questo formato file qui.
