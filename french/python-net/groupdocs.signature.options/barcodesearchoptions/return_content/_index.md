## return_content property

Le drapeau indiquant s'il faut récupérer le contenu image du code-barres d'une signature sur une page du document.

Si la valeur est `True`, le contenu image de la signature code-barres est conservé sous forme de données d'image brutes dans le format spécifié par `return_content_type`. Désactivé par défaut.
