## PngFilterType class

Le type PngFilterType expose les membres suivants :

### Champs
| Champ | Description |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.options/pngfiltertype/none/) | Le filtre null signifie aucune filtration des lignes de données d'image. |
| [SUB](/signature/python-net/groupdocs.signature.options/pngfiltertype/sub/) | Le filtre sub signifie qu'un filtrage soustractif sera appliqué aux données d'image. |
| [UP](/signature/python-net/groupdocs.signature.options/pngfiltertype/up/) | Le filtre up signifie qu'un filtre de soustraction ligne par ligne sera appliqué. |
| [AVG](/signature/python-net/groupdocs.signature.options/pngfiltertype/avg/) | Le filtre avg signifie qu'un filtre moyen sera appliqué aux données d'image. |
| [PAETH](/signature/python-net/groupdocs.signature.options/pngfiltertype/paeth/) | Le filtre prédicteur de chemin. |
| [ADAPTIVE](/signature/python-net/groupdocs.signature.options/pngfiltertype/adaptive/) | Le filtrage adaptatif signifie que le processus d'enregistrement choisira le filtre le plus approprié pour chaque ligne de données. Meilleure compression, temps d'exécution le plus lent. |
