## SignatureSettings.SaveDocumentOnEmptyDelete property

يحصل أو يضبط علامة لإعادة حفظ المستند الأصلي عندما لا يحتوي أسلوب Delete على توقيعات لتُزيل. إذا تم تعيين هذه العلامة إلى true (افتراضيًا) سيُحفظ المستند مع سجل عملية التاريخ ونوع العملية المقابل حتى وإن لم يكن هناك توقيعات لإزالتها. عندما تُضبط هذه العلامة إلى false لن يتم تعديل المستند الأصلي مطلقًا.

public bool SaveDocumentOnEmptyDelete { get; set; }
