## TGA field

Truevision TGA (.tga), noto anche come TARGA, è un formato file immagine raster sviluppato da Truevision Inc. Supporta varie profondità di colore e compressione RLE opzionale. I file TGA sono comunemente usati nei videogiochi, nelle pipeline di animazione e nelle applicazioni grafiche per il rendering di immagini ad alta qualità con supporto opzionale del canale alfa. Scopri di più su questo formato file qui.
