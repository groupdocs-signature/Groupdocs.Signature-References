## TIFF field

Tagged Image File Format (.tiff) mewakili gambar raster yang dimaksudkan untuk penggunaan pada berbagai perangkat yang mematuhi standar format file ini. Format ini dapat menggambarkan data gambar biner, skala abu-abu, palet-warna, dan warna penuh dalam beberapa ruang warna. Pelajari lebih lanjut tentang format file ini di sini.
