## SignResult class

Representerar resultatet av signeringsprocessen för ett dokument med nyss skapade signaturer.

SignResult-typen exponerar följande medlemmar:

### Egenskaper
| Egenskap | Beskrivning |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/signresult/destin_document_size/) | Destinationsdokumentets storlek. |
| [failed](/signature/python-net/groupdocs.signature.domain/signresult/failed/) | Listan över signaturer som misslyckades att skapas. |
| [processing_time](/signature/python-net/groupdocs.signature.domain/signresult/processing_time/) | Processens verkställningstid i millisekunder. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/signresult/source_document_size/) | Källdokumentets storlek. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/signresult/succeeded/) | Listan över nyss skapade signaturer [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/signresult/total_signatures/) | Totalt antal bearbetade signaturer. |
