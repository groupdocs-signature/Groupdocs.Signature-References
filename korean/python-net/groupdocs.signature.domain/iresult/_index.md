## IResult class

서명 프로세스 결과에 대한 공통 인터페이스를 나타냅니다.

IResult 유형은 다음 멤버를 노출합니다:

### 속성
| 속성 | 설명 |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/iresult/destin_document_size/) | 대상 문서 크기. |
| [failed](/signature/python-net/groupdocs.signature.domain/iresult/failed/) | 처리되지 않은 서명 목록. |
| [processing_time](/signature/python-net/groupdocs.signature.domain/iresult/processing_time/) | 프로세스 실행 시간(밀리초). |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/iresult/source_document_size/) | 원본 문서 크기. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/iresult/succeeded/) | 성공적으로 처리된 서명 목록 [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/iresult/total_signatures/) | 전체 처리된 서명 수. |
