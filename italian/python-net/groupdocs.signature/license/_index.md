## License class

Gestisce la licenza di GroupDocs.Signature.

Le build con licenza sbloccano l'intero set di funzionalità del wrapper a
runtime. Le build senza licenza vengono eseguite in modalità di valutazione con la stessa API
interfaccia ma con limiti sulla dimensione dell'output e contenuti con filigrana.

Il tipo License espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [set_license](/signature/python-net/groupdocs.signature/license/set_license/#license_source) | Applica una licenza al processo corrente. |
