## DOCX field

Microsoft Word Open XML 文档 (.docx) 是一种广为人知的 Microsoft Word 文档格式。自 2007 年 Microsoft Office 2007 发布起，引入了此新文档格式，其结构从纯二进制改为 XML 与二进制文件的组合。了解更多关于此文件格式的信息。
