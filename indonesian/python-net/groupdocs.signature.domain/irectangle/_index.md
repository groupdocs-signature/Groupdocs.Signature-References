## IRectangle class

Mendefinisikan properti antarmuka untuk area tanda tangan pada halaman dokumen.

Tipe IRectangle menampilkan anggota-anggota berikut:

### Properti
| Properti | Deskripsi |
| :- | :- |
| [height](/signature/python-net/groupdocs.signature.domain/irectangle/height/) | Tinggi area tanda tangan pada halaman dokumen dalam satuan ukuran (piksel, persen, atau milimeter; lihat `MeasureType` SizeMeasureType). |
| [left](/signature/python-net/groupdocs.signature.domain/irectangle/left/) | Posisi X kiri area tanda tangan pada halaman dokumen dalam satuan ukuran (piksel, persen, atau milimeter). Lihat `MeasureType` untuk enumerasi `LocationMeasureType`. |
| [location_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/location_measure_type/) | Jenis pengukuran (piksel, persen, atau milimeter) untuk properti Left dan Top. |
| [size_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/size_measure_type/) | Jenis pengukuran (piksel, persen, atau milimeter) untuk properti Width dan Height. |
| [stretch](/signature/python-net/groupdocs.signature.domain/irectangle/stretch/) | Mode peregangan pada halaman dokumen. |
| [top](/signature/python-net/groupdocs.signature.domain/irectangle/top/) | Posisi Y atas area tanda tangan pada halaman dokumen dalam satuan ukuran (piksel, persentase, atau milimeter). Lihat `MeasureType` untuk tipe ukuran lokasi. |
| [width](/signature/python-net/groupdocs.signature.domain/irectangle/width/) | Lebar area tanda tangan pada halaman dokumen dalam nilai ukuran (piksel, persentase, atau milimeter). Lihat `MeasureType` SizeMeasureType. |
