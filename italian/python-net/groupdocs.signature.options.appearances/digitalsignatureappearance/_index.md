## DigitalSignatureAppearance class

Rappresenta l'aspetto di una linea di firma per una firma digitale. È possibile applicare una sola linea di firma a una singola firma digitale, ed è sempre posizionata nella prima pagina. Questa funzionalità è utile per i formati di file .docx, .doc, .odt e .xlsx.

Il tipo DigitalSignatureAppearance espone i seguenti membri:

### Costruttori
| Costruttore | Descrizione |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.options.appearances/digitalsignatureappearance/__init__/) | Inizializza un oggetto di aspetto della linea di firma. |
| [__init__](/signature/python-net/groupdocs.signature.options.appearances/digitalsignatureappearance/__init__/#signer-title-email) | Inizializza un aspetto della linea di firma con il firmatario, il titolo e l'email specificati. |

| :- | :- |
