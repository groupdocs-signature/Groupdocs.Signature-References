## APNG field

Animated Portable Network Graphics (.png) είναι μια μορφή αρχείου ραστερικής εικόνας που χρησιμοποιεί ασυμπίεστη συμπίεση. Αναπτύχθηκε ως επέκταση του PNG για υποστήριξη κίνησης, λειτουργώντας ως εναλλακτική λύση στη μορφή GIF χωρίς περιορισμούς πνευματικών δικαιωμάτων. Μάθετε περισσότερα για αυτή τη μορφή αρχείου εδώ.
