## return_content property

Flaggan som indikerar om streckkodbildens innehåll för en signatur placerad på en dokumentsida ska hämtas.

När den är satt till True behålls streckkodssignaturens bildinnehåll som rå bilddata i det format som anges av `return_content_type`. Som standard är detta alternativ inaktiverat (False).
