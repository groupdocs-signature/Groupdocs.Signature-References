## TextSignature constructor

Inicializa el objeto TextSignature con el identificador de firma que se obtuvo después del proceso de búsqueda. Este identificador único se usa para encontrar propiedades adicionales de esta firma en la capa de información de firmas del documento.

public TextSignature(string signatureId)
