## GifSaveOptions.PixelAspectRatio property

获取或设置 GIF 像素宽高比。

```csharp
public byte PixelAspectRatio { get; set; }
```

### 备注

Pixel Aspect Ratio - 用于计算原始图像中像素宽高比近似值的因素。如果该字段的值不为 0，则根据公式计算此宽高比近似值：Aspect Ratio = (Pixel Aspect Ratio + 15) / 64。Pixel Aspect Ratio 定义为像素宽度除以高度的商。此字段的取值范围允许以 1/64 为增量指定最宽像素 4:1 到最高像素 1:4。取值：0 - 未提供宽高比信息。1..255 - 用于计算的值。
