## IRectangle class

문서 페이지의 서명 영역에 대한 인터페이스 속성을 정의합니다.

IRectangle 유형은 다음 멤버를 노출합니다:

### 속성
| 속성 | 설명 |
| :- | :- |
| [height](/signature/python-net/groupdocs.signature.domain/irectangle/height/) | 문서 페이지에서 서명 영역의 높이(측정 단위: 픽셀, 퍼센트 또는 밀리미터; `MeasureType` SizeMeasureType을 참조). |
| [left](/signature/python-net/groupdocs.signature.domain/irectangle/left/) | 문서 페이지에서 서명 영역의 왼쪽 X 위치(측정 단위: 픽셀, 퍼센트 또는 밀리미터). `LocationMeasureType` 열거형은 `MeasureType`을 참조하세요. |
| [location_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/location_measure_type/) | Left 및 Top 속성의 측정 유형(픽셀, 퍼센트 또는 밀리미터). |
| [size_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/size_measure_type/) | Width 및 Height 속성의 측정 유형(픽셀, 퍼센트 또는 밀리미터). |
| [stretch](/signature/python-net/groupdocs.signature.domain/irectangle/stretch/) | 문서 페이지의 스트레치 모드. |
| [top](/signature/python-net/groupdocs.signature.domain/irectangle/top/) | 문서 페이지에서 서명 영역의 상단 Y 위치를 측정 단위(픽셀, 퍼센트 또는 밀리미터)로 나타냅니다. 위치 측정 유형에 대해서는 `MeasureType`을 참조하십시오. |
| [width](/signature/python-net/groupdocs.signature.domain/irectangle/width/) | 문서 페이지에서 서명 영역의 너비를 측정 값(픽셀, 퍼센트 또는 밀리미터)으로 나타냅니다. `MeasureType` SizeMeasureType을 참조하십시오. |
