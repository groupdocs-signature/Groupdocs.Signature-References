Представляет режим растягивания области подписи на странице документа.

## Поля

| Поле | Описание |
| --- | --- |
|  | [None](#None) | Значение по умолчанию. |
|
|  | [PageWidth](#PageWidth) | Растянуть область подписи вдоль ширины страницы. |
|
|  | [PageHeight](#PageHeight) | Растянуть область подписи вдоль высоты страницы. |
|
|  | [PageArea](#PageArea) | Растянуть область подписи вдоль высоты и ширины страницы. |
|
### None {#None}
```
public static final int None
```


Значение по умолчанию. Режим растяжения не будет применён.


### PageWidth {#PageWidth}
```
public static final int PageWidth
```


Растянуть область подписи вдоль ширины страницы. Свойство Margin будет использовано для применения необходимых значений смещения


### PageHeight {#PageHeight}
```
public static final int PageHeight
```


Растянуть область подписи вдоль высоты страницы. Свойство Margin будет использовано для применения необходимых значений смещения.


### PageArea {#PageArea}
```
public static final int PageArea
```


Растянуть область подписи по высоте и ширине страницы. Свойство Margin будет использовано для применения требуемых значений смещения.
