## IDocumentInfo class

Свойства описания документа.

Тип IDocumentInfo раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [barcode_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/barcode_signatures/) | Коллекция штрихкодов подписи документа, добавленных или обновлённых методами [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [digital_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/digital_signatures/) | Коллекция цифровых подписей документа, добавленных или обновлённых методами [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [documents](/signature/python-net/groupdocs.signature.domain/idocumentinfo/documents/) | Коллекция всех существующих документов внутри архивных файлов. Это свойство поддерживается только для типов архивных документов. |
| [file_type](/signature/python-net/groupdocs.signature.domain/idocumentinfo/file_type/) | Тип формата файла. |
| [form_field_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/form_field_signatures/) | Коллекция подписей полей формы документа, добавленных или обновлённых методами [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [form_fields](/signature/python-net/groupdocs.signature.domain/idocumentinfo/form_fields/) | Коллекция всех существующих поддерживаемых полей формы в документе. Это свойство поддерживается только для типов документов PDF и Word Processing. |
| [image_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/image_signatures/) | Коллекция подписей изображений документа, добавленных или обновлённых методами [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [max_page_height](/signature/python-net/groupdocs.signature.domain/idocumentinfo/max_page_height/) | Максимальная высота страницы. |
| [metadata_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/metadata_signatures/) | Коллекция подписей метаданных документа. |
| [page_count](/signature/python-net/groupdocs.signature.domain/idocumentinfo/page_count/) | Количество страниц документа. |
| [pages](/signature/python-net/groupdocs.signature.domain/idocumentinfo/pages/) | Коллекция описаний страниц документа. |
| [process_logs](/signature/python-net/groupdocs.signature.domain/idocumentinfo/process_logs/) | Коллекция журналов процессов истории документа. |
| [qr_code_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/qr_code_signatures/) | Коллекция QR‑кодов подписей документа, добавленных или обновлённых методами [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/signatures/) | Коллекция всех типов подписей, присутствующих в документе в виде объектов [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [size](/signature/python-net/groupdocs.signature.domain/idocumentinfo/size/) | Размер документа в байтах. |
| [text_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/text_signatures/) | Коллекция текстовых подписей документа, добавленных или обновлённых методами [`Signature`](/signature/python-net/groupdocs.signature/signature/). |
| [width_for_max_height](/signature/python-net/groupdocs.signature.domain/idocumentinfo/width_for_max_height/) | Ширина для максимальной высоты страницы. |
