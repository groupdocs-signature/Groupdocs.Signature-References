## TextShadow class

Representa las propiedades de sombra de texto para firmas de texto.

El resultado puede variar dependiendo del tipo de firma y del formato del documento.

Se recomienda TextShadow para su uso con la firma `TextAsImage` para todos los tipos de documentos compatibles, también con simples [`TextSignature`](/signature/python-net/groupdocs.signature.domain/textsignature/) y [`TextSignature`](/signature/python-net/groupdocs.signature.domain/textsignature/) como marca de agua para hojas de cálculo (`.xslx`) y presentaciones (`.pptx`).

También se recomienda la simple [`TextSignature`](/signature/python-net/groupdocs.signature.domain/textsignature/) para documentos Word (`.docx`), pero tiene funcionalidad limitada.

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [angle](/signature/python-net/groupdocs.signature.domain.extensions/textshadow/angle/) | El ángulo para colocar la sombra respecto al texto. El valor predeterminado es 0. |
