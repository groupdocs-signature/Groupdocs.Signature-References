## return_content property

Flaggan som bestämmer om QR‑Code‑bildinnehåll returneras för varje signatur på en dokumentsida. När den är satt till True behålls råbilddata i signaturens `content`‑egenskap med det format som anges av `return_content_type`. Inaktiverad som standard.
