## PNG field

Portable Network Graphic (.png) — это тип растрового формата изображения, использующий без потерь сжатие. Этот формат был создан как замена Graphics Interchange Format (GIF) и не имеет ограничений по авторским правам. Узнайте больше об этом формате файла здесь.
