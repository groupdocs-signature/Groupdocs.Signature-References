## DigitalSignatureAppearance class

Αντιπροσωπεύει την εμφάνιση μιας γραμμής υπογραφής για ψηφιακή υπογραφή. Μπορεί να εφαρμοστεί μόνο μία γραμμή υπογραφής σε μια ψηφιακή υπογραφή και τοποθετείται πάντα στην πρώτη σελίδα. Αυτή η λειτουργία είναι χρήσιμη για μορφές αρχείων .docx, .doc, .odt και .xlsx.
