Это пространство имён предоставляет классы для дополнительных вариантов внешнего вида подписей.

## Классы

| Класс | Описание |
| --- | --- |
| [DigitalSignatureAppearance](./digitalsignatureappearance) | Описывает внешний вид строки подписи для цифровой подписи. Одна строка подписи может быть применена только к одной цифровой подписи. Строка подписи всегда находится на первой странице. Эта функция может быть полезна для форматов файлов .docx, .doc, .odt и .xlsx. |
| [ImageAppearance](./imageappearance) | Описывает расширенные возможности внешнего вида для подписи изображения. |
| [PdfDigitalSignatureAppearance](./pdfdigitalsignatureappearance) | Описывает внешний вид цифровой подписи в PDF-документах. |
| [PdfTextAnnotationAppearance](./pdftextannotationappearance) | Описывает внешний вид объекта текстовой аннотации PDF (Title, Subject, Content). |
| [PdfTextStickerAppearance](./pdftextstickerappearance) | Описывает внешний вид объекта стикера текстовой аннотации PDF и всплывающего окна стикера. |
| [SignatureAppearance](./signatureappearance) | Представляет внешний вид подписи — дополнительные параметры для альтернативных реализаций подписи на странице документа. |
