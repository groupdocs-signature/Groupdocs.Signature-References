## EPC class

Rappresenta il Quick Response Code del European Payments Council.

Il tipo EPC espone i seguenti membri:

### Costruttori
| Costruttore | Descrizione |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.domain.extensions/epc/__init__/) | Inizializza un nuovo oggetto EPC. |

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [equals](/signature/python-net/groupdocs.signature.domain.extensions/epc/equals/#obj) | Sovrascrive il metodo Equals per confrontare le proprietà EPC. |
| [equals_object](/signature/python-net/groupdocs.signature.domain.extensions/epc/equals_object/) |  |
| [get_hash_code](/signature/python-net/groupdocs.signature.domain.extensions/epc/get_hash_code/) | Calcola il codice hash per l'EPC. |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [amount](/signature/python-net/groupdocs.signature.domain.extensions/epc/amount/) | L'importo. |
| [bic](/signature/python-net/groupdocs.signature.domain.extensions/epc/bic/) | Il BIC del beneficiario, con una lunghezza massima di 11 caratteri. |
| [charset](/signature/python-net/groupdocs.signature.domain.extensions/epc/charset/) | L'implementazione del set di caratteri EPC / SEPA QR-Code; per impostazione predefinita questo valore è impostato a 1. |
| [code](/signature/python-net/groupdocs.signature.domain.extensions/epc/code/) | Il codice aziendale, fino a 4 caratteri. |
| [iban](/signature/python-net/groupdocs.signature.domain.extensions/epc/iban/) | Il conto del beneficiario (IBAN). |
| [identification](/signature/python-net/groupdocs.signature.domain.extensions/epc/identification/) | L'identificazione EPC / SEPA QR-Code. Per impostazione predefinita questo valore è impostato su SCT. |
| [information](/signature/python-net/groupdocs.signature.domain.extensions/epc/information/) | Le informazioni di suggerimento, con una lunghezza massima di 70 caratteri. |
| [name](/signature/python-net/groupdocs.signature.domain.extensions/epc/name/) | Il nome del beneficiario con una lunghezza massima di 70 caratteri. |
| [reference](/signature/python-net/groupdocs.signature.domain.extensions/epc/reference/) | Il riferimento di pagamento (massimo 35 caratteri). |
| [remittance](/signature/python-net/groupdocs.signature.domain.extensions/epc/remittance/) | Le informazioni di pagamento (massimo 140 caratteri). |
| [version](/signature/python-net/groupdocs.signature.domain.extensions/epc/version/) | L'implementazione della versione EPC / SEPA QR-Code, impostata per impostazione predefinita su "002". |
