## IResult class

Rappresenta un'interfaccia comune per il risultato del processo di firma.

Il tipo IResult espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/iresult/destin_document_size/) | La dimensione del documento di destinazione. |
| [failed](/signature/python-net/groupdocs.signature.domain/iresult/failed/) | L'elenco delle firme che non sono state elaborate. |
| [processing_time](/signature/python-net/groupdocs.signature.domain/iresult/processing_time/) | Il tempo di esecuzione del processo in millisecondi. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/iresult/source_document_size/) | La dimensione del documento di origine. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/iresult/succeeded/) | L'elenco delle firme elaborate con successo [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/iresult/total_signatures/) | Il totale delle firme elaborate. |
