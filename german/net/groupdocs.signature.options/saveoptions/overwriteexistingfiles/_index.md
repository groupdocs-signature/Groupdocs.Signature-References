## SaveOptions.OverwriteExistingFiles property

Liest oder setzt, ob die vorhandene Datei mit der neuen Ausgabedatei überschrieben werden soll. Andernfalls wird eine neue Datei mit einer Nummer als Suffix erstellt. Standardmäßig ist dieser Wert auf true gesetzt, was bedeutet, dass die Datei überschrieben wird.
