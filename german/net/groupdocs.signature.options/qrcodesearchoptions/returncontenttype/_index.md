## QrCodeSearchOptions.ReturnContentType property

Gibt den Dateityp des zurückgegebenen Bildinhalts der QR‑Code‑Signatur an, wenn die Eigenschaft ReturnContent aktiviert ist. Standardmäßig ist er auf Null gesetzt. Das bedeutet, dass der QR‑Code‑Bildinhalt im Originalformat zurückgegeben wird. Dieses Bildformat ist unter [`Format`](../../../groupdocs.signature.domain/qrcodesignature/format) angegeben. Mögliche unterstützte Werte sind: FileType.JPEG, FileType.PNG, FileType.BMP. Wenn das angegebene Format nicht unterstützt wird, wird der QR‑Code‑Bildinhalt im ursprünglichen .png zurückgegeben.

public FileType ReturnContentType { get; set; }
