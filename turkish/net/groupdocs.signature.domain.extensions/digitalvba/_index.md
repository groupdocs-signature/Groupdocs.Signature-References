## DigitalVBA class

Spreadsheets VBA projeleri için dijital imzayı temsil eder. Xlsm veya Xltm gibi belirli Spreadsheets belge formatlarında VBA projesini imzalama yeteneği sağlar. DigitalSignOptions.Extensions'a birden fazla DigitalVBA uzantısı eklenirse, yalnızca ilk olan belge imzalamasına dahil edilir.

public class DigitalVBA : SignatureExtension
