## StretchMode class

Тип StretchMode раскрывает следующие члены:

### Поля
| Поле | Описание |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/stretchmode/none/) | Значение по умолчанию. Режим растяжения не будет применён. |
| [PAGE_WIDTH](/signature/python-net/groupdocs.signature.domain/stretchmode/page_width/) | Растянуть область подписи по ширине страницы. Свойство Margin будет использовано для применения требуемых значений смещения |
| [PAGE_HEIGHT](/signature/python-net/groupdocs.signature.domain/stretchmode/page_height/) | Растянуть область подписи по высоте страницы. Свойство Margin будет использовано для применения требуемых значений смещения. |
| [PAGE_AREA](/signature/python-net/groupdocs.signature.domain/stretchmode/page_area/) | Растянуть область подписи по высоте и ширине страницы. Свойство Margin будет использовано для применения требуемых значений смещения. |
