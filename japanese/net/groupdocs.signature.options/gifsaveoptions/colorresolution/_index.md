## GifSaveOptions.ColorResolution property

GIF の色解像度を取得または設定します。

```csharp
public byte ColorResolution { get; set; }
```

### 備考

Color Resolution - 元画像で利用可能な各プライマリカラーあたりのビット数から 1 を引いた値です。この値は、グラフィックの色が選択された全パレットのサイズを表し、実際にグラフィックで使用された色の数ではありません。例えば、このフィールドの値が 3 の場合、元画像のパレットは画像作成に利用できる各プライマリカラーあたり 4 ビットを持っていたことになります。この値は、ソースマシンですべてのパレット色が利用できなくても、元パレットの豊かさを示すために設定すべきです。
