## DigitalSignOptions.AllowNotYetValid property

有効期間がまだ開始されていない証明書での署名を許可するフラグを取得または設定します。デフォルト値は false です。このような証明書で署名すると [`GroupDocsSignatureException`](../../../groupdocs.signature/groupdocssignatureexception) がスローされ、ドキュメントは署名されません。

```csharp
public bool AllowNotYetValid { get; set; }
```

### 備考

バリデータは、証明書が有効になる前に作成された署名を無効として報告します。そのような証明書は通常、後日の発行であるか、コンピュータの時計が誤っている場合があります。このプロパティが true の場合、ドキュメントは署名され、[`SignatureSettings`](../../../groupdocs.signature/signaturesettings) で設定されたロガーに警告が書き込まれます。

証明書は UTC の現在時刻と比較されます。このフラグは、有効期間が終了した証明書を制御する [`AllowExpired`](../allowexpired) と同じ証明書に適用されます。
