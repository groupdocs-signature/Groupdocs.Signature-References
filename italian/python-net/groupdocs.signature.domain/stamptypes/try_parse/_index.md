## try_parse {#parsing_type}

Restituisce un tipo di timbro per il nome del tipo di parsing fornito. Se il nome del timbro è sconosciuto, non viene sollevata alcuna eccezione e il metodo restituisce None.

```python
def try_parse(cls, parsing_type):
    ...
```

| Parametro | Tipo | Descrizione |
| :- | :- | :- |
| parsing_type | `str` | Stringa di origine del nome del tipo di timbro. |

**Returns:** StampType: StampType instance.
