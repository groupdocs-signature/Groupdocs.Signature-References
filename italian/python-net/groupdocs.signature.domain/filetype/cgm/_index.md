## CGM field

Il Computer Graphics Metafile (.cgm) è un formato meta file gratuito, indipendente dalla piattaforma, standard internazionale per la memorizzazione e lo scambio di grafica vettoriale (2D), grafica raster e testo. CGM utilizza un approccio orientato agli oggetti e molte funzioni per la produzione di immagini. Scopri di più su questo formato file qui.
