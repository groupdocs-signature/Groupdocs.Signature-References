## VerticalAlignment class

Der VerticalAlignment‑Typ stellt die folgenden Mitglieder bereit:

### Felder
| Feld | Beschreibung |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/verticalalignment/none/) | Das Objekt wird explizit positioniert, normalerweise über seine Top‑Eigenschaft. |
| [TOP](/signature/python-net/groupdocs.signature.domain/verticalalignment/top/) | Gibt an, dass das Objekt am oberen Rand der vertikalen Ausrichtungsbasis liegen soll. |
| [CENTER](/signature/python-net/groupdocs.signature.domain/verticalalignment/center/) | Gibt an, dass das Objekt relativ zur vertikalen Ausrichtungsbasis zentriert sein soll. |
| [BOTTOM](/signature/python-net/groupdocs.signature.domain/verticalalignment/bottom/) | Gibt an, dass das Objekt am unteren Rand der vertikalen Ausrichtungsbasis liegen soll. |
