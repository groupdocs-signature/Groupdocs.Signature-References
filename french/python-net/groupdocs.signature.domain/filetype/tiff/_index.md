## TIFF field

Le format Tagged Image File Format (.tiff) représente des images raster destinées à être utilisées sur une variété d'appareils conformes à cette norme de format de fichier. Il peut décrire des données d'image binaire, en niveaux de gris, en couleur palette et en couleur pleine dans plusieurs espaces colorimétriques. En savoir plus sur ce format de fichier ici.
