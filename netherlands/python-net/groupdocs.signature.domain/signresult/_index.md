## SignResult class

Stelt het resultaat voor van het ondertekeningsproces voor een document met nieuw aangemaakte handtekeningen.

Het SignResult-type geeft de volgende leden weer:

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/signresult/destin_document_size/) | De grootte van het bestemmingsdocument. |
| [failed](/signature/python-net/groupdocs.signature.domain/signresult/failed/) | De lijst met handtekeningen die niet konden worden aangemaakt. |
| [processing_time](/signature/python-net/groupdocs.signature.domain/signresult/processing_time/) | De uitvoeringstijd van het proces in milliseconden. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/signresult/source_document_size/) | De grootte van het brondocument. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/signresult/succeeded/) | De lijst met nieuw aangemaakte handtekeningen [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/signresult/total_signatures/) | Het totale aantal verwerkte handtekeningen. |
