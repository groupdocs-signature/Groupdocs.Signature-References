## ProcessCompleteEventArgs class

Fournit des données sur l'événement complet de signature, de vérification et de recherche.

Le type ProcessCompleteEventArgs expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [canceled](/signature/python-net/groupdocs.signature/processcompleteeventargs/canceled/) | Le processus a été annulé. |
| [completed](/signature/python-net/groupdocs.signature/processcompleteeventargs/completed/) | L'horodatage de la fin du processus. |
| [ticks](/signature/python-net/groupdocs.signature/processcompleteeventargs/ticks/) | Le temps en millisecondes écoulé depuis l'événement de démarrage du processus. |
| [total_signatures](/signature/python-net/groupdocs.signature/processcompleteeventargs/total_signatures/) | La quantité totale de signatures traitées. |
| [status](/signature/python-net/groupdocs.signature/processeventargs/status/) | L'état actuel du processus. (hérité de [`ProcessEventArgs`](/signature/python-net/groupdocs.signature/processeventargs/)) |
