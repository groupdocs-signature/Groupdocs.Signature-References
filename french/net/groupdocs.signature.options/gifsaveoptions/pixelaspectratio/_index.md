## GifSaveOptions.PixelAspectRatio property

Obtient ou définit le rapport d'aspect des pixels du GIF.

```csharp
public byte PixelAspectRatio { get; set; }
```

### Remarques

Pixel Aspect Ratio - Facteur utilisé pour calculer une approximation du rapport d'aspect du pixel dans l'image originale. Si la valeur du champ n'est pas 0, cette approximation du rapport d'aspect est calculée selon la formule : Aspect Ratio = (Pixel Aspect Ratio + 15) / 64 Le Pixel Aspect Ratio est défini comme le quotient de la largeur du pixel sur sa hauteur. L'intervalle de valeurs dans ce champ permet de spécifier le pixel le plus large de 4:1 au pixel le plus haut de 1:4 par incréments de 1/64e. Valeurs : 0 - Aucune information de rapport d'aspect fournie. 1..255 - Valeur utilisée dans le calcul.
