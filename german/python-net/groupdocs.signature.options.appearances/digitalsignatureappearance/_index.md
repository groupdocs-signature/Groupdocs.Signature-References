## DigitalSignatureAppearance class

Stellt das Erscheinungsbild einer Signaturzeile für eine digitale Signatur dar. Pro digitale Signatur kann nur eine Signaturzeile angewendet werden, und sie wird stets auf der ersten Seite platziert. Diese Funktion ist nützlich für die Dateiformate .docx, .doc, .odt und .xlsx.
