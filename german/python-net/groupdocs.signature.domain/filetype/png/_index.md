## PNG field

Portable Network Graphic (.png) ist ein Rasterbilddateiformat, das verlustfreie Kompression verwendet. Dieses Dateiformat wurde als Ersatz des Graphics Interchange Format (GIF) erstellt und hat keine urheberrechtlichen Beschränkungen. Erfahren Sie hier mehr über dieses Dateiformat.
