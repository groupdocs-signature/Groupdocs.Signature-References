## signature_id property

L'identificatore univoco della firma, usato per modificare la firma nel documento tramite operazioni di aggiornamento o eliminazione.

L'identificatore viene impostato automaticamente dopo aver chiamato i metodi sign o search.

Se l'identificatore è stato salvato in precedenza, può essere impostato manualmente per manipolare la firma.
