## License class

Διαχειρίζεται την άδεια χρήσης του GroupDocs.Signature.

Οι αδειοδοτημένες εκδόσεις ξεκλειδώνουν το πλήρες σύνολο λειτουργιών του wrapper στο
χρόνο εκτέλεσης. Οι μη αδειοδοτημένες εκδόσεις εκτελούνται σε λειτουργία αξιολόγησης με το ίδιο API
επιφάνεια, αλλά με περιορισμούς στο μέγεθος εξόδου και στο υδατογράφημα του περιεχομένου.

Ο τύπος License εκθέτει τα ακόλουθα μέλη:
