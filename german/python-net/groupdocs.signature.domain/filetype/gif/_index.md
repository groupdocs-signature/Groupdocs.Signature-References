## GIF field

Graphical Interchange Format File (.gif) ist ein stark komprimiertes Bildformat. Für jedes Bild erlaubt GIF typischerweise bis zu 8 Bit pro Pixel und bis zu 256 Farben im gesamten Bild. Erfahren Sie hier mehr über dieses Dateiformat.
