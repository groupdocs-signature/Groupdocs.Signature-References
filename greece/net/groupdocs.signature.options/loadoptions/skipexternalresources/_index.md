## LoadOptions.SkipExternalResources property

Λαμβάνει ή ορίζει μια σημαία που εμποδίζει το έγγραφο από τη φόρτωση εξωτερικών πόρων. Η προεπιλεγμένη τιμή είναι true: οι εξωτερικοί πόροι δεν φορτώνονται, εκτός αν ταιριάζουν με [`WhitelistedResources`](../whitelistedresources).

```csharp
public bool SkipExternalResources { get; set; }
```

### Παρατηρήσεις

Ένα έγγραφο μπορεί να αναφέρεται σε πόρους που αποθηκεύονται εκτός αυτού: συνδεδεμένες εικόνες, εικόνες που εισάγονται μέσω του πεδίου INCLUDEPICTURE, συνδεδεμένες εικόνες σε παρουσιάσεις και λογιστικά φύλλα, καθώς και εικόνες και φύλλα στυλ που αναφέρεται μια εικόνα SVG. Η φόρτωση τέτοιου πόρου κάνει τη βιβλιοθήκη να ζητήσει τη διεύθυνσή του. Σε έναν διακομιστή που επεξεργάζεται μη αξιόπιστα έγγραφα, ένα έγγραφο θα μπορούσε να το χρησιμοποιήσει για να κάνει τον διακομιστή να στέλνει αιτήματα σε εσωτερικές διευθύνσεις (παραβίαση αιτήματος από τον διακομιστή), και ένα UNC ή διαδρομή file:// θα μπορούσε να κάνει τα Windows να στείλουν τα διαπιστευτήρια NTLM του λογαριασμού σε άλλο κεντρικό υπολογιστή. Σε μια εγκατάσταση εκτός σύνδεσης ή απομονωμένη, τα αιτήματα αποτυγχάνουν ή περιμένουν λήξη χρόνου.

Οι πόροι που παραλείπονται δεν σχεδιάζονται στις προεπισκοπήσεις σελίδων ή σε έγγραφα αποθηκευμένα ως εικόνες, και η αναζήτηση εικόνας, barcode και QR-code δεν τους βλέπει. Ορίστε αυτήν την ιδιότητα σε false μόνο για αξιόπιστα έγγραφα και προτιμήστε την άδεια συγκεκριμένων διευθύνσεων με [`WhitelistedResources`](../whitelistedresources).

Η ρύθμιση εφαρμόζεται σε έγγραφα επεξεργασίας κειμένου, παρουσιάσεις, λογιστικά φύλλα και εικόνες SVG, συμπεριλαμβανομένων των εγγράφων μέσα σε αρχεία. Για εικόνες SVG, οι αναφορές που δεν επιτρέπονται αφαιρούνται από την εικόνα πριν διαβαστεί, και μια εικόνα SVG που δεν είναι σωστά διαμορφωμένο XML απορρίπτεται. Η ρύθμιση δεν ελέγχει ελέγχους ανάκλησης πιστοποιητικού, διακομιστές χρονοσφραγίδωσης ή αδειοδότηση.

Αυτή η ιδιότητα αντικαθιστά το LoadExternalResources, το οποίο έχει το αντίστροφο νόημα.
