## BitmapCompression class

| Campo | Descrizione |
| :- | :- |
| [RGB](/signature/python-net/groupdocs.signature.options/bitmapcompression/rgb/) | Nessuna compressione. |
| [RLE8](/signature/python-net/groupdocs.signature.options/bitmapcompression/rle8/) | Compressione RLE a 8 bit/pixel. Può essere usata solo con bitmap a 8 bit/pixel. |
