**GroupDocs.Signature.Options.Appearances** 名前空間は、追加の署名外観のためのクラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [DigitalSignatureAppearance](../com.groupdocs.signature.options.appearances/digitalsignatureappearance) | デジタル署名の署名ラインの外観を説明します。 |
| [ImageAppearance](../com.groupdocs.signature.options.appearances/imageappearance) | 画像署名の拡張外観機能を説明します。 |
| [PdfDigitalSignatureAppearance](../com.groupdocs.signature.options.appearances/pdfdigitalsignatureappearance) | PDFドキュメント上のデジタル署名の外観を説明します。 |
| [PdfTextAnnotationAppearance](../com.groupdocs.signature.options.appearances/pdftextannotationappearance) | PDFテキスト注釈オブジェクト（タイトル、サブジェクト、コンテンツ）の外観を説明します。 |
| [PdfTextStickerAppearance](../com.groupdocs.signature.options.appearances/pdftextstickerappearance) | PDFテキスト注釈ステッカーオブジェクトとステッカーのポップアップウィンドウの外観を説明します。 |
| [SignatureAppearance](../com.groupdocs.signature.options.appearances/signatureappearance) | 署名の外観を表します - ドキュメントページ上での署名の代替実装のための追加オプション。 |
