## SignatureSettings.IncludeStandardMetadataSignatures property

Yazar, Sahip, belge oluşturma tarihi, değiştirilme tarihi vb. gibi gömülü standart belge meta verisi imzalarını Metadata Listesine dahil etmek için bayrağı alır veya ayarlar. Bu bayrak false (varsayılan) olarak ayarlanırsa GetDocumentInfo bu meta veri imzalarını içermez. Bayrak true olarak ayarlanırsa belge bilgileri bu standart meta veri imzalarını içerir.

public bool IncludeStandardMetadataSignatures { get; set; }
