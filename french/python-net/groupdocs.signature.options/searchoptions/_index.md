## SearchOptions class

Représente les options d'extraction des signatures d'un document.

En savoir plus

- See more simple examples on searching for various electronic signatures with GroupDocs.Signature: https://docs.groupdocs.com/signature/net/search-for-electronic-signatures-in-document/
- See more advanced examples of searching for various electronic signature with GroupDocs.Signature: https://docs.groupdocs.com/signature/net/searching/

Le type SearchOptions expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [all_pages](/signature/python-net/groupdocs.signature.options/searchoptions/all_pages/) | Le drapeau indiquant s'il faut rechercher sur chaque page du document. Par défaut, cette valeur est True. |
| [page_number](/signature/python-net/groupdocs.signature.options/searchoptions/page_number/) | Le numéro de page du document pour la recherche (facultatif). |
| [pages_setup](/signature/python-net/groupdocs.signature.options/searchoptions/pages_setup/) | Les options pour spécifier les pages de recherche de signature. |
| [shape_position](/signature/python-net/groupdocs.signature.options/searchoptions/shape_position/) | Le drapeau indiquant s'il faut renvoyer la position de la forme dans la mise en page du document. Disponible uniquement pour les documents Word. |
| [skip_external](/signature/python-net/groupdocs.signature.options/searchoptions/skip_external/) | Le drapeau pour ne renvoyer que les signatures marquées comme `IsSignature`. Par défaut, la valeur est `False`, ce qui indique que toutes les signatures correspondant aux critères spécifiés sont renvoyées. |
