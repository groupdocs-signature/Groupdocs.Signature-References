## SignOptions class

Rappresenta le opzioni di firma.

Maggiori informazioni

- See more simple examples on creating various electronic signatures with GroupDocs.Signature: https://docs.groupdocs.com/signature/net/electronic-signature-types/
- See more advanced examples of settings of various electronic signature with GroupDocs.Signature: https://docs.groupdocs.com/signature/net/signing/

Il tipo SignOptions espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [all_pages](/signature/python-net/groupdocs.signature.options/signoptions/all_pages/) | La firma verrà posizionata su tutte le pagine del documento. |
| [appearance](/signature/python-net/groupdocs.signature.options/signoptions/appearance/) | L'aspetto aggiuntivo della firma. |
| [document_type](/signature/python-net/groupdocs.signature.options/signoptions/document_type/) | Il tipo di documento delle opzioni di firma (`DocumentType`). |
| [extensions](/signature/python-net/groupdocs.signature.options/signoptions/extensions/) | Le estensioni della firma. |
| [hash_algorithm](/signature/python-net/groupdocs.signature.options/signoptions/hash_algorithm/) | L'algoritmo hash da utilizzare per le operazioni crittografiche. Supportato esclusivamente per le firme digitali nei file PDF. |
| [page_number](/signature/python-net/groupdocs.signature.options/signoptions/page_number/) | Il numero di pagina del documento per la firma. |
| [pages_setup](/signature/python-net/groupdocs.signature.options/signoptions/pages_setup/) | Le opzioni per specificare le pagine da firmare. |
| [signature_type](/signature/python-net/groupdocs.signature.options/signoptions/signature_type/) | Il tipo di firma (`SignatureType`). |
| [zorder](/signature/python-net/groupdocs.signature.options/signoptions/zorder/) | La posizione Z-order della firma testuale, che determina l'ordine di visualizzazione delle firme sovrapposte. |
