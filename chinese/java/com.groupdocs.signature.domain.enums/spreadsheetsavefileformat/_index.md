定义电子表格文档的不同保存格式。

## 字段

| 字段 | 描述 |
| --- | --- |
|  | [Default](#Default) | 文件格式不会被更改。 |
|
|  | [CSV](#CSV) | 将文档另存为逗号分隔值文件。 |
|
|  | [Excel97To2003](#Excel97To2003) | 将文档另存为 Microsoft Excel 97-2003 工作簿（.xls）。 |
|
|  | [Xlsx](#Xlsx) | 将文档另存为 Microsoft Excel OpenXML 工作簿。 |
|
|  | [Xlsm](#Xlsm) | 将文档另存为 Microsoft Excel 启用宏的工作簿。 |
|
|  | [Xltx](#Xltx) | 将文档另存为 Microsoft Excel 模板。 |
|
|  | [Xltm](#Xltm) | 将文档另存为 Microsoft Excel 启用宏的模板。 |
|
|  | [Xlam](#Xlam) | 将文档另存为 Microsoft Excel 启用宏的加载项。 |
|
|  | [Pdf](#Pdf) | 将文档另存为 PDF 文件。 |
|
|  | [ODS](#ODS) | 将文档另存为 Open Office 工作簿。 |
|
|  | [Xlsb](#Xlsb) | 将文档另存为 Microsoft Excel 二进制工作簿。 |
|
|  | [XPS](#XPS) | 将文档另存为 XML Paper Specification 文件。 |
|
|  | [TIFF](#TIFF) | 将文档另存为 Tagged Image File Format。 |
|
|  | [SVG](#SVG) | 将文档另存为 Scalable Vector Graphics 文件。 |
|
|  | [Dif](#Dif) | 将文档另存为 Data Interchange Format。 |
|
|  | [Emf](#Emf) | 将文档保存为 Windows 增强型图元文件格式。 |
|
|  | [Jpg](#Jpg) | 将文档保存为 Jpeg 格式。 |
|
|  | [Png](#Png) | 将文档保存为 Portable Network Graphics 格式。 |
