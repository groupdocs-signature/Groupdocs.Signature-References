## SearchOptions class

Представляет параметры для извлечения подписей из документа.

Узнать больше

- See more simple examples on searching for various electronic signatures with GroupDocs.Signature: https://docs.groupdocs.com/signature/net/search-for-electronic-signatures-in-document/
- See more advanced examples of searching for various electronic signature with GroupDocs.Signature: https://docs.groupdocs.com/signature/net/searching/

Тип SearchOptions раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [all_pages](/signature/python-net/groupdocs.signature.options/searchoptions/all_pages/) | Флаг, указывающий, выполнять ли поиск на каждой странице документа. По умолчанию это значение равно True. |
| [page_number](/signature/python-net/groupdocs.signature.options/searchoptions/page_number/) | Номер страницы документа для поиска (необязательно). |
| [pages_setup](/signature/python-net/groupdocs.signature.options/searchoptions/pages_setup/) | Параметры для указания страниц для поиска подписей. |
| [shape_position](/signature/python-net/groupdocs.signature.options/searchoptions/shape_position/) | Флаг, указывающий, возвращать ли позицию фигуры в макете документа. Доступно только для документов Word. |
| [skip_external](/signature/python-net/groupdocs.signature.options/searchoptions/skip_external/) | Флаг для возврата только подписей, помеченных как `IsSignature`. По умолчанию значение `False`, что означает, что возвращаются все подписи, соответствующие указанным критериям. |
