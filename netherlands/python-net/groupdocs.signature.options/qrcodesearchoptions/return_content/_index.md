## return_content property

De vlag die bepaalt of QR‑Code‑afbeeldingsinhoud wordt geretourneerd voor elke handtekening op een documentpagina. Wanneer ingesteld op True, wordt de ruwe afbeeldingsdata bewaard in de `content`‑eigenschap van de handtekening met het formaat gespecificeerd door `return_content_type`. Standaard uitgeschakeld.
