## BarcodeSearchOptions.ReturnContentType property

ReturnContent 속성이 활성화된 경우 바코드 서명의 반환 이미지 콘텐츠 파일 유형을 지정합니다. 기본값은 Null이며, 이는 바코드 이미지 콘텐츠를 원본 형식으로 반환함을 의미합니다. 이 이미지 형식은 [`Format`](../../../groupdocs.signature.domain/barcodesignature/format)에서 지정됩니다. 지원되는 가능한 값은: FileType.JPEG, FileType.PNG, FileType.BMP입니다. 제공된 형식이 지원되지 않으면 바코드 이미지 콘텐츠가 .png 형식으로 반환됩니다.

public FileType ReturnContentType { get; set; }
