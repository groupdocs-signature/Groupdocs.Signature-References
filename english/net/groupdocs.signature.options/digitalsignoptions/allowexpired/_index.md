## DigitalSignOptions.AllowExpired property

Gets or sets a flag that allows signing with a certificate whose validity period has ended. The default value is false: signing with an expired certificate throws [`GroupDocsSignatureException`](../../../groupdocs.signature/groupdocssignatureexception), and the document is not signed.

```csharp
public bool AllowExpired { get; set; }
```

### Remarks

Validators report a signature made with an expired certificate as not valid. Set this property to true only when you need such a signature anyway, for example to test with an old certificate. The document is then signed, and a warning is written to the logger set in [`SignatureSettings`](../../../groupdocs.signature/signaturesettings).

The certificate is compared with the current time in UTC, not with [`SignTime`](../../../groupdocs.signature.domain/digitalsignature/signtime). The flag applies to the certificate given by [`CertificateFilePath`](../certificatefilepath), [`CertificateStream`](../certificatestream) or [`Signature`](../signature), and, when a spreadsheet is signed, to the certificate of the first [`DigitalVBA`](../../../groupdocs.signature.domain.extensions/digitalvba) extension. Digital signatures of images do not use a certificate and are not checked. A certificate whose validity period has not started yet is controlled by [`AllowNotYetValid`](../allownotyetvalid).
