## FileType.CDR field

CorelDraw Vector Graphic Drawing (.cdr) adalah file gambar vektor yang secara native dibuat dengan CorelDRAW untuk menyimpan gambar digital yang dikodekan dan dikompresi. File gambar tersebut berisi teks, garis, bentuk, gambar, warna, dan efek untuk representasi vektor dari isi gambar. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/image/cdr).
