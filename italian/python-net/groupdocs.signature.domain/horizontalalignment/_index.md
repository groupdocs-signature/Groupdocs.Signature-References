## HorizontalAlignment class

Il tipo HorizontalAlignment espone i seguenti membri:

### Campi
| Campo | Descrizione |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/horizontalalignment/none/) | L'oggetto è posizionato esplicitamente, solitamente usando la sua proprietà Left. |
| [LEFT](/signature/python-net/groupdocs.signature.domain/horizontalalignment/left/) | Specifica che l'oggetto deve essere allineato a sinistra rispetto alla base di allineamento orizzontale. |
| [CENTER](/signature/python-net/groupdocs.signature.domain/horizontalalignment/center/) | Specifica che l'oggetto deve essere centrato rispetto alla base di allineamento orizzontale. |
| [RIGHT](/signature/python-net/groupdocs.signature.domain/horizontalalignment/right/) | Specifica che l'oggetto deve essere allineato a destra rispetto alla base di allineamento orizzontale. |
