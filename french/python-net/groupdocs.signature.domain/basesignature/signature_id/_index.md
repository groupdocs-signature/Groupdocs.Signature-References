## signature_id property

L'identifiant unique de la signature, utilisé pour modifier la signature dans le document via des opérations de mise à jour ou de suppression.

L'identifiant est défini automatiquement après l'appel des méthodes sign ou search.

Si l'identifiant a été enregistré précédemment, il peut être défini manuellement pour manipuler la signature.
