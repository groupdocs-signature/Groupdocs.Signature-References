## DigitalVBA class

يمثل التوقيع الرقمي لمشاريع VBA في جداول البيانات. يوفر القدرة على توقيع مشروع VBA في صيغ مستندات جداول البيانات المحددة مثل Xlsm أو Xltm. إذا تمت إضافة عدة امتدادات DigitalVBA إلى DigitalSignOptions.Extensions فإن الأول فقط يُشارك في توقيع المستند.

```csharp
public class DigitalVBA : SignatureExtension
```
