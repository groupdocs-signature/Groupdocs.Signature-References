## DEFAULT_APPEARANCE field

ステッカーのデフォルト外観を取得します。Options.SignatureAppearance プロパティが指定されていない場合、これらのプロパティはデフォルトとして適用されます。プロパティはユーザーによっていつでも変更可能です。
