## DigitalVBA class

Mewakili tanda tangan digital untuk proyek VBA Spreadsheet. Ini menyediakan kemampuan untuk menandatangani proyek VBA pada format dokumen Spreadsheet tertentu seperti Xlsm atau Xltm. Jika beberapa ekstensi DigitalVBA ditambahkan ke DigitalSignOptions.Extensions, hanya yang pertama yang terlibat dalam penandatanganan dokumen.

```csharp
public class DigitalVBA : SignatureExtension
```
