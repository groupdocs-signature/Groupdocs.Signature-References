## PPTX field

PowerPoint Open XML Presentation (.pptx) — это файлы презентаций, созданные популярным приложением Microsoft PowerPoint. В отличие от предыдущей версии формата презентаций PPT, который был бинарным, формат PPTX основан на открытом XML‑формате презентаций Microsoft PowerPoint.
