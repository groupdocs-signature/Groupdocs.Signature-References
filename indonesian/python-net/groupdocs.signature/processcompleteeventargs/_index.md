## ProcessCompleteEventArgs class

Menyediakan data pada peristiwa lengkap proses penandatanganan, verifikasi, dan pencarian.

Tipe ProcessCompleteEventArgs menampilkan anggota-anggota berikut:

### Properti
| Properti | Deskripsi |
| :- | :- |
| [canceled](/signature/python-net/groupdocs.signature/processcompleteeventargs/canceled/) | Proses telah dibatalkan. |
| [completed](/signature/python-net/groupdocs.signature/processcompleteeventargs/completed/) | Tanda waktu penyelesaian proses. |
| [ticks](/signature/python-net/groupdocs.signature/processcompleteeventargs/ticks/) | Waktu dalam milidetik yang dihabiskan sejak peristiwa Start proses. |
| [total_signatures](/signature/python-net/groupdocs.signature/processcompleteeventargs/total_signatures/) | Jumlah total tanda tangan yang diproses. |
| [status](/signature/python-net/groupdocs.signature/processeventargs/status/) | Status proses saat ini. (diturunkan dari [`ProcessEventArgs`](/signature/python-net/groupdocs.signature/processeventargs/)) |
