## APNG field

Animated Portable Network Graphics (.png) — это растровый формат изображения, использующий без потерь сжатие. Он был разработан как расширение PNG для поддержки анимации, служа альтернативой формату GIF без ограничений по авторским правам. Узнайте больше об этом формате файла здесь.
