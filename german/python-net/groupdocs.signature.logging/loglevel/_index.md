## LogLevel class

Der LogLevel-Typ stellt die folgenden Mitglieder bereit:

### Felder
| Feld | Beschreibung |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.logging/loglevel/none/) | Es wird nichts protokolliert. |
| [ERROR](/signature/python-net/groupdocs.signature.logging/loglevel/error/) | Fehler: Ein Vorgang ist fehlgeschlagen. |
| [WARNING](/signature/python-net/groupdocs.signature.logging/loglevel/warning/) | Warnungen: Ein Vorgang war erfolgreich, aber das Ergebnis entspricht möglicherweise nicht Ihren Erwartungen. |
| [TRACE](/signature/python-net/groupdocs.signature.logging/loglevel/trace/) | Trace-Nachrichten: die Schritte eines Vorgangs, wie dessen Beginn und Ende. |
| [ALL](/signature/python-net/groupdocs.signature.logging/loglevel/all/) | Fehler, Warnungen und Trace-Nachrichten. Dies ist die Standardeinstellung. |
