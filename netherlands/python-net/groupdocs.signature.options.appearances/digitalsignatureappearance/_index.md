## DigitalSignatureAppearance class

Stelt de weergave van een handtekeningregel voor een digitale handtekening voor. Er kan slechts één handtekeningregel worden toegepast op één digitale handtekening, en deze wordt altijd op de eerste pagina geplaatst. Deze functie is nuttig voor .docx-, .doc-, .odt- en .xlsx-bestandsformaten.
