## SignResult class

Представляет результат процесса подписания документа с новыми подписями.

Тип SignResult раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/signresult/destin_document_size/) | Размер целевого документа. |
| [failed](/signature/python-net/groupdocs.signature.domain/signresult/failed/) | Список подписей, которые не удалось создать. |
| [processing_time](/signature/python-net/groupdocs.signature.domain/signresult/processing_time/) | Время выполнения процесса в миллисекундах. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/signresult/source_document_size/) | Размер исходного документа. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/signresult/succeeded/) | Список недавно созданных подписей [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/signresult/total_signatures/) | Общее количество обработанных подписей. |
