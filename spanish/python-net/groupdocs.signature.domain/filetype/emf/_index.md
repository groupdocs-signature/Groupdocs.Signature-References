## EMF field

Enhanced Windows Metafile (.emf) representa imágenes gráficas de forma independiente del dispositivo. Los metarchivos EMF constan de registros de longitud variable en orden cronológico que pueden renderizar la imagen almacenada después de analizarse en cualquier dispositivo de salida. Obtenga más información sobre este formato de archivo aquí.
