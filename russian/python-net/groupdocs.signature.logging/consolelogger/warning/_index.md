## warning {#message}

Записывает предупреждающее сообщение в консоль. Предупреждающие сообщения журнала предоставляют информацию о неожиданных и восстанавливаемых событиях в потоке приложения.

```python
def warning(self, message):
    ...
```

| Параметр | Тип | Описание |
| :- | :- | :- |
| message | `str` | Сообщение warning. |

| Вызывает | Описание |
| :- | :- |
| `ValueError` | Если `message` равно None. |
