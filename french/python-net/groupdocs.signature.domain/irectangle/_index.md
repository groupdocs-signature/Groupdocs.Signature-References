## IRectangle class

Définit les propriétés d'interface pour la zone de signature sur une page de document.

Le type IRectangle expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [height](/signature/python-net/groupdocs.signature.domain/irectangle/height/) | La hauteur de la zone de signature sur une page de document en unités de mesure (pixels, pourcentages ou millimètres ; voir `MeasureType` SizeMeasureType). |
| [left](/signature/python-net/groupdocs.signature.domain/irectangle/left/) | La position X gauche de la zone de signature sur une page de document en unités de mesure (pixels, pourcentages ou millimètres). Voir `MeasureType` pour l'énumération `LocationMeasureType`. |
| [location_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/location_measure_type/) | Le type de mesure (pixels, pourcentages ou millimètres) pour les propriétés Left et Top. |
| [size_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/size_measure_type/) | Le type de mesure (pixels, pourcentages ou millimètres) pour les propriétés Width et Height. |
| [stretch](/signature/python-net/groupdocs.signature.domain/irectangle/stretch/) | Le mode d'étirement sur une page de document. |
| [top](/signature/python-net/groupdocs.signature.domain/irectangle/top/) | La position Y supérieure de la zone de signature sur la page du document en unités de mesure (pixels, pourcentages ou millimètres). Voir `MeasureType` pour le type de mesure de localisation. |
| [width](/signature/python-net/groupdocs.signature.domain/irectangle/width/) | La largeur de la zone de signature sur une page de document en valeurs de mesure (pixels, pourcentages ou millimètres). Voir `MeasureType` SizeMeasureType. |
