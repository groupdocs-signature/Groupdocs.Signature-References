## StretchMode class

StretchMode 유형은 다음 멤버를 노출합니다:

### 필드
| 필드 | 설명 |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/stretchmode/none/) | 기본값. 스트레치 모드가 적용되지 않습니다. |
| [PAGE_WIDTH](/signature/python-net/groupdocs.signature.domain/stretchmode/page_width/) | 페이지 너비를 따라 서명 영역을 늘립니다. 필요한 오프셋 값을 적용하기 위해 Margin 속성이 사용됩니다. |
| [PAGE_HEIGHT](/signature/python-net/groupdocs.signature.domain/stretchmode/page_height/) | 페이지 높이를 따라 서명 영역을 늘립니다. 필요한 오프셋 값을 적용하기 위해 Margin 속성이 사용됩니다. |
| [PAGE_AREA](/signature/python-net/groupdocs.signature.domain/stretchmode/page_area/) | 페이지 높이와 너비를 따라 서명 영역을 늘립니다. 필요한 오프셋 값을 적용하기 위해 Margin 속성이 사용됩니다. |
