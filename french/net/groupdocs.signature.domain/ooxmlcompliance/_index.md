## OoxmlCompliance enumeration

Spécifie le niveau de conformité OOXML pour les documents WordProcessing. Lors de l'enregistrement, il remplace la conformité du document original ; sinon, la conformité du document chargé est conservée lors de l'enregistrement.

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Ecma | `0` | Niveau de conformité ECMA-376 1re édition. |
| Transitional | `1` | Niveau de conformité ISO/IEC 29500:2008 Transitionnel. |
| Strict | `2` | Niveau de conformité ISO/IEC 29500:2008 Strict. |
