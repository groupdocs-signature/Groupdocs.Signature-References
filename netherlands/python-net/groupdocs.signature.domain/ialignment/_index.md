## IAlignment class

Beschrijft de uitlijning van het handtekeninggebied op een documentpagina.

Het type IAlignment bevat de volgende leden:

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [horizontal_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/horizontal_alignment/) | De horizontale uitlijning van de afbeelding op een documentpagina. |
| [margin](/signature/python-net/groupdocs.signature.domain/ialignment/margin/) | De ruimte die standaard wordt gespecificeerd tussen de afbeelding en de documentranden (geldt wanneer horizontale of verticale uitlijning is ingesteld). |
| [margin_measure_type](/signature/python-net/groupdocs.signature.domain/ialignment/margin_measure_type/) | Het type marge‑meting (pixels, procenten of millimeters). |
| [vertical_alignment](/signature/python-net/groupdocs.signature.domain/ialignment/vertical_alignment/) | De verticale uitlijning van de afbeelding op een documentpagina. |
