## BMP field

Il Bitmap Image File (.bmp) è utilizzato per memorizzare immagini bitmap digitali. Queste immagini sono indipendenti dall'adattatore grafico e sono anche chiamate formato bitmap indipendente dal dispositivo (DIB). Scopri di più su questo formato file qui.
