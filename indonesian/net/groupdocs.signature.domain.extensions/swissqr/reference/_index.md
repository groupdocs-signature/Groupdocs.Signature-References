## SwissQR.Reference property

Mendapatkan atau mengatur referensi pembayaran kreditur. Referensi wajib untuk IBAN SwissQR, yaitu IBAN dalam rentang CHxx30000xxxxxx hingga CHxx31999xxxxx. Jika ditentukan, referensi harus berupa referensi SwissQR yang valid (sesuai format referensi ISR) atau referensi kreditur yang valid menurut ISO 11649 ("RFxxxx"). Kedua dapat berisi spasi untuk pemformatan.

```csharp
public string Reference { get; set; }
```

### Property Value

Referensi pembayaran kreditor.
