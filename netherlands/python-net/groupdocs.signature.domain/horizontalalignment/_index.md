## HorizontalAlignment class

Het type HorizontalAlignment exposeert de volgende leden:

### Velden
| Veld | Beschrijving |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/horizontalalignment/none/) | Het object wordt expliciet gepositioneerd, meestal met behulp van zijn Left-eigenschap. |
| [LEFT](/signature/python-net/groupdocs.signature.domain/horizontalalignment/left/) | Specificeert dat het object links uitgelijnd moet worden op de horizontale uitlijningsbasis. |
