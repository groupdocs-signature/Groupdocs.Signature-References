## SignatureSettings.SaveDocumentOnEmptyDelete property

Delete yöntemi kaldırılacak imza içermediğinde kaynak belgeyi yeniden kaydetmek için bayrağı alır veya ayarlar. Bu bayrak true (varsayılan) olarak ayarlanırsa, Delete yöntemi kaldıracak imza olmasa bile belge, ilgili tarih ve işlem türüyle birlikte tarihçe işlem günlüğüyle kaydedilir. Bayrak false olarak ayarlanırsa kaynak belge hiç değiştirilemez.

public bool SaveDocumentOnEmptyDelete { get; set; }
