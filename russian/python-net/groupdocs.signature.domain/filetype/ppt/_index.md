## PPT field

PowerPoint Presentation (.ppt) представляет файл PowerPoint, состоящий из набора слайдов для отображения в виде слайд-шоу. Он определяет двоичный формат файла, используемый Microsoft PowerPoint 97‑2003. Узнайте больше об этом формате файла здесь.
