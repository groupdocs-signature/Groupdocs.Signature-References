## APNG field

Gli Animated Portable Network Graphics (.png) sono un formato file immagine raster che utilizza compressione senza perdita. È stato sviluppato come estensione del PNG per supportare l'animazione, fungendo da alternativa al formato GIF senza limitazioni di copyright. Scopri di più su questo formato file qui.
