## License class

Verwaltet die Lizenzierung von GroupDocs.Signature.

Lizenzierte Builds schalten den vollen Funktionsumfang des Wrappers frei bei
Laufzeit. Nicht lizenzierte Builds laufen im Evaluierungsmodus mit derselben API
Oberfläche, jedoch mit Beschränkungen bei der Ausgabengröße und wassergezeichnetem Inhalt.

Der License Typ stellt die folgenden Mitglieder bereit:

| :- | :- |
| [set_license](/signature/python-net/groupdocs.signature/license/set_license/#license_source) | Wenden Sie eine Lizenz auf den aktuellen Prozess an. |
