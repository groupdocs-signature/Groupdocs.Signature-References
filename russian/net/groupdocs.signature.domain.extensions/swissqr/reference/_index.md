## SwissQR.Reference property

Получает или задаёт платёжную ссылку кредитора. Ссылка обязательна для SwissQR IBAN, т.е. IBAN в диапазоне от CHxx30000xxxxxx до CHxx31999xxxxx. Если указана, ссылка должна быть либо действительной ссылкой SwissQR (соответствующей форме ISR), либо действительной ссылкой кредитора согласно ISO 11649 ("RFxxxx"). Обе могут содержать пробелы для форматирования.

```csharp
public string Reference { get; set; }
```

### Property Value

Референс платежа получателя.
