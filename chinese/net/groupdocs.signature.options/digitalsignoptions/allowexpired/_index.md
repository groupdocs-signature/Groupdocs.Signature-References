## DigitalSignOptions.AllowExpired property

获取或设置一个标志，允许使用已过期的证书进行签名。默认值为 false：使用已过期的证书签名会抛出 [`GroupDocsSignatureException`](../../../groupdocs.signature/groupdocssignatureexception)，文档不会被签名。

```csharp
public bool AllowExpired { get; set; }
```

### 备注

验证器会将使用已过期证书创建的签名报告为无效。仅在确实需要此类签名时（例如使用旧证书进行测试）才将此属性设为 true。文档随后会被签名，并向在 [`SignatureSettings`](../../../groupdocs.signature/signaturesettings) 中设置的日志记录器写入警告。

证书会与 UTC 当前时间进行比较，而不是与 [`SignTime`](../../../groupdocs.signature.domain/digitalsignature/signtime) 比较。该标志适用于由 [`CertificateFilePath`](../certificatefilepath)、[`CertificateStream`](../certificatestream) 或 [`Signature`](../signature) 提供的证书；在对电子表格签名时，还适用于第一个 [`DigitalVBA`](../../../groupdocs.signature.domain.extensions/digitalvba) 扩展的证书。图像的数字签名不使用证书，也不进行检查。尚未开始有效期的证书受 [`AllowNotYetValid`](../allownotyetvalid) 控制。
