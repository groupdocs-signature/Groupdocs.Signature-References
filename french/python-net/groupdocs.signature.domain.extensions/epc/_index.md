Le type EPC expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [amount](/signature/python-net/groupdocs.signature.domain.extensions/epc/amount/) | Le montant. |
| [bic](/signature/python-net/groupdocs.signature.domain.extensions/epc/bic/) | Le BIC du bénéficiaire avec une longueur maximale de 11 caractères. |
| [charset](/signature/python-net/groupdocs.signature.domain.extensions/epc/charset/) | L'implémentation du jeu de caractères EPC / SEPA QR-Code ; par défaut, cette valeur est définie à 1. |
| [code](/signature/python-net/groupdocs.signature.domain.extensions/epc/code/) | Le code d'entreprise, jusqu'à 4 caractères. |
| [iban](/signature/python-net/groupdocs.signature.domain.extensions/epc/iban/) | Le compte du bénéficiaire (IBAN). |
| [identification](/signature/python-net/groupdocs.signature.domain.extensions/epc/identification/) | L'identification EPC / SEPA QR-Code. Par défaut, cette valeur est définie sur SCT. |
| [information](/signature/python-net/groupdocs.signature.domain.extensions/epc/information/) | Les informations d'indice, avec une longueur maximale de 70 caractères. |
| [name](/signature/python-net/groupdocs.signature.domain.extensions/epc/name/) | Le nom du bénéficiaire avec une longueur maximale de 70 caractères. |
| [reference](/signature/python-net/groupdocs.signature.domain.extensions/epc/reference/) | La référence de paiement (maximum 35 caractères). |
| [remittance](/signature/python-net/groupdocs.signature.domain.extensions/epc/remittance/) | Les informations de remise (maximum 140 caractères). |
| [version](/signature/python-net/groupdocs.signature.domain.extensions/epc/version/) | L'implémentation de la version EPC / SEPA QR-Code, par défaut "002". |
