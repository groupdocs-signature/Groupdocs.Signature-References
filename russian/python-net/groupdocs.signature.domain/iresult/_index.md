## IResult class

Представляет общий интерфейс результата процесса подписи.

Тип IResult раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/iresult/destin_document_size/) | Размер целевого документа. |
| [failed](/signature/python-net/groupdocs.signature.domain/iresult/failed/) | Список подписей, которые не были обработаны. |
| [processing_time](/signature/python-net/groupdocs.signature.domain/iresult/processing_time/) | Время выполнения процесса в миллисекундах. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/iresult/source_document_size/) | Размер исходного документа. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/iresult/succeeded/) | Список успешно обработанных подписей [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/iresult/total_signatures/) | Общее количество обработанных подписей. |
