## VerticalAlignment class

Ο τύπος VerticalAlignment εκθέτει τα ακόλουθα μέλη:

### Πεδία
| Πεδίο | Περιγραφή |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/verticalalignment/none/) | Το αντικείμενο τοποθετείται ρητά, συνήθως χρησιμοποιώντας την ιδιότητα Top. |
| [TOP](/signature/python-net/groupdocs.signature.domain/verticalalignment/top/) | Καθορίζει ότι το αντικείμενο θα βρίσκεται στην κορυφή της βάσης κατακόρυφης στοίχισης. |
| [CENTER](/signature/python-net/groupdocs.signature.domain/verticalalignment/center/) | Καθορίζει ότι το αντικείμενο θα κεντράρεται σε σχέση με τη βάση κατακόρυφης στοίχισης. |
| [BOTTOM](/signature/python-net/groupdocs.signature.domain/verticalalignment/bottom/) | Καθορίζει ότι το αντικείμενο θα βρίσκεται στο κάτω μέρος της βάσης κατακόρυφης στοίχισης. |
