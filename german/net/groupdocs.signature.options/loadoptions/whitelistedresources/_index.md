## LoadOptions.WhitelistedResources property

Liest oder setzt Fragmente von Adressen externer Ressourcen, die selbst dann geladen werden, wenn [`SkipExternalResources`](../skipexternalresources) true ist. Der Standardwert ist eine leere Liste.

```csharp
public List<string> WhitelistedResources { get; set; }
```

### Hinweise

Eine Ressource wird geladen, wenn ihre vollständige Adresse eines der Fragmente enthält. Der Vergleich ignoriert Groß‑ und Kleinschreibung, und leere Fragmente werden ignoriert. Bevorzugen Sie lange Fragmente wie "https://cdn.example.com/images/": Ein kurzes Fragment stimmt ebenfalls mit anderen Adressen überein, die es enthalten.

Das Setzen dieser Eigenschaft auf null löscht die Liste. Die Liste hat keine Wirkung, wenn [`SkipExternalResources`](../skipexternalresources) false ist, weil dann jede externe Ressource geladen wird.
