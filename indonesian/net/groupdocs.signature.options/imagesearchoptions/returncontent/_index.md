## ImageSearchOptions.ReturnContent property

Mendapatkan atau mengatur flag untuk mengambil konten gambar dari tanda tangan pada halaman dokumen. Jika flag ini diatur ke true, konten tanda tangan gambar akan mempertahankan data gambar mentah dengan format yang diperlukan [`ReturnContentType`](../returncontenttype). Secara default opsi ini dinonaktifkan.

public bool ReturnContent { get; set; }
