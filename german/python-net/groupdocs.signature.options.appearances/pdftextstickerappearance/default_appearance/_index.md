## DEFAULT_APPEARANCE field

Ermittelt das Standardaussehen für Aufkleber. Diese Eigenschaften werden als Standard angewendet, wenn die Options.SignatureAppearance‑Eigenschaft nicht angegeben ist. Die Eigenschaften können vom Benutzer jederzeit geändert werden.
