| 클래스 | 설명 |

| [`ProcessCompleteEventHandler`](/signature/python-net/groupdocs.signature/processcompleteeventhandler/) | 서명, 검증 및 검색에 대한 프로세스 완료 이벤트를 처리하는 메서드 대리자를 나타냅니다. |

| [`ProcessStartEventArgs`](/signature/python-net/groupdocs.signature/processstarteventargs/) | 서명, 검증 및 검색 프로세스의 시작 이벤트에 대한 데이터를 제공합니다. |
| [`ProcessStartEventHandler`](/signature/python-net/groupdocs.signature/processstarteventhandler/) | 서명, 검증 및 검색에 대한 프로세스 시작 이벤트를 처리하는 메서드 대리자를 나타냅니다. |
| [`Signature`](/signature/python-net/groupdocs.signature/signature/) | 문서 서명 프로세스를 제어하는 주요 클래스를 나타냅니다. |
