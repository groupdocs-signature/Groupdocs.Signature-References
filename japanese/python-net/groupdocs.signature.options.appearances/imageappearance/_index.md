## ImageAppearance class

ImageAppearance 型は次のメンバーを公開します：

### コンストラクタ
| コンストラクタ | 説明 |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.options.appearances/imageappearance/__init__/) | デフォルト値で新しい ImageAppearance インスタンスを初期化します。 |

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [brightness](/signature/python-net/groupdocs.signature.options.appearances/imageappearance/brightness/) | 画像の明るさで、デフォルト値 1 は画像の元の明るさに相当します。 |
| [contrast](/signature/python-net/groupdocs.signature.options.appearances/imageappearance/contrast/) | 画像のコントラストです。デフォルト値は 1 で、画像の元のコントラストに相当します。 |
| [gamma_correction](/signature/python-net/groupdocs.signature.options.appearances/imageappearance/gamma_correction/) | 画像のガンマです。 |
