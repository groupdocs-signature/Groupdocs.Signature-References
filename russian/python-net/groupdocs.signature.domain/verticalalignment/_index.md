## VerticalAlignment class

Тип VerticalAlignment раскрывает следующие члены:

### Поля
| Поле | Описание |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/verticalalignment/none/) | Объект явно позиционируется, обычно с использованием свойства Top. |
| [TOP](/signature/python-net/groupdocs.signature.domain/verticalalignment/top/) | Указывает, что объект должен находиться в верхней части базового вертикального выравнивания. |
| [CENTER](/signature/python-net/groupdocs.signature.domain/verticalalignment/center/) | Указывает, что объект должен быть центрирован относительно базового вертикального выравнивания. |
| [BOTTOM](/signature/python-net/groupdocs.signature.domain/verticalalignment/bottom/) | Указывает, что объект должен находиться в нижней части базового вертикального выравнивания. |
