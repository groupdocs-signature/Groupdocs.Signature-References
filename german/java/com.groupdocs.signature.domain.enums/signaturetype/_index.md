Der Signaturtyp definiert die Methode zum Signieren.

## Felder

| Feld | Beschreibung |
| --- | --- |
|  | [Unknown](#Unknown) | Zeigt einen Fehler an, unbekannter Signaturtyp. |
|
|  | [Text](#Text) | Die Textsignatur - fügt formatierte Zeichenkette zum Dokument hinzu. |
|
|  | [Image](#Image) | Die Bildsignatur - fügt ein Bild an der angegebenen Dokumentposition ein. |
|
|  | [Barcode](#Barcode) | Die Barcodesignatur - signiert das Dokument mit einem Barcode. |
|
|  | [QrCode](#QrCode) | Die QR-Code-Signatur - signiert das Dokument mit einem QR-Code. |
|
|  | [Stamp](#Stamp) | Die Stempelsignatur - signiert das Dokument mit einem Stempel. |
|
|  | [Metadata](#Metadata) | Die Metadaten‑Signatur - fügt dem Dokument Metadaten‑Eigenschaften hinzu. |
|
|  | [FormField](#FormField) | Die Formularfeld‑Signatur - fügt dem Dokument Formularfeld‑Objekte hinzu. |
|
|  | [Digital](#Digital) | Die Digitale Signatur - signiert das Dokument mit einem digitalen Schlüssel. |
