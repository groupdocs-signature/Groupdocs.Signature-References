## return_content property

Le drapeau indiquant s'il faut récupérer le contenu de l'image du code-barres d'une signature placée sur une page de document.

Lorsqu’elle est définie sur True, le contenu de l’image de la signature de code‑barres est conservé sous forme de données d’image brutes dans le format spécifié par `return_content_type`. Par défaut, cette option est désactivée (False).
