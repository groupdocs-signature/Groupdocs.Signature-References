## EMF field

Enhanced Windows Metafile (.emf) αντιπροσωπεύει γραφικές εικόνες ανεξάρτητα από τη συσκευή. Τα meta‑files του EMF αποτελούνται από μεταβλητού μήκους εγγραφές σε χρονολογική σειρά που μπορούν να αποδώσουν την αποθηκευμένη εικόνα μετά την ανάλυση σε οποιαδήποτε έξοδος συσκευής.
