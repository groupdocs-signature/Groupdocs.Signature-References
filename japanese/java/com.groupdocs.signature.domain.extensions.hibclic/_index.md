**GroupDocs.Signature.Domain.Extensions.HIBCLIC** 名前空間は、HIBCLIC を扱うクラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [HIBCLICCombinedData](../com.groupdocs.signature.domain.extensions.hibclic/hibcliccombineddata) | 一次および二次データエンティティを含む、HIBC（Healthcare Industry Bar Code Council）LIC（Licensed Identification Code）結合データを格納するクラスです。 |
| [HIBCLICDateFormat](../com.groupdocs.signature.domain.extensions.hibclic/hibclicdateformat) | HIBC（Healthcare Industry Bar Code）LIC（Licensed Identification Code）の日付形式のさまざまなタイプを指定します。 |
| [HIBCLICPrimaryData](../com.groupdocs.signature.domain.extensions.hibclic/hibclicprimarydata) | HIBC（Healthcare Industry Bar Code Council）LIC（Licensed Identification Code）の一次データを格納するクラスです。 |
| [HIBCLICSecondaryAdditionalData](../com.groupdocs.signature.domain.extensions.hibclic/hibclicsecondaryadditionaldata) | HIBC（Healthcare Industry Bar Code Council）LIC（Licensed Identification Code）の二次および追加データを格納するクラス。 |
