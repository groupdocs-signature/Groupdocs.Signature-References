## ImageSearchOptions.ReturnContentType property

يحدد نوع ملف المحتوى المعاد للّ توقيع الصورة عندما تكون خاصية ReturnContent مفعلة. بشكل افتراضي يتم تعيينه إلى Null. وهذا يعني إرجاع محتوى الصورة بالتنسيق الأصلي. يتم تحديد تنسيق الصورة هذا في [`Format`](../../../groupdocs.signature.domain/imagesignature/format). القيم المدعومة الممكنة هي: FileType.JPEG, FileType.PNG, FileType.BMP. إذا كان التنسيق المقدم غير مدعوم فسيتم إرجاع محتوى الصورة بالتنسيق الأصلي.

public FileType ReturnContentType { get; set; }
