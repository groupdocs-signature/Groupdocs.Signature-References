## FileType.TIFF field

Tagged Image File Format (.tiff) mewakili gambar raster yang dimaksud untuk digunakan pada berbagai perangkat yang mematuhi standar format file ini. Format ini mampu menggambarkan data gambar bilevel, grayscale, palette-color, dan full-color dalam beberapa ruang warna. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/image/tiff).
