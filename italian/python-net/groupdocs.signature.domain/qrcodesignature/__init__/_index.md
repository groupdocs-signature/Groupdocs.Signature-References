## __init__ {#signature_id}

Inizializza un oggetto QrCodeSignature con un identificatore di firma ottenuto dopo un processo di ricerca.

L'identificatore univoco è usato per recuperare proprietà aggiuntive per questa firma dallo strato di informazioni sulla firma del documento.

```python
def __init__(self, signature_id):
    ...
```

| Parametro | Tipo | Descrizione |
| :- | :- | :- |
| signature_id | `str` | Identificatore unico della firma ottenuto tramite il metodo sign o search. |
