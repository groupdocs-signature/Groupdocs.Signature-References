## FileType.TIF field

Tagged Image File (.tif) stellt Rasterbilder dar, die für die Verwendung auf einer Vielzahl von Geräten gedacht sind, die diesem Dateiformatstandard entsprechen. Es kann bilevel‑, Graustufen‑, Paletten‑ und Vollfarbbilddaten in mehreren Farbräumen beschreiben. Erfahren Sie mehr über dieses Dateiformat [hier](https://wiki.fileformat.com/image/tiff).
