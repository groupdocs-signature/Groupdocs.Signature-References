## VerticalAlignment class

El tipo VerticalAlignment expone los siguientes miembros:

### Campos
| Campo | Descripción |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/verticalalignment/none/) | El objeto está posicionado explícitamente, usualmente usando su propiedad Top. |
| [TOP](/signature/python-net/groupdocs.signature.domain/verticalalignment/top/) | Especifica que el objeto debe estar en la parte superior de la base de alineación vertical. |
| [CENTER](/signature/python-net/groupdocs.signature.domain/verticalalignment/center/) | Especifica que el objeto debe estar centrado respecto a la base de alineación vertical. |
| [BOTTOM](/signature/python-net/groupdocs.signature.domain/verticalalignment/bottom/) | Especifica que el objeto debe estar en la parte inferior de la base de alineación vertical. |
