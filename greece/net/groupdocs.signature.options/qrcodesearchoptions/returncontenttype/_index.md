## QrCodeSearchOptions.ReturnContentType property

Καθορίζει τον τύπο αρχείου του επιστρεφόμενου περιεχομένου εικόνας της υπογραφής QR-Code όταν η ιδιότητα ReturnContent είναι ενεργοποιημένη. Προεπιλογή είναι Null. Αυτό σημαίνει ότι η εικόνα QR-Code θα επιστραφεί στην αρχική μορφή. Αυτή η μορφή εικόνας καθορίζεται στο [`Format`](../../../groupdocs.signature.domain/qrcodesignature/format). Πιθανές υποστηριζόμενες τιμές είναι: FileType.JPEG, FileType.PNG, FileType.BMP. Εάν η παρεχόμενη μορφή δεν υποστηρίζεται, τότε το περιεχόμενο εικόνας QR-Code στην αρχική .png θα επιστραφεί.

public FileType ReturnContentType { get; set; }
