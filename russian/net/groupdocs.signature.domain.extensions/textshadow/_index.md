## TextShadow class

Представляет свойства теней текста для текстовых подписей. Результат может различаться в зависимости от типа подписи и формата документа. Рекомендуется использовать TextShadow вместе с подписью TextAsImage для всех поддерживаемых типов документов, а также с простой TextSignature и TextSignature в качестве водяного знака для электронных таблиц (.xslx) и презентаций (.pptx). Простая TextSignature для Word (.docx) также рекомендуется, но имеет ограниченную функциональность.

```csharp
public class TextShadow : SignatureExtension
```
