## ProcessCompleteEventArgs class

Stellt Daten zum Abschlussereignis von Signatur-, Verifizierungs- und Suchvorgängen bereit.

Der ProcessCompleteEventArgs Typ stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [canceled](/signature/python-net/groupdocs.signature/processcompleteeventargs/canceled/) | Der Prozess wurde abgebrochen. |
| [completed](/signature/python-net/groupdocs.signature/processcompleteeventargs/completed/) | Der Zeitstempel des Prozessabschlusses. |
| [ticks](/signature/python-net/groupdocs.signature/processcompleteeventargs/ticks/) | Die seit dem Prozess-Startereignis vergangene Zeit in Millisekunden. |
| [total_signatures](/signature/python-net/groupdocs.signature/processcompleteeventargs/total_signatures/) | Die Gesamtanzahl der verarbeiteten Signaturen. |
| [status](/signature/python-net/groupdocs.signature/processeventargs/status/) | Der aktuelle Prozesszustand. (geerbt von [`ProcessEventArgs`](/signature/python-net/groupdocs.signature/processeventargs/)) |
