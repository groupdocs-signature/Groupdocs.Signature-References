## LoadOptions.WhitelistedResources property

Λαμβάνει ή ορίζει τμήματα διευθύνσεων εξωτερικών πόρων που φορτώνονται ακόμη και όταν το [`SkipExternalResources`](../skipexternalresources) είναι true. Η προεπιλεγμένη τιμή είναι μια κενή λίστα.

```csharp
public List<string> WhitelistedResources { get; set; }
```

### Παρατηρήσεις

Ένας πόρος φορτώνεται όταν η πλήρης διεύθυνσή του περιέχει ένα από τα τμήματα. Η σύγκριση αγνοεί τη διάκριση πεζών-κεφαλαίων, και τα κενά τμήματα αγνοούνται. Προτιμήστε μακρά τμήματα όπως "https://cdn.example.com/images/": ένα σύντομο τμήμα ταιριάζει επίσης με άλλες διευθύνσεις που τυχαία το περιέχουν.

Ορίζοντας αυτήν την ιδιότητα σε null καθαρίζει τη λίστα. Η λίστα δεν έχει καμία επίδραση όταν το [`SkipExternalResources`](../skipexternalresources) είναι false, επειδή τότε κάθε εξωτερικός πόρος φορτώνεται.
