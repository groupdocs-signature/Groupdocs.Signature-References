## BarcodeSearchOptions.ReturnContentType property

Specificeert het bestandstype van de geretourneerde afbeeldingsinhoud van de Barcode-handtekening wanneer de ReturnContent-eigenschap is ingeschakeld. Standaard is deze ingesteld op Null. Dat betekent dat de Barcode-afbeeldingsinhoud in het oorspronkelijke formaat wordt geretourneerd. Dit afbeeldingsformaat wordt gespecificeerd op [`Format`](../../../groupdocs.signature.domain/barcodesignature/format). Mogelijke ondersteunde waarden zijn: FileType.JPEG, FileType.PNG, FileType.BMP. Als het opgegeven formaat niet wordt ondersteund, wordt de Barcode-afbeeldingsinhoud in .png-formaat geretourneerd.

public FileType ReturnContentType { get; set; }
