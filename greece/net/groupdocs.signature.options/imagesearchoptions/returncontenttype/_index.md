## ImageSearchOptions.ReturnContentType property

Καθορίζει τον τύπο αρχείου του επιστρεφόμενου περιεχομένου της υπογραφής εικόνας όταν η ιδιότητα ReturnContent είναι ενεργοποιημένη. Από προεπιλογή ορίζεται σε Null. Αυτό σημαίνει ότι η εικόνα θα επιστραφεί στην αρχική μορφή. Αυτή η μορφή εικόνας καθορίζεται στο [`Format`](../../../groupdocs.signature.domain/imagesignature/format). Οι πιθανές υποστηριζόμενες τιμές είναι: FileType.JPEG, FileType.PNG, FileType.BMP. Εάν η παρεχόμενη μορφή δεν υποστηρίζεται, τότε το περιεχόμενο της εικόνας στην αρχική μορφή θα επιστραφεί.

```csharp
public FileType ReturnContentType { get; set; }
```
