## PPT field

PowerPoint Presentation (.ppt) は、スライドショーとして表示するスライドのコレクションで構成される PowerPoint ファイルを表します。これは Microsoft PowerPoint 97-2003 が使用するバイナリファイル形式を指定しています。このファイル形式の詳細については、こちらをご覧ください。
