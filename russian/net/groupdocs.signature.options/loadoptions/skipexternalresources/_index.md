## LoadOptions.SkipExternalResources property

Получает или задает флаг, который останавливает загрузку внешних ресурсов документом. Значение по умолчанию — true: внешние ресурсы не загружаются, за исключением тех, которые соответствуют [`WhitelistedResources`](../whitelistedresources).

```csharp
public bool SkipExternalResources { get; set; }
```

### Примечания

Документ может ссылаться на ресурсы, хранящиеся за его пределами: связанные изображения, картинки, вставленные полем INCLUDEPICTURE, связанные изображения в презентациях и электронных таблицах, а также изображения и таблицы стилей, на которые ссылается SVG‑изображение. Загрузка такого ресурса заставляет библиотеку запрашивать его адрес. На сервере, обрабатывающем недоверенные документы, документ может использовать это для отправки сервером запросов к внутренним адресам (подделка запросов со стороны сервера), а путь UNC или file:// может заставить Windows передать учетные данные NTLM аккаунта другому хосту. В офлайн‑или изолированной установке запросы завершаются ошибкой или ждут истечения тайм‑аута.

Ресурсы, которые пропускаются, не отображаются в предварительном просмотре страниц и в документах, сохранённых как изображения, и поиск изображений, штрих‑кодов и QR‑кодов их не видит. Устанавливайте это свойство в false только для доверенных документов и предпочтительно разрешайте конкретные адреса с помощью [`WhitelistedResources`](../whitelistedresources).

Эта настройка применяется к документам обработки текста, презентациям, электронным таблицам и SVG‑изображениям, включая документы внутри архивов. Для SVG‑изображений ссылки, которые не разрешены, удаляются из изображения перед его чтением, а SVG‑изображение, которое не является корректным XML, отклоняется. Настройка не управляет проверками отзыва сертификатов, серверами временных меток или лицензированием.

Это свойство заменяет LoadExternalResources, которое имеет противоположное значение.
