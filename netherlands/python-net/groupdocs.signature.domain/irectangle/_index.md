## IRectangle class

Definieert interface-eigenschappen voor het handtekeninggebied op een documentpagina.

Het type IRectangle bevat de volgende leden:

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [height](/signature/python-net/groupdocs.signature.domain/irectangle/height/) | De hoogte van het handtekeninggebied op een documentpagina in meeteenheden (pixels, procenten of millimeters; zie `MeasureType` SizeMeasureType). |
| [left](/signature/python-net/groupdocs.signature.domain/irectangle/left/) | De linkse X‑positie van het handtekeninggebied op een documentpagina in meeteenheden (pixels, procenten of millimeters). Zie `MeasureType` voor de `LocationMeasureType`‑enumeratie. |
| [location_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/location_measure_type/) | Het meettype (pixels, procenten of millimeters) voor de eigenschappen Left en Top. |
| [size_measure_type](/signature/python-net/groupdocs.signature.domain/irectangle/size_measure_type/) | Het meettype (pixels, procenten of millimeters) voor de eigenschappen Width en Height. |
| [stretch](/signature/python-net/groupdocs.signature.domain/irectangle/stretch/) | De stretch‑modus op een documentpagina. |
| [top](/signature/python-net/groupdocs.signature.domain/irectangle/top/) | De bovenste Y‑positie van het handtekeninggebied op de documentpagina in meeteenheden (pixels, procenten of millimeters). Zie `MeasureType` voor het meettype van de locatie. |
| [width](/signature/python-net/groupdocs.signature.domain/irectangle/width/) | De breedte van het handtekeninggebied op een documentpagina in meetwaarden (pixels, procenten of millimeters). Zie `MeasureType` SizeMeasureType. |
