## SignatureSettings.IncludeStandardMetadataSignatures property

Liest oder setzt das Flag, um in die Metadatenliste die eingebetteten Standard‑Dokumentmetadaten‑Signaturen wie Autor, Eigentümer, Erstellungsdatum des Dokuments, Änderungsdatum usw. aufzunehmen. Wenn dieses Flag auf false (standardmäßig) gesetzt ist, werden diese Metadaten‑Signaturen von GetDocumentInfo nicht einbezogen. Wird das Flag auf true gesetzt, enthält die Dokumentinformation diese Standard‑Metadaten‑Signaturen.

public bool IncludeStandardMetadataSignatures { get; set; }
