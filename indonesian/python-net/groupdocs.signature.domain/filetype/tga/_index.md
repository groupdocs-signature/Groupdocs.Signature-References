## TGA field

Truevision TGA (.tga), juga dikenal sebagai TARGA, adalah format file gambar raster yang dikembangkan oleh Truevision Inc. Format ini mendukung berbagai kedalaman warna dan kompresi RLE opsional. File TGA biasanya digunakan dalam video game, alur kerja animasi, dan aplikasi grafis untuk rendering gambar berkualitas tinggi dengan dukungan saluran alfa opsional. Pelajari lebih lanjut tentang format file ini di sini.
