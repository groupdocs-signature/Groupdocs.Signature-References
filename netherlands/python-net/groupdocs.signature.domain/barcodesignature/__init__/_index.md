## __init__ {#signature_id}

Initialiseert een BarcodeSignature-object met een handtekeningidentificatie verkregen na een zoekproces. De identificatie wordt gebruikt om extra eigenschappen voor deze handtekening op te halen uit de handtekeninginformatie‑laag van het document.

```python
def __init__(self, signature_id):
    ...
```

| Parameter | Type | Beschrijving |
| :- | :- | :- |
| signature_id | `str` | Unieke handtekening‑identificatie verkregen via de `Sign`‑ of `Search`‑methode van `Signature`. |
