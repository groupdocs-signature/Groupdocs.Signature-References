Den **GroupDocs.Signature** namnutrymme tillhandahåller klasser för att signera dokument i olika format med stämplar, streckkoder, QR-koder, text, bild, metadata, formulärfält och digitala signaturer.



## Klasser

| Klass | Beskrivning |
| --- | --- |
| [Signature](../com.groupdocs.signature/signature) | Representerar huvudklassen som styr dokumentets signeringsprocess. |
| [SignatureSettings](../com.groupdocs.signature/signaturesettings) | Definierar inställningar för att anpassa beteendet för [Signature](../com.groupdocs.signature/signature). |
