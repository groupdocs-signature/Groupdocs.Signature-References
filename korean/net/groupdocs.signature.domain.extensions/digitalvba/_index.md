## DigitalVBA class

Spreadsheets VBA 프로젝트에 대한 디지털 서명을 나타냅니다. Xlsm 또는 Xltm과 같은 특정 Spreadsheets 문서 형식에서 VBA 프로젝트에 서명할 수 있는 기능을 제공합니다. DigitalSignOptions.Extensions에 여러 DigitalVBA 확장이 추가된 경우, 첫 번째만 문서 서명에 사용됩니다.

public class DigitalVBA : SignatureExtension
