## GifSaveOptions.ColorResolution property

GIF 색 해상도를 가져오거나 설정합니다.

```csharp
public byte ColorResolution { get; set; }
```

### 비고

Color Resolution - 원본 이미지에서 사용할 수 있는 기본 색상당 비트 수에서 1을 뺀 값입니다. 이 값은 그래픽에서 선택된 색상이 아닌 전체 팔레트의 크기를 나타냅니다. 예를 들어, 이 필드의 값이 3이면 원본 이미지의 팔레트는 기본 색상당 4비트를 사용하여 이미지를 생성할 수 있음을 의미합니다. 이 값은 전체 팔레트의 모든 색상이 소스 머신에 존재하지 않더라도 원본 팔레트의 풍부함을 나타내도록 설정해야 합니다.
