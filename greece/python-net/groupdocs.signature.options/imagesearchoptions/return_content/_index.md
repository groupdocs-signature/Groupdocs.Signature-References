## return_content property

Η σημαία που καθορίζει αν επιστρέφεται το περιεχόμενο εικόνας μιας υπογραφής.

Εάν οριστεί σε True, το περιεχόμενο της υπογραφής εικόνας διατηρείται ως ακατέργαστα δεδομένα εικόνας στη μορφή που καθορίζεται από [`ImageSearchOptions.return_content_type`](/signature/python-net/groupdocs.signature.options/imagesearchoptions/return_content_type/). Από προεπιλογή αυτή η επιλογή είναι απενεργοποιημένη (False).
