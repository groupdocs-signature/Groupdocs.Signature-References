Ο ονοματοχώρος παρέχει κλάσεις για πρόσθετες εμφανίσεις υπογραφών.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [DigitalSignatureAppearance](./digitalsignatureappearance) | Περιγράφει την εμφάνιση της Γραμμής Υπογραφής για Ψηφιακή Υπογραφή. Μια Γραμμή Υπογραφής μπορεί να εφαρμοστεί μόνο για μία Ψηφιακή Υπογραφή. Η Γραμμή Υπογραφής βρίσκεται πάντα στην πρώτη σελίδα. Αυτή η δυνατότητα μπορεί να είναι χρήσιμη για μορφές αρχείων .docx, .doc, .odt και .xlsx. |
| [ImageAppearance](./imageappearance) | Περιγράφει επεκταμένες δυνατότητες εμφάνισης για την Υπογραφή Εικόνας. |
| [PdfDigitalSignatureAppearance](./pdfdigitalsignatureappearance) | Περιγράφει την εμφάνιση της Ψηφιακής Υπογραφής σε έγγραφα PDF. |
| [PdfTextAnnotationAppearance](./pdftextannotationappearance) | Περιγράφει την εμφάνιση του αντικειμένου σχολιασμού κειμένου PDF (Τίτλος, Θέμα, Περιεχόμενο). |
| [PdfTextStickerAppearance](./pdftextstickerappearance) | Περιγράφει την εμφάνιση του αντικειμένου αυτοκόλλητου σχολιασμού κειμένου PDF και του αναδυόμενου παραθύρου του αυτοκόλλητου. |
| [SignatureAppearance](./signatureappearance) | Αντιπροσωπεύει την εμφάνιση της υπογραφής - πρόσθετες επιλογές για εναλλακτικές υλοποιήσεις υπογραφής στη σελίδα του εγγράφου. |
