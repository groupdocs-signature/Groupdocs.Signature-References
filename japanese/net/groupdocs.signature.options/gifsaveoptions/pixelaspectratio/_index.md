### 備考

Pixel Aspect Ratio - 元画像のピクセルのアスペクト比の近似値を計算するために使用される係数です。フィールドの値が 0 でない場合、このアスペクト比の近似は次の式に基づいて計算されます: Aspect Ratio = (Pixel Aspect Ratio + 15) / 64 Pixel Aspect Ratio はピクセルの幅を高さで割った商として定義されます。このフィールドの値範囲は、最も広いピクセル 4:1 から最も高いピクセル 1:4 までを 1/64 単位で指定できます。Values : 0 - アスペクト比情報が提供されていません。1..255 - 計算に使用される値。
