## SignResult class

Rappresenta il risultato del processo di firma per un documento con firme appena create.

Il tipo SignResult espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/signresult/destin_document_size/) | La dimensione del documento di destinazione. |
| [failed](/signature/python-net/groupdocs.signature.domain/signresult/failed/) | L'elenco delle firme che non sono state create. |
| [processing_time](/signature/python-net/groupdocs.signature.domain/signresult/processing_time/) | Il tempo di esecuzione del processo in millisecondi. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/signresult/source_document_size/) | La dimensione del documento di origine. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/signresult/succeeded/) | L'elenco delle firme appena create [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/signresult/total_signatures/) | Il totale delle firme elaborate. |
