## TextShadow class

Representerar egenskaper för textskugga för textsignaturer. Resultatet kan variera beroende på signaturtyp och dokumentformat. TextShadow rekommenderas för användning med TextAsImage-signatur för alla stödda dokumenttyper, även med enkel TextSignature och TextSignature som vattenstämpel för kalkylblad (.xslx) och presentationer (.pptx). Enkel TextSignature för Word (.docx) rekommenderas också, men har begränsad funktionalitet.

public class TextShadow : SignatureExtension
