### None {#None}
```
public static final int None
```


Προεπιλεγμένη τιμή. Δεν θα εφαρμοστεί λειτουργία τέντωσης.


### PageWidth {#PageWidth}
```
public static final int PageWidth
```


Τεντώστε την περιοχή υπογραφής κατά το πλάτος της σελίδας. Η ιδιότητα Margin θα χρησιμοποιηθεί για την εφαρμογή των απαιτούμενων τιμών μετατόπισης


### PageHeight {#PageHeight}
```
public static final int PageHeight
```


Τεντώστε την περιοχή υπογραφής κατά το ύψος της σελίδας. Η ιδιότητα Margin θα χρησιμοποιηθεί για την εφαρμογή των απαιτούμενων τιμών μετατόπισης.


### PageArea {#PageArea}
```
public static final int PageArea
```


Τεντώστε την περιοχή υπογραφής κατά το ύψος και το πλάτος της σελίδας. Η ιδιότητα Margin θα χρησιμοποιηθεί για την εφαρμογή των απαιτούμενων τιμών μετατόπισης.
