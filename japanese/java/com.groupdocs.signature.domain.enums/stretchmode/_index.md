### None {#None}
```
public static final int None
```


デフォルト値。ストレッチモードは適用されません。


### PageWidth {#PageWidth}
```
public static final int PageWidth
```


ページ幅に沿って署名領域を伸長します。必要なオフセット値を適用するために Margin プロパティが使用されます


### PageHeight {#PageHeight}
```
public static final int PageHeight
```


ページ高さに沿って署名領域を伸長します。必要なオフセット値を適用するために Margin プロパティが使用されます。


### PageArea {#PageArea}
```
public static final int PageArea
```


ページの高さと幅に沿って署名領域を伸長します。必要なオフセット値を適用するために Margin プロパティが使用されます。
