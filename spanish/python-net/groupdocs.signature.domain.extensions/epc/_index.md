### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [amount](/signature/python-net/groupdocs.signature.domain.extensions/epc/amount/) | El importe. |
| [bic](/signature/python-net/groupdocs.signature.domain.extensions/epc/bic/) | El BIC del beneficiario con una longitud de hasta 11 caracteres. |
| [charset](/signature/python-net/groupdocs.signature.domain.extensions/epc/charset/) | La implementación del conjunto de caracteres EPC / SEPA QR-Code; por defecto este valor se establece en 1. |
| [code](/signature/python-net/groupdocs.signature.domain.extensions/epc/code/) | El código de negocio, de hasta 4 caracteres. |
| [iban](/signature/python-net/groupdocs.signature.domain.extensions/epc/iban/) | La cuenta del beneficiario (IBAN). |
| [identification](/signature/python-net/groupdocs.signature.domain.extensions/epc/identification/) | La identificación EPC / SEPA QR-Code. Por defecto, este valor se establece en SCT. |
| [information](/signature/python-net/groupdocs.signature.domain.extensions/epc/information/) | La información de pista, con una longitud máxima de 70 caracteres. |
| [name](/signature/python-net/groupdocs.signature.domain.extensions/epc/name/) | El nombre del beneficiario con una longitud máxima de 70 caracteres. |
| [reference](/signature/python-net/groupdocs.signature.domain.extensions/epc/reference/) | La referencia de pago (máximo 35 caracteres). |
| [remittance](/signature/python-net/groupdocs.signature.domain.extensions/epc/remittance/) | La información de remesa (máximo 140 caracteres). |
| [version](/signature/python-net/groupdocs.signature.domain.extensions/epc/version/) | La implementación de la versión EPC / SEPA QR-Code, por defecto "002". |
