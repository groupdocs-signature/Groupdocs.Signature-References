## QrCodeSignOptions.ReturnContent property

Liest oder setzt das Flag, um den QR‑Code‑Bildinhalt einer Signatur zu erhalten, die auf einer Dokumentseite platziert wurde. Wenn dieses Flag auf true gesetzt ist, behält der QR‑Code‑Signatur‑Bildinhalt die Rohbilddaten im erforderlichen Format [`ReturnContentType`](../returncontenttype). Standardmäßig ist diese Option deaktiviert.

public bool ReturnContent { get; set; }
