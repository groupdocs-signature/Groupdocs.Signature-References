## DigitalSignatureAppearance class

Décrit l'apparence de la ligne de signature pour la signature numérique. Une ligne de signature ne peut être appliquée qu'à une seule signature numérique. La ligne de signature se trouve toujours sur la première page. Cette fonctionnalité peut être utile pour les formats de fichiers .docx, .doc, .odt et .xlsx.
