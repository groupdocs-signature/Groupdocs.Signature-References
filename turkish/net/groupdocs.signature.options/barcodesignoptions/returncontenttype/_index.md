## BarcodeSignOptions.ReturnContentType property

ReturnContent özelliği etkin olduğunda Barcode imzasının döndürülen görüntü içeriğinin dosya türünü belirtir. Varsayılan olarak Null olarak ayarlanır. Bu, Barcode görüntü içeriğinin orijinal formatta döndürüleceği anlamına gelir. Bu görüntü formatı [`Format`](../../../groupdocs.signature.domain/barcodesignature/format) adresinde belirtilir. Olası desteklenen değerler: FileType.JPEG, FileType.PNG, FileType.BMP. Sağlanan format desteklenmiyorsa Barcode görüntü içeriği .png formatında döndürülecektir.

public FileType ReturnContentType { get; set; }
