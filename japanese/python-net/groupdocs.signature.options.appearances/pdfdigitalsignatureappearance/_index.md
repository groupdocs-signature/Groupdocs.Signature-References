| プロパティ | 説明 |
| :- | :- |

| [location_label](/signature/python-net/groupdocs.signature.options.appearances/pdfdigitalsignatureappearance/location_label/) | デジタル署名領域に表示される場所ラベル（デフォルトは "Location"）です。空文字列に設定した場合、場所ラベルは表示されません。 |
| [reason_label](/signature/python-net/groupdocs.signature.options.appearances/pdfdigitalsignatureappearance/reason_label/) | デジタル署名領域に表示される理由ラベルです。 |
