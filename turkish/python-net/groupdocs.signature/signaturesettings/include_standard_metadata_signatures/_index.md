## include_standard_metadata_signatures property

Standart belge meta verisi imzaları (Yazar, Sahip, oluşturma tarihi ve değiştirilme tarihi gibi) meta veri listesine dahil edilip edilmediğini gösteren bayrak.

False (varsayılan) olarak ayarlanırsa, GetDocumentInfo bu metadata imzalarını içermez. True olarak ayarlandığında, belge bilgileri standart metadata imzalarını içerir.
