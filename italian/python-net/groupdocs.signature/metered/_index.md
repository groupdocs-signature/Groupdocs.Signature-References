## Metered class

Gestisce la licenza a consumo (pay-per-use).

Le licenze Metered fatturano in base al consumo reale (tipicamente pagine o
documenti elaborati). Imposta la coppia di chiavi pubblica/privata una volta al
avvio dell'applicazione; il wrapper segnala l'utilizzo al GroupDocs
server di licenza in background.

Il tipo Metered espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [get_consumption_credit](/signature/python-net/groupdocs.signature/metered/get_consumption_credit/) | Restituisce il numero di crediti consumati finora. |
| [get_consumption_quantity](/signature/python-net/groupdocs.signature/metered/get_consumption_quantity/) | Restituisce la quantità di dati elaborati finora. |
| [set_metered_key](/signature/python-net/groupdocs.signature/metered/set_metered_key/#public_key-private_key) | Attiva la fatturazione metered con la coppia di chiavi pubblica/privata fornita. |
