## min_content_size property

Die minimale Größe von Bilddaten, in Bytes, die bei einer Suche berücksichtigt werden soll. Ein von Null verschiedener Wert gibt die minimale Größe an; der Standardwert ist Null, was das Suchergebnis nicht beeinflusst.
