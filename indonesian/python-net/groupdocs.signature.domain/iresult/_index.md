| Properti | Deskripsi |

| [destin_document_size](/signature/python-net/groupdocs.signature.domain/iresult/destin_document_size/) | Ukuran dokumen tujuan. |
| [failed](/signature/python-net/groupdocs.signature.domain/iresult/failed/) | Daftar tanda tangan yang tidak diproses. |
| [processing_time](/signature/python-net/groupdocs.signature.domain/iresult/processing_time/) | Waktu eksekusi proses dalam milidetik. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/iresult/source_document_size/) | Ukuran dokumen sumber. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/iresult/succeeded/) | Daftar tanda tangan yang berhasil diproses [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
