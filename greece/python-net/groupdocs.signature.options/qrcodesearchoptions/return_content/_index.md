## return_content property

Η σημαία που καθορίζει εάν το περιεχόμενο εικόνας QR‑Code επιστρέφεται για κάθε υπογραφή σε μια σελίδα εγγράφου. Όταν ορίζεται σε True, τα ακατέργαστα δεδομένα εικόνας διατηρούνται στην ιδιότητα `content` της υπογραφής χρησιμοποιώντας τη μορφή που καθορίζεται από το `return_content_type`.
