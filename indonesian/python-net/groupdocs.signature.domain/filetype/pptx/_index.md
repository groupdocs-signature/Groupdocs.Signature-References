## PPTX field

PowerPoint Open XML Presentation (.pptx) adalah file presentasi yang dibuat dengan aplikasi Microsoft PowerPoint yang populer. Tidak seperti versi sebelumnya dari format file presentasi PPT yang bersifat biner, format PPTX berbasis pada format file presentasi open XML Microsoft PowerPoint. Pelajari lebih lanjut tentang format file ini di sini.
