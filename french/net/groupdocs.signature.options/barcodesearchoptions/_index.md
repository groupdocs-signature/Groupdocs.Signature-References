## Propriétés

| Nom | Description |
| --- | --- |
| [AllPages](../../groupdocs.signature.options/searchoptions/allpages) { get; set; } | Indicateur pour rechercher sur chaque page du document. Par défaut, cette valeur est définie sur true. |
| [EncodeType](../../groupdocs.signature.options/barcodesearchoptions/encodetype) { get; set; } | Spécifie la propriété Encode Type pour rechercher les codes-barres. Si cette valeur n'est pas définie, la recherche est effectuée pour tous les types de codes-barres pris en charge. |
| [MatchType](../../groupdocs.signature.options/barcodesearchoptions/matchtype) { get; set; } | Obtient ou définit la recherche du type de correspondance du texte du code-barres. Elle n'est utilisée que lorsque la propriété Text est définie. |
| [PageNumber](../../groupdocs.signature.options/searchoptions/pagenumber) { get; set; } | Obtient ou définit le numéro de page du document pour la recherche. La valeur est facultative. |
| [PagesSetup](../../groupdocs.signature.options/searchoptions/pagessetup) { get; set; } | Options pour spécifier les pages pour la recherche de signature. |
| [ReturnContent](../../groupdocs.signature.options/barcodesearchoptions/returncontent) { get; set; } | Obtient ou définit le drapeau permettant de récupérer le contenu image du code-barres d'une signature sur la page du document. Si ce drapeau est vrai, le contenu image de la signature du code-barres conservera les données brutes au format requis [`ReturnContentType`](./returncontenttype). Par défaut, cette option est désactivée. |
| [ReturnContentType](../../groupdocs.signature.options/barcodesearchoptions/returncontenttype) { get; set; } | Spécifie le type de fichier du contenu image retourné de la signature Barcode lorsque la propriété ReturnContent est activée. Par défaut, il est réglé sur Null. Cela signifie retourner le contenu image du Barcode au format original. Ce format d'image est spécifié à [`Format`](../../groupdocs.signature.domain/barcodesignature/format). Les valeurs prises en charge possibles sont : FileType.JPEG, FileType.PNG, FileType.BMP. Si le format fourni n'est pas supporté, le contenu image du Barcode sera retourné au format .png. |
| [ShapePosition](../../groupdocs.signature.options/searchoptions/shapeposition) { get; set; } | Indicateur pour retourner la position de forme spécifiée dans la mise en page du document. Disponible uniquement pour les documents Word. |
| [SkipExternal](../../groupdocs.signature.options/searchoptions/skipexternal) { get; set; } | Indicateur pour ne retourner que les signatures marquées comme IsSignature. Par défaut, la valeur est false, ce qui indique de retourner toutes les signatures qui correspondent aux critères spécifiés. |
| [Text](../../groupdocs.signature.options/barcodesearchoptions/text) { get; set; } | Spécifie le texte de la signature du code-barres s'il doit être recherché et correspondre. |
