## warning {#message}

Écrit un message d’avertissement dans la console. Les messages d’avertissement du journal fournissent des informations sur les événements inattendus et récupérables dans le flux de l’application.

```python
def warning(self, message):
    ...
```

| Paramètre | Type | Description |
| :- | :- | :- |
| message | `str` | Le message d'avertissement. |

| Lève | Description |
| :- | :- |
| `ValueError` | Si `message` est None. |
