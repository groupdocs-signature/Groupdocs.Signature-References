## show_properties property

Le drapeau qui force les propriétés de la signature à être affichées ou masquées ; lorsqu'il est vrai, le champ de signature utilise un format d'apparence prédéfini (par ex., `Digitally signed by {PdfDigitalSignature.contact_info} Date: {Date} Reason: {PdfDigitalSignature.reason} Location: {PdfDigitalSignature.location}`) et la valeur par défaut est True.
