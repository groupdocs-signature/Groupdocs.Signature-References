## DigitalVBA class

Spreadsheets VBA प्रोजेक्ट्स के लिए डिजिटल हस्ताक्षर दर्शाता है। यह Xlsm या Xltm जैसे विशिष्ट Spreadsheets दस्तावेज़ स्वरूपों पर VBA प्रोजेक्ट पर हस्ताक्षर करने की क्षमता प्रदान करता है। यदि कई DigitalVBA एक्सटेंशन DigitalSignOptions.Extensions में जोड़े जाते हैं, तो केवल पहला दस्तावेज़ हस्ताक्षर में शामिल होता है।

```csharp
public class DigitalVBA : SignatureExtension
```
