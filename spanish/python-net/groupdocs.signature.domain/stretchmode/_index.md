## StretchMode class

El tipo StretchMode expone los siguientes miembros:

### Campos
| Campo | Descripción |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/stretchmode/none/) | Valor predeterminado. No se aplicará ningún modo de estiramiento. |
| [PAGE_WIDTH](/signature/python-net/groupdocs.signature.domain/stretchmode/page_width/) | Estira el área de la firma a lo largo del ancho de la página. La propiedad Margin se usará para aplicar los valores de desplazamiento requeridos. |
| [PAGE_HEIGHT](/signature/python-net/groupdocs.signature.domain/stretchmode/page_height/) | Estira el área de la firma a lo largo de la altura de la página. La propiedad Margin se usará para aplicar los valores de desplazamiento requeridos. |
| [PAGE_AREA](/signature/python-net/groupdocs.signature.domain/stretchmode/page_area/) | Estira el área de la firma a lo largo de la altura y el ancho de la página. La propiedad Margin se usará para aplicar los valores de desplazamiento requeridos. |
