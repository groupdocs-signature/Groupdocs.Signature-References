## BaseSignature class

Rappresenta la classe base per le firme.

Il tipo BaseSignature espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [clone](/signature/python-net/groupdocs.signature.domain/basesignature/clone/) | Clona l'istanza della firma. |
| [equals](/signature/python-net/groupdocs.signature.domain/basesignature/equals/#obj) | Confronta l'oggetto firma fornito con questa istanza per uguaglianza. |
| [equals_object](/signature/python-net/groupdocs.signature.domain/basesignature/equals_object/) |  |
| [get_hash_code](/signature/python-net/groupdocs.signature.domain/basesignature/get_hash_code/) | Fornisce un'implementazione sovrascritta di GetHashCode. |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [created_on](/signature/python-net/groupdocs.signature.domain/basesignature/created_on/) | La data di creazione della firma. |
| [deleted](/signature/python-net/groupdocs.signature.domain/basesignature/deleted/) | Il flag che indica se questa firma è stata eliminata dal documento. |
| [height](/signature/python-net/groupdocs.signature.domain/basesignature/height/) | L'altezza della firma. |
| [is_signature](/signature/python-net/groupdocs.signature.domain/basesignature/is_signature/) | Il flag che indica se questo componente rappresenta una firma (`True`) o contenuto del documento (`False`). |
| [left](/signature/python-net/groupdocs.signature.domain/basesignature/left/) | La posizione sinistra della firma. |
| [modified_on](/signature/python-net/groupdocs.signature.domain/basesignature/modified_on/) | La data di modifica della firma. |
| [page_number](/signature/python-net/groupdocs.signature.domain/basesignature/page_number/) | Il numero di pagina dove è stata trovata la firma. |
| [signature_id](/signature/python-net/groupdocs.signature.domain/basesignature/signature_id/) | L'identificatore univoco della firma, usato per modificare la firma nel documento tramite operazioni di aggiornamento o eliminazione. |
| [signature_type](/signature/python-net/groupdocs.signature.domain/basesignature/signature_type/) | Il tipo di firma. |
| [top](/signature/python-net/groupdocs.signature.domain/basesignature/top/) | La posizione superiore della firma. |
| [width](/signature/python-net/groupdocs.signature.domain/basesignature/width/) | La larghezza della firma. |
