## XLS field

Excel Spreadsheet (.xls) mewakili Format File Biner Excel. File semacam itu dapat dibuat oleh Microsoft Excel maupun program spreadsheet serupa lainnya seperti OpenOffice Calc atau Apple Numbers. Pelajari lebih lanjut tentang format file ini di sini.
