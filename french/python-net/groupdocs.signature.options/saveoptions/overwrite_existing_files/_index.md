## overwrite_existing_files property

Le drapeau indiquant s'il faut écraser un fichier existant avec le nouveau fichier de sortie.

Si False, un nouveau fichier sera créé avec un suffixe numérique. La valeur par défaut est True, ce qui signifie que le fichier sera écrasé.
