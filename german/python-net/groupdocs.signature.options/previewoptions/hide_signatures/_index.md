## hide_signatures property

Das Flag, das angibt, ob Signaturen in den Seitenvorschau-Bildern ausgeblendet sind.

Nur Signaturen, die als `IsSignature` markiert sind, werden vom erzeugten Dokumentseitenbild ausgeblendet.
