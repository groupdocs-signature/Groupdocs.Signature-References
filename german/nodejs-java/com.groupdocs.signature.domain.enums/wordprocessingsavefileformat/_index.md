Definiert verschiedene Dateispeicherformate für Textverarbeitungsdokumente.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [Default](#Default) | Dateiformat wird nicht geändert. |
| [Doc](#Doc) | Speichert das Dokument als Microsoft Word 97-2003-Dokument. |
| [Dot](#Dot) | Speichert das Dokument als Microsoft Word 97-2003-Vorlage. |
| [Docx](#Docx) | Speichert das Dokument als Microsoft Word OpenXML-Dokument. |
| [Docm](#Docm) | Speichert das Dokument als Microsoft Word OpenXML-Makro-aktiviertes Dokument. |
| [Dotx](#Dotx) | Speichert das Dokument als Microsoft Word OpenXML-Vorlage. |
| [Dotm](#Dotm) | Speichert das Dokument als Microsoft Word OpenXML-Makro-aktivierte Vorlage. |
| [FlatOpc](#FlatOpc) | Speichert das Dokument als Office Open XML WordprocessingML, das in einer flachen XML-Datei anstelle eines ZIP-Pakets gespeichert ist. |
| [FlatOpcMacroEnabled](#FlatOpcMacroEnabled) | Speichert das Dokument als Office Open XML WordprocessingML-Makro-aktiviertes Dokument, das in einer flachen XML-Datei anstelle eines ZIP-Pakets gespeichert ist. |
| [FlatOpcTemplate](#FlatOpcTemplate) | Speichert das Dokument als Office Open XML WordprocessingML-Vorlage (makrofrei), die in einer flachen XML-Datei anstelle eines ZIP-Pakets gespeichert ist. |
| [FlatOpcTemplateMacroEnabled](#FlatOpcTemplateMacroEnabled) | Speichert das Dokument als Office Open XML WordprocessingML-Makro-aktivierte Vorlage, die in einer flachen XML-Datei anstelle eines ZIP-Pakets gespeichert ist. |
| [Rtf](#Rtf) | Speichert das Dokument im RTF-Format. |
| [WordML](#WordML) | Speichert das Dokument im Microsoft Word 2003 WordprocessingML-Format. |
| [Pdf](#Pdf) | Speichert das Dokument im PDF (Adobe Portable Document)-Format. |
| [Xps](#Xps) | Speichert das Dokument im XPS (XML Paper Specification)-Format. |
| [Ps](#Ps) | Speichert das Dokument im PS (PostScript)-Format. |
| [Mhtml](#Mhtml) | Speichert das Dokument im MHTML (Web-Archiv)-Format. |
| [Epub](#Epub) | Speichert das Dokument im IDPF EPUB-Format. |
| [Odt](#Odt) | Speichert das Dokument als Open Office-Dokument. |
| [Ott](#Ott) | Speichert das Dokument als Open Office-Dokumentvorlage. |
| [Text](#Text) | Speichert das Dokument im Nur-Text-Format. |
| [Tiff](#Tiff) | Rendert eine Seite oder mehrere Seiten des Dokuments und speichert sie in einer einzelnen oder mehrseitigen TIFF-Datei. |
| [Png](#Png) | Rendert eine Seite des Dokuments und speichert sie als PNG-Datei. |
| [Bmp](#Bmp) | Rendert eine Seite des Dokuments und speichert sie als BMP-Datei. |
| [Emf](#Emf) | Rendert eine Seite des Dokuments und speichert sie als Vektor-EMF (Enhanced Meta File)-Datei. |
| [Jpeg](#Jpeg) | Rendert eine Seite des Dokuments und speichert sie als JPEG-Datei. |
| [Azw3](#Azw3) | Rendert eine Seite des Dokuments und speichert sie als Azw3-Datei. |
