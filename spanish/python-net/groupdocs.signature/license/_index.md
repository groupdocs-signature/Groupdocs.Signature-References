## License class

Administra la licencia de GroupDocs.Signature.

Las compilaciones con licencia desbloquean el conjunto completo de funciones del contenedor en
tiempo de ejecución. Las compilaciones sin licencia se ejecutan en modo de evaluación con la misma API
superficie pero con límites en el tamaño de salida y contenido con marca de agua.

El tipo License expone los siguientes miembros:

### Métodos
| Método | Descripción |
| :- | :- |
| [set_license](/signature/python-net/groupdocs.signature/license/set_license/#license_source) | Aplica una licencia al proceso actual. |
