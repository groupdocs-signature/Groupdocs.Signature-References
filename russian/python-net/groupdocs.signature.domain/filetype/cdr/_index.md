## CDR field

CorelDraw Vector Graphic Drawing (.cdr) — это векторный графический файл, который изначально создаётся в CorelDRAW для хранения цифрового изображения в закодированном и сжатом виде. Такой файл рисунка содержит текст, линии, формы, изображения, цвета и эффекты для векторного представления содержимого изображения. Узнайте больше об этом формате файла здесь.
