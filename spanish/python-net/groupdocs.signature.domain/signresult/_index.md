## SignResult class

Representa el resultado del proceso de firma de un documento con firmas recién creadas.

El tipo SignResult expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [destin_document_size](/signature/python-net/groupdocs.signature.domain/signresult/destin_document_size/) | El tamaño del documento de destino. |
| [failed](/signature/python-net/groupdocs.signature.domain/signresult/failed/) | La lista de firmas que no se pudieron crear. |
| [processing_time](/signature/python-net/groupdocs.signature.domain/signresult/processing_time/) | El tiempo de ejecución del proceso en milisegundos. |
| [source_document_size](/signature/python-net/groupdocs.signature.domain/signresult/source_document_size/) | El tamaño del documento de origen. |
| [succeeded](/signature/python-net/groupdocs.signature.domain/signresult/succeeded/) | La lista de firmas recién creadas [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/). |
| [total_signatures](/signature/python-net/groupdocs.signature.domain/signresult/total_signatures/) | El total de firmas procesadas. |
