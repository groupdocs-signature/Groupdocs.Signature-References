## TextSignatureImplementation class

Тип TextSignatureImplementation раскрывает следующие члены:

### Поля
| Поле | Описание |
| :- | :- |
| [NATIVE](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/native/) | Текстовая подпись как объект нативного текста на странице документа. |
| [IMAGE](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/image/) | Текстовая подпись как объект изображения на странице документа. |
| [ANNOTATION](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/annotation/) | Текстовая подпись как объект текстовой аннотации на странице PDF. Аннотации видимы только в лицензированной версии. |
| [STICKER](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/sticker/) | Текстовая подпись как объект стикера на странице PDF. |
| [FORM_FIELD](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/form_field/) | Текстовая подпись как текст в указанном поле формы. При этом тип реализации может использовать только параметры TextSignOptions.Text, TextSignOptions.FormTextFieldType и TextSignOptions.FormTextFieldTitle. |
| [WATERMARK](/signature/python-net/groupdocs.signature.domain/textsignatureimplementation/watermark/) | Текстовая подпись как водяной знак на странице документа. |
