## DEFAULT_APPEARANCE field

Obtiene la apariencia predeterminada para el sticker. Estas propiedades se aplican por defecto si la propiedad Options.SignatureAppearance no está especificada. Las propiedades pueden ser cambiadas por el usuario en cualquier momento.
