Der Signaturtyp definiert die Methode zum Signieren.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [Unknown](#Unknown) | Zeigt einen Fehler an, unbekannter Signaturtyp. |
| [Text](#Text) | Die Textsignatur – fügt einen formatierten String in das Dokument ein. |
| [Image](#Image) | Die Bildsignatur – fügt ein Bild an der angegebenen Dokumentposition ein. |
| [Barcode](#Barcode) | Die Barcode‑Signatur – signiert das Dokument mit einem Barcode. |
| [QrCode](#QrCode) | Die QR‑Code‑Signatur – signiert das Dokument mit einem QR‑Code. |
| [Stamp](#Stamp) | Die Stempel‑Signatur – signiert das Dokument mit einem Stempel. |
| [Metadata](#Metadata) | Die Metadaten‑Signatur – fügt Metadaten‑Eigenschaften zum Dokument hinzu. |
| [FormField](#FormField) | Die Formularfeld‑Signatur – fügt Formularfeld‑Objekte zum Dokument hinzu. |
| [Digital](#Digital) | Die Digitale Signatur – Dokument mit digitalem Schlüssel signieren. |
