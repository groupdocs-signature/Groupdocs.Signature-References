## EMF field

Enhanced Windows Metafile（.emf）は、デバイスに依存しないグラフィック画像を表します。EMF のメタファイルは、任意の出力デバイスで解析後に保存された画像をレンダリングできる、時系列順の可変長レコードで構成されています。こちらでこのファイル形式の詳細をご覧ください。
