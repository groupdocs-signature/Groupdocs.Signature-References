## BarcodeSignOptions.ReturnContent property

Ruft das Flag ab oder setzt es, um den Barcode‑Bildinhalt einer Signatur zu erhalten, die auf einer Dokumentseite platziert wurde. Wenn dieses Flag auf true gesetzt ist, bleibt der Barcode‑Signatur‑Bildinhalt in Rohdaten im erforderlichen Format [`ReturnContentType`](../returncontenttype) erhalten. Standardmäßig ist diese Option deaktiviert.

public bool ReturnContent { get; set; }
