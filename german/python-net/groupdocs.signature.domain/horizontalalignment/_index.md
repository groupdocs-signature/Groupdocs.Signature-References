## HorizontalAlignment class

Der HorizontalAlignment-Typ stellt die folgenden Mitglieder bereit:

### Felder
| Feld | Beschreibung |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/horizontalalignment/none/) | Das Objekt ist explizit positioniert, normalerweise über seine Left-Eigenschaft. |
| [LEFT](/signature/python-net/groupdocs.signature.domain/horizontalalignment/left/) | Gibt an, dass das Objekt linksbündig zur horizontalen Ausrichtungsbasis ausgerichtet werden soll. |
| [CENTER](/signature/python-net/groupdocs.signature.domain/horizontalalignment/center/) | Gibt an, dass das Objekt relativ zur horizontalen Ausrichtungsbasis zentriert werden soll. |
| [RIGHT](/signature/python-net/groupdocs.signature.domain/horizontalalignment/right/) | Gibt an, dass das Objekt rechtsbündig zur horizontalen Ausrichtungsbasis ausgerichtet werden soll. |
