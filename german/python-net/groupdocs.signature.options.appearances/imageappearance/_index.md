## ImageAppearance class

Stellt erweiterte Erscheinungsmerkmale für eine Bildsignatur dar.

Der ImageAppearance-Typ stellt die folgenden Mitglieder bereit:

### Konstruktoren
| Konstruktor | Beschreibung |
| :- | :- |
| [__init__](/signature/python-net/groupdocs.signature.options.appearances/imageappearance/__init__/) | Initialisiert eine neue ImageAppearance-Instanz mit Standardwerten. |

| Eigenschaft | Beschreibung |
| :- | :- |
| [brightness](/signature/python-net/groupdocs.signature.options.appearances/imageappearance/brightness/) | Die Bildhelligkeit, wobei ein Standardwert von 1 der ursprünglichen Helligkeit des Bildes entspricht. |
| [contrast](/signature/python-net/groupdocs.signature.options.appearances/imageappearance/contrast/) | Der Bildkontrast. Der Standardwert ist 1, was dem ursprünglichen Kontrast des Bildes entspricht. |

| [grayscale](/signature/python-net/groupdocs.signature.options.appearances/imageappearance/grayscale/) | Das Graustufen-Flag; auf True setzen, um einen Graustufenfilter anzuwenden. |
