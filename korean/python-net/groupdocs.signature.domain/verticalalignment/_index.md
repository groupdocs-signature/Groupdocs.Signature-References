## VerticalAlignment class

VerticalAlignment 유형은 다음 멤버를 노출합니다:

### 필드
| 필드 | 설명 |
| :- | :- |
| [NONE](/signature/python-net/groupdocs.signature.domain/verticalalignment/none/) | 객체는 명시적으로 위치가 지정되며, 일반적으로 Top 속성을 사용합니다. |
| [TOP](/signature/python-net/groupdocs.signature.domain/verticalalignment/top/) | 객체가 수직 정렬 기준의 상단에 위치하도록 지정합니다. |
| [CENTER](/signature/python-net/groupdocs.signature.domain/verticalalignment/center/) | 객체가 수직 정렬 기준에 대해 가운데에 위치하도록 지정합니다. |
| [BOTTOM](/signature/python-net/groupdocs.signature.domain/verticalalignment/bottom/) | 객체가 수직 정렬 기준의 하단에 위치하도록 지정합니다. |
