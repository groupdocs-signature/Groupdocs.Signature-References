## return_content property

Das Flag, das bestimmt, ob QR‑Code‑Bildinhalt für jede Signatur auf einer Dokumentenseite zurückgegeben wird. Wenn es auf True gesetzt ist, werden die Rohbilddaten in der `content`‑Eigenschaft der Signatur im durch `return_content_type` angegebenen Format gespeichert. Standardmäßig deaktiviert.
