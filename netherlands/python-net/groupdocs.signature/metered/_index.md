## Metered class

Beheert meter- (pay-per-use) licenties.

Metered-licenties factureren op basis van daadwerkelijk verbruik (meestal pagina's of
verwerkte documenten). Stel het public/private-sleutelpaar één keer in bij
applicatiestart; de wrapper rapporteert het gebruik terug naar de GroupDocs
licentieserver op de achtergrond.

Het type Metered exposeert de volgende leden:

| Methode | Beschrijving |
| :- | :- |
| [get_consumption_credit](/signature/python-net/groupdocs.signature/metered/get_consumption_credit/) | Retourneer het aantal verbruikte credits tot nu toe. |
| [get_consumption_quantity](/signature/python-net/groupdocs.signature/metered/get_consumption_quantity/) | Retourneer de hoeveelheid verwerkte data tot nu toe. |
| [set_metered_key](/signature/python-net/groupdocs.signature/metered/set_metered_key/#public_key-private_key) | Activeer meterbilling met het opgegeven public/private-sleutelpaar. |
