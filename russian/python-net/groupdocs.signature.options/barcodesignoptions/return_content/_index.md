## return_content property

Флаг, указывающий, следует ли получать содержимое изображения штрихкода подписи, размещённой на странице документа.

Когда установлено в True, содержимое изображения подписи штрих‑кода сохраняется как необработанные данные изображения в формате, указанном параметром `return_content_type`. По умолчанию эта опция отключена (False).
