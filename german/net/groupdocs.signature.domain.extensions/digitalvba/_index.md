## DigitalVBA class

Stellt eine digitale Signatur für VBA-Projekte von Tabellenkalkulationen dar. Sie ermöglicht das Signieren von VBA-Projekten in bestimmten Tabellenkalkulations-Dokumentformaten wie Xlsm oder Xltm. Wenn mehrere DigitalVBA-Erweiterungen zu DigitalSignOptions.Extensions hinzugefügt werden, ist nur die erste an der Dokumentensignatur beteiligt.

public class DigitalVBA : SignatureExtension
