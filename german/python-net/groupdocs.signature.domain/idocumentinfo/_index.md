## IDocumentInfo class

Die Eigenschaften der Dokumentbeschreibung.

Der IDocumentInfo Typ stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [barcode_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/barcode_signatures/) | Die Sammlung von Dokument‑Barcode‑Signaturen, die durch [`Signature`](/signature/python-net/groupdocs.signature/signature/)‑Methoden hinzugefügt oder aktualisiert wurden. |
| [digital_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/digital_signatures/) | Die Sammlung von Dokument‑Digital‑Signaturen, die durch [`Signature`](/signature/python-net/groupdocs.signature/signature/)‑Methoden hinzugefügt oder aktualisiert wurden. |
| [documents](/signature/python-net/groupdocs.signature.domain/idocumentinfo/documents/) | Die Sammlung aller vorhandenen Dokumente innerhalb der Archivdateien. Diese Eigenschaft wird nur für Archiv-Dokumenttypen unterstützt. |
| [file_type](/signature/python-net/groupdocs.signature.domain/idocumentinfo/file_type/) | Der Dateiformattyp. |
| [form_field_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/form_field_signatures/) | Die Sammlung von Dokument‑Formularfeld‑Signaturen, die durch [`Signature`](/signature/python-net/groupdocs.signature/signature/)‑Methoden hinzugefügt oder aktualisiert wurden. |
| [form_fields](/signature/python-net/groupdocs.signature.domain/idocumentinfo/form_fields/) | Die Sammlung aller vorhandenen unterstützten Formularfelder im Dokument. Diese Eigenschaft wird nur für PDF‑ und Textverarbeitungs‑Dokumenttypen unterstützt. |
| [image_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/image_signatures/) | Die Sammlung von Dokument‑Bild‑Signaturen, die durch [`Signature`](/signature/python-net/groupdocs.signature/signature/)‑Methoden hinzugefügt oder aktualisiert wurden. |
| [max_page_height](/signature/python-net/groupdocs.signature.domain/idocumentinfo/max_page_height/) | Die maximale Seitenhöhe. |
| [metadata_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/metadata_signatures/) | Die Sammlung von Dokument‑Metadaten‑Signaturen. |
| [page_count](/signature/python-net/groupdocs.signature.domain/idocumentinfo/page_count/) | Die Anzahl der Dokumentseiten. |
| [pages](/signature/python-net/groupdocs.signature.domain/idocumentinfo/pages/) | Die Sammlung von Beschreibungen der Dokumentseiten. |
| [process_logs](/signature/python-net/groupdocs.signature.domain/idocumentinfo/process_logs/) | Die Sammlung von Prozessprotokollen der Dokumenthistorie. |
| [qr_code_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/qr_code_signatures/) | Die Sammlung von QR-Code‑Signaturen des Dokuments, die durch Methoden von [`Signature`](/signature/python-net/groupdocs.signature/signature/) hinzugefügt oder aktualisiert wurden. |
| [signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/signatures/) | Die Sammlung aller im Dokument vorhandenen Signaturtypen als [`BaseSignature`](/signature/python-net/groupdocs.signature.domain/basesignature/) Objekte. |
| [size](/signature/python-net/groupdocs.signature.domain/idocumentinfo/size/) | Die Dokumentgröße in Bytes. |
| [text_signatures](/signature/python-net/groupdocs.signature.domain/idocumentinfo/text_signatures/) | Die Sammlung von Textsignaturen des Dokuments, die durch Methoden von [`Signature`](/signature/python-net/groupdocs.signature/signature/) hinzugefügt oder aktualisiert wurden. |
| [width_for_max_height](/signature/python-net/groupdocs.signature.domain/idocumentinfo/width_for_max_height/) | Die Breite für die maximale Seitenhöhe. |
